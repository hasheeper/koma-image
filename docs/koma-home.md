# HOME 工作区

更新：2026-10-29。本文维护首页当前的数据、界面与 ASK 契约。HD／HM1–HM3 已完成本地实现与相应核验，设计迭代及原章节编号保留在[历史规划](archive/2026-10-28-home-plan.md)，阶段证据见[历史索引](archive/README.md#home-与独立-edit)。本地实现不代表线上发布。

## 1. 定位与范围

HOME 是创作桌面，以「继续／进行中／定稿」回答上次做到哪里、还有哪些方案、哪些图已经定下。IMAGE、CHAT、EDIT 各自负责创作，TAGS 负责查词；首页从这些服务投影数据，不另建项目、图库或任务数据库。

默认打开 HOME；显式车间和设置深链保持原位置。首页没有车间顶栏或额度栏，头部使用现有品牌、真实目录状态、设置入口、共享 ASK 输入条及四个车间入口。连接、目录和模型状态来自现有服务，不写死名称、在线状态或演示计时器。

## 2. 数据与所有权

一条创作线对应一个 IMAGE 画板、一个有轮次的 CHAT 会话或一个本页 EDIT 画板。定稿就是普通收藏 `#f`，只由用户主动收藏；绑图任务不会自动增加收藏。Todo 仅通过已绑成果关联到创作线，未绑图任务留在原清单与总览。

| 数据 | 首页取法与生命周期 |
| --- | --- |
| IMAGE | 读取现有画板、全局普通历史与收藏；提交结果保留画板身份，首页不复制表单或历史 |
| CHAT | 读取本地会话与实际版本；收藏复制具体图片原字节，源会话删除后收藏独立存在 |
| EDIT | 投影本页画板及当前查看版本，直接使用原图 URL；刷新后清空，不建立持久编辑预览 |
| 展示副本 | 每 IMAGE 画板最多一张长边 1080px WebP，小图不放大；保存在 `koma-home/previews`，只供展示 |
| HOME 偏好 | `koma.home.v1` 保存封面指针、上次车间及行／列／拼图选择；未主动选布局时为 `null` |
| 来源链 | 从稳定画板、CHAT 会话／轮次／版本／资产及 `editId`／`editParent` 推导；不持久绑定易失的 `#h`／`#c` 编号 |

展示副本不进入 `#h`、ASK 图片编号、收藏、Slate 或普通 ZIP；不能下载、恢复参数或送去 EDIT／CHAT。IMAGE 刷新仍清空历史和画布，首页有预览不表示原图仍可读取。CHAT 收藏及 NAI 编辑配方的区别遵循[对话](chat-workspace.md)与[编辑](edit-workspace.md)。

新图覆盖同板旧展示副本，删除画板时清理；写入通过 `data.write` 和注册的 flush／reload，不占生成槽、不阻塞生成收尾。慢编码或另一标签页较旧的源图不能覆盖较新副本。替换、删除、销毁释放 Object URL；偏好用专用锁合并，当前页返回位置不随另一页切换。

## 3. 创作线的封面与排序

| 类型 | 封面优先级 |
| --- | --- |
| IMAGE | 有效收藏封面 → 本页匹配 `boardId` 的最新历史图（含该来源的 EDIT 结果）→ 展示副本 → 占位 |
| CHAT | 有效收藏封面 → 最新完成版本的图片 → 占位；新记录按 `completedAt`，旧记录按原版本顺序回落 |
| EDIT | 当前查看版本的原图 URL，无图片时占位 |

占位只用于「继续」大卡，使用 chrome 面板、细线与静止车间标记，不显示假图。其他没有图的线不进陈列；空画板、其他空会话和未绑图 Todo 仍从各自入口管理。

继续线优先使用上次车间的活动 EDIT 画板或当前 CHAT 会话，其余回到活动 IMAGE 画板；导航仍能恢复上次 TAGS 位置。其余有图线先按活动 Slate 已绑成果的 Todo 顺序，再按最近活动时间排列；CHAT 限最近六个有轮次会话。封面取消收藏或来源删除后退回下一优先级。

状态从真实服务读取：生成进度、待确认草稿、未执行蒙版、暂不应用的 Photopea 文档、CHAT 轮次或时间。普通历史计数与 EDIT 状态仅本页有效，不从展示副本补造历史。

## 4. 页面结构与样式

整体使用[设计语言](design-language.md)中的衬纸、字标、画框与 tokens；内容宽 `min(84%, 1080px)`，860px 及以下两侧各留 16px。卡片完整显示图片、不裁切，外层不叠加底色与边框。

| 区域 | 当前呈现 |
| --- | --- |
| 头部 | 常规宽屏字标、ASK 输入与车间入口居中；目录／设置胶囊在右上。常规 560px 及以下字标靠左、设置靠右。全空时品牌与欢迎区一起居中。品牌复用 Fredoka 字标与现有方块动画 |
| 车间入口 | 一行四枚 34px 描边胶囊：「新画板」「新对话」「精修图片」「查词」；窄屏等分，精修打开系统图片选择器后进入 EDIT |
| 继续 | 进行中领头大卡；脸与文字并列，画板／会话标题为主，关联任务仅显示小图标与单行标题，长标题省略、悬停可看全文，不展示内部 ID；最近几张图按可用宽度展示，无最近图时不留空段；40px 继续按钮按内容宽度左对齐 |
| 其他创作线 | 与大卡并排横向陈列，图片区完整展示，下方只留标题与必要状态；右缘保留 40px 渐隐，只有大卡时不加渐隐 |
| 窄屏 | 大卡按可用空间上下排列，继续按钮铺满文字栏；其他图另起横向滚动行，渐隐只作用于该行 |
| 任务 | 进行中区头显示活动 Slate 的名称和真实进度，点击打开既有轻量总览；没有活动 Slate 时不占位 |
| 定稿 | 收藏图片及三种布局选择；说明悬停／聚焦显示，触屏常显；无收藏时不留空区 |

本地展示副本、收藏和 CHAT 读取完成后，没有收藏、没有可显示图片且没有 CHAT 轮次时显示欢迎区；读取未完成或失败时不把未知数据当成空库。欢迎区与 ASK 同宽，五格交错图形为 80×80px，标题「这里还空着呢」，副句「有个想法？快去试试吧。」。卡片采用比衬底略亮一档的 `--chrome` 纯色表面，不加内部格纹；背景用以 ASK 输入条为中心、略高于其中线的极淡灰紫光，并铺静态细颗粒。桌面卡片高 176px，860px 及以下高 160px。

全空时，品牌、ASK、四个入口与欢迎区作为一组略高于视口中心；品牌桌面图形／字标为 44／40px，560px 及以下为 38／34px。目录／设置仍在右上角，四个入口在窄屏保持一行。出现真实图片、收藏或 CHAT 轮次后恢复原有内容布局，背景光改为从内容列页顶中央下落的顶光，随首屏滚走，细颗粒保留；输入条的光挂在其外层，不进入 HOME↔ASK 过渡快照。从其他工作区返回已有内容时不显示欢迎区。页面最底部居中一行页脚小字：GitHub 标志加 `hasheeper/koma-image`，在新标签页打开源码仓库；全空时贴在视口底部，有内容时跟在最后一组之后。打开 ASK 时使用原有头部与停靠布局；减少动态时直接切换。

只有一条线、没有定稿时，宽屏进行中区随头部居中。首页不常驻 Prompt、完整参数、教程或快捷键说明。

## 5. 入口与导航

- 空／未知路由规范化为 `#/home`，显式 `#/image`／`#/chat`／`#/edit`／`#/tags` 及设置、旧 backup 深链保留；旧 EDIT 覆盖层地址归到独立 EDIT。
- 车间 Logo 菜单按 HOME／IMAGE／CHAT／EDIT／TAGS 排列，底部保留设置，已移除任务总览。IMAGE 原任务图标、ASK Todo 和 HOME 的活动任务入口保留。
- `G` 往返 HOME 与上次车间；HOME 页面背景按回车继续。输入、组字、修饰键、模态框或高级编辑期间不触发导航快捷键。
- 点击继续或创作线定位真实画板／会话；本页 EDIT 可以继续，刷新后无编辑画板时回退到 IMAGE。历史缩略图进入舞台、收藏打开大图、CHAT 图片定位版本。
- HOME／IMAGE／CHAT／TAGS 使用上限 4 的 KeepAlive；EDIT 首次访问后原位隐藏保活，避免 iframe DOM 移动。切页暂停界面驱动，不中断应用级任务。

## 6. 定稿排列与操作

| 模式 | 当前规则 |
| --- | --- |
| 行对齐 `rows` | 标准等高行，目标高 220px、窄屏 140px；末行不强拉满 |
| 列对齐 `cols` | 标准等宽列，按比例放入最短列；目标列宽 230px、窄屏 160px，至少两列，不混入跨列拼图规则 |
| 拼图 `mosaic` | 大致水平对齐的完整行带，允许有限双图上下组合；按画幅分配面积，宽图获得相应面积，无行带内部空洞，不递归切成复杂网格 |

未选择时宽于 860px 默认行对齐，否则列对齐；明确选择后随宽度保持偏好。三种模式均不裁图，按收藏时间排列，不按来源另分库。

定稿大图复用原路径：读取绘图参数、送去 CHAT、送去 EDIT、绑入 Todo、设为创作线封面、取消收藏。CHAT 原词文／选项不伪装为绘图配方；缺少原图时不能拿展示副本执行这些动作。不增加多选和批量管理。

## 7. ASK 在 HOME

### 7.1 同一个 ASK

头部、停靠窗口与车间浮窗共享同一 ASK 服务、输入、模型、发送／停止、会话、草稿、收藏与撤销；不是另一个聊天产品。`ask/presentation.ts` 统一判断收起状态，Vue 模板与 Teleport 管节点所有权。

- 头部输入随页面滚动，宽不超过 720px、高 56px（860px 及以下 50px）；发送／停止 36px。发送后打开窗口；未发送内容在输入条与窗口间同步。HOME 不显示闲置圆形与浮动胶囊。
- 默认右侧半屏停靠：三边 12px、宽 `clamp(420px, 32vw, 480px)`、18px 圆角、chrome 实色；页面让出对应空间。全屏铺满视口、canvas 实色，阅读列沿用 760px，不用浮窗玻璃。
- 窄于 1280px 直接全屏并隐藏放大／还原；宽度恢复后使用本页选择。半屏／全屏只存本页，不写 HOME 偏好。全屏隐藏首页内容并锁滚动，还原恢复位置。
- 窗口打开时头部不重复输入框；半屏下收成字标、车间入口和设置一行，目录由窗口输入区承担。窗口不能拖动，离开 HOME 后恢复车间浮窗位置与形态；EDIT 继续使用同一 ASK；仅在 Photopea 打开时收起。
- 收起、Esc 和 ⌘J／Ctrl+J 回到输入条。打开窗口视为看过结果；窗口中完成后普通收起仍显示结果行，Esc 收起不显示；切换会话清理该行。

输入条下方只出现一行真实状态：运行中的动作与工具数、结果及摘要、待确认草稿，或纯任务应用后的「已写入」（3 秒消失）。待确认草稿点击后进入原窗口审阅，不在首页直接应用，也不提供关闭掩盖待审。

### 7.2 状态、草稿与附件

`workspace=home` 时保留活动 IMAGE 全文和现有 CHAT 状态，附创作线简表、可读取封面编号、状态、定稿数量及近期来源链；活动任务沿用 `active_slate`。不预载历史正文和图片像素，展示副本没有可读编号。提示词来源及版本见[提示词维护](ask/ask-prompts.md)。

IMAGE 草稿确认后切到 IMAGE，新板沿用既有确认行为；`chat_handoff` 切到 CHAT 新开会话并准备输入，不发送。纯 `slate_edit` 留在 HOME。步骤校验、冲突、写入及撤销仍由共享草稿服务承担。

图片／资料拖到输入条或 ASK 窗口进入附件托盘、打开窗口但不发送；图片拖到首页其他位置进入 EDIT，其他文件不处理。全空且 ASK 收起时，在页面背景粘贴 PNG／JPEG／WebP 也进入 EDIT；输入控件、ASK、弹窗和菜单中的粘贴保持原路径。展示副本不成为原图附件或拖出来源。手动文件始终用原生选择器、拖放或粘贴。

### 7.3 过渡与生命周期

输入条与窗口、半屏与全屏、状态行重排及同图进入车间使用原生 View Transitions。窗口几何沿用 520ms 曲线，文字不缩放；只对可见且同源的图建立共享过渡，其他内容淡出／出现。不支持或减少动态时直接更新。

过渡名与页面状态仅在本次过渡存在，结束、打断和离页均清理；更新回调等待 Vue 完成 DOM 更新，不等待截图暂停的动画帧。停用 HOME 时解除 Observer、监听和测量回调，不搬移 Vue 管理的 DOM，不从静态脚本复制模拟状态。

| 模块 | 责任 |
| --- | --- |
| `src/home/derive.ts`、`model.ts` | 纯身份／元数据投影、封面、排序和状态，不访问 Vue、网络或原图 Blob |

| `transition.ts`、`src/ask/presentation.ts` | 临时过渡与共享 ASK 呈现，不持有另一套会话 |

持续检查：四宽无溢出，原图与展示副本权限分开，刷新不复活历史／EDIT，封面失效回落，三种排列符合规则，ASK 在停靠／浮窗间保留内容，界面停用后不泄漏资源。HOME 的本地加载不触发模型目录、报价或额度请求。
