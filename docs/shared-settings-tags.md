# 设置、备份与词典

更新：2026-10-25。本文维护当前连接、凭据、备份与 Tag 规则；阶段过程见[归档](archive/2026-10-25/README.md)。

## 设置分组

连接、模型、通用、安全与备份、ASK 分组独立。Tag 自动补全、历史保留及数量使用绘图同一偏好，放在通用；关闭历史只留最新一张，0 表示不限制。设置即时保存、跨工作区可用，并同步其他标签页。

安全、备份、配置导入导出集中同页分组列表；`settings/backup` 为兼容入口。不重复大标题和说明，只保留基本信息与反馈。安全与备份无 Key 也可进入；需要凭据操作时显式解锁。

## 连接、目录与反馈

初始连接为空，填写连接名、URL 与 Key 后才访问上游。显式选择六种 Profile 中实际支持的协议，不按域名或名称推断。目录、额度和诊断使用只读请求，不提交生成。

连接采用已批准的摘要卡：头部显示名称、协议、地址、状态和测试；有账户额度时显示余额与额度池；模型数量打开模型列表。窄屏状态移到地址下方，测试只保留图标。完整地址和完整可用诊断通过提示查看，错误展示原因。

「⋯」菜单提供编辑连接、配置／解锁或更换 Key、删除。添加／编辑共用表单，只保存变化字段，地址下方说明 Key 接收对象；改协议清空该连接模型来源。不得把另一主机已保存的 Key 自动发送给 NovelAI 官方，需单独添加。删除前确认；Key 加密且锁定时先解锁，再一并移除 Key 与来源。

模型支持自动匹配、手动完整 ID、来源开关和恢复自动。多个连接提供同一规范图像模型时按连接顺序取第一个启用来源。OpenAI／Gemini 每次只读取一次目录，不按品牌前缀或额外能力字段筛掉 ID；未匹配 ID 供用户选择，不自动成为可执行模型。

启动时，有地址和可用 Key 自动读目录并显示进度及汇总结果；缺 Key 先填写／解锁，失败可手动测试。空配置只引导设置，不请求上游。连接／凭据改变重新反馈，迟到响应失效；改名和来源调整静默刷新。没有可用模型时的生成提示可打开设置。

本地模式使用固定服务端配置，连接与安全展示只读，不显示连接菜单或添加按钮；模型来源仍可编辑。运行时地址、Key 和令牌不持久化，两种模式分别保存来源。详见[发布说明](release-guide.md)。

## 凭据与安全

- Vault 保存每连接凭据；PBKDF2-SHA256 210000 次派生，AES-GCM 256 位加密，加密模式本地只写密文。
- 「不保存」使用 sessionStorage，加密模式的派生密钥也仅当前会话；刷新可恢复，页面间经 Koma 同步频道共享解锁，启动等待 200ms。
- 口令和 Key 输入使用原生 input 引用，CryptoKey 和凭据不进入深层 reactive；空输入不覆盖已有 Key，更换口令保留所有连接。
- 跨页锁定／清除先等待任务结束；迟到共享消息不能重新解锁，显式解锁仍同步其他页面。保留生成后锁定和原生 dialog 的焦点／Esc 语义。

## 普通备份


只接受 `app=koma-image`、`kind=backup`、`version=2` 的 ZIP。支持收藏原图及缩略图、对话与素材、逻辑偏好和不含 Key 的连接配置。

- 文件先通过 ZIP 结构、CRC、manifest 引用和素材 SHA-256 校验，才显示可导入预览；未校验对象不能导入。
- 使用原图字节，不重新编码。保留 ZIP32、条目数、目录、manifest 和单图片大小限制。
- 导入通过应用级独占数据租约，先排空写入并释放本页共享租约；其他标签页或进行中的任务会阻止导入。
- 对话与素材同事务写入；冲突创建副本，重映射轮次、版本和上下文引用。收藏按 ID 与原图哈希去重，冲突保留副本。同一备份重复导入不重复新增。
- 部分失败后恢复租约、刷新缓存；保留已校验文件供重试。偏好覆盖，Key 不覆盖。导入／导出过程中禁用页面导航，并拦截浏览器历史切页与离开提醒。
- 不导出 Key、派生密钥、普通历史、编辑会话及交接票据。没有旧数据检测、迁移、转换或对应 UI。

## 词典与描述控件

- 词典保持中文／英文搜索、默认分类、每页 25 条、分页、组合持久化、0.1–5 权重、复制和明确跳往公共词典的外链。候选数量以在线接口实际返回为准。
- 查询只在用户搜索或启用补全后输入时发送；保留公开 Tag 服务和英文查询的官方回退行为。生成业务不增加重试。
- 应用组合通过显式交接原地切换到绘图，确认后追加；30 分钟过期、只认领一次，保活激活不会重复插入。
- 页内选词面板直接插入／移除 Tag，保留未编辑文字；保留本次插入列表、方向键、IME、焦点返回和移动端布局。
- 高亮 `.hl-wrap`、镜像和 textarea 全部由 Vue 模板声明，纯算法生成经过转义的镜像内容；原生测量驱动只操作空测量宿主内部及明确委托的布局样式。
- 自动补全最多 20 条、280ms 防抖，支持 Enter／Tab／方向键；IME 使用实际 textarea 内容计算光标片段，关闭补全卸载监听，隐藏工作区中止查询和尺寸观察。
- 提示消息复用原图标、停留时间、重复合并和悬停暂停，通过 Teleport 进入当前弹窗，避免多个宿主重复计时。移动端侧栏仍使用已有 Teleport 宿主。

## ASK 设置与隔离

ASK 独立管理推理模型、命名模型、图片开关、个人偏好、自由创作、压缩阈值及附件上限，见[ASK 现行契约](ask/ask-implementation-plan.md)。配置可进入普通备份，独立自由创作开关不进入。

ASK 收藏会话、附件、记忆与归档保存在本机 `koma-ask`，刷新可续聊，不属于普通 ZIP；撤销执行栈和调用调试只留本页。普通绘图历史、编辑会话与交接票据仍为临时数据。
