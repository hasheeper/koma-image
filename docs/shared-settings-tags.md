# M3：公共界面、设置、Key、备份与词典

2026-10-19。本阶段已接入浏览器直连模式的设置、凭据与备份，完成词典和提示词公共控件。后续 M4–M6 已接入绘图、收藏、对话和编辑工作区，详见各阶段实施记录。实际页面复用原 7 份正式 CSS，没有重设计布局。

## 设置与凭据

- 初始连接为空；用户填写连接名、URL 和 Key 后才访问网关。连接头像采用本地默认头像。
- 地址编辑、连接诊断、余额及模型列表、规范模型自动匹配、手动指定 ID、来源开关、恢复自动匹配和设置文件导入导出均接入。配置即时保存并同步其他标签页。
- 设置只用 GET 请求查询模型和额度，测试使用模拟服务，不执行收费生成。
- Vault 保存各连接凭据表，PBKDF2-SHA256 210000 次派生，AES-GCM 256 位加密；本地仅写密文。口令与 Key 输入使用原生 input 引用，CryptoKey 和凭据服务不进入 Vue 深层响应式状态。
- 「不保存」使用 sessionStorage；加密模式的派生密钥也仅在当前会话保存。刷新可恢复，会话之间通过 Koma 同步频道共享解锁状态，启动等待 200ms。
- 所有标签页一起锁定／清除，先等待正在运行的任务结束。迟到的共享消息不能撤销锁定，之后主动解锁仍同步到其他页面。更换口令保留所有连接 Key；空输入不覆盖已有 Key。
- 未解锁时仍可进入备份子页。锁定、解锁和确认框沿用原生 dialog 的焦点与 Escape 语义。

启动时，已保存连接且 Key 可用会自动读取模型目录，沿用现有请求显示「正在连接」并替换为成功或失败结果；多个连接汇总反馈，缺少 Key 或部分失败可直接进入设置。没有连接时自动打开「设置／连接」，关闭后本次页面内切换工作区不再弹出；直接访问设置或编辑入口时保留原入口。已保存地址但没有可用 Key 时先填写或解锁，完成后自动连接；安全与备份入口继续无需 Key。连接地址、协议或凭据改变时重新反馈，改名及模型来源调整静默刷新。手动「测试连接」同样显示进度与结果。空配置不请求上游，连接检查不提交生成。

启动反馈使用模拟网关补充 6 项浏览器检查：空配置引导、会话恢复连接、失败后手动重测、缺失 Key 与多连接汇总、加密解锁后连接，以及变更地址后忽略过期结果。设置状态查询等待弹窗打开后再执行，避免首次打开停在「未检查」。

M3 当时验证的是浏览器直连；本地服务持有 Key 时的只读连接／安全展示已在 [M7](release-acceptance.md) 接入并验收，`.env.example` 已用于实际本地服务。两种模式分别保存模型来源，本地运行时连接不写入备份。

### M7 后的设置整理

按用户后续要求，导航统一为「连接／模型／通用／安全与备份」。绘图面板的设置抽屉移除；Tag 自动补全、保留历史及数量限制移至通用，继续调用同一绘图偏好服务，即改即存、跨工作区可用，关闭历史只留最新一张，0 仍表示不限制。

安全、备份和配置导入导出使用同一页的分组列表，备份不再使用独立页面的大卡片和多层标题；删去冗长说明，仅显示数量、动作及状态反馈。`settings/backup` 保留为同页兼容入口。锁定后当前页仍可导出备份，需要凭据操作时再点解锁。

填充型 SVG 在 sprite 定义中显式声明 `fill="currentColor"`、`stroke="none"`，避免模型、齿轮等图标继承通用线框图标的空填充。其余线框图标维持原样。

本次类型／构建、42 项单元及 11 项相关浏览器检查通过，包括偏好开关即时生效、历史数量恢复与持久化、合页的无 Key 备份、锁定后显式解锁、旧路由和四视口；修正后的图标与布局截图见忽略提交的 `.local/settings-polish/`。

### P3.0 连接管理

2026-10-19，为接入公开官方协议做准备，补齐连接管理：

- 连接标题行可改名、删除；本地服务模式不显示这两个按钮。名称过长时截断，按钮与下方各行对齐。
- 删除前确认，同时删除这个连接的 Key 和模型来源，其他打开的页面同步。Key 已加密且锁定时，先提示解锁，不留下无主的密文条目。
- 同一规范模型由多个连接提供时，按连接排列顺序（即添加先后）取第一个启用的来源；要换来源，关闭前一个连接上的该来源。
- 绘图没有可用模型时，按快捷键生成弹出的提示带「设置」，直接打开「连接」一节。
- 设置跨页同步只靠 `storage` 事件，删除了没有发送方的频道监听。
- 连接诊断的单元测试覆盖：可用、401／403、404、非 JSON、429、5xx、协议不符（含版本过低）、超时、跨域拦截、网络不可达、本地代理令牌，以及请求期间连接改变。

`npm run check`（47 项单元）和 7 组浏览器测试（共 36 项）通过。新增的浏览器检查覆盖改名、取消改名、删除及 Key 清理（解密核对 vault 表）、锁定时删除先解锁，以及无连接时提示的「设置」动作。

### 连接摘要卡（2026-10-21）

用户从三个方案中选定 A「摘要卡」，取代上文 P3.0 的标题行按钮和逐行表单：

- 每个连接一张卡，分三层：头部；有余额时显示积分／Anlas 与各额度池，有上限的额度带细进度条；最后一行是模型数量，点击打开模型列表。接口不提供余额时不显示用量层。
- 头部左侧两行：半粗体名称旁带协议标签，下一行只放灰色地址（省略 https，完整地址在悬停提示）。右侧是状态、「测试」按钮和 ⋯ 菜单；可用时只显示「可用」，完整诊断文字在悬停提示，出错时整句红字显示。窄屏（≤640px）状态移到地址下方，「测试」只留图标。
- ⋯ 菜单为编辑连接…／更换 Key…（未解锁时为「配置或解锁 Key…」，Key 可读时在右侧显示前 3 位与后 4 位）／删除连接。名称、协议和地址在与「添加连接」共用的连接表单中修改，只保存有变化的字段；改协议照旧清空该连接的模型来源，改成 NovelAI 官方仍须单独添加连接，并在表单内提示。Esc 只关闭表单或菜单，不关闭设置页。
- 卡片上移除「Key 会发送到…」提示、每行的标签列、常驻的协议下拉、逐行铅笔按钮、「不保存」标记（它属于全局安全模式）和小节说明；本地服务模式保留说明，不显示菜单与添加按钮。添加或编辑表单仍在地址下方用灰字提示 Key 的发送对象。
- 空状态改用卡片同款外框，修正原分组规则下底部圆角缺失的问题。删除确认、锁定时先解锁、诊断文字和查询请求不变。
- `npm run check`（66 项单元测试、样式、类型、构建）与全部浏览器／发布包 56 项测试通过。320／390／768／1440px 检查卡片、菜单、编辑表单和空状态：无横向溢出，菜单在视口内，控制台无错误；截图在忽略提交的 `.local/conn/`。

## 普通备份

只接受 `app=koma-image`、`kind=backup`、`version=2` 的 ZIP。支持收藏原图及缩略图、对话与素材、逻辑偏好和不含 Key 的连接配置。

- 文件先通过 ZIP 结构、CRC、manifest 引用和素材 SHA-256 校验，才显示可导入预览；未校验对象不能导入。
- 使用原图字节，不重新编码。保留 ZIP32、条目数、目录、manifest 和单图片大小限制。
- 导入通过 M2 独占数据租约，先排空写入并释放本页共享租约；其他标签页或进行中的任务会阻止导入。
- 对话与素材同事务写入；冲突创建副本，重映射轮次、版本和上下文引用。收藏按 ID 与原图哈希去重，冲突保留副本。同一备份重复导入不重复新增。
- 部分失败后恢复租约、刷新缓存；保留已校验文件供重试。偏好覆盖，Key 不覆盖。导入／导出过程中禁用页面导航，并拦截浏览器历史切页与离开提醒。
- 不导出 Key、派生密钥、普通历史、编辑会话及交接票据。没有旧数据检测、迁移、转换或对应 UI。

## 词典与描述控件

- 词典保持中文／英文搜索、默认分类、每页 25 条、分页、组合持久化、0.1–5 权重、复制和明确跳往公共词典的外链。候选数量以在线接口实际返回为准。
- 查询只在用户搜索或启用补全后输入时发送；保留公开 Tag 服务和英文查询的官方回退行为。生成业务不增加重试。
- 应用组合通过显式交接原地切换到绘图，确认后追加；30 分钟过期、只认领一次，保活激活不会重复插入。
- 页内选词面板直接插入／移除 Tag，保留未编辑文字；保留本次插入列表、方向键、IME、焦点返回和移动端布局。
- 高亮 `.hl-wrap`、镜像和 textarea 全部由 Vue 模板声明，纯算法生成经过转义的镜像内容；原生测量驱动只操作空测量宿主内部及明确委托的布局样式。
- 自动补全最多 20 条、280ms 防抖，支持 Enter／Tab／方向键；IME 使用实际 textarea 内容计算光标片段，关闭补全卸载监听，隐藏工作区中止查询和尺寸观察。
- 提示消息复用原图标、停留时间、重复合并和悬停暂停，通过 Teleport 进入当前弹窗，避免多个宿主重复计时。移动端侧栏仍使用已有 Teleport 宿主。

2026-10-20 修复 Tag 接口：原先补全、查词和词典调用的 `/api/tags` 实际返回 404，且没有跨域响应头，浏览器因此报通用网络错误。按在线服务的公开接口定义改用 `/api/tags/suggest`，只发送 `q`；当前接口最多返回 30 个候选，不支持服务端 `limit/offset`。三个入口共享候选缓存，词典按该结果每页 25 条切分，不伪造后续页或重复显示同一批词。英文官方回退保留，中文不回退到只支持英文的接口；每个来源限制 8 秒，取消不重试，网络／超时／异常响应有对应反馈。测试服务严格匹配接口路径，并覆盖分页尾页、缓存共用与取消。
