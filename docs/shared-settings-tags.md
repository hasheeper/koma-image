# 设置、备份与词典

更新：2026-10-28。本文维护当前连接、凭据、备份与 Tag 规则；阶段过程见[归档](archive/2026-10-25/README.md)。

## 设置分组

连接、模型、通用、安全与备份、ASK 分组独立。Tag 自动补全、历史保留及数量使用绘图同一偏好，放在通用；关闭历史只留最新一张，0 表示不限制。设置即时保存、跨工作区可用，并同步其他标签页。

安全、备份、配置导入导出集中同页分组列表；`settings/backup` 为兼容入口。不重复大标题和说明，只保留基本信息与反馈。安全与备份无 Key 也可进入；需要凭据操作时显式解锁。

## 连接、目录与反馈

初始连接为空，填写连接名、URL 与 Key 后才访问上游。显式选择六种 Profile 中实际支持的协议，不按域名或名称推断。目录、额度和诊断使用只读请求，不提交生成。

连接采用已批准的摘要卡：头部显示名称、协议、地址、状态和测试；有账户额度时显示余额与额度池；模型数量打开模型列表。窄屏状态移到地址下方，测试只保留图标。完整地址和完整可用诊断通过提示查看，错误展示原因。

连接页分为「图像」和「文本」两区，按实际配置的协议能力分别列出，不按供应商名称或域名猜测。综合供应商的图像、推理接口可以同时出现在对应分区；两区独立筛选，不强行归到唯一类别。仅图像区提供优先级排序，文本区保持原添加顺序和 ASK 手动选模，不参与自动余额分流。

连接图标统一用于卡片、模型列表标题和模型来源：NovelAI 官方 Profile 使用已有品牌 Logo；Google AI Studio／GCP Vertex AI、OpenAI 官方／Azure OpenAI 按明确的官方地址使用对应 Google/Gemini 或 OpenAI Logo。其余连接按 Profile 能力分为文本对话图标与生图图片图标，空列表使用中性连接图标。图标复用本地 SVG，不请求远程头像。

官方图标地址在 `domain/connection-icon.ts` 维护：Google AI Studio 为 `generativelanguage.googleapis.com`；Vertex 为 `aiplatform.googleapis.com`、区域 `*-aiplatform.googleapis.com` 与 `*.prediction.vertexai.goog`；OpenAI 为 `api.openai.com`；Azure OpenAI 为 `*.openai.azure.com`，以及 `*.services.ai.azure.com` 的 `/openai` 路径。只接受 HTTPS 官方主机边界，连接名、兼容协议名和转发路径不用于冒认品牌。此匹配仅选择图标，不改变协议、请求地址、鉴权、模型能力或默认连接。

NovelAI 官方的账户与图片请求统一发送到 `image.novelai.net`。有效账户响应即显示「Key 有效」，完整状态另行标明订阅是否激活；未订阅或零余额不会被当作 Key 无效。启动连接失败保留具体原因；403 与 Cloudflare 拦截不再笼统归为鉴权失败。真实生成权限及扣费由官方决定，不用账户识别结果承诺免费或可生成。

官方 NAI 连接卡将 Anlas 与 V5 额度分开：保留接口百分比与进度条，正值加购百分比单列；已激活 Opus 且用量可用时，百分比右侧同一行显示「约 X 张」，不增加卡片高度，提示注明官方 23 步、约 1MP 的换算基准。额度暂不可用和缺失数据分别展示，不显示恢复时间注释。未订阅或非 Opus 账号返回用量不等于拥有对应权益，也不展示可用张数。打开设置与测试成功后刷新，详见[官方额度规则](novelai-official.md)。

「⋯」菜单提供编辑连接、配置／解锁或更换 Key、删除。添加／编辑共用表单，只保存变化字段，地址下方说明 Key 接收对象；改协议清空该连接模型来源。不得把另一主机已保存的 Key 自动发送给 NovelAI 官方，需单独添加。删除前确认；Key 加密且锁定时先解锁，再一并移除 Key 与来源。

模型支持自动匹配、手动完整 ID、来源开关和恢复自动。「可用」表示已启用的模型来源；卡底行左侧聚合模型入口与辅助计数，全部启用时显示「X 个可用」，部分启用时显示「可用数／总数 可用」，完整数量保留在读屏描述中。右侧平铺「优先级」编号与上下箭头，不增加外框或下方说明；数字越小越优先。排序不会关闭其他来源；模型页列出来源顺序，并标明当前工作区实际使用的来源。模型列表可分别筛选可用、优先来源与未启用。

排序、改名、来源开关和 ID 映射即时更新本地配置，保留目录列表、搜索、展开状态和当前操作节点，不先清空整页数据。原始目录按连接地址、协议与凭据版本复用，规范模型按新配置重新映射；地址、协议、Key 改变只使对应连接的目录和余额失效，锁定／删除也清除对应缓存。模型列表的「重新拉取」和连接测试只刷新该连接；设置分区之间切换不重复拉取已加载目录。文本连接的编辑不触发图像工作区目录重载。生成前的报价、额度和上下文有效性检查保持独立，不能使用目录缓存绕过。

顺序保存在非秘密的 `Routing.order`，经数据租约即时保存、跨标签同步并进入配置及普通备份；新连接追加到末尾，删除连接从顺序中移除。本地固定连接不提供排序编辑。绘图／CHAT／编辑按当前模型和操作筛选来源：停用、缺 Key、没有该模型或不支持原参数／工具的连接不参与；其余从上到下检查。标准网关按本次报价与积分余额判断；NAI 仅在明确无订阅且无余额，或 V5 暂不可用、加购为零且 Anlas 为零时判为不足。不将估算张数当报价，不用 V5 用量推导 V4.5 权益；日请求额度用尽的标准网关来源判为不足。余额接口缺失或读取失败视为未知，仍按排序使用；目录、鉴权或报价错误不冒充余额不足。提交后失败、取消及响应处理错误不换源重试。

报价预览与执行均从高优先级重新检查，额度恢复后重新优先使用前面的来源；执行使用新报价和对应 `max_cost`。来源变化使旧报价与额度失效；顶栏按当前模型显示品牌 Logo、实际来源的额度与余额，提示包含来源名称。官方 V5 同行显示百分比、张数估算和独立 Anlas；V4.5 只展示 Anlas，不增加下方注释。NAI 官方不支持的重绘／放大仍可由后面的可用来源执行，保留原参数，不压缩画布或删减附件以迁就来源。

OpenAI／Gemini 每次只读取一次目录，不按品牌前缀或额外能力字段筛掉 ID；未匹配 ID 供用户选择，不自动成为可执行模型。

启动时，有地址和可用 Key 自动读目录并显示进度及汇总结果；缺 Key 先填写／解锁，失败可手动测试。空配置只引导设置，不请求上游。连接／凭据改变重新反馈，迟到响应失效；改名和来源调整静默更新，排序不重新播报连接进度。没有可用模型时的生成提示可打开设置。

本地模式使用固定服务端配置，连接与安全展示只读，不显示连接菜单或添加按钮；模型来源仍可编辑。运行时地址、Key 和令牌不持久化，两种模式分别保存来源。详见[发布说明](release-guide.md)。

## 凭据与安全

- Vault 保存每连接凭据；PBKDF2-SHA256 210000 次派生，AES-GCM 256 位加密，加密模式本地只写密文。
- 「不保存」使用 sessionStorage，加密模式的派生密钥也仅当前会话；刷新可恢复，页面间经 Koma 同步频道共享解锁，启动等待 200ms。
- 口令和 Key 输入使用原生 input 引用，CryptoKey 和凭据不进入深层 reactive；空输入不覆盖已有 Key，更换口令保留所有连接。
- 跨页锁定／清除先等待任务结束；迟到共享消息不能重新解锁，显式解锁仍同步其他页面。保留生成后锁定和原生 dialog 的焦点／Esc 语义。

## 普通备份


只接受 `app=koma-image`、`kind=backup`、`version=2` 的 ZIP。支持收藏原图及缩略图、对话与素材、逻辑偏好和不含 Key 的连接配置；NAI 参考原图与 Vibe 编码缓存一并保存，导入后恢复引用。

- 文件先通过 ZIP 结构、CRC、manifest 引用和素材 SHA-256 校验，才显示可导入预览；未校验对象不能导入。
- 使用原图字节，不重新编码。保留 ZIP32、条目数、目录、manifest 和单图片大小限制。
- 导入通过应用级独占数据租约，先排空写入并释放本页共享租约；其他标签页或进行中的任务会阻止导入。
- 对话与素材同事务写入；冲突创建副本，重映射轮次、版本和上下文引用。收藏按 ID 与原图哈希去重，冲突保留副本。同一备份重复导入不重复新增。
- 部分失败后恢复租约、刷新缓存；保留已校验文件供重试。偏好覆盖，Key 不覆盖。导入／导出过程中禁用页面导航，并拦截浏览器历史切页与离开提醒。
- 不导出 Key、派生密钥、普通历史、EDIT 画板／版本／蒙版与 Photopea 分层、交接票据、HOME 展示副本与偏好、ASK 收藏、Slate 任务／成果及 Bridge 目录状态。没有旧数据检测、迁移、转换或对应 UI。

## 词典与描述控件

- 词典保持中文／英文搜索、默认分类、每页 25 条、分页、组合持久化、0.1–5 权重、复制和明确跳往公共词典的外链。候选数量以在线接口实际返回为准。
- 绘图的基础／角色补全和页内查词面板随 Anime／Furry 模式切换。Furry 使用公开 NAI Furry 英文词库，不携带 Key，不混用动漫分类或回退；缓存按数据集隔离，切换立即取消旧请求并清除候选。完整词典与其他工作区保持原行为，详见[模式规则](novelai-official.md#animefurry-模式)。
- 查询只在用户搜索或启用补全后输入时发送；保留公开 Tag 服务和英文查询的官方回退行为。生成业务不增加重试。
- 应用组合通过显式交接原地切换到绘图，确认后追加；30 分钟过期、只认领一次，保活激活不会重复插入。
- 页内选词面板直接插入／移除 Tag，保留未编辑文字；保留本次插入列表、方向键、IME、焦点返回和移动端布局。
- 高亮 `.hl-wrap`、镜像和 textarea 全部由 Vue 模板声明，纯算法生成经过转义的镜像内容；原生测量驱动只操作空测量宿主内部及明确委托的布局样式。
- 自动补全最多 20 条、280ms 防抖，支持 Enter／Tab／方向键；IME 使用实际 textarea 内容计算光标片段，关闭补全卸载监听，隐藏工作区中止查询和尺寸观察。
- 提示消息复用原图标、停留时间、重复合并和悬停暂停，通过 Teleport 进入当前弹窗，避免多个宿主重复计时。移动端侧栏仍使用已有 Teleport 宿主。

Tag 查询使用公开 `/api/tags/suggest`，只发送 `q`；每个来源上限 8 秒，候选缓存共享，词典按实际结果每页 25 条切分，不伪造分页。英文保留官方备用源，中文不回退到仅英文接口。错误区分未命中、网络／超时／取消、JSON 格式与备用源失败原因；不把响应体读取失败误报成格式错误，不改变既有回退顺序或增加生成重试。

## ASK 设置与隔离

ASK 独立管理推理模型、命名模型、图片开关、个人偏好、自由创作、压缩阈值及附件上限，见[ASK 现行契约](ask/ask-implementation-plan.md)。配置可进入普通备份，独立自由创作开关不进入。

ASK 收藏会话、附件、记忆与归档保存在本机 `koma-ask`，刷新可续聊，不属于普通 ZIP；撤销执行栈和调用调试只留本页。普通绘图历史和 EDIT 编辑现场仅留本页，交接票据为有过期时间的一次性数据；Slate 的任务与成果独立持久保存。
