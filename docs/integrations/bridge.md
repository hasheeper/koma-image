# 外部协同与本地任务

更新：2026-10-28。本文维护目录、共享草稿、资料与默认本地 Todo 的当前契约。B1–B3 的阶段要求与本地／实战验收统一见[历史索引](../archive/README.md#外部协同与任务)。macOS Edge 已完成一次原生目录、刷新恢复和外部协作实测；其他浏览器、撤权恢复与跨进程并发仍待验证。

## 使用入口

在 **HOME 头部**或 **Koma ASK 输入框的附件「＋」旁**点击目录标签挂载协同目录；挂载后只显示目录名，点击可切换或卸载。**现有「设置 → ASK → 外部协同」页面分组**提供目录管理、导入草稿 JSON、导出工作台状态与导出协议，不另设 ASK 设置弹窗。右上角更多菜单仅保留「压缩上下文」「调用调试」。建议使用专用 `.koma-bridge/` 文件夹，实际名称不影响识别。目录同步使用浏览器 File System Access API；不支持此 API 时仍可手动导入和下载 JSON。

外部 Agent 操作指南由 [SKILL.md](../../public/skills/koma-bridge/SKILL.md) 维护，构建后可从站点的 `/skills/koma-bridge/SKILL.md` 直接 GET 读取，无需先下载或安装技能。Pages 响应头将它作为 UTF-8 纯文本内联展示，本地 Node 服务同样按纯文本提供；发布前须检查生产地址是否已包含该版本。公开指南不包含用户状态、图片、Key 或目录句柄，也不授予远程 Agent 本机目录访问权；实际字段继续以挂载目录内 `PROTOCOL.md` 为准。

无需配置 ASK 文本推理 Key。外部 Agent 提供建议，Koma 负责审阅、确认写入与撤销；内置 ASK 推理仍需用户配置文本连接。协同收件、状态导出及草稿应用均不触发生图、报价、参考编码、扣费、文本推理或 CHAT 发送。

挂载时创建或更新 `PROTOCOL.md`、`state.live.json` 及需要的 `live/*.webp`，并受限扫描 `refs/` 的文件名和大小。不改写 `draft.inbox.json`，不扫描整个工程。挂载自动映射当前活动任务板与其中已绑成果；挂载期间手动新建或经草稿确认创建的活动任务板也自动加入，其他已有任务板在任务总览的更多菜单显式加入。不导出整库历史／收藏。目录选择意味着授权写出这些状态、预览与已选绑图；更改提示词后，前台同步会更新状态。

## 文件与同步

| 文件 | 当前责任 |
| --- | --- |
| `PROTOCOL.md` | Koma 生成的操作说明、示例和实际共享草稿 Schema |
| `state.live.json` | Koma 写出当前 IMAGE 状态、图片参数、轻量索引及最后一份收件回执 |
| `draft.inbox.json` | 外部写入一份完整草稿；Koma 只读 |
| `live/*.webp` | 当前选择图与最近三张历史的去重预览，最多四张、最长边 768px |
| `slates/*.slate.json` | 任务文件，外部修改转为草稿审阅；本机确认后同步 |
| `assets/` | 已映射任务中选定的原图、同名 `.json` 生成回执和 `.txt` 标注 |
| `refs/` | 共享文本／图片的元数据清单；ASK 工具调用才读内容；确认文件草稿后写入配方／备忘录／任务交接资料 |

表单与回执变化约 300ms 防抖；前台约每 1.5s 检查收件，聚焦或恢复可见时立即同步。隐藏时停止轮询读写。图片未变化时不重新编码、覆写 WebP；先写新预览，再提交 JSON，成功后清理旧预览。仅清理本机登记为 Koma 所有的文件，不依赖外部可编辑 JSON 判断文件归属。

同源页面通过专用 Web Lock 保证同一目录只有一个同步写入者；另一个页面显示占用，释放后可手动重新连接。挂载上下文中的手动导入也检查该锁，不绕过另一个页面的收件保护；可在占用页面导入，或卸载后使用独立的本页手动入口。跨网站、不同应用或外部进程不共享此保证，应保持一个 Koma 写入者。

挂载句柄保存于本机；重开时先检查权限，不自动弹授权。权限不足时目录标签提示恢复，设置中也可恢复连接，读写失败暂停该挂载并保留手动入口。卸载停止同步、释放锁及缓存，保留目录已有文件和 ASK 草稿记录。数据维护期间暂停目录驱动，完成后恢复。

## 导出的状态

`schema` 固定为 `koma.bridge.live.v1`。`scope_id` 标记当前页面，`picture_scope_id` 标记当前 ASK 图片编号作用域；`active_workspace` 反映实际工作区，在 HOME／CHAT／EDIT／TAGS 页面也仅导出 IMAGE 活动画板，不将 EDIT 画板作为外部写入目标。

- `boards`、`active_board_id` 和 `form` 来自同一实时快照，沿用 DrawingBoard／DrawingForm：包括 `cfgRescale`、模式、复杂度、预设、透明底、带稳定 ID／坐标／启停的角色与参考配置。Effort 沿用模型 ID。
- `selected_image`、`recent_history` 保存真实记录 ID、编号、尺寸和该图已有的参数。区分 `basePrompt`／`baseNegative` 与实际请求词文，不用当前表单补造旧图参数。
- `history_index`、`favorites_index` 列出当前 `#h`／`#f` 可用目录，每项仅编号、宽高、可用 Seed 和最多 160 个字符的 Prompt 摘录；不额外编码图片。
- `base_hash` 由现有草稿状态哈希生成，外部只需原样带回。`updated_at` 与递增 `revision` 不参与哈希。
- `last_inbox_receipt` 是最后一份可关联投递的结果，初始为空。
- `active_slate` 为活动任务板的 ID／标题／版本、配方概况与锁定状态、Todo ID／标题／状态／要求、Bonus、交图与绑图状态。要求最多 320 字，超出用 `requirements_truncated` 标明；完整内容按需读取。
- `refs_index` 为资料清单，含 `available`、`files: [{path, bytes}]`、`total`、`omitted`、`limited`，不含文件正文或图片。

手动下载只提供 JSON，图片的 `preview` 为 `null`，不声称附带目录预览。连接、Key、目录句柄、Blob、Object URL、Vibe 编码不进入导出；参考配置内的本机资产 ID 不代表外部已获得图片。

## 提交与确认

外部文件使用 `koma.bridge.draft.v1`，正文直接复用站内 `propose_draft`，支持 IMAGE 的 `prompt_patch`、`character_edit`、`restore_partial` 、`params_patch` 、`slate_edit` 和 `save_ref`。不支持外部 CHAT 写入。文件上限 1MiB，单份草稿最多 12 步。

```json
{
  "schema": "koma.bridge.draft.v1",
  "draft_id": "landscape-001",
  "source_label": "外部助手",
  "draft_title": "调整横向构图和光线",
  "steps": [
    { "kind": "params_patch", "params": { "width": 1216, "height": 832, "seed": "0" } },
    { "kind": "prompt_patch", "target": "image.prompt", "mode": "append", "text": ", warm evening light" }
  ]
}
```

`draft_id` 为 1–120 位字母、数字、下划线、点或短横线；可选 `source_label` 最长 80 字符。不带 `base_hash` 时，收件管线在异步处理前冻结当时的活动画板与图片库；带哈希时必须匹配本页最近保留的导出基底。最多保留 16 份，过期或歧义时要求重新导出。

`restore_partial` 或 `slate_edit.bind` 引用 `#h`／`#f` 时必须带回对应 `picture_scope_id`，真实恢复值由冻结的本机记录读取，不能提交 `values`。角色目标使用 `image.char.c1.prompt` 等稳定 ID，插入模式使用 `after`。可选 `new_board_name` 沿用原有新板确认行为。

`prompt_patch` 的 `rewrite` 替换目标全文，`append` 在末尾追加；`replace`／`before`／`after` 修改局部，必须提供在目标中恰好出现一次的非空 `anchor`。空 Prompt 使用 `rewrite` 或 `append`。

有效草稿在接收时所属的 ASK 会话内追加紧凑来源行。应用后直接替换为已有工具调用的完成态：动作结果、同行「来自外部」与栈顶撤销按钮；具体来源与明细按需展开，不重复显示草稿标题、已应用脚标或独立外框。忙于推理、压缩、保存或正在审阅另一份草稿时进入该会话的等待队列，最多 32 份；切换会话不搬移草稿。回到所属会话且审阅槽空闲后才展示下一份，不自动应用。

Diff、逐项勾选、参数冲突、应用到来源板／新板、Tab 确认与 ⌘Z 撤销均复用原链路。保存失败保留待处理内容；外部记录不是模型回答，不产生用量或自动命名。外部草稿需要重提时提示发送方重新导出和投递，不代替发送方调用文本模型。

## 直接修改参数

内置 ASK 与外部来源共用 `params_patch.params` 白名单：

| 字段 | 值与约束 |
| --- | --- |
| `width`、`height` | 64–2048 的整数，64px 对齐，同时符合最终模型面积上限 |
| `steps`、`scale`、`cfgRescale` | 分别 1–50 整数、0–20、0–1；NAI Medium 固定 14 步且不接受非零 Rescale |
| `seed` | 表单字符串，空串为随机，非空为 uint32；`"0"` 合法 |
| `model`、`sampler` | 当前可用模型与采样器，不猜别名或替换非法值 |
| `naiMode`、`complexity`、`qualityPreset`、`negativePreset`、`transparentBg` | 现有枚举／布尔值，按最终模型能力检查 |
| `batchCount` | 正安全整数；只提议表单值，不执行生成 |

参数对象不能为空，未知字段拒绝。连接、Key、路由、额度策略、并发、缓存开关、全局偏好和参考资产导入不可由此修改。按最终勾选组合校验；取消必要关联项或参数发生外部冲突时不能部分写入整稿。Prompt／角色继续使用原步骤，参数复用已有 Diff 分组。

## 回执、去重与保存

| `status` | 含义 |
| --- | --- |
| `pending` | 等待或审阅；保存失败也保留此状态并带错误 |
| `applied` | 用户勾选内容已保存，不代表已生成或后来未撤销 |
| `dismissed` | 忽略、取消等待或删除所属会话 |
| `invalid` | 可识别 ID，但结构、版本、基底或接收条件无效 |

较早草稿的终态不会覆盖较新的回执。同一上下文的相同 ID／正文不重复接收，改变正文须使用新 ID。坏 JSON 静默间隔 120ms 重读一次，仍失败则等文件改变；读不出 ID 时保留上一份回执，不伪造新 ID。外部宜先写临时文件再替换，并等自己 ID 的终态再投下一份；单文件无法保留从未被读取就遭覆盖的内容。

外部记录、待审草稿与队列随所属 ASK 会话：未收藏只在本页，收藏后保存在 `koma-ask`。刷新后未收藏的 pending 投递标记为上下文失效，不重放。已应用／忽略的目录投递通过 `koma-bridge` 去重。挂载时手动导入共享目录上下文，未挂载时使用本页上下文。

50 条页面撤销执行记录不持久化，恢复的检查点只供查看。ASK 收藏、Bridge 句柄、回执和预览归属不进入普通 Koma ZIP。

## 共享资料与按需读取

直接向 ASK 提及清单中的资料，由只读 `read_ref({path, offset?})` 读取，无需重复确认。没有应用内资料选择弹窗；手动传文件使用输入框「＋」打开系统原生选择器，或粘贴／拖入。工具无目录写入端口；它只在用户发起的推理轮次中执行，不因挂载或刷新自动请求。

初始 `<workspace_state>` 与 `state.live.json` 使用同源元数据清单，最多列出 48 项，不另外提供搜索勾选列表。扫描上限为 512 个支持的文件、4096 项目录条目、8 层子目录，相对路径最多 1024 字符。`omitted` 表示未放入摘要的条目数，`limited=true` 时 `total` 只是已发现数量。不为清单读取正文、解码图片或计算文件哈希。

支持 TXT／Markdown／JSON／CSV／TSV／YAML／LOG 文本及常见浏览器可解码位图。SVG、隐藏路径、已知凭据文件名、绝对路径和父级跳转拒绝；根目录之外及根层 `assets/` 不可访问。`refs/` 应仅放准备共享的创作资料。相同名称用完整相对路径消歧；确切相对路径优先。不存在、文件已移除、目录失联、权限失效或超限均返回错误，不回退读取其他文件。

本地附件和工具读取共用附件池、每轮最多 4 个文本／4 张图片、文本字符限制与本页 200MiB 上限。工具文本每次最多 8000 字符，返回 `next_offset`；同一路径首次成功读取后，本轮分页和重复读取固定同一版本，下一轮可读新版本。图片按 look 最大 768px 输出，与 `view_image`／`view_sheet` 共用每轮 4 次／1.5MP／400KB 视觉预算；重复看同图也计预算。关闭发送图片时只能看清单，工具不读取图片内容。

实际引用内容记录相对路径、修改时间和 SHA-256，读取时冻结为附件；后来修改或卸载目录不回改旧消息。收藏保存实际文本／原图及发送编码，刷新恢复不依赖目录；未收藏仅留本页。文本压缩后按原分页恢复，不自动展开整篇资料。工具读取的附件在重试／编辑重答时重新按工具预算取用，不偷偷转为显式用户附件绕过预算。卸载、服务销毁与失败清理沿用原资源责任。

## 文件保存草稿

配方、备忘录和任务交接资料统一进入原有 DraftCard 的「文件」分组。普通 IMAGE 草稿的应用下拉菜单可附加画板配方、创作备忘录或活动任务交接资料；已完成回答下的「保存为备忘录」为该条回答创建文件草稿。内外 Agent 使用同一个 `save_ref` 步骤，不获得直接写入工具。

```json
{ "kind": "save_ref", "document": "memo", "document_title": "创作笔记", "text": "经审阅的备忘录正文" }
```

`document` 为 `recipe`／`memo`／`slate`；标题可选，最长 80 字符；`memo.text` 必填，最多 24,000 字符。配方固定 JSON（`koma.bridge.recipe.v1`）、备忘录固定 Markdown、任务交接资料固定 JSON（`koma.bridge.slate.v1`），不接受自定义路径、格式或覆盖操作。文件名由安全标题与唯一后缀生成，不覆盖既有资料。

**配方与任务资料保存提议时的冻结快照**，不是同卡应用后的表单或任务状态。预览明确标注「提议时画板」，配方保留完整表单与角色结构、来源和时间；本机参考资产仅保存标识，不附原图或编码。备忘录只保存所选回答正文或草稿给出的原文，不自动附带会话、系统指令、压缩记忆或调用调试，也不额外调用模型。

每个文件默认一行标题与去向，点击箭头展开真实路径、来源和可读摘要；不展示原始 JSON／Markdown 代码或格式下拉。Prompt、参数、任务、配方与文件沿用同卡分组和对齐。含文件时不显示只统计词文的 ± 总数。Tab 或应用统一确认，忽略不写文件。

目标在提议时冻结：已挂载时为该目录的 `refs/`，未挂载时为浏览器下载。原目录失联、权限不足或切换目录时阻断整个组合，保留草稿，不改为下载。恢复同一目录后重新校验。写入失败保留草稿和错误并补偿本次文件；本机提交失败也补偿文件。成功保存后刷新资料索引。

撤销只删除本次写入且仍未被外部修改的 `refs/` 文件，遇到内容冲突保留文件与本机状态；恢复重新核对所有权和内容。浏览器已发起的下载无法收回，恢复会再次准备下载。文件系统与本机数据库之间依赖预检和补偿，不提供跨进程原子事务。

## 默认本地任务板

绘图顶栏 API Key 旁的任务图标打开 280px 轻量总览：每份清单只有图标、标题与完成进度。点击返回关联 ASK 会话；更多菜单提供新建清单、在新会话中打开和导入 JSON。已有未映射清单的同步入口及冲突时的保留本机版本也放在此低频菜单，不占常驻清单空间。

活动会话的 Todo 位于输入框上方，收起为「待办／完成数／当前项」一行；展开是紧凑的状态、标题、单个成果图标。没有添加任务行、常驻关联控件或单项详情编辑。点击标题仅准备提问；内外 AI 通过草稿增改清单与配方。勾选走原任务提交路径，需交图时先选择成果。长清单内滚动，已完成项可折叠；使用真实高度展开／收起动画，减少动态偏好时直接切换。

无需 ASK Key、目录挂载或目录 API 即可从总览创建清单、手动交付／勾选，或导入外部草稿；内置 AI 推进仍需配置推理模型。任务和成果独立保存在 `koma-slate`，刷新、删除 ASK 会话、清空普通历史或卸载目录均不移除已绑成果。会话保存关联的 Slate ID；从总览选择时同步活动清单身份，没有任务的会话不留关联占位。

这里的「本机」指当前站点在浏览器中的本地存储，Cloudflare Pages 等 HTTPS 静态托管同样支持 Todo；不要求启动本地服务。不同域名／浏览器的数据相互独立，目录 API 的支持情况只影响外部文件同步。

任务进度为 `todo`／`in_progress`／`done`／`abandoned`；默认需要交图，纯文本任务可关闭「需交图」。需交图任务没有持久绑定时不能完成。任务进度、本机成果与目录同步分开显示。挂载失败不禁用本机任务。

## ASK 推进与复合草稿

内置 ASK 可从零拆解任务清单、追加 Bonus、修改描述与 `mutation`、推进状态、绑定本轮 `#h`／`#f`／`#e`、更新并锁定 `golden_recipe`。`get_state({include_slate:true})` 按需返回完整冻结任务板；默认初始状态只含摘要，`scope: latest` 仅用于检查当前变化。没有新增直接写入工具。

共享 `slate_edit` 支持 `op: create/update/delete`；已有目标必须带 `slate_id`、`expected_version`，创建标题使用 `slate_title`／`todo_title`（持久数据仍用 `title`），避免兼容中转剥离 Schema 标题元数据；新 Slate／Todo ID 由应用分配。每份草稿最多一个 `slate_edit`，其中 `todos` 最多 100 项操作，单板正文最多 900KiB。新增 Todo 使用 `{op:"add",todo_title:"任务标题"}`，省略 `id`；若 Agent 误填字符串 ID，解析时忽略该值并生成新稳定 ID，不因此拒绝整稿，也不据此覆盖或引用已有任务。`update/remove` 仍须引用状态中的真实稳定 `id`，不接受 CG 序号或自行编造的 ID。绑定使用 `bind: {source, caption_source, caption_mode, target_path?, character_id?}`，解绑使用 `unbind: true`。图像只接受本轮历史／收藏／EDIT，不能伪造本机资产或交付回执。

配方可用 `golden_recipe.capture_current: true` 保存同稿修改后的完整画板，也可提议经结构校验的 `form`；`locked` 控制锁定，锁定配方修改必须显式 `unlock: true`。配方是创作数据，不改变生成锁，不自动应用到画板或补造图片回执。

同稿可以同时编辑任务、Prompt、表单参数与文件保存。DraftCard 中「任务」「配方」「文件」与 Prompt 同级，字段标题为一级，内容明细缩进；任务只列真实变更，默认最多三行，其余按需展开。每行仅标题、变化提示或状态与箭头；展开只列改变的前后字段，`mutation` 统一显示「更改记录」。长配方默认一行，完整长文本另行按需展开并限高滚动，不把大段 JSON 印在卡片上。参数／提示词 Diff 保持原样。

组合步骤整体确认，不能单独取消依赖项；Tab 与点击应用共用联合校验。任务版本、图片可用性、目录目标或画板变化时整体阻断。支持来源板／新板、检查点、50 条页面撤销和恢复；恢复检查点不跨刷新执行。任务与文件检查点复用工具调用完成态，组合更改以单行计数摘要呈现，展开可看各项结果；外部来源同行保留「来自外部」。

## 本机成果、事务与清理

绑图即时复制实际原字节，保存 SHA-256、实际记录尺寸／MIME、稳定资产 ID、绑定时间和该图片已有生成参数；不拿当前画板替代旧图参数。基础 Prompt、实际发送 Prompt 和角色 Prompt 分开。长期关联不依赖 `#hN` 或某个 ASK 会话；原图只在普通对象／IndexedDB 中，不进入深层响应式状态。

任务、独立资产和提交记录通过 `data.write` 写入 `koma-slate/state`、`assets`，纳入维护 flush／reload。页面间用专用锁及持久版本检查，通知只触发轻量状态重读。任务版本在删除／撤销恢复后仍递增。

复合操作先持久化提交记录和选定资产，再按既有绘图写入路径保存画板，最后同一 IndexedDB 事务提交任务并清除记录。保存失败尝试只撤销自己尚未被改动的画板写入；进程中断后按提交记录恢复。若画板已继续修改，保留现场并显示恢复入口，不盲目覆盖。IndexedDB、画板偏好和文件系统之间不是原生原子事务。

删除／解绑后只清理 Slate 自有且无任务、提交记录、当前页面撤销／恢复记录持有的资产。页面保留记录有独立生命期锁；过期页面的保留项可回收。清理不删除收藏、参考资产或外部文件。普通 Koma ZIP 不收录任务板、成果或目录映射；任务资料 JSON 和成果原图／参数／标注有独立下载入口。

## 目录任务与交付

挂载自动映射当时活动 Slate；挂载期间手动新建或经草稿确认创建的活动任务板默认自动加入当前目录，通过外部任务文件创建时沿用原文件映射，不重复导出。切换到其他已有且未映射的任务板仍需从任务总览的更多菜单点击「同步到当前目录」加入。自动加入沿用原有冲突检查与失败反馈，不覆盖已有外部修改；本机保存成功与目录交付成功仍分别记录。`active_slate` 摘要存在不等于任务文件已成功写出，外部读取完整任务前应检查 `slates/` 中的文件；仍可按摘要中的 ID／版本提交草稿。目录身份独立持有映射与回执；卸载保留本机任务、原图及目录文件，换目录不会复用旧目录的交付成功状态。

`koma.bridge.slate.v1` 文件包含 `slate`（完整任务与配方）和 Koma 维护的 `deliveries`。目录扫描最多查看 `slates/` 下 100 个条目，单文件最多 1MiB。新文件、已映射文件变化或同 ID 文件冲突都生成来源明确的 ASK 草稿，确认前不更改任务；新对象身份由本机分配后回写映射。外部 `deliveries` 不授予资产访问或删除权限。手动导入同格式任务 JSON 也走草稿管线。

修改已有任务文件前重读，保留当前 `slate.id` 与 `slate.version`；版本过期或缺失会被拒绝，不将旧正文自动视作当前版本，也不由外部递增版本。确认通过后才由 Koma 递增并回写；共享草稿仍使用 `slate_id`／`expected_version` 检查目标。

外部文件不能凭空宣称本机绑图；新增成果使用共享草稿的 `bind`。已有本机绑定必须原样保留，或明确解绑且满足完成状态规则。锁定配方的外部修改在待审草稿中明确呈现解锁与修改。外部删除使用 `{schema: "koma.bridge.slate.v1", id, deleted: true}`，仍须审阅。

同步先检查任务文件内容哈希，再依次核对／写入选定原图、参数回执、标注，最后提交任务 JSON 与目录回执。目标限定在 `assets/`，图片扩展名须匹配原格式；已存在不同字节的成果不覆盖，需选择新路径。中断写入记录准备状态，恢复时复用校验通过的文件，只续办缺失文件或本次已登记的空占位文件；不重新生成。

默认草稿本机保存成功后，即使目录失败也保留本机任务与成果，并明确提示待同步。显式 `directory_required: true` 的草稿先完成文件与回执，再提交本机组合，失败不报告整稿应用成功；撤销同样检查目录条件。外部进程不参与浏览器锁，文件写前／写后重读只能检查可观察的冲突，不能保证跨进程原子替换。

外部冲突可继续审阅，或用户明确选择「保留本机版本」覆盖任务 JSON；不会自动采用最后写入者。删除／撤销不删原图文件，任务删除以受版本检查的 tombstone 表示。用户后来修改的文件保留，错误显示在同步状态中。

## 标注与资料沉淀

绑定时明确选择 `base`（基础 Prompt）、`sent`（实际发送 Prompt）或 `character`（指定本机角色 ID），缺失该来源时拒绝保存，不悄悄改用其他原文。仅提供：

- `full`：逐字符保留所选来源。
- `strip_syntax`：移除配对的 `{}`／`[]`、数字权重 `1.2::正文::` 与无属性的配对 XML 块标签，保留内容、顺序及转义；畸形或不确定包装保持原文。不猜测画师名，不做词义过滤，括号式其他语法原样保留。

任务交接资料通过 DraftCard 的「附加任务交接资料」保存完整任务、配方、进度与更改记录，固定为 JSON。配方、备忘录与任务资料是各自冻结的文件行，不提供第二套导出弹窗。资料文件不附原图；成果图标打开必要的选图／查看界面，标注来源由用户明确选择，已绑成果可用图标下载原图、真实生成回执和标注文本；浏览器仅报告已发起下载。

## 图片引用格式 v2

`state.live.json` 保持 live.v1，新增 `picture_ref_version:2`、`favorites_scope_id` 与 EDIT 只读目录。新版草稿引用 `#h/#e` 验证 `picture_scope_id`，引用固定 `#f` 验证收藏库作用域；混合时分别带回。EDIT 推荐完整 `#e板号.版本[a-c]`；若用本板简写，另带 `edit_board_id` 匹配活动编辑板。旧无标记投递维持保守校验，不能猜测旧 `#f` 含义。

Slate 可直接绑定 EDIT 原图／衍生图，保存独立原图及来源实体、记录与引用；无需注册 IMAGE 历史。已交付资产不依赖页内版本继续存在。外部仍仅向 IMAGE 提草稿，EDIT 索引不增加预览或原图自动导出。精确规则见[图片身份](../engineering/image-identity.md)与生成的 `PROTOCOL.md`。

## 内置 EDIT 与外部协议隔离

内置 ASK 已有 EDIT 现场、参数草稿和 edit_handoff，但外部 Bridge 仍只写 IMAGE。edit.* 靶点、director_patch、edit_handoff 及内部 edit_config 在收件入口返回 invalid；state.live.json 不增加 EDIT 表单／蒙版几何／费用。#e 只读引用、部分恢复到 IMAGE 和 Slate 绑图继续可用。生成的 PROTOCOL 与公开 SKILL 明确此边界。
