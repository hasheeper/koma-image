# 业务与交互契约

这些契约是复刻的验收目标，尚未代表已实现或验证通过。Gateway Profile 保留现有行为；已批准的单页导航、默认头像、连接配置与 Koma 数据命名按下表执行。

| 编号 | 区域 | 迁移时逐项核对 |
| --- | --- | --- |
| B01 | 工作区入口 | 唯一 App Shell；绘图／对话／词典原地切换并保活；编辑全屏、设置弹窗、备份为设置子页；旧 HTML 重定向兼容 |
| B02 | 启动 | 旧用户由独立同源过渡桥先检测并迁移；正式外壳只认 Koma schema／迁移状态，再持共享数据租约并初始化；全新环境不加载桥；切页不重复初始化 |
| B03 | NAI 默认值 | 模型、步数 25、Scale 5、CFG 10、单张、历史 25、关闭压缩和缓存等以源码为准逐项复制 |
| B04 | 描述 | 留空发固定 best quality；填写原样发送；不改写；透明底开关的附加 Tag 保持原规则 |
| B05 | 画幅 | 各档独立预设、64px 对齐、64–2048 边长和模型面积限制、自定义匹配、方形记忆与互换一致 |
| B06 | Seed | 空值随机、0 是合法值、批量递增、uint32 回绕；不能用 truthy 判断丢掉 0 |
| B07 | 报价 | NAI／对话 650ms、编辑器原有默认 400ms 防抖；旧请求失效、旧价淡显及报错展示按原实现 |
| B08 | 执行费用（已确认） | Gateway Profile 费用能力严格复刻：执行前重报、携带该次 max_cost、无付费确认弹窗；涨价提示后继续，批量最多提示一次；无报价能力与报价失败区分 |
| B09 | 请求路线 | Gateway Profile 路线能力保留免费且满足条件时走原生入口，付费／开启缓存走 Studio，工具使用原工具路径；无厂商判断，无自动回退 |
| B10 | 串行与额度 | 全应用默认并发为 1，批量占同一槽位逐张执行；Gateway Profile 保留日额度 300 阈值、400 警示条件、未知额度与原生免费路径差别；不提前启用预占 |
| B11 | 取消与失败 | 不自动重试生成；失败停止队列；取消中止等待和未提交队列，已完成图片保留；原超时语义一致 |
| B12 | 生成锁 | 全局调度器＋Koma 命名的任务门和 1..N 槽位池，默认 N=1；旧锁只由过渡桥交接，交接完成前不生成；忙时提示，不支持安全锁仍拒绝 |
| B13 | 结果展示 | 浏览旧图与当前生成是两个独立状态；新图不抢画面；占位尺寸提交时固定；批量对比在本机合成 |
| B14 | 普通历史 | 默认 25、0 表示无限、关闭保留时最新一张；刷新清空；清空确认与离开提醒条件一致 |
| B15 | 收藏 | 独立保存原图、缩略图与参数；写入成功才点亮；不受历史上限影响；取消后 8 秒撤销 |
| B16 | 结果操作 | 编辑、放大、对话改图、复用参数、复制 Tag、收藏、下载；Seed 复制和文件命名一致 |
| B17 | 图片导入 | PNG／JPEG、NAI／WebUI 参数、压缩元数据、采样器映射、对照勾选、无法映射提示一致 |
| B18 | 对话上下文 | 底图／参考图、跟随最新、文字勾选、分支、版本、实际发送文本、超限灰显一致 |
| B19 | 对话附件 | 上传／粘贴／拖入；单张 8MB、总量 32MB、模型数量上限取较小值；发送后附件消费规则不变 |
| B20 | 对话管理 | 空白复用、重命名、置顶、复制、删除确认；本地草稿与图片恢复；中断轮次标记一致 |
| B21 | 编辑模式 | 图生图、重绘、放大；各模式的强度／噪声／模型记忆；放大描述与主描述独立 |
| B22 | 编辑画布 | EXIF 归一化、源像素蒙版、白色重绘、笔刷／擦除／撤销／重做、空蒙版拦截、缩放／平移／对比一致 |
| B23 | 编辑会话 | 全屏覆盖层按来源保留会话，关闭后保留、刷新清空、最多 30 版本；运行中 Esc 不关闭；结果回到原工作区的规则一致 |
| B24 | 设置 | 单例弹窗含备份子页；连接为中性名称与默认头像，初始 URL／Key 为空；原手动模型 ID、自动匹配、来源移除、即改即存、跨标签同步和本地只读保持 |
| B25 | Key | PBKDF2 210000、AES-GCM、session 模式、共享解锁 0.2 秒等待、生成后锁定、清除语义保持；旧密文转换由桥在具备解锁材料后完成，不用空值覆盖 Key |
| B26 | 图片交接 | 独立票据、只领一次、30 分钟过期；超过 8MB／4000 万像素按原规则压缩；准备完原地切换对话，已保活工作区也能接收，旧票据链接仍可用 |
| B27 | Tag | 补全最多 20、搜索每页 25、分类默认、组合权重、原有防抖、关闭补全卸载监听；30 分钟交接和覆盖确认保持，显式导航接收而非重复挂载 |

| B30 | 输入与键盘 | IME 回车不提交、桌面 Enter／Shift+Enter、触屏回车、⌘/Ctrl+Enter、Esc 层级、方向键和焦点返回一致 |
| B31 | 窗口与资源 | mobile visualViewport、安全区、分栏偏好、真正离开文档时保存、Object URL 撤销时机与下载原字节保持；保活切换暂停界面监听与绘制，不释放仍被会话持有的资源 |

报价、执行和持久化由显式操作调用。watch 可以调度报价或偏好保存，但不能因挂载、恢复值、热更新或设置同步而自动发起生成。状态类型区分空报价、零积分报价、错误和加载；不把它们合并为一个布尔值。

B08 是用户明确确认的当前产品规则，不是待修正问题；调度器迁移及后续费用预占均不得恢复逐次付费确认弹窗，也不能把涨价提示改为阻断执行。
