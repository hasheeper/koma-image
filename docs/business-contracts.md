# 业务与交互契约

更新：2026-10-29。下表是当前仍须保持的业务与交互约束。产品定位与功能框架见[产品总览](product-overview.md)，具体范围与真实待验项见[当前状态](implementation-plan.md)，历史证据见[归档](archive/2026-10-25/README.md)。表格不构成真实供应商联调证明。Gateway Profile 按能力保留原行为；图像协议差异见[协议能力](native-image-protocols.md)。

| 编号 | 区域 | 复刻时逐项核对 |
| --- | --- | --- |
| B01 | 工作区入口 | 唯一 App Shell；HOME／绘图／对话／编辑／词典同级切换并保活；空或未知路由进入 HOME，显式深链保留；EDIT 独立页面、设置弹窗、备份为设置子页；旧 HTML 重定向兼容 |
| B02 | 启动 | 直接初始化 Koma schema；持应用级共享数据租约，切页不重复初始化；已有连接与可用 Key 时自动读取目录并提示进度与结果，缺少 Key 先填写／解锁；空连接打开设置，显式覆盖层入口保留，空配置不请求上游；不检查迁移状态，不检测、读取或清理旧应用数据 |
| B03 | NAI 默认值 | 默认 Anime 模式、步数 25、Guidance 5、Rescale 0、Variety+／质量／负向／Complexity 关闭；Variety+ 仅官方 V4.5 支持，按输出尺寸换算；Medium 有固定参数约束，旧 cfg 默认空且所有请求不发送；单张、历史 25、关闭压缩和缓存保持 |
| B04 | 描述 | 无有效词时发 best quality；保留输入原文，所选质量／负向／Complexity／透明底仅在请求快照按能力追加；Medium 不使用用户负向 |
| B05 | 画幅 | 各档独立预设、64px 对齐、64–2048 边长和模型面积限制、自定义匹配、方形记忆与互换一致 |
| B06 | Seed | 空值随机、0 是合法值、批量递增、uint32 回绕；不能用 truthy 判断丢掉 0 |
| B07 | 报价 | NAI／对话 650ms、编辑器原有默认 400ms 防抖；旧请求失效、旧价淡显及报错展示按原实现 |
| B08 | 执行费用（已确认） | Gateway Profile 费用能力严格复刻：执行前重报、携带该次 max_cost、无付费确认弹窗；涨价提示后继续，批量最多提示一次；无报价能力与报价失败区分 |
| B09 | 请求路线 | Gateway Profile 路线能力保留免费且满足条件时走原生入口，付费／开启缓存走 Studio，工具使用原工具路径；无厂商判断，无自动回退 |
| B10 | 串行批量 | 全应用默认并发为 1，批量占同一槽位逐张执行，失败或取消时停止剩余队列；批量张数不受日额度限制；不提前启用预占 |
| B11 | 取消与失败 | 不自动重试生成；失败停止队列；取消中止等待和未提交队列，已完成图片保留；原超时语义一致 |
| B12 | 生成锁 | 全局调度器＋Koma 命名的任务门和 1..N 槽位池，默认 N=1；只协调新应用任务，不等待旧锁交接；忙时提示，不支持安全锁仍拒绝 |
| B13 | 结果展示 | 浏览旧图与当前生成是两个独立状态；新图不抢画面；占位尺寸提交时固定；批量对比在本机合成 |
| B14 | 普通历史 | 默认 25、0 表示无限、关闭保留时最新一张；刷新清空；清空确认与离开提醒条件一致 |
| B15 | 收藏 | 独立保存 IMAGE／EDIT／CHAT 原图、缩略图与参数；CHAT 按具体版本收藏，源会话删除不删除收藏；写入成功才点亮；不受历史上限影响；取消后 8 秒撤销；固定 `#f` 跨刷新不重排，撤销保号、重新收藏用新号 |
| B16 | 结果操作 | 编辑、放大、对话改图、收藏、下载；Seed 复制和文件命名一致。结果栏不再提供复用参数和复制 Tag；绘图配方仍可拖进导入页读回参数；CHAT 及其纯手动修图不伪装为绘图配方 |
| B17 | 图片导入 | PNG／JPEG、NAI／WebUI 参数、压缩元数据、采样器映射、对照勾选、无法映射提示一致 |
| B18 | 对话上下文 | 底图／参考图、跟随最新、文字勾选、分支、版本、实际发送文本、超限灰显一致 |
| B19 | 对话附件 | 上传／粘贴／拖入；单张 8MB、总量 32MB、模型数量上限取较小值；发送后附件消费规则不变 |
| B20 | 对话管理 | 空白复用、重命名、置顶、复制、删除确认；本地草稿与图片恢复；中断轮次标记一致 |
| B21 | 编辑模式 | 图生图、重绘、放大；各模式的强度／噪声／模型记忆；编辑原文／预设／角色／参考完整继承，实际 Seed 随结果记录；共用绘图控件但会话写入独立，放大描述与主描述独立；六项 Director Tools 独立处理查看版本，不继承生图参数，去背景三种结果成组切换、不重复请求，保留实际工具与来源配方 |
| B22 | 编辑画布 | EXIF 归一化、源像素蒙版、白色重绘、笔刷／擦除／撤销／重做、空蒙版拦截、缩放／平移／对比一致；支持位图蒙版导入；蒙版属会话画布，同尺寸跨版本沿用，清空或尺寸变化才重置，灰度与透明覆盖明确区分，不静默缩放套用；聚焦重绘由用户另框选参考范围，须包含全部蒙版，同尺寸沿用、异尺寸清空；单次裁切重绘后仅贴回蒙版像素，最终保持原尺寸 |
| B23 | 编辑会话 | 独立 EDIT 页面按来源图保留画板，切换保留、刷新清空、每板最多 30 版本；离开页面不中断生成，结果写回发起画板；手动子版本可直接进入收藏／Slate，所有编辑结果留在 EDIT、不自动进入 IMAGE 历史，不强制生图，来源配方独立记录；Photopea 保留分层文档，同尺寸换底不拆栈；自动／仅图像／仅蒙版共用干净图像导出，合法空值与失败分开；外部图像和蒙版全部校验后一次应用，CHAT 保持显式回传 |
| B24 | 设置 | 单例弹窗含备份子页；连接为中性名称，官方 Profile／已识别官方地址使用品牌 Logo，其他连接图标区分文本／生图；图标识别不改协议与请求；初始 URL／Key 为空；手动 ID、自动匹配、来源开关、即改即存、跨标签同步和本地只读保持；可用来源与优先级分开，按模型／操作选择，未知余额仍按顺序、明确不足才顺位；提交后不换源重试，顶栏跟随实际来源 |
| B25 | Key | PBKDF2 210000、AES-GCM、session 模式、共享解锁 0.2 秒等待、生成后锁定、清除语义保持；不转换旧密文，用户重新配置 Key；仍不得用空值覆盖现有 Koma Key |
| B26 | 图片交接 | 独立票据、只领一次、30 分钟过期；超过 8MB／4000 万像素按原规则压缩；准备完原地切换对话，已保活工作区也能接收，兼容 HTML 票据链接保留参数，仅认领 Koma 票据，不转换旧库票据 |
| B27 | Tag | 补全最多 20、搜索每页 25、动漫分类默认，绘图 Furry 模式使用独立补全；组合权重、原有防抖、关闭补全卸载监听；30 分钟交接和覆盖确认保持，显式导航接收而非重复挂载 |
| B28 | 完整备份 | 设置中的「备份与恢复」无 Key 可用；仅支持新版 Koma schema（version=2），旧格式不转换且不写入；原图字节、合并／冲突副本、去重、偏好覆盖、失败重试和 ZIP 限制保持 |
| B29 | 备份隔离 | Key／派生密钥／普通历史／编辑会话／交接数据／HOME 展示副本与偏好不导出；释放自身共享租约后获取独占数据锁和 Koma 任务门；刷新缓存后恢复写入 |
| B30 | 输入与键盘 | IME 回车不提交、桌面 Enter／Shift+Enter、触屏回车、⌘/Ctrl+Enter、Esc 层级、方向键和焦点返回一致 |
| B31 | 窗口与资源 | mobile visualViewport、安全区、分栏偏好、真正离开文档时保存、Object URL 撤销时机与下载原字节保持；保活切换暂停界面监听与绘制，不释放仍被会话持有的资源 |

HOME 的「定稿」直接读取普通收藏，保持同一 `#f` 编号与原图操作路径；画板暂存副本仅供展示，不回填历史、下载或交付。`G` 在 HOME 与上次车间间切换，HOME 背景回车继续；输入／组字、修饰键和弹窗中不触发。刷新清空 EDIT；本页的继续定位独立编辑画板，刷新后回退 IMAGE。

HOME 欢迎区只在本地数据读取成功且确实无内容时出现，不把读取中的收藏／展示副本／CHAT 当成空库；第一份真实内容出现后恢复原布局。全空背景粘贴图片进入 EDIT，输入、ASK、弹窗和菜单的粘贴不被首页截走；离开 HOME 解除该监听。

HOME 停靠使用同一 ASK，宽屏可选半屏／全屏、窄于 1280px 自动全屏；运行／结果／草稿／已写入状态与车间共用收起判定。HOME 不直接确认草稿：图像与 CHAT 草稿应用时切到目标车间，不生成、不发送；纯 Slate 草稿留在 HOME。拖入 ASK 使用原图或文件附件，展示副本不可附加；拖入页面其他位置的本机图片打开 EDIT。

NAI V4.5 的 Vibe／Precise 配置随画板保留，两组启用互斥，浏览不启用；不支持时明确拦截，不静默丢图。编码只随显式生成进入任务锁，成功即持久化，失败／取消不重试；已知参考费用下限不足时停止，余额未知保持原选择规则。详见[参考契约](novelai-official.md#vibe-与精确参考边界)。

报价、执行和持久化由显式操作调用。watch 可以调度报价或偏好保存，但不能因挂载、恢复值、热更新或设置同步而自动发起生成。状态类型区分空报价、零积分报价、错误和加载；不把它们合并为一个布尔值。

B08 是用户明确确认的当前产品规则，不是待修正问题；调度器重构及后续费用预占均不得恢复逐次付费确认弹窗，也不能把涨价提示改为阻断执行。

ASK 的只读工具、确认草稿、检查点、收藏会话和压缩遵守独立的[现行 ASK 契约](ask/ask-implementation-plan.md)，不改变上表的生成、报价、额度、取消与失败规则。活动画板及角色遵守[多角色与画板](multi-character-boards.md)，不以当前表单覆盖在途快照。

默认本地任务板与外部协同的现行契约见 [B1–B3](ask/bridge.md)：任务保存在当前站点的浏览器中，HTTPS 静态托管与本地运行均可用，不依赖挂载目录或 ASK Key；内置 AI 推进仍需推理连接。AI 修改必须经过共享草稿确认，新 Todo 由应用分配稳定 ID，已有任务仍检查真实 ID 与版本；独立持久绑图不会因历史／ASK 删除丢失。任务状态与目录交付分离，组合写入留可恢复提交记录，不改生成、报价、并发或付费规则。

配方、备忘录和任务资料的文件保存统一通过 `save_ref` 草稿确认，目标和内容在提议时冻结；目录失联或切换时保留草稿，不静默换为下载。`refs/` 清单与只读 `read_ref` 保留，手动附件使用原生文件入口，不新增资料勾选或独立导出预览弹窗。

图片实体、五类编号、作用域及备份合并以[图片身份与引用](image-identity.md)为准；展示短码不能作为跨作用域主键，参数按具体记录读取。
