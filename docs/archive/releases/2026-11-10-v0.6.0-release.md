1. 独立发布包缺少 `models.ts` 新依赖的 `seedream.ts`，导致解压服务报 `ERR_MODULE_NOT_FOUND`；已加入显式运行文件清单，解压启动测试通过。
2. 清理 `public/skills/` 及对应构建中的 macOS 目录元数据；打包器继续拒绝隐藏文件和未审查产物，未放宽发布清单。
3. 文档中的本机绝对路径改为仓库相对链接；补齐 Seedream 浏览器直连说明，版本与状态入口同步。
4. 日志采用可识别的版本标题与平铺分组，避免 Markdown 标记和嵌套列表在设置页显示为原始文字；色彩对齐描述保留实际效果边界。
