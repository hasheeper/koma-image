## 边界

静态 Pages 继续直接访问 Danbooru，受原站网络、CORS 与站点验证限制；本地转发不随静态部署上线。用户在发布后明确提供了在线版直连帖子 JSON 的 403；v0.2.1 的开发服务修复不解决此线上问题。

另在临时 Pages 预览中验证了服务端匿名读取：使用明确的 Koma 客户端标识、不携带 Cookie、不跟随重定向，原站仍返回 403、HTML 与 `cf-mitigated: challenge`。所以本轮没有把无效的边缘转发接入生产；在线帖子读取仍未恢复，须有原站允许访问的服务端出口后再验证。该结果仅针对当次 Cloudflare 出站请求，不声称所有服务端都不可用。上述检查不代表真实供应商生成、模型质量或费用验收。

本轮已有的两处旧阶段归档改动保留在本机，未混入产品提交；本机配置、截图和审计副本未提交或上传。
