## 1. 已确认决策

1. 打开 Koma 默认进入 HOME。
2. 「定稿」就是收藏 `#f`，只由用户主动收藏。
3. HOME 的起点输入框就是 ASK：同一会话，换一种呈现。
4. 每个画板默认展示最近的画布图。这张图不收藏，只在本机暂存一张展示副本，刷新后仍能显示。
5. 兼容优先：不改变收藏记录结构、普通备份格式、Slate 绑图、`#h` 刷新清空、ASK 草稿应用、生成与报价规则。新增信息只作为可选参数字段或 HOME 本机数据，缺失时退回默认表现。
6. 刷新不一定回 HOME：只有不带路由或路由未知时进入 HOME，显式路由停在原处。
7. 在 HOME 应用 IMAGE／CHAT 草稿会切到对应车间，沿用现有写入路径。
8. 概念稿不直接应用。HOME 的页面形态已在 UI 设计阶段（HD）用真实 Koma tokens、组件和合成图的交互预览确认，实施按 §6–§8 进行。
9. HOME 没有外壳顶栏。头部是 Koma HOME 字标、ASK 输入条和四个车间入口；进行中由「继续」大卡领头横排，其余有图的线并排；定稿保留标准行对齐、标准列对齐与拼图三种模式；未主动选择时，桌面默认行对齐，860px 及以下默认列对齐。
10. 在 HOME 上，ASK 用同一窗口停靠呈现：从输入条发送后，窗口默认半屏停靠在页面右侧，可放大为全屏；收起后由输入条承接运行与结果状态。

## 2. 定位

HOME 是创作者的桌面，不是作品仓库。作品要经过 IMAGE 出毛坯、CHAT 改构图和叙事、EDIT 局部精修，最终的图往往不在 IMAGE 里，所以不让任何一个车间兼任首页。HOME 是三个车间共用的门厅：

| 用户的问题 | HOME 的区块 |
| --- | --- |
| 我上次做到哪了 | 继续（进行中的领头大卡） |
| 手上还有哪些没做完 | 进行中 |
| 哪些已经定下来了 | 定稿 |
| 我想开始一个新的 | 起点（头部的 ASK 输入条与车间入口） |

HOME 不包含：统计与仪表盘、全部历史图库、文件夹或标签体系、批量管理、资料库与黄金基底面板、协同目录配置、模型与连接设置。头部的目录与设置按钮只是现有入口：目录按钮与 ASK 目录标签是同一挂载，设置按钮打开现有设置弹窗。

## 4. 核心概念

### 4.1 创作线

HOME 的展示单位是创作线：一个 IMAGE 画板、一个有轮次的 CHAT 会话，以及一个本页保留的 EDIT 画板各是一条线。EDIT 使用当前版本原图，不新增持久预览；结果仍保留原 IMAGE／CHAT 出处。待办只通过绑定成果关联到线，未绑图的待办不在 HOME 显示，留在任务总览（§6.2）。不新增「项目」概念。

### 4.2 线的脸

每条线只露一张图，按顺序取第一项：

| 线 | 取法 |
| --- | --- |
| IMAGE 画板 | ① 在定稿中「设为封面」的收藏 ② 本页该画板的最新图：普通历史中 `boardId` 匹配的最新记录，含 IMAGE 来源的 EDIT 结果 ③ 该画板的暂存展示副本 ④ 占位封面 |
| CHAT 会话 | ① 「设为封面」的收藏 ② 会话中最新完成版本的图片 ③ 占位封面 |
| EDIT 画板 | 当前查看版本的原图 URL；未载入图片时为占位封面，刷新后该线清空 |

- CHAT 新完成版本记录 `completedAt`，较早轮次的后续重试也能成为最新封面；旧记录缺少时间时按原有轮次／版本顺序回落，不改写旧数据。
- 默认就是最近的画布图，连续抽卡时脸跟着最新图变化。想固定某张，就收藏后设为封面。
- 占位封面只在确实没有可显示的图时出现，且只用于「继续」大卡；其他没有图的线不进陈列（§6.2）。它与脸同尺寸，是 `--chrome` 面板加 `--line` 描边与 `--r3` 圆角，正中以该车间的方块标识（IMAGE 或 CHAT，80px，`--line-2`，不呼吸）作淡水印；不写标题和摘要，线名只在文字栏出现。上下排布时为整宽、高 160px 的横条，水印 64px。不显示假图。

### 4.3 最近画布图暂存

| 项 | 规则 |
| --- | --- |
| 时机 | 某画板出现新图（生成完成，或 IMAGE 来源 EDIT 结果进入历史）时，覆盖该画板的暂存；每个画板只保留一张 |
| 内容 | 展示用缩小副本（不是原图），长边不超过 1080px 的 WebP（小图不放大）；另存尺寸、来源记录 ID、产生时间、Prompt 摘要。1080px 覆盖继续大卡的脸在 2 倍屏上的最大显示（高 368、横图宽约 540 CSS px），以及手机 3 倍屏上下排布时的脸 |
| 存放 | 新本机库 `koma-home`；写入走数据租约，并作为延迟保存注册 flush，不阻塞生成任务退出 |
| 生命周期 | 同一画板出新图时覆盖；删除画板时删除；不随普通备份导出或导入；导入后按真实画板清理失效项 |
| 边界 | 只供 HOME 展示。不收藏，不进入 `#h`、ASK 图片编号或画布；不能绑图、送去 EDIT／CHAT 或下载。IMAGE 刷新后仍按现行契约清空历史与画布 |

### 4.4 定稿

- 定稿就是收藏 `#f`，来源不限 IMAGE、CHAT 或 EDIT，只由用户主动收藏。
- 绑入待办不自动收藏，成果仍按现行规则冻结在 `koma-slate`。已绑定的收藏在定稿区显示待办名，按 Slate 成果的 `sourceId` 与收藏 ID 匹配。
- 车间里唯一新增的动作：CHAT 结果工具增加「收藏」，把该版本图片复制为普通收藏记录，参数带会话来源。EDIT 收藏沿用现有按钮。
- CHAT 收藏同样出现在 IMAGE 收藏列表和 ASK 的 `#f` 中。它的参数不是绘图参数，不提供「读取参数」写入画板。

### 4.5 来源链

- 不存 `#h4 → #c2.1` 这类本页编号（刷新后会重排或失效），而是从收藏参数推出可读文字，显示时再附当前 `#f` 编号。
- 现有字段已能覆盖：生成画板名、编辑工具（图生图／重绘／放大／手动修图）、手动修图的 `editParent`。
- 已接入的可选字段：CHAT 收藏的会话、轮次、版本 ID 与会话标题；AI 编辑结果的父图（与手动修图同义的 `editParent`）；CHAT 来源 EDIT 结果的会话 ID。这些字段已加入 `imageParameters` 白名单，绑图成果同样保留。旧收藏缺少字段时只显示已知部分。
- 示例：`月夜棋盘花园 → 重绘`、`镜之回廊 · 第 3 轮 → 手动修图`。来源画板已删除时写「已删除的画板」。

### 4.6 HOME 自有数据

HOME 不复制作品数据，其余内容都从画板、普通历史、收藏、CHAT、EDIT 会话、ASK 与 Slate 推导。自有数据全部本机保存、不进普通备份，丢失时只退回默认表现：

| 数据 | 内容 | 存放 |
| --- | --- | --- |
| 最近画布图暂存 | 见 §4.3 | `koma-home` 库 |
| 封面指针 | 线 ID → 收藏 ID；收藏取消或线删除时失效 | 本机偏好 `koma.home.v1` |
| 上次位置 | 最后离开的车间与时间；画板和会话沿用现有活动画板与当前会话 | 同上 |
| 定稿排列 | `rows`／`cols`／`mosaic`；未主动选择存 `null`，按可用宽度自动取行／列；明确选择后保持 | 同上 |

ASK 在 HOME 的半屏／全屏选择只存本页内存，不写入 `koma.home.v1`（§7.1）。

HM1 的编码与写入不占生成任务锁；经 `data.write` 与注册的 flush／reload 完成，导入维护使用维护提供的 writer。每个画板保留最新源记录，慢编码或其他标签页的较旧结果不能覆盖较新的副本；失败保留待存项供后续 flush，生成结果不受影响。替换、删除和服务销毁时释放预览 Object URL。HOME 偏好使用专用锁合并写入；本页的返回位置不随另一标签页切换。

CHAT 使用 `readStored()` 只加载本机内容，不预热模型目录、报价或额度；已进入 CHAT 或 ASK 明确预热后的连接刷新仍沿用原服务。HOME 不猜测连接品牌、模型可用性或供应商状态。

## 5. 入口与导航

### 5.1 默认进入与路由兼容

- 新增 `#/home`。空路由和未知路由进入 HOME，并替换写入 `#/home`。
- 显式路由照常打开：`#/image`、`#/chat`、`#/tags`、设置各分组（含旧 backup 深链）及独立 `#/edit` 页面；旧 EDIT 覆盖层地址规范化到独立路由。刷新停在原处，浏览器前进后退不变。
- 设置可叠在 HOME 上（`#/home/settings/…`），关闭后回到 HOME；EDIT 使用独立 `#/edit` 页面。首次没有连接时仍自动打开「设置 → 连接」。
- 原有 IMAGE 浏览器测试使用显式 `#/image`；HOME 测试独立检查默认入口。

### 5.2 导航

- HOME 没有外壳顶栏，页面从自己的头部开始（§6.1）。额度不在 HOME 显示；连接与 Key 从头部的设置按钮进入；任务总览从进行中区头的任务板胶囊打开，没有活动任务板时从车间顶栏进入。
- 车间顶栏的 Logo 下拉菜单按 HOME／IMAGE／CHAT／EDIT／TAGS 排列，底部保留设置，不放任务总览。从 HOME 进入车间靠头部的车间入口、「继续」、进行中的卡片和 `G`。
- `G` 在 HOME 与上次所在车间之间切换，页面上不写快捷键提示。输入框聚焦、输入法组字、模态对话框或 Photopea 编辑打开时不触发。
- 在 HOME 上，焦点位于页面本身时，回车等同「继续」。
- HOME／IMAGE／CHAT／TAGS 共用上限为 4 的 KeepAlive；EDIT 原位隐藏保活，避免移动 iframe 导致 Photopea 重载。切换工作区保存当前编辑视图并暂停界面监听，任务继续归发起画板。

## 6. 页面结构

本节定义每个区块显示什么、如何排序、点击后去哪里，以及 HD 确认的版面。尺寸为 CSS px，实施时取现有变量；示例文案按[设计语言](../design-language.md) §7 写成事实短句。

页面自上而下为：头部（字标、设置胶囊、ASK 输入条与车间入口）、进行中（「继续」大卡领头）、定稿，没有外壳顶栏。内容列宽 min(视口 84%, 1080px) 居中，让内容向中间收拢，顶部留 `--sp-6`；860px 及以下宽 `100% − 32px`，顶部 `--sp-5`。ASK 半屏停靠时，内容列按扣除窗口后的宽度计算（§7.1）。头部与进行中相距 `--sp-7`（窄屏 `--sp-6`），进行中与定稿相距 `--sp-6`（窄屏 `--sp-5`）。

区头为标题加计数，与右侧控件共用一条中线：标题 18px 中粗、行高 32px（窄屏 30px）；计数为 22px 高的等宽圆胶囊（窄屏 20px），`--raised` 填充，数字 `--fg-2`。

### 6.1 头部

头部在宽屏居中：第一行正中为字标、右端为设置胶囊，其下是居中的 ASK 输入条（§7.1），再下是居中的车间入口，左右重量对称。560px 及以下字标靠左、胶囊靠右，输入条与入口铺满内容列。

- **字标**：沿用现有品牌组合，即呼吸方块标记、Fredoka「Koma」与字距拉开的副标题 HOME，标记使用 HOME 图形（屋顶、两墙与门）。标记 36px、字标 32px、副标题 12px（字距 .16em），标记与字相距 12px；560px 及以下为 32／28／11px，相距 10px。HOME 没有顶栏，字标是页面唯一的品牌，宽屏时在内容列正中，不外探；560px 及以下贴齐内容左缘。不加底板和光晕；减少动态时不呼吸。字标与输入条相距 `--sp-5`（560px 及以下 16px）。
- **设置胶囊**：宽屏位于第一行右端，与字标共用中线，右端贴齐内容列；560px 及以下贴在第一行底部、距输入条 8px，右端内缩 `--sp-2`，与输入条的圆端对齐。胶囊高 32px，表面与输入条相同（`--raised`、`--line-2` 描边、`--sh-1`），圆角 16px；内有目录按钮与设置按钮，中间用 1px 分隔线隔开。
  - 目录按钮高 26px，依次是状态点（已连接 `--ok`，断开 `--warn`）、文件夹图标和目录名（`--fz-xs`，最宽 180px，860px 及以下 128px，超出省略）；未挂载时没有状态点，写「挂载目录」。它与 ASK 目录标签是同一挂载，点击行为相同：未挂载时挂载，断开时恢复，已连接时打开切换／卸载菜单。560px 及以下只留状态点与图标。
  - 设置按钮为 26px 圆形图标按钮，打开现有设置弹窗。两个按钮的提示向右对齐，不超出视口。
- **车间入口**：输入条下方 12px，一行四枚 34px 描边胶囊居中排列，沿用 CHAT 起始页 `.chat-starter`，间距 8px，四枚同级，不突出首项。
  - 「新画板」：进入 IMAGE，沿用现有新建画板。
  - 「新对话」：进入 CHAT，沿用现有新建会话。
  - 「精修图片」：打开本机图片选择器，选定后以该图打开 EDIT，复用 EDIT 的本机图片来源。
  - 「查词」：进入 TAGS。
  - 560px 及以下四枚等分整行，「精修图片」缩写为「精修」；360px 及以下去掉图标。不加快捷键提示或说明行。
- **首次使用**：所有画板都没有图（含暂存）、没有收藏，也没有含轮次的 CHAT 会话时，只显示头部，不显示进行中与定稿，不另加空状态说明。

### 6.2 进行中与继续

区头为「进行中」加计数（只计陈列中的线，含继续大卡）；右侧是活动任务板胶囊，30px（窄屏 28px），沿用词典 `.tag-filter` 的描边胶囊，内含任务板名、进度条与等宽的 `完成／总数`，点击打开现有任务总览。400px 及以下省略进度条；没有活动任务板时不显示。

区内一行横向陈列，按滚动吸附：第一项是当前线的「继续」大卡，其后是其他线。整行同高 H = clamp(330, 视口高 − 530, 370)，大卡与相邻卡片上下边对齐。陈列和卡片都不加卡片底色与边框，文字直接放在衬纸上。横向滚动区隐藏滚动条，右侧保留原稿的 40px 渐隐遮罩；上下堆叠时只作用于下方横向列表，不遮住继续大卡；只有继续大卡时不加遮罩。

**继续大卡**

- 左为脸：高 H − 2px（保留透明边界），宽按原图比例，完整显示不裁切，画框为 `.print`（`--r3`、`--print-shadow`）。点击脸等同继续。
- 右为文字栏，左距 28px，宽度随内容在 200–400px 之间（含左距）：有最近的图时与那一行同宽，没有时收窄到线名与按钮所需的宽度，其他卡片随之靠近。没有其他卡片时，上限放宽到这一行除脸以外的剩余宽度，最近的图随之多排几张。内容分上中下：
  - 上：有绑定待办时先写待办编号（等宽 11px `--fg-3`）和待办名；线名 22px 中粗，最多两行；元信息胶囊「9 张 · 12 分钟前」。没有草稿但有状态句时，状态句作为带圆点的胶囊并排。
  - 中：最近的图（见下）。
  - 下：有待确认草稿时为 32px 草稿胶囊，依次是琥珀圆点、状态句「草稿待确认」、单行截断的草稿摘要和等宽差异计数 `+3 −1`；其下为扁平主按钮「继续绘图」（CHAT 线为「继续对话」），高 40px、按内容宽度左对齐，附 ↵ 键帽；仅上下堆叠布局铺满文字栏。
- 没有最近的图时不留中段：待办、线名、元信息与按钮整组靠下，组间距 `--sp-5`，按钮仍与脸的底边对齐，和相邻卡片的说明落在同一底部区域。
- 不显示 Prompt 原文与生成参数。
- 文字栏里的胶囊用 `--raised` 填充、不描边，不再套凹槽框。

**最近的图**

- 该线除脸以外较新的几张，新的在前。统一高 clamp(84, H − 244, 124)，宽按比例、不裁切，`--r2` 画框加 `--print-shadow`，间距 8px，在文字栏内排一行，放得下几张显示几张。
- 来源依次为：本页普通历史中该画板的记录（含 IMAGE 来源的 EDIT 结果）；没有时取该画板的收藏，按收藏时间；CHAT 线取会话中较早版本的图片。都没有时不显示这一行，文字栏按上一节收窄并整组靠下。
- 点击进入对应车间，沿用这张图在车间里的打开方式：历史图显示到画布，收藏打开收藏大图，CHAT 定位到该版本。

**其他卡片**

- 脸高 H − 66px（扣除说明和透明边界），宽按比例，`.print` 画框；下方 64px 说明：线名 13px 中粗（有待办时前附等宽编号），一行状态（张数或轮次 · 时间，有状态句时为小号带点胶囊）。
- 悬停只抬起 1px；键盘聚焦显示紫色焦点环。点击进入对应车间，并切到该画板或会话。

**上下排布**：脸宽加 382px 超过内容宽时（手机），大卡改为上下排布并单独成行：脸在上，高 min(clamp(220, 视口高 − 520, 320), 内容宽 ÷ 比例)；文字在下，不显示最近的图，继续按钮占满整行。其他卡片在下方横向滑动，脸高 174px。

**只有继续大卡**：没有其他卡片也没有定稿时，561px 及以上的「进行中」整区（区头与大卡）收拢到内容宽度，在居中的头部下方居中；有定稿时仍左对齐，与定稿区头同一左边；560px 及以下保持左对齐。

**只陈列有图的线**：「继续」大卡总是显示当前线，没有图时用占位封面（§4.2）；其他没有可显示图片（含暂存）的画板和会话不进陈列，未绑图的待办也不在 HOME 显示。它们分别留在 IMAGE 画板列表、CHAT 会话列表和任务总览里。陈列下方不放胶囊行，不使用概念稿的虚线大卡，也不在图片之间放文字卡。

**排序**

1. 「继续」大卡是上次所在车间的活动画板或当前会话。
2. 有活动任务板时，已绑图待办把成果所属的线（成果参数中的画板或会话）按待办顺序带到前面。
3. 其余有图的线按最近活动排序：画板取本页最新图或暂存的时间，CHAT 取 `updatedAt`。
4. 有图的画板全部显示；CHAT 只取最近 6 个有轮次的会话，其余留在 CHAT 会话列表。

**状态句**取第一条成立的。张数等本页数据只在本页有效，刷新后元信息胶囊只写时间：

| 条件 | 示例 | 刷新后 |
| --- | --- | --- |
| 正在生成 | 正在生成 2／4 | 不保留 |
| ASK 有待确认草稿 | 草稿待确认 | 收藏会话中的草稿可恢复 |
| EDIT 已画蒙版、尚未执行 | 蒙版未重绘 | 不保留 |
| Photopea 已打开文档并选择「暂不应用」 | 高级编辑未应用 | 不保留 |
| CHAT 会话 | 第 3 轮 | 保留 |
| 其他 | 12 分钟前 | 取暂存时间 |

标题直接显示画板或会话名，不额外添加色点、车间文字标签。「继续」回到上次所在车间及其活动画板或当前会话；同一页面内 EDIT 会话仍在时重新打开 EDIT，刷新后 EDIT 会话已清空，只回到车间。

### 6.3 定稿

- 区头为「定稿」加等宽计数胶囊；右侧是 `.seg` 分段「行对齐｜列对齐｜拼图」，窄屏也不竖排，选择存入 `koma.home.v1`。没有收藏时不显示定稿区。
- **行对齐**：等高行铺满内容宽，目标行高 220px（窄屏 140px），间距 16px（窄屏 8px）；末行保持目标行高，不拉伸。
- **列对齐**：等宽列，目标列宽 230px（窄屏 160px），列数为 max(2, round((内容宽 + 间距) ÷ (目标列宽 + 间距)))，1440px 视口、1080px 内容列下为 4 列，390px 下为 2 列；每张按原比例，按收藏时间依次放入当前最短的一列。
- **拼图**：在大致水平对齐的完整行带内，允许有限的双图上下组合；按原始宽高比分配面积，宽幅图应获得更大的可见面积，不按数组中间位置放大某张图。不使用任意层级的递归分割，不留行带内部空洞，也不裁切图片。布局已按确认预览重写为纯尺寸计算，并以横／竖／方混排验证；标准列对齐不混入跨列拼图规则。
- 未主动选择时，桌面默认行对齐，860px 及以下自动列对齐；有明确选择后不因宽度变化覆盖偏好。
- 三种排列都完整显示原图，不裁切，画框 `--r2` 加 `--print-shadow`。图上不常驻文字或角标；悬停或聚焦时底部浮出说明：`#f` 编号、名称、精修图标，以及来源链与已绑定的待办名；触屏常显。
- 全部收藏按收藏时间排列，不按来源分组；精修来源用现有编辑图标标识，不加文字角标。
- 点击打开大图，操作复用现有路径：送去 IMAGE（读取参数，只对绘图参数可用）、送去 CHAT（现有 IMAGE→CHAT 交接）、送去 EDIT、绑入待办（现有交付对话框）、设为封面（写 HOME 数据）、取消收藏。
- 不提供多选与批量操作。

## 7. ASK 在 HOME

头部、停靠窗口与车间浮窗共享同一 ASK 服务及应用级呈现状态。以下行为均已接入真实数据；没有复制静态预览的模拟计时器或 DOM 搬移脚本。

### 7.1 同一个 ASK

同一 `AskDrawer`、会话、草稿卡、撤销栈、收藏与压缩，不新建会话类型。HOME 改变的只是呈现：入口是头部输入条，窗口停靠而不浮动，收起后的状态由输入条承接。[ASK UI 规范](../ask/ask-ui-spec.md) §1.1 引用本节。

**输入条**

- 位于头部（§6.1），随页面滚动，不固定在底部，不遮挡内容，是页面上最亮的表面：宽 min(内容列, 720px) 居中（560px 及以下铺满内容列），高 56px（860px 及以下 50px），圆角为高度的一半，`--raised` 实色、`--line-2` 描边、`--sh-2`，聚焦时描边混入 45% `--a`。内距 `0 9px 0 20px`（窄屏 `0 7px 0 16px`），部件间距 12px。
- 内容依次为 ASK 标记、单行输入（15px，占位「问任一画板或会话，用 #f 引用定稿…」）、模型选择（860px 及以下隐藏）和发送按钮。标记、模型选择与发送／停止直接复用 B v5 部件；发送／停止放大到 36px、图标 `--ico-md`，停止圆角 10px，与输入条同心。附件、目录标签与占用环留在 ASK 窗口。
- 输入条与窗口输入框共用 `ask.input`。回车或发送按钮发送后打开窗口，文字成为窗口里的提问；收起窗口时，输入框里未发送的文字回到输入条。
- HOME 上不显示 ASK 静默圆形和收起胶囊，窗口也不能拖动；⌘J／Ctrl+J 在输入条与窗口之间切换。

**停靠窗口**

- 停靠时下方没有内容可透出，窗口不用玻璃，改用页面的实色表面（[设计语言](../design-language.md) §4.6）；消息、草稿和输入的叠加底色不变。
- **半屏**：停靠在视口右侧，上、右、下各留 12px，宽 clamp(420, 视口 32%, 480)px，圆角 18px，`--chrome` 表面加 `--line-2` 内描边，不加投影。页面右侧让出窗口宽加 12px，内容列按剩余宽度重排，仍可滚动和点击。
- **全屏**：铺满视口，`--canvas` 表面，没有描边和圆角；消息区与输入区沿用放大窗口的 760px 阅读列居中，顶栏贴两端。页面在过渡结束后隐藏并锁定滚动，还原时回到原来的滚动位置。
- 默认半屏。窗口顶栏的放大／还原按钮在半屏与全屏之间切换；选择只存本页内存，下次打开沿用。视口窄于 1280px 时放不下半屏，直接全屏，并隐藏放大／还原按钮；视口变宽后回到所选形态。
- 窗口顶栏没有拖动区，依次为标识、标题下拉、放大／还原、更多、收起。收起按钮、Esc 和 ⌘J 都回到输入条。
- 窗口打开期间头部没有输入条，目录由窗口输入框的目录标签承担，设置胶囊只留设置按钮。半屏时头部收成一行：字标、靠右的四枚车间入口和 34px 设置胶囊。
- 离开 HOME 时，窗口回到该车间记忆的浮动位置与形态，内容不变；回到 HOME 时按所选半屏或全屏停靠。

**过渡**

- 输入条与窗口之间用浏览器原生 View Transitions。输入条的表面连续变形为窗口表面（圆角、填充与描边），旧内容在 160ms 内淡出，新窗口内容按 B v5 的入场动画出现；提问文字从输入条移到提问气泡，收起时未发送的文字移回输入条。字标、设置胶囊、车间入口、区头、继续大卡、卡片和可见的图片各自移到重排后的位置，图片缩放，文字不缩放。只消失的部分淡出，只出现的部分以透明度加 4px 上移出现。
- 半屏与全屏之间是同一窗口的几何过渡（上、右、下、宽、圆角与表面）。
- 输入条下方的状态行出现或消失时，头部和下方内容按同样方式重排，输入条表面不变。
- 时长与曲线沿用 ASK 浮窗的 520ms `cubic-bezier(.32, .72, 0, 1)`，淡出和出现取 `--t2`／`--t3`。过渡名只在过渡期间设置并在结束、打断或离页时清理；View Transition 更新回调等待 Vue 更新后同步测量，不等待被截图阶段暂停的动画帧。被进行中滚动行裁切或在视口外的图片随页面淡出。浏览器不支持或减少动态时直接切换。

**收起后的输入条**

车间里窗口收起后由运行胶囊、结果卡和「已写入」胶囊承接；HOME 上由输入条承接，用同一份 `mode` 与收起判定：

- **运行中**：ASK 标记由内向外呼吸，发送原位换成停止。输入框下方 10px 出现一行状态（高 20px，与输入文字左缘对齐），内容同运行胶囊：当前动作（如「正在读取 定稿 #f3」，对象带微光）和已完成工具数（如「2✓」）。点击该行打开窗口。运行中可以继续输入，但不能发送；停止与窗口里的停止相同，本轮不计入对话。
- **有结果**：该行改为结果与收起按钮。结果为「已完成」「未能完成」或「已停止」，加上回复首句摘要（单行省略），以及「继续对话 ↗」（失败或停止时为「查看详情与重试 ↗」）；点击打开窗口，× 收起该行。
- **草稿待确认**：该行写「草稿待确认」与草稿标题，末尾为「核对草稿 ↗」，点击打开窗口核对与应用；不在输入条上直接应用，也没有 ×。
- **已写入**：只有 `slate_edit` 的草稿应用后留在 HOME，该行显示「已写入」，3 秒后消失。
- 收起规则与车间相同：打开窗口时，已有的结果视为已看过。窗口打开期间完成的回答，用收起按钮或 ⌘J 回到输入条后仍显示结果行；按 Esc 收起则不显示。切换会话时该行收起。

### 7.2 状态

- `<workspace_state>` 的 `workspace` 增加 `home`；活动画板与 CHAT 状态照旧发送。
- HOME 摘要包括：各线简表（线 ID、类型、标题、可读取的脸编号、状态句）；定稿数量，以及最近若干项的 `#f` 编号和来源链；活动任务板沿用 `active_slate`。暂存副本没有编号，ASK 不读取。
- 不预载历史词文或图片像素，需要时仍由现有工具读取。

### 7.3 草稿

沿用现有步骤和应用行为，不新增草稿类型：

- IMAGE 草稿（常带 `new_board_name`）：按钮为「切到绘图并新建」或「切到绘图并应用」，点击后切到 IMAGE 并写入，不生成。
- `chat_handoff`：按钮为「切到对话并新开」，写入后不发送。
- 只有 `slate_edit` 时留在 HOME；新待办写入任务板，未绑图前不在 HOME 显示。
- 按钮文案中的「切回」在 HOME 改为「切到」。

### 7.4 拖入

- 拖到输入条或 ASK 窗口：图片与文本、设定文件都进入 ASK 附件托盘，窗口未打开时随之打开，不自动发送。投放提示与窗口内相同。
- 拖到页面其他位置：图片以该图打开 EDIT，与「精修图片」入口相同；其他文件不处理。
- 页面上不写拖入提示。

### 7.5 提示词

`workspaces` 当前为 v19，说明 HOME 的草稿目标与独立 EDIT 的权限边界，只写事实：

```text
### HOME 首页
- HOME 汇总各画板与 CHAT 会话（每条创作线一张封面）、收藏定稿与活动任务板，不是生成工作区。workspace 为 home 时，仍可按活动画板状态提交 IMAGE 草稿，或用 chat_handoff、slate_edit 推进；应用 IMAGE 或 CHAT 草稿会切到对应工作区，仍不生成、不发送。
- 定稿即收藏 #f，可能来自 IMAGE、CHAT 或 EDIT，来源链为可读文字。
```

### 8.2 确认的形态

方向为「看片台」：HOME 是同一张创作台上整理印样的那一面，是外壳中的首页视图，不是网站首页。

- **外壳与标识**：HOME 不放外壳顶栏，底色为 `--canvas`，没有渐变或环境光。页面从自己的头部开始：字标沿用现有品牌组合，是页面唯一的品牌；宽屏时字标、输入条与车间入口居中，目录与设置收在右上角一枚与输入条同材质的胶囊里；额度不在 HOME 显示（§6.1）。
- **图片**：脸、最近的图与定稿都是 `.print` 画框，完整显示、不裁切，图上不常驻文字；不加光晕、高光和噪点。竖图是常态，横图按比例变宽。
- **容器**：只有 ASK 输入条（及同材质的设置胶囊）、信息胶囊和入口胶囊。继续大卡与其他卡片都不加卡片底色和边框，不出现框里套框。文字栏与卡片说明里的胶囊用 `--raised` 填充、不描边；任务板入口沿用词典 `.tag-filter` 的描边胶囊，车间入口沿用 CHAT 起始页 `.chat-starter`。
- **层次**：区头 18px 中粗加 22px 等宽计数胶囊；线名在大卡为 22px、在卡片为 13px；状态 `--fg-2`，元信息 `--fg-3`，数字等宽；小字不低于 `--fg-3`。
- **操作**：继续是扁平主按钮附 ↵ 键帽，点击脸也可以继续；HOME 不新增实体按钮。
- **版面**：内容列取视口 84%、最宽 1080px 居中，向中间收拢；区块间距不超过 `--sp-7`；不使用大标题或眉题。首屏在 1280×720 时仍能露出头部，以及继续大卡与相邻卡片的完整高度。
- **动效**：入场为透明度加 4px 位移。输入条与 ASK 窗口之间的过渡见 §7.1；点击卡片进入车间的共享元素过渡同样使用浏览器原生 View Transitions。两者均已实现；不支持、目标没有同一张图或减少动态时直接切换。
- **窄屏**：860px 及以下内容宽 `100% − 32px`；560px 及以下字标靠左、胶囊靠右，输入条与入口铺满；大卡按 §6.2 上下排布，其他卡片横向滑动；输入条留在头部，不固定在底部。视口窄于 1280px 时 ASK 直接全屏。

设计语言 §9 已登记 HOME 布局、表面与停靠特例：

- HOME 信息胶囊：设计语言 §4.3 原则上不用底色表示层次；HOME 的状态、计数与草稿摘要按用户在 HD 的要求收成填充胶囊，前提是外层不再有卡片框。
- 设置胶囊：与 ASK 输入条同材质（`--raised`、`--line-2` 描边、阴影），作为输入条的附属，不按普通工具栏按钮处理。
- 预览里的个别半透明值（胶囊填充、定稿说明的底部渐隐）实施时换成现有变量；确需新值时先登记。
- ASK 停靠窗口：B v5 的统一玻璃材质在 HOME 停靠时改为实色表面（半屏 `--chrome`，全屏 `--canvas`），符合 §4.6 毛玻璃「只用于浮在工作区上方的 ASK 容器」。
- 输入条里的发送／停止为 36px、图标 `--ico-md`，大于 B v5 输入框的 28px，与 56px 输入条同心。

## 9. 边界情况

| 情况 | 处理 |
| --- | --- |
| 刷新 | `#h` 与画布照常清空；画板的脸改用暂存副本，没有暂存时用占位封面 |
| 最新图被「保留历史」上限裁掉 | 改用暂存副本 |
| 画板被删除 | 线、暂存与封面指针一并删除；收藏保留，来源链写「已删除的画板」 |
| 收藏被取消 | 若它是封面，退回默认的脸 |
| 生成进行中进入 HOME | 对应线的状态句显示进度；生成不受影响 |
| Photopea 修改未回传 | 对应线的状态句为「高级编辑未应用」；实例保持存活 |
| ASK 打开时视口缩窄到 1280px 以下 | 半屏改为全屏并隐藏放大／还原按钮；视口恢复后回到所选形态 |
| ASK 收起且运行中时离开 HOME | 车间以运行胶囊承接；回到 HOME 时输入条显示运行行 |
| 多个标签页 | 已打开的页面按本页记录的上次位置；新打开的页面读最后写入的位置；封面以最新提交为准；暂存比较源图时间，较旧结果不覆盖较新结果 |

### 10.3 验收要点

1. 连续抽卡时，脸跟随该画板最新图；设为封面的收藏不会被新图顶掉。
2. 刷新后 `#h` 与画布仍然清空；HOME 用暂存副本显示各画板的脸。
3. CHAT 结果可以收藏，来源链正确，出现在定稿区和 IMAGE 收藏列表中。
4. 绑图不新增收藏；未绑图的待办与没有图的线不进陈列，「继续」大卡没有图时用占位封面。
5. 不带路由打开时进入 HOME；显式路由按原样打开。
6. 「继续」回到正确的车间、画板或会话；同一页面内能回到 EDIT。

8. HOME 本身不发起生成、报价或额度请求，也不显示额度。
9. 刷新后最近的图改用该画板的收藏，没有时不显示；定稿的行／列／拼图选择在刷新后保留。
10. 头部在四种宽度及 1280／1920px 下不溢出；ASK 半屏时头部收成一行，目录只出现在窗口输入框。

## 12. 与概念稿及早先草案的差异

| 项 | 概念稿／早先草案 | 本文 |
| --- | --- | --- |
| 刷新 | 打开或刷新都进入 HOME | 不带路由打开时进入 HOME；显式路由刷新停在原处 |
| 图片丢失 | 文字封面「原图已随刷新清空」 | 先用暂存副本，没有可显示的图才用占位封面 |
| 脸的取法 | 车间 Pin > 最近精修 > 最近生成 | 设为封面的收藏 > 最近画布图（含精修）> 暂存 > 占位封面 |
| 设为封面 | 可在历史胶片、CHAT 版本、EDIT 结果上操作 | 只在定稿大图中对收藏操作 |
| 绑图 | 自动收藏 | 不收藏，成果仍只在 Slate |
| 来源链 | 存 `#h4 → #c2.1` | 从参数推出可读文字 |
| 应用草稿 | 不跳转，草稿卡提供「去画布」 | 沿用现有按钮，点击应用即切到对应车间，仍不生成、不发送 |
| 车间新增动作 | 设为封面，以及 CHAT／EDIT 收藏 | 只有 CHAT 收藏 |
| 导航 | 「Logo 即 HOME 入口，车间 Tab 不变」 | 没有 Tab；车间 Logo 下拉菜单首项为 HOME，HOME 用头部入口、「继续」与 `G` 进入车间 |
