# 测试组织与按需加载整理

日期：2026-10-29。基线：`79dbd72`。本记录针对本地工作树，不代表已推送或发布。

## 范围

- `scripts/test-browser.mjs` 自动发现所有根目录浏览器套件，支持按文件前缀筛选、清单预览及两个文件并行；完整入口包含发布包检查。CI 在 `npm run check` 后调用同一入口。
- ASK 与原生协议大文件按功能拆分，原 95／45 个注册语句（含参数循环）保留。ASK 与 HOME ASK 共用模拟连接和响应；原生协议共用图片与请求准备。
- Vite 测试服务器按套件隔离缓存、固定预构建依赖并关闭 HMR；HOME 数据测试通过测试模块导入 Vue，不引用优化器内部缓存路径。
- 将五处用于等待已有状态就绪的固定休眠改为状态等待。验证无报价／无生成的观察窗口、动画中间帧等仍保留。
- 设置、Photopea 与任务总览按需加载；设置首次挂载后保留同一 dialog，Photopea 继续原位保留 iframe。工作区和应用服务的生命周期保持既有所有权。

测试整理以覆盖和可维护性为准，不按语言占比删除测试或转换扩展名。没有修改 GitHub Linguist 分类。拆分增加少量入口代码，测试总字节数没有显著缩小；共享准备逻辑和较小的功能文件减少重复维护。

## 构建测量

同一构建配置下，基线初始 JS 为 1,246,762 字节；新入口及其全部静态依赖合计 1,163,368 字节，减少约 6.7%。分别 gzip 后合计约从 445,079 降至 423,618 字节，减少约 4.8%。分块压缩与单文件压缩不同，不能仅用主入口缩小的比例描述实际传输收益。

三个延迟界面约 94 KB，只有首次使用才请求。全部应用 JS 分块合计为 1,257,659 字节，比基线增加约 0.9%；分块入口与跨块导出有额外开销，收益在初始加载量。核心工作区与 ASK 服务仍随应用加载，构建的大块警告仍存在；本轮没有改变 KeepAlive 导航或图片任务时序。
