## 已落地行为

- EDIT 蒙版由会话画布持有，同尺寸版本／底图／查看图／手动结果沿用；主动清空和不同尺寸才重置，不从版本快照恢复旧蒙版。查看图的蒙版单改与设底图共同撤销／重做。
- Photopea 初始化三层可见工作栈及用户已接受的隐藏锁定选区辅助层；既有蒙版还原为专用层且没有残留选区。回传默认自动，提供仅图像／仅蒙版；图像与区域完全校验后提交。
- 同图重入不打开回传 PNG，保留实际文档、普通层／分组和历史；外层改动只刷新专用蒙版。同尺寸换底保留工作栈，隐藏已烘焙的旧修补／自定义根级层并建立新修补层。
- 导出使用临时内存 PSD（128MiB 上限）而非操作原文档的历史状态；PSD 元数据检查专用角色的附加光栅／矢量蒙版及效果，完成后关闭临时文档。独立图像／蒙版仍受 8MiB、3200 万像素和严格尺寸检查。
- 仅合法空覆盖可清空。角色缺失、结构变化、来源失效或输出不完整不半写；已知脚本错误显式回执。没有收费生成、自动重试或费用／路由修改。

## 公开 API 的核验结论

- `Document.duplicate`、部分通道 API 不能按完整 Photoshop API 假定。直接改变原文档再回到 `activeHistoryState` 会破坏已存在的重做分支，因此改用临时 PSD 副本。
- 公开 `layer.id` 在同一文档的改名、重排及回传后稳定。Photopea 跨文档 duplicate 从输入文档分配 ID，且不会完整推进目标计数；输入通过预留 ID 和临时占位避免碰撞，目标活动层为嵌套层时先切到根级，完成后恢复。宿主拒绝重复根级 ID。
- 解释器会忽略部分 `throw`／`finally`，`try` 内直接 `return` 的值也不可靠。结构检查使用显式编号错误回执并返回；选区读取在 `try` 外返回结果。未支持操作仍可能超时，由通道隔离阻止写回。
- 从隐藏锁定的不透明辅助层复制选区不增加原文档历史项；在后续完成的命令中粘贴到临时文档，才能稳定导出。此操作替换 Photopea 内部剪贴板内容。

探索期间的失败试验在确认原因后均已修正；只采用上表通过的最终路径，不把中间失败或旧 PE 套件成功冒充当前验证。

## 保留边界

- 分层保留仅在当前保活文档内。不同尺寸／EDIT 会话、显式重载、不可恢复通道重建和页面刷新会重建工作栈；没有 PSD 数据库存储或跨刷新恢复。
- 辅助层在选区外接矩形内必须完全不透明；扩展画布后选到未覆盖区域会拒绝，不静默取交集。辅助层不参与图像与最终蒙版合成。
- 专用层需保持独立根级像素层。默认名称和常见副本名可识别；复制后彻底改名的普通像素层不能可靠反推用途，不按颜色清理图像内容。
- 换底保留旧底图，已烘焙图层隐藏而非删除。依据会话内可追踪祖先关系；不猜测独立外来图片是否包含旧修补。原图角色合并／删除后，换底要求先保留需要的 PSD 再重载。
- 当前 API 输入限制图层 ID 不超过 10,000，超过时提示保存分层文件后重载，避免构造大量临时输入层。
- 实际 Safari、移动真机、复杂蒙版／效果／大工程的长时操作仍待独立验证；Playwright 触摸模拟不等同移动设备。没有执行真实 NAI 生成、扣费验证或 Pages 发布后验收。
