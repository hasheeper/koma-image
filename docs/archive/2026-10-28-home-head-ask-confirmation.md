## 预览与规划的差异

收起后的输入条在规划中与浮窗共用同一份状态和收起判定，因此有几处与预览不同：

- 停止：预览直接去掉状态行；规划按浮窗显示「已停止」结果行。
- 窗口打开期间完成的回答：预览收起后不显示结果行；规划沿用浮窗，用收起按钮或 ⌘J 回到输入条后仍显示，按 Esc 收起则不显示。
- 草稿待确认、失败、已写入行与拖入：预览未做，规划按浮窗规则写定（草稿只在窗口里核对与应用）。
- 定稿：预览另有「拼图」选项，未选择时窄屏默认列对齐；规划仍为行对齐与列对齐两种，默认行对齐。

## 实施后调整

HM3 接入后，用户在实际页面上先后提出四处问题，直接在 `src/home/` 调整，规则已写回 HOME 规划 §4.2、§6.1、§6.2、§7.1、§8.2 与设计语言 §9：

| 问题 | 处理 |
| --- | --- |
| 头部太大、重心偏左 | 宽屏改为居中：字标在第一行正中，输入条宽 min(内容列, 720px) 居中，车间入口居中，设置胶囊在右上角；字标缩到 36／32／12px（手机 32／28／11px），取消向左探出。560px 及以下保持字标靠左、胶囊靠右 |
| 继续大卡没有最近的图时中间空 | 文字栏宽度随内容在 200–400px 之间；没有最近的图时线名、元信息与按钮整组靠下，按钮仍对齐脸的底边。另试过整组靠上，按钮悬在中部，未采用 |
| 没有图的继续大卡只有暗底与重复标题 | 改为占位封面：`--chrome` 面板加 `--line` 描边，正中是车间方块标识的淡水印，不写标题；上下排布时为整宽 160px 横条。水印先用 56px，用户认可浓淡后放大到 80px（横条 64px） |
| 只有一条继续时整页偏空 | 没有其他卡片时不加渐隐，文字栏上限放宽到行内剩余宽度，最近的图多排几张；同时没有定稿时，561px 及以上「进行中」整区收拢并随头部居中。有定稿时保持左对齐，曾在此时居中，与定稿左边错开，未采用；手机居中会与靠左的字标错开，也未采用 |
