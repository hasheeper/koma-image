# EDIT 独立工作区迁移与收口核验

日期：2026-10-28。核验对象为 `codex/ask-chat-handoff` 工作区，Git 基点 `1fd1be3`，包含尚未提交的本地改动；不代表该提交或线上站点已经包含本次实现。本轮没有提交、推送或发布。

## 实现范围

- EDIT 从覆盖层迁至 `#/edit`，与 IMAGE／CHAT 同级；旧 `#/<workspace>/editor` 地址归一到新路由，设置关闭后仍回到 EDIT。
- 独立来源图片创建独立编辑画板；图生图、重绘、放大与手动修图成为板内衍生版本。按稳定来源重开时定位已有画板，保留当前参数和版本。参数、蒙版、视图和资源按画板隔离。
- 切页和换板不取消已提交的任务，结果及错误回到发起画板。异步 CHAT 参考图回传冻结来源会话，中途换板不会改写当前板错误或跳转到其他会话。
- EDIT 首次挂载后原位隐藏保活；单个 Photopea iframe 保存多个画板的分层文档，A → B → A 保留 A 的自定义层。关闭画板串行释放对应文档。
- HOME 可继续当前编辑画板，直接读取板内版本原图；EDIT 中隐藏 ASK。工作区菜单移除任务总览，既有绘图顶栏任务图标、会话内 Todo 与 HOME 活动任务入口继续使用。
- 编辑画板胶囊、列表与管理菜单沿用 IMAGE 样式；修正画板与模型之间多余留白，并确保展开参数抽屉时重绘强度不被压缩到不可操作。

现行行为与保存边界见 [EDIT 工作区](../edit-workspace.md)。本轮同步了架构、业务契约、产品／设计／样式入口、HOME、ASK 与 Photopea 文档；工作区提示词更新为 v19。
