# ASK NAI 基础感知与 EDIT 接入验收

日期：2026-10-29。范围为获批的 EA0 → EA1 → EA2 → EA3；代码和本地模拟验证已完成。现行契约见 [NAI 基础感知](../ask/ask-nai-awareness.md)与 [ASK × EDIT](../ask/ask-edit.md)，原始方案见 [EA0](2026-10-29-ask-nai-awareness-plan.md)及 [EA1–EA3](2026-10-29-ask-edit-plan.md)。

## 实施结果

- EA0：IMAGE／EDIT 共用只读能力、生效参数、分段 token／Text 与费用快照；新增 `check_nai_input`，候选检查不创建草稿或分配真实角色 ID。费用只读匹配缓存或调用本地公式，连接修订及过期状态有校验。
- EA1：EDIT 使用既有 ASK 浮窗；冻结活动编辑板、版本身份、表单、蒙版几何及聚焦框，支持按需读其他板。Photopea 打开时收起 ASK 并让出快捷键。
- EA2：编辑词文、角色、模式、强度／噪声、Enhance、聚焦框、Director 预设通过共享卡片确认；支持任务／文件组合、冲突、补偿和撤销。应用、撤销与恢复保持底图／蒙版，清除旧价，不主动请求报价、额度、编码或生成。
- EA3：`edit_handoff` 创建或复用编辑板，应用后留在原页，检查点提供「去编辑」；`#e → CHAT` 保存原图或转换后的实体与来源。Bridge 保持 IMAGE 写入范围并拒绝 EDIT 新步骤。

提示词同步为 `c12.w23.m8.k8`，工作台摘要为 v7。EDIT 输出仍不自动进入 `#h`。

## 新增链路证据

1. 实际 ASK 请求携带 EDIT 画板、两个蒙版区域、`#e` 底图与可用 token 结果；不夹带蒙版像素、Blob URL 或凭据。候选「blue sky + 启用角色」实际 T5 正向为 9、负向为 2；没有新草稿、持久写入或角色序号消耗。
2. 同稿切为聚焦重绘、改词并预设表情后，可以整份应用／撤销／恢复；IMAGE 词文、底图和蒙版保持原值，旁路报价／额度／生成请求数为零。
3. 用户在审阅期间切板，写回冻结原板；补涂到聚焦框外或打开 Photopea 后阻止应用，草稿保留。
4. `edit_handoff` 对 513×512 来源给出尺寸提示，创建时不缩放、不导航；未操作的新板可撤销移除并恢复，已有板复用时不更换底图。
5. `#e` 交给 CHAT 后原始字节与来源引用跨刷新保留；通过既有参考尺寸限制触发转换时产生新实体，记录原实体与 `reference-fit`。
6. 人为制造 Slate IndexedDB 写入失败，EDIT 配置回滚、任务未半应用、卡片仍可确认；重试成功后捕获最终配方，撤销同时恢复配置与任务。全过程未发起费用请求。
7. 在 320／390／768／1440px 检查 ASK 浮窗边界和已有紧凑卡片路径；Photopea 期间 ASK 快捷键不重新拉起窗口。既有回传测试同时覆盖同尺寸蒙版沿用、取消、版本切换与显式交付。
