# HOME HD 页面形态确认

日期：2026-10-27。范围：[HOME 规划](2026-10-28-home-plan.md) 的 UI 设计阶段（HD）。只有本地预览，`src/` 未改动；未推送、未发布。预览载入真实的 Koma 样式表与组件样式快照，数据为演示数据，图片只存本机、不入库，未调用任何生成接口。

## 比较过的方案

预览位于被 Git 忽略的 `.local/home-ui/`。打开时的默认值就是确认形态；下列候选保留为查询参数，只作对照。

| 项 | 候选 | 确认 |
| --- | --- | --- |
| 继续区（`hero`） | A 单张大图；B 大图与说明分栏；C 横幅；D 大卡领头、与其他线并排 | D，并与相邻卡片上下边对齐，元信息收成胶囊 |
| 定稿（`fin`） | 行对齐（等高行）；列对齐（等宽列） | 两者都提供，可切换，默认行对齐 |
| ASK 入口（`dock`） | `glass` 底部玻璃条；`pill` 底部窄胶囊、点击展开；`island` 右下角方块与卡片；`head` 页面顶部输入条 | `head` |
| 继续大卡（`lc`） | `fill` 带底色的卡片；`open` 去掉卡片框、文字直接放在衬纸上 | `open` |
| 字标（`logo`） | `above` 字标在输入条上方；`side` 字标与输入条并排 | `above` |

迭代中用户提出的问题与处理：

- 大卡里框套框、通透感差：去掉卡片底色与边框，只保留图片画框和信息胶囊。
- 文字栏罗列一串 Tag 不好看：不显示 Prompt 与参数。
- 去掉 Tag 后中间太空：加入一行「最近的图」，高度随行高变化，放得下几张显示几张。
- 底部输入条不好看：改为页面顶部输入条，随页面滚动。
- 需要 Logo 但不要太大、不要商业化：沿用现有品牌组合，取 ASK 起始页的尺寸，左对齐，不加底板。

确认后的规则写回 HOME 规划 §6–§8。

## 检查结果

| 检查 | 结果 |
| --- | --- |
| 横向溢出与控制台 | 320／390／768／1280／1440px 页面横向溢出均为 0，无控制台错误；超出视口的只有进行中横向滚动行里的卡片，被滚动容器裁切 |
| 「继续」按钮是否被遮挡 | 四种入口在 1440×900、1280×720、768×900、390×844、320×844 下都不遮挡（两组演示数据）。320×568 下三种固定入口会压住按钮；顶部输入条不遮挡，但按钮在首屏以下 |
| 定稿切换 | 1440／390／320px 分段高 32px，窄屏不竖排；切到列对齐后分别为 5／2／2 列，选择写入地址参数 |
| 最近的图 | 1440×900 显示 4 张（高 124px），1280×720 显示 5 张（高 86px），768px 显示 4 张；上下排布时隐藏 |
| 设计语言自查 | 小字不低于 `--fg-3`；间距取 `--sp-*`；HOME 不新增实体按钮。填充信息胶囊与个别半透明值待 HM2 登记或换成变量（HOME 规划 §8.2） |
