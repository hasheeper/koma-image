# ASK 调用上下文调试

用户于 2026-10-22 要求查看每次实际调用的上下文和缓存信息，并选择本次只做查看、复制与导出，不增加手动会话回滚。

## 入口与记录

ASK 顶栏更多菜单的「调用上下文」查看当前对话及本页画板命名记录；每轮回复底部的同名入口查看该轮，导出全部包含所有对话。工具循环中的每次模型请求各记一条，包含模型、协议、提示词版本、时间、耗时、响应状态及结束原因。失败或停止的调用也保留，失败轮次仍按原事务规则从后续模型上下文中回滚。

2026-10-23 新增的独立 AI 命名请求同样逐次记录，可在顶栏更多菜单的「调用上下文」中查看「AI 命名 · ASK／画板」。提示词版本为 `naming-1`、轮次为 0，命名不向 ASK 会话追加消息；用量计入本页总量。命名运行时也禁止清空请求记录。

2026-10-24 CP2 新增「压缩」调用标识（`purpose=compaction`，轮次为 0），并标记压缩成功后实际分发的首次普通调用（`afterCompaction=true`）。压缩不作为用户问答追加到会话；失败／停止仍保留原始载荷和已报告用量。导出保留这两个标识，收藏不保存调用调试。CP3 已接入更多菜单中的手动入口与发送前自动压缩；记忆行展示当前账本，调试保留实际冻结的发送记忆。

记录在 `provider.ts` 的实际 fetch 分发处捕获序列化后的请求体，位于词表处理与协议转换之后。面板支持按请求顺序查看工具定义、系统提示词、历史消息、工作台快照、提问、工具调用与结果，或查看请求 JSON。图片仅在预览中折叠 Base64，缩略图使用实际发送的处理后图像；复制请求与导出记录保留完整字节字符串。

复制得到原始请求 JSON。导出的 `koma-ask-calls-*.json` 为 `app=koma-ask`、`kind=call-debug`、`version=1`，每条记录的 `body` 字段保存原始请求 JSON 字符串。不会记录 HTTP 头、Key、本地代理令牌或上游地址。导出不会重新发送请求，也不是备份或恢复格式。

## 缓存信息的含义

- 输入、输出与缓存计数来自上游响应。缓存字段缺失、无效或响应未完成时显示「未报告」；明确返回的 0 显示为 0。
- 「缓存命中」是已从缓存读取的输入 token。「未从缓存读取」为输入减去缓存读取，包含新建缓存；读取计数未知时不推算。Anthropic 的输入总量沿用适配器的普通输入＋缓存读取＋缓存创建归一化，缓存创建仍单列展示。
- OpenAI Chat 兼容协议不新增缓存请求参数；由上游决定是否使用自动前缀缓存。Anthropic 显示请求里真实存在的 `cache_control` 路径，标记代表申请缓存，不代表已命中。
- Anthropic 的 tools 末尾、System 末尾、最新消息末尾继续保留断点；存在实际 `<session_memory>` 消息时增加第四个断点，不从用户正文猜测记忆消息。静态前缀只在用户配置不变时稳定，命中仍以上游 usage 为准。
- 分块比较只与保留的同连接、同协议、同模型前次调用比较。忽略 `cache_control` 后标出相同、变化与新增内容，并列出连续相同的前缀块数量。这是本地内容比较，不能当作服务器缓存结果。
- 上游只提供累计 token 计数，不能据此精确给每段文字标注「已缓存／未缓存」。面板明确区分缓存用量、显式标记和本地比较，不伪造逐段命中信息。

## 生命周期与边界

调试记录与会话分开，仅保存在本页内存，不写入 localStorage、数据库或普通备份；刷新后清空，不能重建更新前已发送的请求。最多保留最近 20 次和约 16 MiB 的请求字符串（按 UTF-16 内存估计），超限释放较早记录；单次超过限制时完整保留最新一条，避免静默截断。面板显示释放数量，可手动清空已保留记录；请求运行中禁用清空。

Vue 仅持有低频摘要与选择状态；原始 JSON 和图片字节留在普通内存记录中。查看面板使用原生 dialog，通过 Vue Teleport 挂载；Esc 只关闭查看面板，不忽略草稿或停止后台正在运行的 ASK。关闭、卸载时释放面板与图片预览，应用服务销毁时清空调试记录。调试不更改发送载荷、缓存标记、会话提交、工具预算或生成权限。
