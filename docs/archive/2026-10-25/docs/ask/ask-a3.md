# Koma ASK A3：CHAT 上下文与分支草稿

2026-10-21，分支 `codex/ask-a3`，接续 A2 `ba297e6`。

新增 `get_chat_context`：发送时锁定当前会话当前分支，包含各轮文字与勾选、底图、跟随状态、图片限额与超出数量、已知额度及实际发送文字。其他分支不自动附带。已完成的当前版本使用 `#cN.M`，可由现有元数据和视觉工具读取，仍受图片预算约束；不向模型发送内部资产 ID、路由和原始额度响应。

`chat_distill_branch` 独立成稿，三步分别为锁定起点、可撤回的文字排除、可撤回的提纯描述。来源必须是当前分支已完成的选中版本。确认后复用 `selectSource` 的底图／起点规则，重设勾选并填入输入框，不创建生成轮次、不发送、不报价。下一次用户发送时才形成新分支。

对话选择、引用、版本、轮次完成或输入改变会使旧草稿失效。写入再次核对会话指纹，运行中的 CHAT 拒绝分支写入。保存经现有数据租约；失败只在仍为本次草稿状态时回滚。撤销恢复起点、底图、勾选和文字，选择修订号继续递增，防止迟到结果覆盖；无关的会话重命名不会阻止撤销。

预览复用 A2 草稿卡，增加锁定起点、分支切片与输入光标；减少动态时关闭光标动画。支持 320／390／768／1440px。

验证：阶段内 `npm run check` 通过（115 项单元测试、样式、严格类型和构建）；新增 S6 浏览器流程通过，验证确认前状态不变、上下文工具、逐步恢复、应用、一次撤销、外部变化冲突和零 CHAT 发送／生成请求。合成图片、模拟推理，截图保存在 `.local/ask/a3/`，不代表真实模型的提纯质量。随后在 A4 集中回归中，119 项单元测试及 78 项浏览器／发布包检查全部通过，见 [A4 记录](ask-a4.md)。
