## 1. 草稿协议

工具注册表新增 `propose_draft`，总计 8 个工具。工具只拿到发送时的表单／CHAT 输入框副本、图片元数据快照和本轮问题，不持有写入端口。

- 一轮最多提交一份草稿，成功提交后立即结束工具执行；同一回复里后续工具不执行，但补齐对应调用 ID 的结果以维持协议完整。2026-10-23 收口：整轮无正文时仅补一次说明请求（tool_choice=none），不会再次执行草稿，见实施规划 §2.10。
- `base_hash` 必须与本轮发送快照一致。一份草稿只指向一个工作区，含 1–12 步。
- `prompt_patch`：`replace`（空字符串为删除）、`before`、`after` 使用唯一子串锚点；`append` 追加；`rewrite` 提供完整新文本。
- `restore_partial`：从本轮图片 ID（如 `#h1`、`#f1`）选择已有参数。数值由本地快照读取，模型不能提交替代值。来源缺失的字段禁用，不用导入默认值清空当前输入。
- 提交后仍等待显示节拍和轮次事务成功才展示卡片。停止、错误和失败轮次不会留下可应用的草稿。

`image.char.N.prompt/negative` 仅预留；当前表单没有角色对象，显示「目标不存在」。A2 支持普通 `chat.composer` 文字草稿；选择分支起点、上下文勾选、`chat_distill_branch` 留到 A3。

## 2. 校验与冲突

`draft/validate.ts` 为纯函数。先精确匹配；无精确匹配时再归一化连续空白、中文逗号和逗号两侧空白，并映射回原文偏移。多处匹配、重叠歧义或不存在的锚点均禁用，不猜测位置。

发送后发生外部修改时，局部锚点仍唯一则按当前文本对齐，并明确显示提示。整段改写／追加在目标原文已变化时禁用；参数按字段检查发送快照，其他无关字段的修改不会被覆盖。步骤按顺序计算，撤回前一步后，依赖它的后续锚点重新校验。界面按钮携带已展示预览的指纹；点击与写入前分别复核，过期预览不能直接应用。

画师保护使用词典内存中分类 1 以及显式 `artist:` 标签，检查删除、新增、顺序、原始权重写法和未取整的有效权重，包括跨逗号权重组。只有本轮问题明确点名并要求修改的画师例外。识别意图使用保守规则：带「保留」「不要」等否定词的同一句不授权修改；复杂表达可能需要重新明确提问。词典未加载的未知画师仍是 A1 既有识别边界，不能声称覆盖完整画师库。

参数恢复与图片导入共用 `prepareDrawingFields`，沿用步数、Scale、CFG 的原有范围和步长；额外核对尺寸、种子（包括 0）、批次、可用模型及采样器。模型／采样器／尺寸的组合无效时一起禁用，防止写入时隐式调整未展示参数；其他有效步骤仍可选择应用。

## 3. 界面与写入

`DraftCard.vue` 位于 ASK 输入框上方，使用站内 tokens 和组件私有样式：

- 局部增删以原文上下文、删除与新增片段预览；多步带编号、连接线与当前步骤强调。
- 整段改写提供「新稿／原文」切换，保留词的 `.keep` 下划线由本地大小写不敏感匹配计算。所有模型文本用文本节点显示，不解释模型 HTML。
- 参数恢复采用三列核对卡，显示旧值／新值、逐字段撤回／恢复，模型与采样器显示可读名称。卡片内部滚动，标题、应用按钮和输入框保持可达。
- 无效步骤灰显并说明原因，可显式「基于当前内容重新提议」。全部撤回或全部无效时禁用应用。
- 应用后收为「已写入表单 · 未生成」或「已写入输入框 · 未发送」，消息流写入操作记录并读屏播报。

`draft/apply.ts` 是 ASK 唯一持有写端口的模块，只被用户确认与撤销调用。跨工作区时按钮标为「切回绘图并应用」／「切回对话并应用」，切换成功后才写入；文本写入后聚焦目标输入框末尾，复用现有输入高亮。

绘图与 CHAT 分别增加 `writeDraft`，复用原服务与数据租约保存。草稿写入和撤销会使旧报价失效，但不发起报价、额度、生成或 CHAT 发送请求；绘图下一次手动编辑恢复原自动报价流程，生成按钮仍按现有执行链路重新报价。保存失败回滚仍等于草稿值的字段，保留并发发生的手动编辑；如果模型／采样器／尺寸组在等待保存时有手动改动，则保留整组，避免回滚模型时隐式重置新的采样器。

撤销记录只保存最近一次已应用草稿触及的字段。按钮或 ⌘Z／Ctrl+Z 一次撤回；无关字段的后续编辑保留，目标字段已变或 CHAT 会话已切换则拒绝撤销。新草稿替换旧卡及其撤销点，不建立持久化撤销历史。

Tab 仅在抽屉非输入区或 body 上应用，不劫持 Prompt／CHAT／ASK 输入框、选词或输入法。Esc 依次关闭浮层、忽略未决草稿、中止运行轮次、关闭抽屉。模态面板和编辑器继续优先处理按键。
