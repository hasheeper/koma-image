- `AskMemory.vue`：无底色分隔行、记忆／轮次／附件页签、短预览与全文、组件内原文预览、返回／Esc／方向键和引用。
- `AskStream.vue`：运行扫光、可展开原因的简洁失败行和显式重试。复用原停止入口。
- 原文读取仍走原有服务，只增加预览位置标记；普通附件浮层、归档内容、冻结记忆和模型请求保持原有契约。

验收：`npm run check` 通过（226 项单元、字体、样式、严格类型和构建）；9 项相关浏览器用例通过，覆盖 Chat／Messages 的手动压缩、内部预览与引用、长附件滚动、焦点返回、自动压缩停止／失败重试、账本回退，以及普通附件／编辑键盘回归。增加原文预览返回的实际焦点断言，修复切换预览时重建列表导致焦点丢失的问题。最终变更后重跑受影响的 4 项双协议界面／失败流程均通过。320／390／768／1440px 已检查布局，手机和桌面截图已目视复核。
