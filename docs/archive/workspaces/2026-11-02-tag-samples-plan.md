## 来源与网络

- 只识别 `danbooru.donmai.us/posts/<正整数 ID>`，支持查询参数、锚点、尾斜杠与省略协议。其他文字保持原输入，不作为任意网址请求。
- 帖子信息固定请求 `GET https://danbooru.donmai.us/posts/<id>.json`；示例图列表使用 `GET /posts.json`。图片仅接受 `https://cdn.donmai.us` 的可用图片地址。
- 帖子／示例图查询 8 秒超时，图片读取 20 秒超时；匿名请求、无 Cookie、无 Key、无 Referer。不自动重试帖子或图片请求，失败可再次手动操作。
- 帖子及示例图按 ID／Tag 与档位在本页内有界缓存；失败不缓存。成功缓存不能绕过取消信号。
- 原图无法读取时，IMAGE 仍可打开 Tag 勾选面板，并在「其他」中显示原图失败原因。ASK 图片失败时不创建残缺附件，提示错误后可重试。
- 中文释义沿用既有双语词典逐词精确匹配，最多四个并行查询，命中缓存共享。未收录或失败保留原 Tag 与「暂无中文翻译」，不编造释义或丢掉分类。
- 最初实现为浏览器直连，初次验收没有请求真实上游。后续真实使用暴露站点验证拦截，本地模式的修复与验证见下文；静态部署仍取决于网络、跨域和原站可用性。

## 示例图与分级

示例图只在用户点开时读取画师／角色的高分帖子，显示前四张 360px 缩略图。当前档位保持官方 `rating` 的逐级规则：自由创作关闭只显示 g；开启显示 g+s；NSFW 加 q；R18 加 e。q 标 R15、e 标 R18。不按 Tag 文义追加本地分类或过滤。

用户主动提供具体帖子链接时直接读取该帖，不套用示例图的搜索档位；帖子的分级作为来源事实随预览和附件保留。图片是否外发仍由既有 ASK 图片开关及用户发送操作决定。

## 附件与数据归属

- 图片使用已有 `#a` 身份、每条四张及原有字节／像素限制。附件准备期间保留加载态，不能提前发送。
- 元数据绑定到具体附件：`post_id`、`rating`、原帖 URL，以及 artist、character、copyright、general 原始 Tag，保留下划线；不伪装成生成参数或图片反推结果。
- 下载归发起时的 ASK 会话，切换会话不串图；失败不占托盘位置。示例图按钮在下载期间禁用，完成或失败后可再次操作。

- 已收藏会话沿既有 `koma-ask`、数据租约和附件引用路径保存，刷新恢复不依赖 CDN；未收藏附件保持本页生命周期，不进普通备份。

## 同日真实网络故障收口

用户报告画师示例图和帖子链接均提示「连不上 Danbooru」。在用户 Edge 的开发者工具中复现单帖请求 `403 Forbidden`，响应含 `cf-mitigated: challenge`，内容为 HTML 验证页且没有允许跨域读取的响应头；浏览器因此只向前端暴露 Fetch 网络错误。原站页面可打开不代表该跨站 JSON 请求可读。原提示把这种拦截和超时混为一谈。

修复后的本地服务使用清楚标识项目的 Koma User-Agent，匿名读取固定 Danbooru 帖子接口与 CDN 哈希图片，不使用浏览器 Cookie，不接受任意目标或上游跳转。JSON 使用独立会话令牌，与图像／推理连接隔离；公开图片保留同源与固定路径校验，不将令牌放入图片 URL。JSON 限制 8 秒／4MB，图片流式限制 20 秒／64MB，浏览器附件上限继续按原规则。`npm start` 支持显式环境变量代理；静态版与 Vite 不探测转发服务。网络／验证、超时、HTTP 状态与格式错误分别展示。

真实只读验证：

- 用户给出的 `#12477557` 返回四组共 125 个 Tag，页面分类与中文释义加载成功。
- `lulu-chan92` 的全年龄示例图返回并解码四张 360px 变体。
- 首张示例图 `#3576445` 的 sample 解码为 850×618，进入 ASK `#a1` 托盘；没有发送给模型、没有生成或计费。

本轮通过 `npm run check`（严格类型、405 项单元测试、构建），7 项现有 Danbooru 浏览器用例、新增本地生产构建浏览器用例与发布包验证。新增覆盖固定路径、匿名请求、令牌隔离、返回类型与字节上限、超时／取消，以及本地模式下的缩略图／ASK 托盘与供应商设置可编辑性。真实核验仅证明此次本机网络下可用，不证明静态部署能通过原站验证，也不证明模型理解或改写质量。
