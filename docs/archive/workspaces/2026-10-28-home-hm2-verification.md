# HOME HM2 页面与入口核验

日期：2026-10-28。分支：`codex/ask-chat-handoff`。本记录只说明本地代码与模拟核验；未提交、推送或部署，不代表生产版本。

## 落地范围

- `#/home` 默认入口与未知路由归一，保留显式 IMAGE／CHAT／TAGS、设置／backup 和 EDIT 深链；KeepAlive 扩为四视图，Logo 菜单加入 HOME。
- HOME 头部、真实目录与设置、同一 ASK 输入／模型选择和发送入口、四个车间入口；首次空白只有头部。
- 继续／进行中按现有创作线展示，返回活动画板、CHAT 会话与版本、本页匹配的 EDIT 会话；从 HOME 直接编辑返回时记住实际图像／对话来源。`G` 与背景回车保留输入、IME、修饰键、弹窗的边界。
- 定稿直接读取收藏与同一 `#f` 编号，标准行对齐、标准列对齐、有限双图堆叠的拼图分别计算；响应式默认与用户选择分开保存。
- 大图调用现有参数读取、CHAT 票据、EDIT、Slate 交付、封面和取消收藏路径；CHAT 收藏不出现绘图参数读取。仅用于展示的暂存封面不恢复成原图。
- 头部目录复用 `DirectoryChip`，模型选择抽成 `AskModelPicker`；菜单 ID 唯一、停用时关闭。HOME 不显示重复的闲置 ASK 悬浮圆形入口。
