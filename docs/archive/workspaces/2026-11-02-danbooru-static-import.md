# Danbooru 纯静态读取与手动导入

日期：2026-11-02。基线：v0.2.1 后的 main。版本：v0.3.0。状态：本地实现与验收完成，发布待核验。

## 直接读取的实测边界

浏览器分别尝试公开的单帖 JSON 与按 ID 检索的列表 API，均无法完成跨站读取。原站顶层页面可在自己的安全验证流程完成后显示该帖 JSON；随后复查站外匿名读取仍失败。没有跟随登录 Cookie、使用第三方代理或自动操作验证控件。

因此保持原直连行为，以用户手动复制或下载 JSON 为替代，不声称纯静态前端能消除原站的跨域／验证限制。此前 Pages 服务端返回 challenge 的证据见[v0.2 发布记录](../releases/2026-11-02-v0.2-release.md)。

## 实现与验收

- TAGS 欢迎页和帖子错误卡提供导入入口，支持文件选择、拖入与文本粘贴；原生 dialog 复用共享样式、关闭和工作区生命周期。
- 单帖结构、目标 ID、4 MB 大小和分类 Tag 数量校验；只提取已知字段，过滤非公开 CDN 图片地址。手动来源随结果和附件元数据标记，不接受页面 HTML。
- 使用已有本页缓存，IMAGE／ASK 再接收同一链接时不重读帖子 API；不自动发送模型或修改画板，不新增持久库、后端、Worker、Key 或代理发现。
- 本地严格类型、406 项单元测试和构建通过。Danbooru 相关浏览器 9 项通过，包含失败后粘贴、错误及错帖拒绝、文件选择／拖入／取消、离页清理、IMAGE 与 ASK 的缓存复用及附件元数据；全部自动化用例使用合成数据和模拟接口。

静态构建预览没有本地词典转发：真实帖子 #12477557 的原站 JSON 经手动粘贴导入后，125 个分类 Tag 与可用中文释义正常显示；CDN 缩略图本次未加载，页面显示「预览未加载 · 在原帖查看」，分类词块仍可使用。桌面和窄屏导入弹窗已目视检查。这证明手动资料导入可用，不代表自动跨站读取或图片下载恢复，也不是 Pages 发布验收。

现行操作与限制由[设置与 TAGS](../../workspaces/settings-and-tags.md#纯静态模式的手动帖子导入)维护。图片与中文释义仍受各自上游限制，不将模拟结果当作原站可用性保证。
