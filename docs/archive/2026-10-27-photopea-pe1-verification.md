# Photopea PE1：图片、蒙版与纯修图交付核验

日期：2026-10-27。范围：`codex/ask-chat-handoff` 工作区的 PE1 增量；包含前轮尚未提交的 NAI 编辑实现，不将其归为本轮新增。未推送、未发布、未执行真实收费生成。

## 实现范围

- 统一外部回传入口支持图像、选区、图像与选区。来源会话／版本／蒙版修订匹配，图片和蒙版全部校验后才写入；取消、关闭、换会话和重复回传不落入新上下文。
- 仅选区回传核对归一化像素哈希。同尺寸改图也会拒绝单独套蒙版；组合回传的尺寸或内容不合法时不创建半份版本。
- 手动图像是带父版本的 `manual` 子版本，单独记录 `tool: manual-edit`、编辑来源／标识和 `sourceRecipe`；不伪造生成 Seed、费用或耗时。来源生成配方、实际编辑尺寸和手动状态分开保存。
- IMAGE 来源手动版本直接进入历史，可在 EDIT 收藏与下载；保存失败保留版本并可重试。重复保存不重复入库。CHAT 仍显式回传，也可显式存入主历史／收藏。
- Slate 可绑定修图结果，原图与来源配方经原 `data.write` 路径持久保存，刷新后可读取。标注来源显示为来源配方，而非本次修图的“实际发送”。
- 导入黑白／灰度文件与显式 alpha 覆盖分开解释；彩色、空白、尺寸不符拒绝写入。蒙版按底图版本保留，支持位图上的涂抹、擦除、清空、撤销／重做。二值阈值仍为覆盖值大于 32。
- 位图以一位／像素保存并在快照间共享，单份蒙版历史的位图预算为 16MiB，超出后将旧段合并为基底；原生 Canvas 保持指针移动不触发 Vue 更新。

PE1 用例没有配置供应商，并拦截所有非本地请求，证明纯修图的历史／收藏／Slate 链路不依赖生成。额外覆盖：不透明黑白 PNG 不误读为全选、蒙版导入后的擦除／撤销、来源切换恢复、保存失败重试、中途取消与会话切换的迟到结果、相同投递 ID 重复应用、收藏与 Slate 刷新持久化。

本地日志与合成截图位于忽略目录 `.local/pe1/`，不进入发布包。主检查记录为 `check.log`，浏览器记录为 `browser-final.log`、`nai-edit.log`，稳定截图为 `editor-*-settled.png`。
