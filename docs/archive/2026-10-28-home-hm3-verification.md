# HOME HM3 停靠、状态行与动效核验

日期：2026-10-28。基于 `a537b53` 上包含 HM1／HM2 与 EDIT 工作的当前工作区。本文记录本地实现和验证，不代表独立提交、推送或 Pages 发布。

## 实现范围

- `ask/presentation.ts` 统一窗口和 HOME 收起态；头部复用模型、发送／停止、工具活动与完成计数。半屏／全屏与车间浮窗共用窗口、会话、输入和草稿 DOM。
- HOME 默认右侧半屏，窄于 1280px 时全屏，回到宽屏恢复本页偏好；展开、收起及返回车间保留输入、焦点和滚动。半屏用 chrome、全屏用 canvas，与确认稿的实色材质一致。
- 收起行承接真实运行、回答、失败、停止、待确认草稿和已写入状态；草稿必须进入原卡审阅。IMAGE 草稿切到绘图应用，纯 Slate 草稿留在 HOME，不触发生成。
- HOME 状态包含真实创作线和定稿目录；可读取原图才获得图片编号，展示缓存没有编号。输入条／窗口拖入原图或资料只添加附件；背景图片进入 EDIT。
- View Transitions 使用按次注册的共享元素名，Vue／Teleport 管理 DOM；取消、跳转与结束时清理。同步测量在 Vue 更新之后进行，不在过渡更新回调里等待 rAF；减少动态或不支持时直接切换。
- 蒙版状态只在提交的蒙版版本改变后检查覆盖区域；高级编辑未应用状态来自显式保留的 Photopea 文档，不声称实时检测第三方像素修改。

## 视觉对照

对照已确认的 `.local/home-ui/` HOME 头部、开放陈列与 ASK 停靠形态，不修改静态原稿。

- 恢复原有 Fredoka 650 品牌字、品牌渐变、副标和 HOME 图形；头部几何、字体和入口在 320／390／768／1440px 分别核对。
- 宽屏「继续绘图」恢复内容宽度，实测约 127.86 × 40px，与原稿一致；手机上下堆叠时铺满文字栏。保留 22 × 20px 键帽及原稿的 12px 回车图标。
- 横向陈列补齐右侧 40px 渐隐遮罩、滚动条隐藏和画框边缘留白；窄屏只遮罩下方横向列表。
- 本地使用合成图片检查收起状态、草稿、半屏与手机全屏；不复制用户图片或将真实连接写入测试。

检查使用 Chromium、合成图片和模拟推理接口。没有真实收费生成，也未执行 Git 推送或 Pages 发布。真实供应商回复质量、Safari、移动真机与发布后体验不由本轮结果代替。
