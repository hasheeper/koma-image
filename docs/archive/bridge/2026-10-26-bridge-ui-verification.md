# 协同 UI 与文件草稿收口验收

日期：2026-10-26。分支 `codex/ask-chat-handoff` 的未提交工作区。在此前 B1–B3 和实战验收基础上，按用户确认的静态稿应用到主程序；不是 Git 推送或 Pages 发布证明。本轮未进行真实推理或收费生成。

## 落地范围

- ASK 更多菜单仅保留压缩上下文、调用调试。目录标签位于输入框附件按钮旁，菜单与按钮保持紧邻；未连接可恢复，连接后可切换／卸载。
- 手动导入草稿、导出状态与协议归入已有「设置 → ASK → 外部协同」页面分组，不是独立 ASK 设置弹窗。图片发送开关仍在原 ASK 设置中。
- 删除协同资料搜索勾选弹窗、独立配方／备忘录导出弹窗及触发入口。refs 清单注入、read_ref、原生附件选择／拖入／粘贴继续使用。
- 会话输入框上方使用紧凑 Todo，含状态、标题和单个成果图标；无常驻关联、添加任务或单项详情。顶栏只打开 280px 轻量总览，低频新建／新会话／目录映射与冲突操作放入其菜单。
- 原 DraftCard 增加任务、配方和文件分组，图标与正文按同一槽位对齐。更改记录与长配方默认紧凑，详情仅展示变化字段并限高滚动。
- `save_ref` 为真实共享草稿步骤，支持配方 JSON、备忘录 Markdown、任务交接 JSON。内容和目录身份在提议时冻结；确认后才保存，目录失联或切换阻断整稿，失败保留草稿并补偿本次文件，撤销检查文件归属及内容。
- 任务、文件和外部草稿的应用结果复用现有工具完成态。应用后不再保留外部记录的大外框、重复标题和已应用脚标；同行显示「来自外部」，具体来源与动作明细按需展开，撤销／恢复同一行。
- 选择清单同步活动身份；手动交付明确选择标注来源，不能默默混用基础／实际发送／角色 Prompt。菜单处理窗口缩放与内容变化，关闭时释放 Observer、监听器和 rAF。

## 仍需保留的限制

配方／任务文件保存提议时快照，而 `golden_recipe.capture_current` 可以保存同稿修改后的画板，两者不能混称。浏览器下载不能通过撤销收回；refs 撤销遇到外部编辑保留文件与本机状态。文件系统、IndexedDB 与外部进程之间仍依赖预检和补偿，没有跨进程原子事务保证。
