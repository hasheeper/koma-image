## 实现范围

- `src/slate/` 提供默认本地任务／配方／持久成果、共享 `slate_edit`、恢复记录与目录映射；`koma-slate` 独立于 ASK 会话与普通 ZIP。
- 绘图顶栏与工作区菜单提供任务入口；无目录／无 ASK Key 可手动创建、编辑、推进、绑图与下载。
- 内置两种 ASK 协议及外部 JSON 共用步骤。摘要随内外状态发送，完整任务按需读取；任务与 Prompt／参数组合整体确认，沿用 DraftCard、检查点、Tab 与页面撤销。
- 绑图保存真实原字节、SHA-256、尺寸／MIME 和真实参数；清空历史、刷新与删除 ASK 不丢失成果。页面撤销持有通过生命周期锁参与独立资产回收。
- 目录挂载映射活动任务；其他任务板显式加入。原图／回执／标注依次校验，外部任务变更经草稿审阅，冲突不自动覆盖；部分失败可续办。
- 任务、目录交付与本机绑定分开；目录必需草稿失败不报告组合成功。提交记录可在画板未被后来修改时补偿，无法安全补偿则保留恢复状态。
- `full`／`strip_syntax` 确定性标注和显式任务／配方／备忘录沉淀，不做画师名清洗。
