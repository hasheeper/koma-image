# Koma 企划集面板设计方案

**设计原则：** 企划集是一个弹窗，不是一个页面。弹窗只有一层表面，不在里面再加卡片；区分层次只用分隔线、一级表面差和文字亮度；默认不出现紫色，紫色只用于选中和焦点。

---

## 1. 层级与入口

```
目录 chip（已挂载时显示企划标题）
└─ ProjectDialog（.modal 变体 .pj）
   ├─ 头部：标题 · 描述 ………… 刷新 ⟳ ｜ 更多 ⋯ ｜ 关闭 ×
   ├─ 栏条：角色 12｜设定 8｜参考 30｜成果 46      ［该栏的筛选 select］
   └─ 主体（按栏切换，各栏保持自己的滚动位置与选中项）
      ├─ 角色：列表 ｜ 详情（简介 + 内页签：TAG／人设／参考图）
      ├─ 设定：分组列表 ｜ 原文阅读
      ├─ 参考：单栏网格，点击打开现有大图预览
      └─ 成果：按 assets／slates／refs 分组的列表 ｜ 预览
```

**组件拆分建议**

| 类型 | 组件 | 说明 |
|---|---|---|
| 栏目 | `ProjectDialog.vue`、`ProjectCharacters.vue`、`ProjectLore.vue`、`ProjectRefs.vue`、`ProjectOutputs.vue` | 每栏一个组件 |
| 共用 | `ProjectThumb.vue` | 懒加载缩略图 |
| 共用 | `ProjectReader.vue` | 分段加载的原文阅读 |
| 共用 | `useProjectSendMenu()` | 生成「送往」菜单项，四栏共用同一份文案与顺序 |
| 复用 | `.modal`、`.ibtn`、`.seg`（或已有的 library tabs）、`PopoverMenu` + `.menu-item`、`AppIcon`、既有 select 与 `.btn`、现有大图预览、Toast | 不新增全局样式 |

## 2. 弹窗几何

- **桌面尺寸：**
  - 宽 `min(1040px, 100vw − 48px)`。
  - 高固定为 `min(720px, 100dvh − 48px)`，切换栏目时弹窗不跳动。
- **双栏：**
  - 列表列 `minmax(240px, 296px)`，详情列占满剩余宽度。
  - 两列之间只画一条 1px `--line` 竖线，详情列不加底色、不加卡片。
- **头部（约 52px）：**
  - 标题 15px semibold `--fg`，单行省略。
  - 描述 12px `--fg-3`，紧跟在标题右侧，单行省略，悬停看全文。
  - 不使用 22px 的弹窗标题字号：内容是主角，标题只需定位。
  - 右侧三枚 32px `.ibtn`，均带 `data-tip`：
    - **刷新：** 读取期间图标换成小号转圈。刷新后按路径保留选中项，不自动轮询。
    - **更多：** 打开 PopoverMenu，右对齐，包含：
      - 切换企划目录…
      - 在设置中管理
      - 分隔线
      - 卸载目录（危险红字）
    - **关闭**
- **栏条（约 40px）：**
  - 左侧用现有 `.seg` 或 library tabs，标签后附 11px 等宽计数 `--fg-4`。
  - 右侧只在需要时出现一个既有 select：参考栏按分类筛选，成果栏按路径筛选；角色和设定栏不放。
  - 栏条下方一条 `--line` 分隔线，这是全弹窗唯一的横向分隔线。
- **目录连接异常：** 只在头部描述位置换成一行 `--warn` 文字加一枚「重新授权」按钮，不弹二级框。

## 3. 角色栏

**列表行（56px）**
- 左侧 40px 头像：圆角 `--r2`，`object-fit: cover`，取景偏上（`50% 15%`），让脸部入框。
- 右侧两行：
  - 第一行：姓名 13px medium，别名 12px `--fg-3`，用「·」相连。
  - 第二行：brief 12px `--fg-3`，单行省略。
- 无 TAG 的角色在右侧加 11px `--fg-4` 附注「无 TAG」；有 TAG 时不额外标记。
- 状态只换底色：悬停半透明 hover，选中 `--hover` 并把姓名改为 medium（亮色下姓名改用 `--nav-active-ink`）。不加描边或竖条。

**详情头（不套框）**
- 左侧是 120px 宽的立绘，带 `--print-shadow`，点击打开现有大图预览。
- 右侧依次是：
  1. 姓名 15px semibold
  2. 别名 12px `--fg-3`
  3. brief 13px `--fg-2`，最多 3 行
  4. 操作行：一枚 ghost 小号 `.btn`「引用给 ASK」，加一枚 ⋯ `.ibtn`
- ⋯ 菜单内容：
  - 作为 ASK 附件
  - 设为 IMAGE 参考
  - 在 CHAT 准备
  - 在 EDIT 打开
- 立绘没有真实生成参数时，只作为素材导入，不显示回执。

**内页签**
- 用小号 `.seg` 做三项「TAG｜人设｜参考图」，记住上次选中的页签，默认 TAG。
- 外层栏条与内页签可能同为分段控件，二者必须在字号或尺寸上有一档差异。

**TAG 页签**
- **服装：** 仅在存在服装时出现一个既有 select，选项为「仅共同 TAG／服装 A／服装 B…」。
- **TAG 正文：**
  - 显示在只读凹槽里（`--panel-well`），13px/1.6，最高 200px，内部滚动，可以选中文字。
  - 正文为「共同 TAG + 当前所选服装」，不把多套服装拼在一起。
- **操作行（凹槽下方）：**
  - 复制 `.ibtn`，提示「复制 TAG」。
  - 「填入角色栏 ▾」`.btn`，打开 Popo
