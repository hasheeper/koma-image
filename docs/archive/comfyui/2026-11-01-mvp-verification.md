## 配置分页、文件导入与等待反馈

按后续反馈，将 ComfyUI 供应商配置分成「连接信息」「工作流」两页，保留一次完整保存。工作流默认选择本机 JSON 文件，并提供粘贴方式；导入方式及配置页面切换共用同一份草稿。文件读取过程显示加载状态，关闭后的迟到结果不能更新新表单。其他协议保持原有单页配置。

修复 ComfyUI 尺寸未知时以 1×1 占位参与“不放大原图”测量，使方块波纹动画也缩为一个像素的问题。等待时按舞台展示，原图到达后使用实际宽高揭示；批次下一张恢复等待状态。连接测试补充转动图标，减少动效设置下保留文字反馈。

## 采样器、调度器与已有 LoRA 位置

按后续确认扩展可选绑定：采样器／调度器各绑定一个字面量名称输入，支持合并或拆分的采样节点；LoRA 只绑定图中已接好的加载位置，支持标准双强度与仅模型强度节点。结构相似的自定义节点需确认全部强度已绑定、归零能够停用，不添加节点或改变连线。

IMAGE 的参数抽屉显示已绑定的采样器／调度器；Prompt、Negative 旁增加 LoRA 页签，复用原有 tabs 和表单控件。文件、启停、模型／文本强度按画板与工作流保存。停用时提交副本中全部绑定强度归零，草稿保留记住的值。选项从目标节点的 `object_info` 声明读取，共用本页缓存、加载反馈和显式刷新；读取失败保留设置，缺失文件／枚举和已知强度范围在提交前检查，自定义自由字符串输入被拒绝时恢复实际保存值。

批次冻结采样与 LoRA，配方记录启用状态和记住的强度，历史审阅、收藏、备份及 EDIT 来源配方保留。历史回填检查工作流身份及该组绑定／默认值签名。ASK 能读取这些值，不增加采样／LoRA 草稿写入能力。
