日期：2026-11-01。状态：**暂停开发，仅作存档，不并入主线，不发布。**

本分支 `codex/archive-comfyui-2026-11-01` 保存本轮 ComfyUI 接入实现、示例配置与验收记录。开发前基线为 `59c757126888418e2168c7ad8fae8dded773e825`（`docs: record light surface refinement release`）；本地主线回到该基线。当前能力与未验事项均指本存档快照，不代表 `main` 或线上版本。

## 暂停原因与重启条件

接入逐步扩展到工作流、主模型名单、采样与 LoRA 配置，开始重复 ComfyUI 工作台已有的职责。尚无足够产品依据证明用户需要在 Koma 再维护这些配置，因此暂停本轮开发，避免由已经投入的实现反推产品需求。

将来重启前，先确认具体创作场景、相对 ComfyUI 原生界面和 Agent 的可验证收益，以及 Koma 应承担的配置边界。代码和模拟验收只用于降低重新评估成本，不构成继续开发或发布授权。

## 保存内容

- 静态浏览器直连、可选鉴权、API JSON 上传／粘贴与规则扫描、显式字段绑定。
- 一个供应商多份架构管线、每份允许的主模型名单，以及 FLUX／SDXL／Anima 示例配置包。
- Prompt／Negative／Seed、基础参数、采样器／调度器、已有 LoRA 位置及只读节点选项。

实现说明见 [ComfyUI 接入](../../integrations/comfyui.md)，验证边界见 [MVP 验收记录](2026-11-01-mvp-verification.md)。存档前严格类型、425 项单元测试、构建、样式检查、12 项 ComfyUI 浏览器模拟及 2 项 NAI 回归通过。真实生成仅按验收记录中已完成的目标管线判断，不能据此声称完整多模型矩阵或真实 LoRA 效果通过。
