## 仍待真实验证

- **供应商与模型**：逐地址核验鉴权、CORS、账户权限、型号、手动来源参数、请求／返回、生成质量和实际扣费。标准网关曾有一次界面报价免费的 V5 Full [绑图实战](archive/bridge/2026-10-26-bridge-field-verification.md)，只证明该次路径。
- **Seedream**：方舟官方模型目录未放行网页跨域预检，生图端点预检已放行，两者须分开判断。已修正连接检测的错误探测组合，自动检查与测试共用目录受限分类；卡片随当前模型来源及本页成功请求记录显示等待配置／已配置／连接成功和已启用数量，手动来源可跳过目录。5.0 Lite／Pro／Flash 真实权限、文生图与参考图编辑／局部回贴，以及 Studio 实际目录、报价保护声明及生图路径仍待验。5.5 仅预留模板，须用供应商正式 ID 和参数核验，不标记为已联调。见[接入边界](integrations/image-protocols.md)。
- **NovelAI**：五型号文生图／Img2Img／普通 Enhance、V5 Max Enhance、四型号普通／聚焦 Inpaint、4× Upscale、六项 Director Tools（含三种去背景结果）、多角色、参考效果、Vibe 编码与缓存命中；同时核验原图／参数／前后额度、Opus 资格、订阅优惠、V5 实际消耗与回充。本地近似费用与只读账户结果不代替生成验证。
- **ASK 与批注质量**：真实图片黄金样例、诊断／提纯／命名、提示词和 Unicode 编码效果、EDIT 动态状态理解、交接备忘录、CHAT 尺寸项、工具正文兼容和真实缓存；双图／原生标注的多区域指令、整体位移与羽化接缝还须人工核验；2.6 以及各来源的独立标注层支持仍待真实调用验证。
- **单图演进质量**：换题边界、自然语言回退、分支推演和视觉归因仍待真实案例验证；合成记录与脚本化模型只验证数据和交互链路。
- **ASK 空响应稳定性**：已修复诊断、EDIT 冗余状态及连续对话锚点，空流直接报错并保留手动重试。曾观察到同内容非流式 `content_filter`、流式仅结束事件；一次字段隔离成功不能证明稳定修复，也不能把所有空流都归因于过滤。证据见[隔离记录](archive/ask/2026-11-06-edit-empty-response-isolation.md)。
- **目录兼容**：Chromium OPFS 和 macOS Edge 本地选择器／授权／刷新恢复／外部文件闭环已有验证；浏览器重启、撤权恢复、其他浏览器和跨进程竞争仍待验。
- **企划集实用性**：本次根目录扫描、任务隔离、TAG 与素材交接已用 OPFS 合成企划／模拟服务验证，桌面亮暗与窄屏已目视检查；真实用户企划的规模、复杂元数据、外部编辑刷新与原生选择器端到端体验待验。
- **编辑与设备兼容**：实际 Safari、移动真机、Photopea 复杂分层长时使用及真实发布环境体验仍待核验；Playwright WebKit 不等于实际 Safari。
- **局部融合质量**：色彩对齐的本地像素测试及真实 Photopea 软蒙版／回传已用合成素材验证；真实供应商返回中的色温、明度、纹理和人工精修接缝效果仍待实图核验。

真实收费生成、推送和部署按工程约定取得对应授权；每次发布按具体提交核验。

## 当前范围之外与已取消事项

- EDIT 跨刷新恢复、PSD 持久化与外部 Bridge EDIT 草稿未开放；原图可经收藏或 Slate 保存，分层由用户另存 PSD。
- SVG／动画 GIF 输出、OpenAI Responses／Mask 上传／部分图片流式返回、Gemini 图像链路的有状态多轮与签名续传、原生图像协议本地代理不在基础适配范围。
- ASK 不做 RAG／Embedding、跨会话记忆、云同步、后台静默压缩、自动生成或自动发送。
- 自定义并发与额度预占只保留边界，默认全应用 N=1。
- 旧应用迁移整条线已取消，不建迁移桥、旧库检测／清理、旧备份转换或对应 UI，也不列为待办；新版 Koma 字段的兼容读取不属于旧应用迁移。
