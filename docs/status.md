本地 v0.6.1 待发布改进与修复：IMAGE 演进支持并行预设分支，单轮最多 4 个成功预设、每树最多 16 个未生成预设且计入 80 总节点；用户先看 Diff 再载入与手动生图，支持撤销和微调后原地转实。CHAT 演进采用带会话号的稳定图片编号，避免跨对话同号覆盖；IMAGE 历史保留完整索引，最近 X 张及演进／收藏引用保留原图，其余释放原件并保留缩略图与完整配方，支持事后首次整理演进与配方回退；EDIT 已引用版本继续受保护，主动删除与刷新边界保持；共享图标随应用内联，消除单独 SVG 请求失败后的空白。ASK 压缩账本移除重复的完整图片绑定表，完整来源保留在本地轮次供召回；近期原文保留预算收紧为 20K 与阈值 40% 的较小值，仍保护至少一轮和待确认草稿。已有冻结记忆在下次成功压缩时替换，详见[压缩契约](ask/compaction.md)。

演进参数与多工作区重整已按 IW1–IW6 落到本地源码：IMAGE 唯一实时主干，手动尝试默认入阶段相册，「立为阶段」只提拔选中图并推进 IMAGE 游标；EDIT／CHAT 明确交接后保留待交付工单，原生试错不自动长树。首次交付原位点亮，续交可追加本阶段或作为下一步，接力不抢 IMAGE 游标。交付结清当时的尝试并收起待交付标记；同一工作面板续修产生新图才重新待交付，打开入口精确定位当前未交付结果，历史图从演进节点查看。工坊原文分别展示，IMAGE 恢复、提拔、交付及定稿进入共享撤销。现行规则见[版本演进](workspaces/recipe-retrospect.md)，实现与模拟验证见[实施记录](archive/workspaces/2026-11-11-evolution-image-workshops-plan.md)。本次未 build、未推送或部署，不表示用户现有静态页面已经更新。

本地 v0.6.1 待发布新增：CHAT 会话菜单增加「AI 命名」，设置 → ASK 增加 ASK／CHAT 共用的「自动命名」开关；分别在新会话首次回复成功／首次需求提交后触发一次，共用命名模型并保留手动标题。见[命名契约](ask/prompts.md#ai-命名)。普通 ASK 图片附件 `#aN` 可经草稿交接 CHAT／EDIT；CHAT 草稿明确底图与参考图，支持新会话或当前对话的完整图片组合，上传图片可用稳定编号读取，收藏恢复与撤销沿用原图资源池。详见[图片交接](ask/runtime.md#草稿与校验)。ASK 消息区从第三轮起显示轮次导航，悬停摘要与「回到最近」保留；导航显隐不预留单侧空白，每次展开自动定位最新内容；见[消息流与滚动](ask/ui.md#4-消息流与操作)。

EDIT 参考图已接入本地源码：通用模型由画布批注上传参考并自动关联对应区域，修改说明框下方以带「参考图」区头的紧凑图片附件区汇总参考，保留用途预览与排序；批注框采用紧凑编辑条，尾部参考按钮可上传或复用已有图片，使用评论气泡图标与明确的「完成批注」出口；生成冻结参考并按双图／原生标注换算图序。ASK 可读参考、经确认草稿管理完整组合或多图交接 EDIT；批注可携参考送入 ASK／CHAT，回到 EDIT 恢复关联，CHAT 沿原资产路径保存。ASK 每轮仍限 4 图，批注原图／指示图占两张；超限明确提示。详见[批注参考](workspaces/annotations.md#edit-参考图与批注关联)和[ASK × EDIT](ask/edit.md)。本次不 build，未推送或部署；真实模型的参考理解与改图质量待验。

调用调试的 v0.6.1 待发布改进：默认导出省略图片 Base64，并合并重复的整条消息、系统块与工具定义；完整文本、调用顺序与诊断保留，原始请求仍可复制或完整导出。格式由[调用调试契约](ask/runtime.md#调用调试)维护。

## 当前范围之外与已取消事项

- EDIT 跨刷新恢复、PSD 持久化与外部 Bridge EDIT 草稿未开放；原图可经收藏或 Slate 保存，分层由用户另存 PSD。
- SVG／动画 GIF 输出、OpenAI Responses／Mask 上传／部分图片流式返回、Gemini 图像链路的有状态多轮与签名续传、原生图像协议本地代理不在基础适配范围。
- ASK 不做 RAG／Embedding、跨会话记忆、云同步、后台静默压缩、自动生成或自动发送。
- 自定义并发与额度预占只保留边界，默认全应用 N=1。
- 旧应用迁移整条线已取消，不建迁移桥、旧库检测／清理、旧备份转换或对应 UI，也不列为待办；新版 Koma 字段的兼容读取不属于旧应用迁移。
