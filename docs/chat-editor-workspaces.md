# M5／M6 对话与编辑工作区

状态：2026-10-19。M5 对话、M6 编辑／重绘／放大和工作区间图片交接已接入。沿用原 7 份正式 CSS、类名与控件结构，没有重新设计界面。验证使用模拟网关和合成图片，没有真实收费生成或部署。

## M5 对话

- 会话列表支持空白复用、重命名、置顶、复制、删除确认及中断轮次恢复。列表、草稿、附件和分支状态由应用级服务保留，KeepAlive 切换不取消在途任务。
- 保留底图／参考图、跟随最新、历史文字勾选、分支与多版本、实际发送文本和模型数量限制。手动改变上下文或版本会增加选择版本号，迟到的生成结果不能覆盖用户选择。
- 上传／粘贴／拖入沿用单张 8MB、总量 32MB 和模型图片数限制。附件在取得任务槽、开始轮次时消费；失败或取消不退回附件栏，轮次引用与保留参考仍可找回。
- 预报价防抖 650ms；执行前由网关按提交快照重新报价，携带当次 `max_cost`，涨价提示后继续。一个轮次始终占同一全局任务槽，直到全部图片解码、校验和资源登记完成，无付费确认、自动重试或路线回退。
- 保留返回中的文本与全部图片顺序，支持版本翻页、下载原字节、继续编辑、加入参考、重试及放大。结果揭示与等待波浪由原生 Canvas 驱动。
- 会话与图片在同一 IndexedDB 事务保存，400ms 防抖，失败保留脏数据供下次保存。恢复时把未完成轮次标为中断；离开页面和进入备份读取前刷新待保存草稿。浏览器强制结束进程仍无法保证异步写入完成。
- 绘图图片先准备并保存 Koma 独立票据，再原地进入对话；票据只领取一次、30 分钟过期，已保活的对话也能领取。超限图片使用原压缩规则。没有读取旧应用票据或数据库。

## M6 编辑

- 图生图、重绘、放大沿用原控件、原生 dialog／popover 和快捷键。模式分别记忆模型、强度、噪声；专用放大模型的描述与选项独立于主描述。预报价沿用 400ms 防抖，空蒙版显示「先涂抹」并禁止执行。
- 原生蒙版使用源像素坐标，保留笔刷／擦除／撤销／重做、黑底白色重绘、32 阈值、缩放／平移／双指与对比。JPEG EXIF 归一化后的 PNG 与蒙版使用相同方向和尺寸；放大提交查看版本的原始字节。
- 编辑会话在 App 中按 `image` 或 `chat:<conversationId>` 保留，关闭覆盖层后仍在，刷新清空。每个会话最多 30 个版本，淘汰时保护底图与当前查看版本并释放 Object URL。
- 底图和查看结果分别保存；生成结果默认不自动变成下一次底图。进入重绘时，查看版本按原规则成为底图。蒙版、参数与版本在关闭／重开和来源切换后恢复。
- 绘图来源的编辑结果自动回到普通历史；对话来源通过「用作参考图」显式交回原会话，不会附到后来切换的另一条对话。运行中 Esc、返回和路由切换不能关闭编辑器，用户先停止任务。

## 服务与 DOM 所有权

`services/chat.ts`、`services/editor.ts` 在 App 中各创建一次，位于 KeepAlive 外。会话与参数算法已在 [T2](typescript-migration-plan.md) 中迁为 `domain/conversation.ts` 与 `domain/media.ts`，实现直接接受严格类型检查；图片尺寸模块也已在 T1 迁为 TS。T3／T4 已完成图片处理、原生蒙版与波浪的 TS 实现并移除配对声明，保留生命周期接口；笔画／清空记录与可空资源状态由实现直接定义。

Vue 模板拥有 `.hl-wrap`、控件、消息和图片结构；移动端账户操作仍经 Teleport 切换宿主。原生驱动只操作独立 Canvas 宿主和明确委托的尺寸、光标、滚动、计时样式。Blob、图片 URL、AbortController、蒙版笔画与编辑会话都不进入深层 reactive；组件只订阅浅层显示快照。

切出工作区或关闭编辑器时暂停指针、键盘、ResizeObserver、计时和波浪；任务与会话资源继续保留。删除引用、版本淘汰或销毁服务时释放对应图片 URL。引用中的图片不因单纯切页被释放。

持久化写入通过 `data.write`。备份维护先刷新已加载会话；未打开过的对话工作区不把空缓存写回数据库。维护结束先完成全部缓存 reload，再恢复调度并调用参与者的 `ready`，此后才重新获取模型与报价，避免异步 reload 之间发起请求。
