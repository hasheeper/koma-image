# EDIT 独立工作区

更新：2026-10-28。EDIT 与 IMAGE、CHAT 同级，主路由为 `#/edit`；设置使用 `#/edit/settings/<section>`。旧的 `#/<workspace>/editor` 地址规范化到独立 EDIT。

## 画板与版本

每个编辑画板拥有稳定 ID、名称、来源归属、参数、角色、参考、蒙版、版本栏、当前底图与查看版本，以及缩放、平移、笔刷和提示词页签。上传、粘贴或拖入独立图片创建新画板；空白编辑画板接收第一张图时复用自身。

图生图、重绘、放大、Director Tools 和 Photopea 修图结果属于同一画板的衍生版本。通过稳定来源 ID、结果身份或本页同一来源 Blob 再次打开图片时，定位已有画板，保留参数与当前版本；显式选择重绘或放大仍打开对应工具。历史与收藏中的同一记录共享来源身份。

不同画板的蒙版完全隔离。同一画板内同尺寸切换版本沿用蒙版；主动清空或尺寸变化才重置，不从旧版本复活已清空的区域。每画板最多 30 个版本，淘汰保护底图与当前查看版本，释放原图 URL。

画板入口沿用 IMAGE 的胶囊、下拉列表、当前项标记和「⋯」管理菜单。关闭画板前说明编辑现场将释放，历史与收藏保留。生成中画板不能关闭，其他画板可继续查看和编辑。

## 编辑表单与生成

- 图生图、重绘与放大在独立 EDIT 页面中操作，菜单使用原生 popover 并保留快捷键。模式分别记忆模型、强度、噪声；专用放大模型的描述与选项独立于主描述。预报价沿用 400ms 防抖，空蒙版显示「先涂抹」并禁止执行。
- 官方图生图表单内提供 Enhance 开关，默认关闭；开启显示倍率、实际输出尺寸与五档 Magnitude，强度／噪声仍可微调，手调后为自定义。V5 三型号的倍率另有 Max，按官方源图面积限制提供；使用服务端标记与专用输出尺寸，和普通倍率分开校验。增强配置归各编辑画板，普通图生图的强度／噪声／Seed 独立保留；每次增强冻结新随机 Seed，原词文保留。单个执行按钮完成生成、尺寸校验与历史记录，不增加独立模式或弹窗。倍率与协议边界见[Enhance](novelai-official.md#普通-enhance)。
- 图生图与重绘的 Guidance／Guidance Rescale 分别发送 `scale`／`cfg_rescale`；Rescale 范围 0–1，读取来源的 `cfgRescale` 或 `cfg_rescale`，缺失时为 0，结果记录与绘图复用保留数值。Medium 不发送 Rescale，放大不携带这组编辑参数；所有路线不发送遗留 `cfg`。
- 官方 V4.5 Full／Curated 在 Guidance 同行显示 `Variety+` 小按钮，默认关闭；继承来源开关并随编辑结果保存实际生效状态，切 V5 隐藏且不发送。图生图、Enhance 和重绘按最终请求尺寸换算官方 CFG Delay 阈值，聚焦重绘使用裁切放大后的尺寸；不影响 `scale`／`cfg_rescale`，放大不携带。
- 官方 Img2Img 强度为 0.01–0.99、噪声为 0–0.99；Inpaint 强度为 0.01–1。六种采样器与绘图共用，V4.5 可选噪声调度，V5 固定 Karras；Guidance 滑杆 0–10／0.1，点击数值可手输更高的非负有限值。目录、表单与出站分别校验，结果记录实际调度，参数往返保留。标准网关继续使用其声明目录和既有范围。
- 编辑面板复用绘图页的模型框、Anime／Furry、适用的 Effort、Complexity、质量／负向预设、透明底和角色控件；参数／Vibe／Precise 使用同一底部抽屉，强度保留在主表单。控件有独立 ID 与会话所有者，编辑不写回活动画板；角色定位浮层留在编辑页面内。Esc 关闭菜单或抽屉。
- 从图片打开时优先继承 `basePrompt`／`baseNegative` 原文以及模式、预设、参考配置、角色启停与坐标；没有原文字段时才采用已有有效提示词。绘图与编辑共用自动标签编译，关闭预设不会留下上一轮自动追加的词。角色可增删、排序、启停、编辑正负词和定位，超出型号上限时阻止提交，不截断角色。
- 随机 Seed 在显式执行、冻结快照时确定，预报价不改输入框；提交、编辑版本和绘图历史保存同一个实际 uint32 值，0 保持合法。结果同时保存原始词文、有效参数、本地角色和轻量参考配置，不把底图、蒙版或参考编码写入参数。
- Medium 只在当前来源确实声明编辑操作时可选；官方已声明 Img2Img／Inpaint。官方与适用的中转请求固定 14 步／Euler Ancestral／Heavy 负向正文、抑制用户与角色负向、忽略可调 Rescale；切回 High 恢复本地值。
- V4.5 官方 img2img 可继承、上传并编辑 Vibe／Precise；普通 Inpaint 仅开放 Precise，底栏显示参数／Precise 两项。启用的 Vibe 配置保留并提示停用，不编码、不静默丢弃；共用绘图的原图与编码缓存，仅显式执行时进入任务锁准备参考，检查已知参考费用下限并固定来源。失败或取消不丢已完成编码，也不自动重试。切到不支持的型号、来源或操作时保留配置并阻止发送，用户可明确停用。异步上传不能写入已切换的编辑会话，缩略图按使用者释放，不影响背后的绘图页。
- 原生蒙版使用源像素坐标，保留笔刷／擦除／撤销／重做、黑底白色重绘、32 阈值、缩放／平移／双指与对比。JPEG EXIF 归一化后的 PNG 与蒙版使用相同方向和尺寸；放大提交查看版本的原始字节。
- 官方普通重绘发送 `action: infill` 和对应的 `-inpainting` 型号，支持 V4.5 Full／Curated 与 V5 Full High／Medium；V5 Curated 无独立重绘接口，菜单不提供该组合，也不静默替换成 V4.5。强度低于 1 时使用 `img2img: { strength, color_correct: true }`；不沿用整图噪声滑块，结果噪声记录为 0。返回图必须与源图同尺寸，再将白色蒙版内的像素贴回底图，蒙版外保持归一化原图像素；普通重绘不裁剪放大或自动羽化。合成重新输出 PNG，完整参数保存在编辑版本与本机历史中，不保留上游 PNG 文本块。官方编辑宽高须至少 64、64 像素对齐、面积不超过 3,145,728，不额外限制 2048 单边；8MB 是 Koma 本地文件限制。超限明确提示，不自动缩图。
- 画布工具栏使用重绘图标与箭头组成的分体入口：主按钮在图生图与上次使用的重绘类型之间切换，箭头菜单选择普通／聚焦重绘并直接进入，悬停显示当前类型。普通／聚焦互切保留蒙版与框。首次选择聚焦且无框时进入框选；已有框时恢复范围并保留涂画操作。左侧不增加聚焦字段。
- 聚焦重绘（Focused Inpainting）复用上述四型号与蒙版工具，默认关闭。用户手动框选包含全部蒙版及周边参考的范围，支持移动／拖角／方向键调整；工具栏框选图标或 F 调整，B／E 切回涂画，Esc 取消手势。范围角标显示所选尺寸与自动处理尺寸。框按每画板保存，同尺寸沿用、尺寸变化清空。客户端裁切并放大至约 1MP，单次普通 `infill` 后缩回，仅替换全图蒙版像素，最终原尺寸；缺框、空蒙版、框外覆盖、返回尺寸不符均不写结果。不自动识别、自动扩框或静默换源，完整算法与角色坐标映射见[聚焦重绘](novelai-official.md#聚焦重绘focused-inpainting)。
- 官方放大菜单合并为一个 NovelAI Upscale 入口，显示固定 4× 和目标尺寸；请求走 `/ai/upscale`，原图字节与 JSON request 使用 multipart，不发送生图提示词、Seed、Guidance 或 max_cost。源图面积不超过 3,145,728；标准网关的既有 1,048,576 限制保持。接收 ZIP／直接图片，尺寸不符合 4× 时不写版本，取消／失败不重试；实际型号与倍率随结果保存。
- 放大与重绘复用图标分体入口，旁边为 Director Tools 魔棒按钮；三个图片操作之后只有一条分隔线，图标与箭头之间不画线。放大箭头提供「原生放大／外部放大」：原生使用已有 NAI 放大能力（官方连接或支持此工具的网关），外部使用已配置的专用放大模型。选择类型后打开该类模型与参数，未配置的类型禁用；主按钮重新打开当前类型。切换类型不执行放大。放大面板紧贴工具栏向上打开，单个模型显示一行，多个才提供列表；NovelAI Upscale 使用界面统一字体与 600 字重，4×、目标尺寸与执行按钮同排。

## Director Tools

魔棒面板复用放大的紧凑菜单材质，底部一排图标与名称提供去背景、线稿、草图、上色、表情和去杂物；窄屏横向滚动。上色显示 0–5 强度和可选描述；表情显示 24 种选择、六档强度与可选描述。参数位于执行行上方，不扩张左侧表单。打开期间随窗口、工具栏及面板自身尺寸重新定位，避免费用或字体加载后越界。面板互斥，Esc 逐层关闭，切页／换板／进入 Photopea 时关闭并暂停定位监听与尺寸观察。

工具处理当前查看版本，设置归各画板，与左侧模型、Seed、蒙版和参考独立；只能由已配置的 NovelAI 官方连接执行，使用独立 Anlas 估算和选源。请求、尺寸预处理与费用见[NAI 工具协议](novelai-official.md#director-tools)。提交后源图和画板冻结，结果不抢占当前查看版本，解码和写入完成后释放原有任务锁。

去背景一次返回抠图／重建／混合三张原图，版本栏同组显示一个带图标的入口，查看时在信息栏切换结果，不重复请求；透明结果使用棋盘背景。三个版本各有稳定身份，收藏、下载、来源回流与 Slate 交付保持原路径；移除或淘汰整组时释放全部资源，保护底图及当前查看组。工具结果保存实际工具／参数／尺寸及来源配方，不伪造生图 Seed。

编辑操作仍受[图像协议](native-image-protocols.md)与[NAI 型号能力](novelai-official.md)约束；参数控件复用不扩大供应商能力。

## 页面与任务生命周期

应用服务持有画板，页面只订阅浅快照。EDIT 页面首次访问才创建，之后在外壳中隐藏保留，避免 KeepAlive 移动 iframe DOM 导致 Photopea 重载。隐藏时保存蒙版与视图，暂停原生 Canvas、Observer、计时和活动监听，关闭菜单；返回时恢复。

切换工作区不会停止已提交的生成。生成仍使用全应用任务调度器与既有来源、报价和额度规则，默认并发为 1。准备快照时短暂禁止换板，提交后可切换画板，迟到结果、错误及来源信息始终归发起画板。后台生成不抢占当前活动画板。

Photopea 打开时先通过「应用并返回」或「暂不应用」返回 EDIT，再切换工作区；不在异步回传期间隐式丢弃编辑。Esc 关闭当前菜单或参数抽屉，不再退出 EDIT 页面。

## 蒙版与外部图像回传

原生蒙版支持笔画和导入位图共同擦除、清空、撤销／重做。工具栏接受黑白／灰度文件，白色重绘、黑色保留；底层另有显式透明覆盖语义，不按图片外观猜测。文件导入和 Photopea 的合法空回传分开校验，尺寸不符不静默缩放。

外部图像／蒙版统一经编辑服务提交：冻结画板、源版本与蒙版修订，完整校验后一次应用；过期、重复、错序和迟到结果拒绝写入。只修改蒙版不创建图片版本，纯修图不要求经过一次生成。

## Photopea 文档

一个保活 iframe 持有多个编辑画板的独立文档；宿主按画板保存文档身份、专用图层身份、源版本、蒙版摘要与已烘焙图层信息。

- A → B → A：分别激活对应文档，A 的自定义层、蒙版与历史继续保留。
- 同画板同图：唤醒原文档，不能用回传 PNG 覆盖它。
- 同画板同尺寸衍生图：替换原图层，保留上层工作栈；已烘焙的叠加层按原规则隐藏。
- 同画板尺寸变化：只重建该画板的工作栈。
- 关闭画板：串行关闭对应 Photopea 文档，释放该画板图片与蒙版资源。
- 显式重载整个 iframe、通信故障重建或刷新页面：全部保活分层丢失；重载文案说明所有画板的分层范围。

自动／仅图像／仅蒙版及防污染回传规则继续遵循[工作栈规范](photopea-workstack-spec.md)。

## 来源与交付

结果保存 `editBoardId`／`editBoardName`、`editId`／`editParent`，并保留原 IMAGE 画板或 CHAT 会话／轮次／图片身份。编辑画板身份不替换原始出处。

IMAGE 和直接上传来源的编辑结果进入主历史；手动版本可直接收藏与交付 Slate，无需生成，历史保存失败可重试。手动结果标为「手动编辑」，来源配方放在 `sourceRecipe`，不伪造新的生成 Seed、耗时或费用；Slate 回执与标注保留该区分。CHAT 来源仍显式添加到原会话的参考图，回传成功后定位该会话；也可显式保存手动版本到历史／收藏。

HOME 的进行中与继续入口包含本页编辑画板，预览直接使用其版本原图 URL，不建立额外副本；关闭画板后从 HOME 移除。刷新后编辑画板不复活，继续入口回退到 IMAGE。

## 保存与 ASK 边界

编辑现场沿用页内存储边界：编辑画板、未保存版本、蒙版、撤销和 Photopea 分层刷新后清空，不进入普通 ZIP。历史仍为页内数据；已收藏图片与 Slate 成果通过各自持久化路径保存。没有 EDIT 数据库或跨刷新 PSD 恢复，长期分层文件由用户在 Photopea 另存。

EDIT 内 ASK 保持隐藏，不自动把编辑参数作为 IMAGE 草稿目标。Bridge 仍只面向 IMAGE；EDIT 的专用状态摘要、草稿与只读工具当前未开放。
