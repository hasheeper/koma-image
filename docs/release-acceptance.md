## 实现范围

- `server.mjs` 同时提供 `dist/` 静态资源与固定协议代理。默认 `127.0.0.1:3218`；支持根路径和 `/app/` 等子路径。
- `KOMA_GATEWAY_URL`／`KOMA_GATEWAY_KEY` 都为空时维持浏览器配置模式；仅设置一项时启动失败；两项齐全时启用本地模式。没有默认上游地址。
- 页面只注入模式标记和进程内随机令牌，客户端从自身文档地址解析 API 路径。URL、Key 留在服务端；令牌不写入存储、配置导出或备份。静态产物不含运行时标记，也不主动请求配置端点。
- 本地连接／安全设置只读，仍显示连接状态、额度和模型目录。手动模型来源、自动匹配与来源开关继续可用，即改即存并跨标签同步。
- 本地连接是内存中的托管连接；模型来源单独保存于 `koma.local.models.v1`。不覆盖普通 `koma.routing.v1`，不恢复或共享浏览器 vault。配置导出只包含 `kind=local-models`；完整备份以可选 `localModels` 字段保存，仍为 Koma v2。

代理复用标准 Profile 的 8 条路径及 GET／POST 约束。原 JSON 请求字节、`max_cost` 和成功图片／ZIP 字节保持不变；统计鉴权由服务端加入。没有新增付费确认、生成重试、路线回退或并发配置，N=1 调度与额度护栏继续由共享服务执行。

代理拒绝跨站来源、异常 Host、失效令牌、任意目标和任意查询参数，只服务构建目录内的普通文件。POST 限 JSON 对象、最大 64MiB，覆盖现有 32MiB 附件的 base64 请求；取消传递给上游，执行保持 240 秒超时。错误保留 HTTP 状态并隐藏回显的配置地址和 Key；不转发上游 Cookie 或自定义响应头。成功业务 JSON 仍按原协议返回，不改写内容。

## 发布交付

`npm run package` 重新构建并按显式清单打包，生成 `.local/releases/koma-image-0.1.0.tar.gz` 与 `.sha256`。包内含静态 `dist/`、本地服务器及其 4 个共享运行时模块、空环境变量模板、使用说明、资源许可、源码版本记录和 `SHA256SUMS`。不复制 `.git`、真实 `.env`、测试、截图、node_modules 或本机应用数据。

解压后使用 Node 26 运行 `npm start`，无需安装依赖。也可只使用 `dist/` 静态托管。操作、更新与回退方法见 [发布包说明](release-guide.md)。CI 已增加本地模式和发布包测试，远端执行结果以实际发布时的 CI 为准。

旧数据迁移桥、转换器、迁移 UI 和兼容窗口仍是明确取消项。发布包不会访问或删除旧应用数据。自定义并发与费用预占保持预留，未提前启用。
