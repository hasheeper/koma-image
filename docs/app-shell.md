# M1：单页外壳

2026-10-19。此文记录 M1 阶段的导航、保活、覆盖层宿主和布局协调。M1 当时未实现上游请求、真实生成或存储写入；M2 后续已添加共享服务和 Koma 数据库初始化，见 [M2 实施记录](gateway-data-scheduler.md)。后续 M3–M6 已接入持久化界面与工作区执行；本文的验证范围仍限于 M1 外壳。

## 结构与所有权

- `App.vue` 提供唯一的路由和外壳状态；KeepAlive 以 image／chat／tags 为稳定 key，最多缓存三个实例。切换覆盖层或查询参数不更换工作区实例。
- Vue 直接挂载 body 的子节点，保持绘图顶栏与图片栏依赖的层级；工作区可以返回 Fragment，对话仍使用 chat-app 容器。
- `presentation.ts` 独占页面 class、data 属性、标题、favicon 和工作区样式开关。缓存中的组件不得修改当前页面的全局外观。
- 七份正式 CSS 保留现用视觉声明；按最新范围裁撤旧站迁移提示的闲置样式。设置头像选择器改为中性名称；唯一新增外壳 CSS 防止词典的零宽图片栏变量影响全局编辑器。
- 图标精灵包含原词典内嵌的购物篮图标；三套本地字体及许可证保留；旧头像没有复制。
- 移动端图片栏和 Key 工具由 Teleport 移动。目标是工作区自己的元素引用，随其一起进入 KeepAlive 缓存，不把隐藏工作区的节点留在当前页面。
- 高亮包裹和 mirror 已写入 Vue 模板；高亮算法及补全行为在 M3 接入。没有调用外部包裹／搬移脚本。

## 导航与生命周期

工作区使用 `#/image`、`#/chat`、`#/tags`。设置使用 `#/<workspace>/settings/<section>`，编辑宿主使用 `#/<workspace>/editor`。设置中的 backup 子页名为「备份与恢复」，替代独立备份页面；旧站迁移入口与状态 UI 已取消。

`chat.html`、`tags.html` 和 `transfer.html` 只运行中性重定向脚本，保留 search 中的业务参数，根目录与静态子目录均可用。地址兼容不代表旧数据兼容；只保留参数，不转换旧库或旧票据。图片票据认领尚未接入。

切换前先保存滚动位置，再更改样式与 DOM；激活后恢复滚动。当前输入草稿与分类／折叠状态在组件或外壳内存中保留。真正刷新仍会丢弃这些临时值，正式草稿持久化在对应业务阶段接入。

`useWorkspaceLifecycle` 为活跃界面提供 AbortSignal，切出和卸载时中止键盘／visualViewport 监听。绘图空态保留原来的两行收藏骨架与手机端画布高度算法；ResizeObserver 在切出时断开。该生命周期只控制 UI，不应在后续接入时用于取消后台任务。

设置和编辑 dialog 持续挂载，使用 showModal／close，保留焦点返回及 Esc 语义。编辑入口当前保持未解锁状态；直接路由只用于验证宿主，未接入编辑会话或运行中关闭护栏。

## 已验证的范围

运行 `npm run check` 和 `npm run test:shell`：

- TypeScript 检查、路由单元检查与生产构建。
- 三工作区保持同一文档；草稿、分类与折叠状态保留；浏览器前进／后退可用。
- 同一输入和图片栏 DOM 实例跨切换、跨 Teleport 位置保留；切页时移动端滚动恢复。
- 320／390／768／1440px 下无页面横向溢出，顶栏和图片侧栏保持原层级；对话切入后停用绘图的全局样式。
- 全局 dialog 单例、Esc 与焦点返回、备份子页、静态子路径重定向及业务查询参数保留。
- 循环切换工作区及打开／关闭覆盖层后，window 和 visualViewport 监听数量不增长，无重复活动工作区或 dialog。
- 默认头像加载正确，无外部请求、浏览器运行错误或应用存储写入。

这里只验证外壳生命周期。大图片、执行任务、附件资源和 Canvas 驱动还未接入，因此不把此检查当成这些模块的内存或高频渲染验收。完整 UI 对齐、画幅／参数、真实列表和交互依照后续阶段逐项补齐；当前缺失的业务区域不代表重新设计。

CI 已配置相同检查，远端运行结果以实际执行为准。
