每阶段只标记实际完成和验证过的部分。网关服务已用模拟接口验证；默认启动不通信，工作区尚未接入生成。没有生产发布、数据迁移或旧库清理行为。

**范围变更已确认：取消整条旧数据迁移线，删除独立过渡／M6.5 阶段。** 用户少且尚未正式上线，不再建设迁移桥、旧备份转换器、恢复日志、旧锁交接、凭据续迁、兼容窗口及迁移 UI。M2 直接建立 Koma schema；M3 保留普通「备份与恢复」，只支持新版格式。连接与 Key 重新配置，旧数据不自动处理。本项已取消，不是延期。

M1 的工作区仅接入导航、草稿、折叠／分类状态、空态和布局宿主；M2 已接入单次服务初始化、共享数据租约与 Koma 数据库。绘图画幅／参数、真实收藏、对话数据、词典查询、Key 解锁、编辑画布及备份读写仍属于后续阶段；未接入的业务按钮禁用。下一步是 M3 的设置、Key 管理、普通备份与恢复及公共控件／词典。

前置验证环境为 Node 26.8.2、npm 11.19.1、Chromium 151.0.7922.34；开发入口、构建根路径与静态子路径均成功挂载，默认头像解码通过，没有上游请求或应用数据写入。源码与产物经过私有标识检查。上述结果仅覆盖启动骨架，不代替后续工作区、业务或新版备份验收；CI 配置已添加，尚未在远端执行。

公开发布仅包含本工程审查后的源码与资源，无过渡部署或旧数据接管。新应用更新与回退围绕 Koma schema 验证，不删除或降级用户的新数据；旧应用及其数据独立保留。
