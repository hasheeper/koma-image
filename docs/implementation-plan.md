每阶段只标记实际完成和验证过的部分。网关服务已用模拟接口验证；默认启动不通信，绘图／对话／编辑已共用全局调度服务。生产发布不包含数据迁移或旧库清理。

**范围变更已确认：取消整条旧数据迁移线，删除独立过渡／M6.5 阶段。** 用户少且尚未正式上线，不再建设迁移桥、旧备份转换器、恢复日志、旧锁交接、凭据续迁、兼容窗口及迁移 UI。M2 直接建立 Koma schema；M3 保留普通「备份与恢复」，只支持新版格式。连接与 Key 重新配置，旧数据不自动处理。本项已取消，不是延期。

M1 已接入单页外壳，M2 已接入共享服务，M3 已接入设置、Key、普通备份、词典和提示词公共控件。M4 已接入绘图面板、生成与结果、普通历史、独立收藏和参数导入。M5／M6 已接入对话数据与执行、原生编辑画布、版本会话、放大和跨工作区图片交接。M7 已接入本地环境变量代理与只读设置，完成 77 项本地自动化检查、四视口和资源生命周期验收，并准备可解压运行的发布包。M7 基线保留正式 CSS，后续按用户要求整理设置、结果参数滚动、绘图空白页与品牌字。生产发布目标为 hasheeper/koma-image 的 main 分支和现有 koma-image Pages 项目，仅上传 dist/。

P3 接入 NovelAI 官方连接。P3.0 补齐连接改名、删除和诊断测试，P3.1 将 Profile 改为登记表和可声明能力，标准 Profile 行为不变，合计 86 项自动化检查通过。官方 Profile、生图、编辑和钱包无法在没有 Key 时核实请求与扣费，暂停到拿到 Key 后再做。

前置验证环境为 Node 26.8.2、npm 11.19.1、Chromium 151.0.7922.34；开发入口、构建根路径与静态子路径均成功挂载，默认头像解码通过，没有上游请求或应用数据写入。源码与产物经过私有标识检查。上述结果仅覆盖启动骨架，不代替后续工作区、业务或新版备份验收；CI 配置已添加，尚未在远端执行。

公开发布仅包含本工程审查后的源码与资源，无过渡部署或旧数据接管。新应用更新与回退围绕 Koma schema 验证，不删除或降级用户的新数据；旧应用及其数据独立保留。
