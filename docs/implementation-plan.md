每阶段只标记实际完成和验证过的部分。网关服务已用模拟接口验证；默认启动不通信，绘图／对话／编辑已共用全局调度服务。生产发布不包含数据迁移或旧库清理。

**范围变更已确认：取消整条旧数据迁移线，删除独立过渡／M6.5 阶段。** 用户少且尚未正式上线，不再建设迁移桥、旧备份转换器、恢复日志、旧锁交接、凭据续迁、兼容窗口及迁移 UI。M2 直接建立 Koma schema；M3 保留普通「备份与恢复」，只支持新版格式。连接与 Key 重新配置，旧数据不自动处理。本项已取消，不是延期。

M1 已接入单页外壳，M2 已接入共享服务，M3 已接入设置、Key、普通备份、词典和提示词公共控件。M4 已接入绘图面板、生成与结果、普通历史、独立收藏和参数导入。M5／M6 已接入对话数据与执行、原生编辑画布、版本会话、放大和跨工作区图片交接。M7 已接入本地环境变量代理与只读设置，完成 77 项本地自动化检查、四视口和资源生命周期验收，并准备可解压运行的发布包。M7 基线保留正式 CSS，后续按用户要求整理设置、结果参数滚动、绘图空白页、品牌字与界面字体（资源圆体）。生产发布目标为 hasheeper/koma-image 的 main 分支和现有 koma-image Pages 项目，仅上传 dist/。

P3 接入 NovelAI 官方连接。P3.0 补齐连接改名、删除和诊断测试，P3.1 将 Profile 改为登记表和可声明能力，标准 Profile 行为不变，当时合计 86 项自动化检查通过。2026-10-21 按用户新要求继续实现原生协议基础适配：NAI 静态目录、基础生图、图生图和 Anlas 查询接入现有工作区；OpenAI Images 与 Gemini 原生接入对话生成和参考图修改。模拟测试覆盖前端请求与结果处理，不代表官方具体型号、扣费、CORS 或账户权限已经验证；NAI 重绘／放大等能力等待核验后再开放。

T0 于 2026-10-20 完成勘探，当时应用剩余 9 个 JS 模块、1,840 行。T1–T4 完成全部九个模块的 TS 实现，移除配对声明并更新调用方；T5 已按既有 CI 检查顺序完成本地验收，108 项测试、严格类型、构建、脱敏与发布包验证通过，UI、业务、存储格式及原生高频所有权保持原样。蒙版／波浪新增 Canvas 上下文不可用时的明确错误与初始化清理，详见 TS 迁移记录。`src/` 已无 JS 实现，T0–T5 全部收口；测试／工具脚本保留 JS。实现与文档已整理为本地提交，本次未推送或部署。

2026-10-21 用户批准新子产品 Koma ASK：能看、能查、能提议，不能动手，草稿是唯一写入出口。设计见 `docs/ask/` 下文档 1–3。用户随后确认的决策记录在文档 4：只做 `openai-chat` 与 `anthropic-messages` 两种推理协议；字体统一使用站内圆体；模型能力由用户界定；保留内容中立、词表混淆与失败回滚，并以 R18 自行确认作为门控、以代码排除表固化未成年与 R18G 边界；「设置 → ASK」单独分组；文档之间的矛盾以文档 3 为准。A0–A4 的任务、测试与退出标准见[决策与实施规划](ask/ask-implementation-plan.md)。A0.1 已在 `codex/ask-a0` 实现两种推理 Profile、请求组装与流式解析、词表混淆与排除表、「设置 → ASK」及备份字段，用模拟接口验证，未请求真实推理服务。A0.2 在同一分支实现应用级 ASK 服务、⌘J／Ctrl+J 抽屉（窄屏底部面板）、轮次事务与工具循环、L0 摘要与基础版提示词、失败回滚与按门控显示的重试；抽屉的可见入口按规划留到 A1 先出截图方案。两阶段记录见 [A0 记录](ask/ask-a0.md)。

A1 在 `codex/ask-a1` 实现七个只读工具、glance／look／crop／sheet 与硬预算、模式 A／B 历史索引、旧图片脱水、候选消歧、ID 预览与定位。用户批准截图后接入 Ask、Ask Diff、Ask Why，全部只打开或预填，不自动发送。按用户选择先用合成图片验证，真实图片黄金样例与供应商实测保留待办，见 [A1 记录](ask/ask-a1.md)。

A2 在 `codex/ask-a2` 实现 `propose_draft`、两级锚点与画师保护、局部修改／改写／参数恢复切片、确认前只读、跨工作区确认写入、单次撤销与快捷键护栏。参数恢复复用图片导入归一化，应用和撤销不触发报价、额度、生成或 CHAT 发送；普通 CHAT 输入框草稿已支持，分支与上下文工具仍属 A3。合成样例、保存失败和外部修改回归见 [A2 记录](ask/ask-a2.md)。

A3 在 `codex/ask-a3` 完成当前分支快照与 `get_chat_context`、`#cN.M` 图片读取、分支草稿审阅与单次撤销；不自动包含其他分支，不发送 CHAT。A4 在 `codex/ask-a4` 完成两种 ASK 协议的独立服务端配置、固定路径流式代理，以及复用草稿链路的 ⌘K／Ctrl+K 行内模式。两阶段集中回归与配置说明见 [A4 记录](ask/ask-a4.md)，本地提交，未推送或部署。
