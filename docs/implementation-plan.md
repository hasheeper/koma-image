每阶段只标记实际完成和验证过的部分。当前没有网关通信、生产发布、数据迁移或旧库清理行为。

M1 的工作区仅接入导航、草稿、折叠／分类状态、空态和布局宿主。绘图画幅／参数、真实收藏、对话数据、词典查询、Key 解锁、编辑画布及备份读写仍属于后续阶段；未接入的业务按钮禁用。下一步是 M2 的 Gateway Profile、连接／存储契约与全局默认 N=1 调度器。

前置验证环境为 Node 26.8.2、npm 11.19.1、Chromium 151.0.7922.34；开发入口、构建根路径与静态子路径均成功挂载，默认头像解码通过，没有上游请求或应用数据写入。源码与产物经过私有标识检查。上述结果仅覆盖启动骨架，不代替后续工作区、业务或迁移验收；CI 配置已添加，尚未在远端执行。

公开发布仅包含本工程审查后的源码与资源。旧应用和迁移桥不成为运行依赖。旧数据清理后，回退版本必须能读取 Koma schema；不能直接恢复只认识旧数据格式的页面。
