## 仍待真实验证

- **供应商联调**：目标地址的目录、鉴权、CORS、账户权限、真实型号、请求参数、返回格式、生成效果与实际扣费；不把只读目录或报价成功当作生成成功。
- **NovelAI 官方兼容缺口**：四个 V4.5／V5 基础型号与 V5 Full Medium 文生图、绘图页动漫／兽人模式、Furry 补全、Effort／Complexity／预设／Rescale 已实现；请求与交互经本地模拟核验，公开 Furry 词库已有免鉴权只读检查；V4.5 Vibe／精确参考已接入并以模拟接口检查；仍缺官方重绘、PNG 参考编码恢复与独立图像工具。当前官网的 V5 三档均无两种参考入口，Vibe 通用文档的“V4 及以上”不能代替 V5 可用证明，见[参考能力边界](novelai-official.md#vibe-与精确参考边界)。基础参数还需按协议和型号收口。具体 wire ID、蒙版、参考图编码、参数、尺寸和扣费逐项核验；订阅优惠、V5 实际消耗／回充与各档账户规则仍待真实验证。只读用量不代替实际消费验证。见[型号与功能对照](novelai-official.md#型号与模式覆盖)。
- **ASK 质量**：真实图片黄金样例、诊断和提纯质量、用户提示词效果、命名质量、交接备忘录质量、CHAT 交接尺寸项在真实供应商上的效果及真实缓存命中；目前合成样例与模拟响应仅验证程序契约。
- **交付状态**：远端 CI 和线上脚本须对具体提交核对。历史记录不自动延续为当前部署证明或授权。

真实收费生成、推送和部署均须按工程约定取得对应授权。

## 当前范围之外

- OpenAI Responses／蒙版／流式部分图片，Gemini 原生有状态多轮与签名续传，以及原生图像协议的本地代理，均未包含在基础适配中。
- ASK 不做 RAG／Embedding、跨会话记忆、云端同步、后台静默压缩、自动生成或自动发送；编辑器内 ASK 和其他新入口需独立确认范围。
- 自定义并发与额度预占只保留边界，默认仍为全应用 N=1。
