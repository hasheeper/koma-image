## 产品权限

ASK 感知工作台、按需查图查词并给出诊断；任何修改先成为草稿，用户确认后才走既有数据写入路径。ASK 不生图、编辑、放大、报价、扣费或发送 CHAT 消息，不参与生成锁。

模型能力由用户界定，不按名称拦截；只使用 `openai-chat`、`anthropic-messages`。兼容服务按显式 Profile 和地址接入，不按域名猜协议或自动回退。命名与压缩复用推理能力，仍不获得生成权限。

## 现行决策

| 对象 | 契约 |
| --- | --- |
| 界面 | 用户批准的 B v5 五态浮窗，不挤压工作区；编辑覆盖层打开时隐藏 |
| 会话 | 本页最多 20 个；可新建、切换、重命名、删除、编辑重答和从回答分支；分支默认未收藏 |
| 活动画板 | 完整基础／角色原文随初始状态发送；其他画板只有目录；无锚点历史原文按需读取 |
| 草稿 | 一轮最多一份，字段分组审阅；支持安全参数直接设值；源板默认应用，可选新板；模型指定新板名时仅「新建并应用」 |
| 外部协同 B1 | 输入框附件旁目录标签挂载；现有设置 → ASK → 外部协同提供手动 JSON；外部 IMAGE 草稿无需文本 Key，进入接收时的 ASK 会话并排队，共用审阅／写入／撤销 |
| 共享资料 B2 | refs/ 仅清单随状态发送，`read_ref` 按需读取，共享附件和视觉预算；手动文件走原生附件入口，无资料选择弹窗；配方／备忘录／任务资料通过共享 `save_ref` 草稿确认后写入 refs/ 或下载 |
| 默认任务板 B3 | 默认本地持久清单，ASK 输入框上方紧凑 Todo、顶栏轻量总览；没有单项详情或常驻关联行。内外 `slate_edit` 修改任务／配方并与 IMAGE／文件草稿整体确认；任务与文件完成记录复用工具完成态，外部来源同行标注。挂载期间新建的活动任务板自动加入目录，其他已有任务板显式加入；目录交付与任务进度分开 |
| CHAT 交接 | 从 IMAGE／TAGS 写入 CHAT 一律新开会话，写入参考图、尺寸类选项与输入框；quality 只读、由回复提醒；AI 每轮可见当前 CHAT 模型能力，多图版本逐张编号 |
| 回退 | 应用／回退呈现为轮次检查点；页面共享最多 50 条完整撤销记录，按所有权操作全局栈顶 |
| 检索 | 本地历史使用冻结快照；词典按需调用共享在线只读查询，不是离线全词库 |
| 提示词 | 用户维护的创作正文保留；程序只维护协议、工具和状态事实，不增加词义分类或画师拦截 |
| 压缩 | 默认 64,000 tokens，轮次之间执行；常规自动触发只看最后有效输入量，详见压缩专题 |

## 会话、收藏与资源

未收藏对话只在本页内存。标题菜单可收藏／取消收藏，收藏置前；数据库写入成功才完成操作，失败保留原状态。取消收藏移除持久记录，当前页仍可继续聊天。

收藏保存到 `koma-ask/conversations`，通过 `data.write` 更新单条记录，不整体覆盖其他标签页。消息、标题、输入、附件、待确认草稿变化走既有延迟保存与 flush／reload；隐藏／离页时尝试 flush。

保存内容包括消息、工具结果、用量、标题、未发送输入、附件原件／发送编码、待确认草稿、外部草稿记录及等待队列，以及压缩的稳定编号、记忆、账本、归档和附件索引。恢复时重建 Object URL，未完成请求标为停止，不自动请求。普通 `#h` 历史不会因收藏 ASK 变成持久图片；编号作用域保留，不能指向刷新后新图。

Key、运行控制器、调用调试、Object URL 和撤销执行记录不持久化。恢复的已应用检查点只供查看，不能伪造可执行回退。保存的待确认草稿应用前仍检查当前目标与冲突。ASK 收藏及其附件不进入普通 Koma ZIP。

## 设置、自由创作与附件

「设置 → ASK」独立管理推理模型、命名模型、图片开关、个人偏好、自由创作、压缩阈值和附件上限及外部协同分组。更多菜单仅保留「压缩上下文」「调用调试」，不承载设置开关或手动导出。设置中的 ASK 配置可进入普通备份，收藏内容不进入；自由创作开关单独保存于 `koma.ask.adult.v1`，不进备份。

「自由创作」默认关闭，无下方附加说明。开启后才加载附加创作语境并启用词表混淆／A → B 替换；词条与规则默认空，只检查格式、长度、重复及逆向映射冲突，不做语义排除或代码级画师判断。关闭时隐藏编辑区并暂停转换，保留配置；规则变化仅在轮次边界生效。本地表单、草稿与展示始终为原始文本，出站转换、入站先还原再校验。

文本附件默认单个 50,000、每轮 100,000 字符，可设置正安全整数，总上限至少为单个上限；恢复默认与压缩阈值共用设置区。新限额只作用于后续添加，不截断现有附件或历史。图片与文本每轮分别最多 4 个，图片大小和视觉预算见[附件与视觉](ask-contracts-and-decisions.md#附件与视觉)。

## 命名与压缩

AI 命名由用户点击发起，默认沿用 ASK 模型，也可独立指定连接与完整模型 ID。命名仅写回目标名称，不加入主 ASK 上下文或执行工具。细节见[提示词与命名](ask-prompts.md)。

压缩使用发起时选定的 ASK 连接与模型，没有独立压缩模型或后台静默任务。收藏随同保存记忆与归档；当前表单永远由最新状态决定，记忆不代替原图或当前草稿基底。详见[压缩契约](../compaction-plan.md)。
