# Koma ASK：前端 UI 方案与交互定稿

日期：2026-10-21。状态：定稿；字体、颜色、按钮与动效时长已按《决策与实施规划》（文档 4，`ask-implementation-plan.md`）§2.2 统一到站内 tokens。优先级：文档 4 > 文档 3 > 本文 > 文档 1。
依据：基于《动画节奏 v2》《消息流 v6》《标识 B+》《草稿》四份 HTML 原型（`实际参考前端UI.txt`）提炼，作为 `src/ask/` 下 Vue 3 组件拆分与样式落地的规范。下文的色值与字号保留原型记录，落地时按文档 4 §2.2 映射。

## 1. 抽屉容器与全局布局

`Koma ASK` 作为外壳层级的常驻抽屉（`AskDrawer.vue`），在 `#/image`、`#/chat`、`#/tags` 切换时保活，覆盖在右侧图片栏之上，不挤压中间画布。

* **尺寸与定位**：固定宽度 `460px–470px`，高度 `100vh`（窄屏/移动端降级为底部面板），背景色 `--l1 (#141416)` 或 `--panel (#18181a)`，左侧带深色投影 `box-shadow: -30px 0 60px rgba(0,0,0,.45)` 与 `1px` 描边 `--line (#26262a)`。
* **纵向三段式结构**：
  1. **顶栏（`header / .ah`）**：固定高度 `54px–60px`，左侧为 `B+` 方块标识 + `Koma`（站内字标字体 `--brand`，`700` 字重）+ `ASK`（`--sans`）（`11px–12px`，字距 `0.14em`，暗灰 `--lo`），右侧为辅助开关或偏好入口。
  2. **消息流（`.stream`）**：`flex: 1`，内边距 `4px 24px 24px`，隐藏滚动条（`scrollbar-width: none`）。
  3. **底部停靠区（`.bottom`）**：`flex: none`，内边距 `0 14px 14px`，由上至下依次承载**「草稿卡槽（`#slot / .card`）」**与**「输入框（`.composer`）」**。

## 2. 色彩与排版（统一站内字体与 tokens）

* **字体统一**：
  * 正文、标题、按钮、工具行与草稿卡全部使用站内圆体 `--sans`（Koma Rounded）；ID 锚点、行内 Tag／代码与等宽统计使用 `--mono`；顶栏字标「Koma」使用 `--brand`。不引入 Manrope 或系统字体栈，不新增字体文件。
  * 渲染跟随 `public/styles/base.css` 的全站设置，不在 ASK 内单独关闭 antialiased。
* **字重**：
  * 正文基准 **`400`**（`15px/1.7`）。
  * 唯一强调句（`.lead`）与卡片标题使用 **`600`** 字重（由 Koma Rounded 的 Bold 文件承担），颜色 `--fg`，靠字重与 `400` 正文拉开主次。
  * 字号优先使用站内阶梯（11／12／13／15／18），原型中的 14／13.5／12.5px 落地时取相邻档位。
* **色彩语义表**（原型色值；实现映射见文档 4 §2.2，如 `--panel` → `--chrome`、`--acc` → `--a`、`--ins`／`--del` → `--ok`／`--err`）：

| 变量 | 色值 | 用途 |
| :--- | :--- | :--- |
| `--bg / --field` | `#0d0d0f / #111113` | 底层背景 / 草稿内嵌代码与参数切片底色 |
| `--panel / --l2` | `#18181a / #1a1a1d` | 抽屉主背景 / 草稿卡片背景 |
| `--l3 / --bubble` | `#222225 / #2a2a2d` | 输入框背景 / 用户提问气泡背景 |
| `--hi / --tx` | `#ffffff / #ececee` | 核心结论与标题 / 普通正文列表 |
| `--ob / --lo` | `#8a8a92 / #62626a` | 工具操作对象与次要说明 / 图标、耗时与占位符 |
| `--acc` | `#b3a1ff` | 品牌丁香紫：ID 锚点、当前步骤高亮、选中描边 |
| `--ins / --del` | `#7fd4a0 / #e58b8b` | 草稿新增（薄荷绿） / 草稿删除或冲突改写（暖红） |

## 3. 品牌标识系统：B+ 聚光矩阵

延续全站 3×3 小方块母题，采用**向心聚焦（B+）**参数，隐喻“中心取景与审视”：

* **几何参数（`19×19` 坐标系，中心 `9.5`，圆角 `rx = min(2.1, s * 0.28)`）**：
  * **中心块（Core, `r=0`）**：尺寸 `7.4`，坐标 `(9.5, 9.5)`，基础不透明度 `1.0`。
  * **四边块（Edge, `r=1`）**：尺寸 `3.6`，边距 `ec = 2.6`，基础不透明度 `0.50`。
  * **四角块（Corner, `r=2`）**：尺寸 `2.8`，角距 `cc = 3.0`，基础不透明度 `0.24`。
* **思考态呼吸波（`.think`）**：
  * 当 ASK 处于请求或工具循环中时，顶栏 `22px` 图标激活径向脉冲动画（周期 `1.8s`，缓动 `cubic-bezier(.4,0,.2,1)`）。
  * 按 `r = 0 → 1 → 2` 依次延迟 `220ms` 将不透明度推至 `1.0` 再回落，形成由中心向外扩散的思考涟漪。

## 4. 消息流（Stream）组件规范

消息流彻底去除了 AI 侧的气泡框，采用**“右对齐用户气泡 + 左对齐散文与单行证据链”**的排版：

1. **轮次间距（`.turn`）**：轮与轮之间间隔 `30px`；同轮内部元素默认间隔 `12px`，连续段落（`p+p`、`p+ul`）收紧为 `6px`，核心结论（`.lead`）上方留白 `16px`。
2. **用户提问（`.u`）**：右对齐，最大宽度 `84%`。若附带当前图像上下文，上方右对齐悬挂 `32×42px`（圆角 `7px`）的微缩图预览，下方为 `--bubble` 圆角胶囊文本。
3. **只读工具轨迹行（`.tools > .tool`）**：
   * 固定高度 `26px`，字号 `14px`，`15px` 线性图标居左。
   * **结构**：`[图标] 动作词(已对比/已查看/已裁切/已检索) + 操作对象(.o, #8a8a92) + 等宽统计(.s, 12.5px, 如 "3 处变化" / "42 KB" / "+1 -1")`。
   * 连续调用多个工具时归入同一个 `.tools` 容器，行间无额外外边距，紧凑排列。
4. **行内元素**：
   * **ID 锚点（`.id`）**：`JetBrains Mono` `14px`，丁香紫 `#b3a1ff`，可点击定位画布。
   * **行内代码/Tag（`code`）**：`13.5px` 等宽字体，底色 `rgba(255,255,255,.08)`，圆角 `5px`，继承所在行字重与颜色。
5. **外部状态分隔（`.note`）**：当用户在 ASK 会话中途手动修改了外部提示词时，流中插入 `13px` 暗灰提示行（如 `提示词已在外部修改`），上下留白 `30px / 16px`。
6. **冷区检索消歧器（`.pick`）**：当模糊检索命中多张历史图时，横向排列候选按钮（间距 `10px`），每个按钮由 `64×86px` 缩略图（圆角 `9px`）+ 底部 `.id` 组成，悬停时缩略图亮起 `2px` 丁香紫描边。

## 5. 动画节奏与滚动跟随（Pacing & Motion）

统一三档时长，落地使用站内 `--t1 (120ms)`、`--t2 (220ms)`、`--t3 (380ms)` 与缓动 `--e`／`--e-out`。原型中的 `--d1–--d3` 与 `--k` 慢放倍率只用于演示，不实现：

* **入场与切换**：
  * 新消息/新工具入场（`.enter`）：`380ms`，**透明度先行**（`--soft: cubic-bezier(.25,.1,.25,1)`），**`4px` 向上位移跟随**（`--out: cubic-bezier(.2,.7,.2,1)`）。
  * 工具完成态切换（`.swap`）：整行从“正在查看…”交叉淡化为“已查看…”，时长 `220ms`。
  * 初始思考占位退场（`.leave`）：`120ms` 淡出后再移除 DOM。
* **运行态微光（`.run .txt`）**：采用低对比度慢速扫光（`--ob #8a8a92` $\leftrightarrow$ `--tx #ececee`，背景宽 `250%`，周期 `2.4s ease-in-out`），温和不刺眼。
* **诚实节拍器（最小驻留补足，只补足不累加）**：
  * `toolMin: 600ms`：本地瞬时完成的工具（如元数据对比、草稿生成）至少在运行态停留 `600ms`，防止界面闪烁。
  * `betweenTools: 160ms`：连续工具之间的出现间隔。
  * `afterText: 320ms`：文字段落输出后的阅读停顿。
  * `beforeDraft: 300ms`：正文与工具流完全静止 `300ms` 后，底部才弹出草稿卡。
* **阻尼滚动跟随**：流式输出期间通过 `requestAnimationFrame` 以阻尼系数缓动滑向底部；**一旦检测到用户向上滚动滚轮（`e.deltaY < 0`），立即解除自动跟随**，直至用户滚回底部（距离 `< 4px`）才恢复。
* **减少动态（`prefers-reduced-motion: reduce`）**：所有位移与微光扫光全部关闭，入场简化为 `120ms` 纯透明度渐变，运行态文字末尾静态追加 `…`。

## 6. 聚合草稿卡（Draft Card）规范

草稿卡位于输入框正上方，圆角 `20px`，背景 `--l2 (#1a1a1d)`，是 ASK 唯一的写入出口。

### 6.1 卡片头部与全局操作（`.head`）
* 左侧为类型图标（紫 `#b3a1ff`）+ 标题（如 `修改提示词` / `从 #h12 恢复` / `提纯并新开分支`）+ 副标题定心丸（明确标注 **`N 处 · 应用后不会生成`** 或 **`应用后不会发送`**）。
* 右侧为 `[忽略]`（快捷键 `Esc`）与主按钮 `[应用]`（沿用站内 `.btn-primary`：`--a` 底、`--a-ink` 字；快捷键 `Tab`，焦点护栏见文档 3 §4.2）。

### 6.2 步骤时间轴与单步控制（`.steps > .step`）
* 多步草稿（`.steps.multi`）在左侧 `32×32px` 步骤图标下方绘制 `1px` 纵向连接线。当前核心步骤（`.cur`）图标背景高亮为淡紫 `rgba(179,161,255,.15)`。
* **单步撤回/恢复**：非锁定的步骤在鼠标悬停时右侧浮现 `[撤回]` 按钮；点击后该步透明度降为 `0.3`（`.step.off`），按钮变为 `[恢复]`。若所有可选步均被撤回且无锁定步，`[应用]` 按钮自动进入 `aria-disabled="true"` 禁用态。前置必选步（如新开分支的起点）标记 `data-lock`，不显示撤回按钮。

### 6.3 四种原位预览切片（`.slice`）
1. **局部增改切片（`small` / `prompt_patch`）**：
   * 文本框左侧带 `3px` 竖条指示器（修改为紫 `--acc`，纯新增为绿 `--ins`）。
   * 未改动上下文设为暗色（`.dim`）；权重修改处使用暖红底色 + `1.5px` 紫色描边包裹（`.rw`）；新增词使用薄荷绿底色 + 绿色描边包裹（`.add`）。
2. **整段改写切片（`rewrite`）**：
   * 步骤右侧提供 `[新稿 | 原文]` 切换标签。
   * 新稿中**凡属保留下来的用户原词，一律添加 `1.5px` 丁香紫下划线（`.keep`，偏移 `5px`）**，方便用户一眼核对核心特征是否丢失。
3. **参数恢复切片（`restore` / `restore_partial`）**：
   * 采用 3 列网格（`.inputs`）展示参数小卡片。发生变更的参数卡带 `1.5px` 紫色内描边（`.inp.on`），内部并排显示 `~~旧值~~` 与高亮 `新值`；未变更的参数卡以 `0.4` 透明度灰显作为参照。可与文本补回步骤混排在同一张草稿卡中。
4. **对话分支提纯切片（`branch` / `chat_distill_branch`）**：
   * 聚合展示三步：`① 从 #c2 新开分支（锁定）` $\rightarrow$ `② 排除 #c3–#c8（可撤回）` $\rightarrow$ `③ 填入描述，等你发送`。
   * 第三步切片内展示合并提纯后的文本，末尾附带 `1s` 步进闪烁的 `2px` 丁香紫输入光标（`.cursor`），直观传达“仅填入输入框、不自动发送”。

### 6.4 结束态与撤销闭环（`.done`）
* 点击 `[应用]` 或按 `Tab` 后，草稿卡原地坍缩为单行完成态：`[绿色对勾] 已写入提示词 · 未生成 ─── [撤销]`，同时在消息流末尾落下一行工具记录 `已应用草稿 修改提示词 +1 -1`，并触发 `aria-live="polite"` 读屏播报。
* 点击 `[撤销]` 可立即恢复完整的草稿卡片并回滚表单状态。

## 7. 输入框（Composer）规范

* 与对话页输入框保持一致：`--raised` 背景、`--line-2` 描边、`24px` 圆角；内边距按原型 `13px 10px 10px 18px` 起步，落地时对齐对话输入框。
* 上层为多行输入区（占位符 `问这张图，或用 #h 引用历史…`）；下层工具栏（`.cbar`）左侧显示当前绑定的上下文锚点胶囊（如 `#h24`），右侧显示当前选用的多模态模型名称（如 `Gemini 2.5 Pro`）与 `32×32px` 圆形发送按钮（样式沿用对话输入框的发送按钮）。「发送图片给模型」关闭时，工具栏标明受限模式。
* 运行期间，发送按钮原地切换为深灰底色（`--l4`）的圆角方形停止按钮（`.send.stop`），按 `Esc` 或点击即可中断当前轮次。
