## 工具与缓存

状态摘要已删除 `image.prompt_sections`；原始 prompt/negative 和根层 base_hash 保留。历史检索支持多关键词与当前来源；词典使用 queries 数组批量核验，复用共享在线服务，不要求先打开词典。具体接口由 tools.ts 的 Schema 及 [检索规范](ask-retrieval-state.md)约束。

`get_model_manual({ id })` 只读取三份内置手册，不接收任意路径或 URL，不联网。手册正文只作为 `<data>` 工具结果追加，不预装进静态 System；计入原六次工具调用预算。

切换工作区/生图模型不替换静态核心。版本或 Schema 变化可能影响缓存；实际命中仍以上游 usage 为准。
