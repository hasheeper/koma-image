## 状态、工具与创作正文

活动画板基础／角色原文直接随 `<workspace_state>` 发送，其他板仅目录；无锚点历史按需读取。角色靶点使用完整稳定 ID，add／set_position 不隐式开启手动定位。新板草稿可带 `new_board_name`，提议时不建板，确认才写入；不会为了草稿名称另调命名模型。

所有静态核心和 tools 顺序保持稳定，动态状态在队尾。专项手册和召回结果通过工具追加，不回改 System；详见[协议与运行契约](ask-contracts-and-decisions.md)。前端不依据文体、画师名字、词义或自然语言推断权限，只校验草稿结构并交给用户确认。

## 自由创作

开关保存于 `koma.ask.adult.v1`，默认关闭，不进备份。关闭不加载附加语境、不转换词表或替换；开启后在中立核心追加一次附加块，规则默认空。个人偏好与映射保持在实际最后一个 System 块。

出站在 provider 网络边界确定性转换，入站文本与草稿先还原再展示／校验；本地表单始终原文。只检查格式、长度、重复与逆向冲突，不建立语义排除表。规则切换在下一轮生效，同轮请求冻结 System 和 codec；关闭不改写历史。

## AI 命名

ASK 标题和画板胶囊的星光按钮由用户点击发起，再次点击可停止。设置中「命名模型」默认沿用 ASK，也可独立选择连接并手填完整 ID；显式不可用时报告配置问题，不静默回退。配置作为 `koma.ask.v1` 可选 `naming` 字段进入普通备份。

命名要求单行中文短名，优先 4–12 字。ASK 只取完成轮次的提问／回复正文（首轮及最近四轮，约 12,000 字符上限），画板只取基础正向词与启用角色正向词。不会发送其他会话、其他板、Negative、历史图片、附件原件、工具轨迹或完整状态，不加载主提示词与工具。

每次点击只发一次文本请求，60 秒未完成停止并保留原名，不自动重试。完成后只更新发起目标，目标被删除或手动改名则丢弃迟到结果；画板保存失败还原名称。ASK 名称随收藏持久化。命名沿用自由创作规则，并进入「AI 命名 · ASK／画板」调用调试，用量计入本页。

## 压缩与验证

压缩使用当前 ASK 模型，指令只覆盖归档边界之前的成功历史，不读取待发提问或托盘附件，不新写提示词或调用工具。全文和输出校验由 `prompts/compaction.ts`、`compact/validate.ts` 维护；触发与事务见[压缩专题](../compaction-plan.md)。

模拟只能证明请求、还原、名称写回和备忘录结构的程序契约。真实命名、提示词质量、诊断和压缩备忘录质量仍待验证。
