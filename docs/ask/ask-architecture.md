# ASK 产品与架构

更新：2026-10-29。现行决策以[ASK 维护入口](ask-implementation-plan.md)为准；本文负责定位和所有权，不保存阶段计划。

## 定位

ASK 是图片工作台的创作搭档：感知当前状态，按需读取图片、参数、词典和模型手册，给出诊断与可审阅的草稿。用户始终掌握写入、生成和发送。普通建议可以直接忽略，确认草稿可以检查冲突并回退。

典型任务包括提示词局部修改、参数诊断、对比历史、查找先前方案、角色描述调整、CHAT 上下文诊断与提纯分支，以及把图片、画幅和描述交给新的 CHAT 会话。多图项目可用默认 Todo／Slate 分解、推进和绑定成果；任务、共用配方与文件保存可和画板修改组成同一份确认草稿。通用联网搜索、后台自主代理、RAG、云同步与跨会话记忆不在当前范围。产品整体关系见[产品总览](../product-overview.md)。

## 外壳与状态

`AskDrawer.vue` 在唯一 App Shell 中持续挂载；车间同一容器在圆形入口、运行胶囊、结果卡、写入胶囊和窗口间变形，不占工作区栏位。HOME 复用同一服务与窗口停靠呈现，头部承接收起状态，详见[HOME](../koma-home.md#7-ask-在-home)。收起保留会话和运行，EDIT 同样可用；Photopea 打开时收起并让出键盘。

发送时冻结工作区与图片快照：活动画板完整基础／角色词文直接发送，其他画板仅目录；历史图片有锚点时提供相关上下文，无锚点时不预载历史原文。`get_state` 默认读取 initial，显式 latest 追加最新状态，不回改本轮草稿基底。当前状态和记忆的优先级见[检索](ask-retrieval-state.md)与[压缩](compaction.md)。

外部协同由应用级 `src/bridge/` 提供，目录入口位于 HOME 头部或 ASK 输入框附件按钮旁，手动兜底位于现有设置 → ASK 页面。它负责文件传输、收件、refs 元数据／受限读取和用户显式导出；外部草稿、等待队列、检查点与撤销仍由 ASK 管理，不要求文本推理连接。ASK 经只读端口调用 `read_ref`，实际引用内容归现有附件池；文件保存通过 `propose_draft.steps` 的 `save_ref` 提议，经 DraftCard 确认后写入；没有直接文件写入工具。详细生命周期见[外部协同与本地任务](bridge.md)。

## 工具总览

当前固定工具集共有十三项，Schema 与描述由实现提供，不随工作区或模型名字切换：

| 工具 | 责任 |
| --- | --- |
| `get_state` | 当前工作台、冻结或最新状态、指定 IMAGE／EDIT 画板 |
| `check_nai_input` | 本轮候选修改的能力、token／Text 与只读费用检查，不写入 |
| `get_meta` | 图片完整参数，不发送像素 |
| `diff_meta` | 参数与词文差异，不能代替视觉对比 |
| `search_history` | 本轮历史、收藏、EDIT 版本与当前 CHAT 分支图片检索 |
| `view_image` | glance／look／crop 按需看图 |
| `view_sheet` | 2–6 图带 ID 拼图，用于预览与对比 |
| `get_chat_context` | 冻结的当前 CHAT 分支、实际发送上下文与当前模型能力 |
| `search_tags` | 共享在线词典的只读批量核验 |
| `get_model_manual` | 内置模型专项手册 |
| `propose_draft` | 提议唯一待确认草稿，不直接写入 |
| `get_turn` | 本会话成功轮次及附件的原文召回 |
| `read_ref` | 挂载 refs/ 的资料按需读取，复用附件与视觉预算 |

正文 ID 引用和结构化候选是两条通道。选择候选只绑定／预填，下一轮才以其为锚点，不自动发送。工具结果作为资料包裹，不升级为指令。详细预算、签名和错误处理由运行／检索／压缩专题维护。

## 模块与写入所有权

| 文件／目录 | 责任 |
| --- | --- |
| `service.ts` | 应用级服务、会话准入、UI 与工作区桥接、收藏和调用协调 |
| `session.ts`、`runner.ts` | 轮次事务、稳定编号、上下文、工具循环与失败回滚 |
| `provider.ts`、`adapters/` | 两协议转换、流式解析、编解码和实际请求捕获 |
| `tools.ts` | 只读工具注册，仅接收只读端口 |
| `digest/`、`library.ts`、`ids.ts`、`edit-context.ts` | 状态摘要、冻结图片索引、EDIT 现场与目录、可公开编号与作用域 |
| `search-history.ts`、`search-tags.ts` | 本地历史与共享词典查询 |
| `../services/nai-awareness.ts`、`edit-awareness.ts` | 共用 NAI 能力／有效输入／预算／费用的只读投影 |
| `draft/` | 结构校验、字段 diff、确认写入、冲突与撤销栈 |
| `attachments.ts`、`vision.ts` | 用户附件、像素处理、引用计数与视觉预算 |
| `conversations.ts`、`favorites.ts` | 多会话、分支和显式收藏的持久快照 |
| `compact/` | 账本、布局、触发、归档、备忘录校验与原子提交 |
| `prompts/`、`naming.ts`、`debug.ts` | 提示词、独立命名和调用调试 |

工作区通过 ASK 服务打开或预填，不导入内部实现。只读工具不能取得生成或表单写入服务；确认后经 `draft/apply.ts` 和既有 `data.write` 路径应用，失败不能留下半套写入。草稿不触发报价、生图或 CHAT 发送。

Vue 持低频界面状态，大图片、数据库、原始调试 body 和控制器保留在服务普通内存。浮窗拖动由原生驱动，结束再同步必要状态；预览 URL 和监听按引用和生命周期回收。

## 生命周期与验证

本页最多 20 个会话；未收藏刷新清空，收藏保存于本机 `koma-ask` 并可续聊。撤销执行栈最多 50 条，调试只留本页。保存范围、编号恢复与历史检查点限制见[现行契约](ask-implementation-plan.md#会话收藏与资源)。

浏览器内运行工具循环；静态版可直连推理服务，本地 `server.mjs` 仅承担固定路径流式转发和服务端 Key 注入。模型实际工具、视觉、缓存与质量能力需真实验证，合成样例仅证明程序契约。

本地任务服务 `src/slate/service.ts` 独立于 ASK 会话与目录。ASK 仅以冻结摘要、`get_state(include_slate=true)` 和共享 `slate_edit` 感知／提议任务；确认时草稿写入器协调任务、资产与画板提交记录，沿用原检查点／撤销。目录和下载复用相同的成果回执与确定性标注。

Todo 持久化同样运行于 HTTPS 静态站；「本机」表示浏览器本地数据，不要求本地服务器或目录 API。会话持有清单关联，删除会话不删除独立任务与成果。任务身份、版本和绑图校验由共享 Slate 规则负责，内外草稿复用同一实现。

UI 沿用共享基础：会话内紧凑 Todo、图标入口的轻量总览、附件旁目录标签，以及统一 DraftCard 的任务／配方／文件摘要行。文件确认、任务推进与外部草稿完成记录复用工具完成态；没有资料勾选或原始代码导出预览弹窗。更多菜单保留压缩与调用调试，配置和手动兜底进入既有设置 ASK 页面。
