# 图片身份与引用

更新：2026-10-29。维护 IMAGE、HOME、CHAT、EDIT、ASK 的图片身份、展示编号及外部引用规则。生成执行、参数和资源仍由原工作区持有；本文不授予 ASK 编辑或生成权限。

## 实体与记录

`entity_key` 为实际原图文件字节的 `sha256:<64 位小写十六进制>`。原图入站先取得身份，哈希在 IndexedDB 写事务外完成并按 Blob 弱缓存；缩略图、视觉编码、HOME 展示副本均不是原图身份。相同原图重新读取为另一个 Blob 仍可共享派生编码。不做像素或感知去重，重新编码后字节不同则是另一个实体。

记录主键不变：IMAGE／收藏记录、CHAT 资产、EDIT 版本和 Slate 成果仍走原存储路径。参数、Seed、时间及血统归具体记录；两个生成事件即使字节相同，也保留各自配方。实体索引只关联原有资源，不持有第二份全局 Blob 库。

已知原记录从 IMAGE／收藏进入 EDIT 原图位置，只增加别名，不制造生成事件或父实体自环；收藏复用原记录。实际图生图、重绘、Enhance、放大、Director Tools 和 Photopea 结果各有记录，血统保存父记录／父实体、操作类型与工具细节。未知出处不推断。

## 展示编号

| 区域 | 形式 | 生命周期 |
| --- | --- | --- |
| IMAGE 历史 | `#h12` | 应用本页单调递增，删图不补洞；刷新重置，切 ASK 会话不重置 |
| HOME／收藏 | `#f3` | 收藏项固定 `favSeq`，收藏库保存身份和下一个可用序号；刷新保持，取消不重排 |
| EDIT 完整码 | `#e2.3`、`#e2.3a` | 本页板号与板内逻辑版本递增；关闭画板、移除版本不复用 |
| EDIT 本板简写 | `#e3`、`#e3a` | 只在当前活动编辑画板解释；每轮冻结活动板 |
| CHAT | `#c2.1`、`#c2.1a` | 会话／分支中的轮次与版本，引用冻结具体轮次、版本和资产 |
| ASK 图片附件 | `#a1` | 当前 ASK 附件作用域单调递增；收藏恢复计数器，释放图片不回收编号 |

EDIT 原图为版本 1，不能删除或淘汰；衍生图归 EDIT，不自动进入 IMAGE 的 `#h`。每板默认保留 35 张物理图片，上限在通用设置独立调整，0 为不限；逻辑编号与容量分开，修改数量不重排或复用编号；去背景一组三张占三张，淘汰按组释放，原图、当前底图、查看组与最新结果受保护，可暂时超限。去背景 `a=masked`、`b=generated`、`c=blend`；省略字母指该组当前选择，默认 a。整轮冻结后不随界面切换。

CHAT 多图优先显示字母，旧 `#c2.1.1/#c2.1.2` 继续解析为对应资产；省略字母仍指该版本第一张图。超出单字母范围的既有成员保留数字别名，不增加供应商输出上限。非法额外段、残缺前缀不解析，句末点号不属于引用。

## 冻结绑定与作用域

`ImageTagBinding` 保存标签、实体、具体记录及作用域，包含必要的板／轮次／版本／资产身份。工具使用整轮冻结图片库，`get_state(scope="latest")` 不重绑本轮标签。回复预览、候选、草稿来源、收藏 ASK、账本、压缩与归档保留绑定；不全局替换旧会话正文中的编号。

- `picture_scope_id` 是整个应用页面的 `#h/#e` 空间，仅重新初始化页面时改变，切板、切工作区与 ASK 会话不改变。
- `favorites_scope_id` 是持久收藏库身份，普通刷新、删除收藏及合并导入不改变。
- CHAT 引用冻结会话、具体轮次／版本／资产，不按切换后的分支位置重解。
- 附件绑定所属 ASK 附件作用域；新会话不借用其他会话的同名 `#a1`。

旧页面标签不能绑定新页同号图。若原记录仍有持久收藏，可以显示准确原图；同实体只帮助恢复像素，不借用另一条记录的参数。只有旧编号快照的 Koma 会话按其原记录映射恢复预览，不将旧 `#f3` 自动认作当前库的新 `#f3`。缺失稳定绑定的文字记忆不具有恢复参数或绑图权限。

## 收藏与备份

`koma-image-favorites` schema v3 保留原 `favorites/referenceAssets/vibeEncodings`，增加 `identity` 与 `favoriteTags`。最小登记为序号、记录、实体及 active／retired 状态，不保留已删除原图载荷。

分配收藏、登记与计数器在同一 readwrite 事务中提交，外层经过 `data.write`。多标签页由 IDB 串行分配；失败不点亮收藏。取消收藏停用原号；8 秒撤销恢复原号，之后重新收藏取得新号。删空不重置库或计数器。

实时编号表只读取存储分配的 `favSeq`，不按列表位置、时间或旧会话快照补号；缺号或重号视为数据未就绪或冲突。停用登记只由收藏存储维护。ASK 只保留一套本页历史编号表，收藏会话恢复不向其注入旧编号；旧快照仅用于恢复历史引用。EDIT 没有向 IMAGE 历史外部入库的入口，只有 IMAGE 生成结果进入其历史。

现有 Koma 收藏一次性补齐身份和编号：优先无歧义的已有编号快照，其余按 `favoritedAt/createdAt/id` 稳定排序；有效固定编号保持。无关旧应用迁移仍不提供。

普通备份仍为 Koma v2，继续合并导入，增加可选 `imageIdentity.version=1`、收藏登记、实体和血统。读取验证原图字节，不信任自报实体；显式不支持的身份版本拒绝。导出在同一收藏读事务中取得记录和编号状态。

- 从未使用过的新空库可继承备份库身份、固定号与计数器。
- 同库一致的停用登记可恢复原号，冲突不覆盖本机登记。
- 异库新增记录取得本地新号；重复导入幂等，既有记录和配方保留。同记录发生原图或配方冲突时保留独立副本；导入 CHAT 冲突副本时同步调整收藏与血统中的会话／轮次／版本关联。
- 用过再删空的库不是新空库，不能继承另一库的号码。
- 普通备份仍不包含页内历史、编辑现场、ASK 收藏或 Slate。

## 视觉与参数

视觉编码按实体＋规格＋裁切范围缓存，全图已看资格保存在当前 ASK 会话。成功看过 `#h1` 后，可对其 `#e1.1/#f1` 别名裁切；实际随请求发送的附件也按原图实体登记资格。拼图不授予单图全图资格。

同一轮相同实体、相同规格／区域的重复工具请求可返回已查看，不重复发送或计预算；显式 `reinspect=true` 仍发送。glance 升 look、新 crop、跨轮重看正常计预算。编码缓存命中本身不代表已发送，其他 ASK 会话不继承资格。仅元数据、停止或失败不提交新的已看记录。

继续使用每轮 4 次、1.5MP、400KB 的工具视觉上限。`get_meta/diff_meta/restore_partial` 始终读取引用绑定的具体记录参数；同实体的不同记录不互相覆盖。图片库与检索按记录去重，按实际来源成员筛选 history／favorites／edit／chat。

## Bridge、Slate 与 HOME

外部 live.v1／draft.v1 外层使用 `picture_ref_version:2`：`#h/#e` 校验页面作用域，`#f` 校验收藏库作用域，混合引用分别校验。EDIT 简写还须带 `edit_board_id` 匹配活动编辑板，推荐外部使用完整码。旧无标记投递继续执行原有保守检查。IMAGE 的 `base_hash` 冲突检查保持。

状态提供 EDIT 各板与轻量版本目录：完整码、本板简写、实体、尺寸、工具、父记录与出处。Bridge 的 EDIT 索引保持只读、外部草稿目标仍为 IMAGE；内置 ASK 已开放编辑状态、页内配置草稿与交接，见 [ASK × EDIT](../ask/edit.md)。精确协议由目录 `PROTOCOL.md` 生成，公开技能同步维护。

EDIT 原图与衍生版本可直接绑 Slate，保留独立持久成果、实体及来源绑定；无需先变成 `#h` 或强制收藏，源版本移除或页面刷新不删除已交付成果。CHAT 仍可经收藏路径交付，ASK 附件不扩大为成果来源。

HOME 封面继续绑定创作线与收藏记录，实体不使另一条创作线的同图替换封面。展示缓存没有可读原图编号。

## 界面与维护

IMAGE 显示 `#h` 及已收藏的星标／`#f`；收藏与 HOME 显示固定 `#f`；EDIT 版本栏显示本板简写，复制和详情使用完整码。界面不展示哈希或 UUID。

ASK 输入 `#` 提供紧凑图片候选，方向键选择，Enter／Tab 插入，Esc 关闭；输入法组合不抢键，选择不发送、不清空正文。补全关闭时保持原有发送与草稿确认行为。

核心实现为 `domain/image-identity.ts`、`services/image-identities.ts`、`ask/ids.ts`、`ask/edit-context.ts`、`ask/library.ts`、`ask/vision.ts`。[本地验收](../archive/image-identity/2026-10-28-image-identity-verification.md)使用合成图与模拟接口；真实供应商效果和额度不由本地通过结果代替。
