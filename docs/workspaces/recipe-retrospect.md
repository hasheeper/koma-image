# 版本演进

更新：2026-11-09。版本演进已覆盖 IMAGE、EDIT 与 CHAT 的候选读取、持续跟踪、回退和定稿，并比较实际配方与操作来源。日常创作无需预先建树；遇到瓶颈时由 ASK 识别同图边界与语义关系，激活后程序按具体基底记录后续生成，ASK 可继续归纳阶段。本文是唯一现行维护入口；设计背景见[概念记录](../archive/workspaces/2026-11-07-recipe-retrospect.md)，实施与验收见[版本演进记录](../archive/workspaces/2026-11-08-version-evolution-plan.md)，发布与真实待验状态见[当前状态](../status.md)。

## 使用与职责

在 IMAGE 历史区更多菜单、EDIT 画板入口或 CHAT 顶栏选择「请 ASK 发起演进」，或直接向 ASK 请求「复盘」「演进」「梳理／回顾修改脉络」「看看之前哪版更好」，均可开启或更新版本演进。入口只预填，发送后才推理。围绕同一画面连续多轮打磨仍陷入瓶颈时，ASK 可在回复末尾提醒用户使用演进；未获用户请求时不主动调用演进工具。日常生图不必提前开启或维护演进。

- 完整面板不设顶栏，演进图与大图铺满画布。底部复用 EDIT 胶囊，提供「大图／演进图」切换、当前视图工具、配方开关和独立 ASK；右上仅保留关闭按钮。图节点采用折叠相册，同一演进阶段的多图可就地翻页；外框按当前样本的真实图片比例完整展示，翻页从横图切至长竖图时同步变形，自动布局的行列间距、连线端点、框选和批注定位随尺寸更新；独立摆放后按主图左边缘与垂直中心锚点变形。原图失效时优先按所选样本配方中的尺寸展示占位。图支持平移、缩放；默认视野适度放大并围绕当前版本与对比基底，点击「适应全部」查看整棵树，双击节点进入大图。大图可查看 A、B 或并排，支持滚轮／双指缩放与拖动。节点默认采用代表图，切换 A 或 B 内的具体样本时，图片、右栏配方 Diff、恢复与 ASK 引用同步采用该图的真实配方；节点拓扑保持原样。
- 图外轻量标题行仅显示版本号与有足够空间的阶段名；NEW、A／B、定稿状态和样本翻页位于相册背图下方，右对齐主图边缘，采用按内容收缩的小浮片承托：短圆角、主题玻璃底色、细边和短投影，状态与翻页之间用轻分隔线区分。NEW 用主题强调色文字，翻页按钮只在悬停或键盘聚焦时提供反馈；远景减去模糊与分隔线。图片右上提供图钉「从这里开始」，默认隐藏，仅悬停节点或键盘焦点进入节点时展示，当前基底也遵循此规则；左下仅在有批注时提示。主图保留一圈边界，B 与多选同时存在时不叠第二个框；相册背图轻微向下叠放，图外文字按最大叠放位置留距，悬停不推动文字。图钉恢复该节点当前显示的具体样本，不改变 A／B 对照或触发批注、生图；只有活动基底的节点与样本均匹配时图钉点亮。配方收起时，恢复结果与错误仍在画布内反馈。原记录失效或当前不可写时禁用对应图钉，已解除的演进不会因恢复自动续跟踪。
- 图片按画布真实缩放；标题、图钉和分页采用受限的反向缩放，屏幕尺寸缓慢变化并封顶于常规控件大小，放大后相对图片变小。阶段名按自身剩余宽度决定是否展示，空间仅够一两个字时直接隐藏，完整名称仍可悬停查看；图外状态浮片按空间收起样本数字与次要状态。远景只保留版本和必要标记，极小概览隐藏控件，以起点圆点标识当前基底。上下文字预留、连线图中点和框选／批注命中使用同一尺寸规则，缩放不重排拓扑。
- 新版本节点用亮色 `NEW` 文字提示，位于图片外侧右下方的状态与翻页行，空间不足时缩为亮色圆点。首次打开面板时保留，关闭后再次进入消失；面板打开期间新建的节点同样保留到本次离开。首次整理、自动新增及 ASK 新建阶段均按节点身份判断，已有阶段追加样本不重复标记。仅本页查看状态，不修改演进修订号、配方或草稿基底。
- 单选版本设为 B，默认对比父版本 A；自动生成的分支优先采用当时实际回退的父版样本，连续续抽沿同阶段来源找到该样本。ASK 推演或旧快照中没有生成来源的连线沿用父版代表图。手动翻选 A 样本优先于自动参照，图节点、大图、Diff、恢复与 ASK 引用始终一致。Shift 点击或对比基准菜单选择任意 A，支持交换与恢复跟随父版。手选 A 后切换 B 保留 A；若 A 与 B 相同则恢复自动父版。多选／框选不改变右栏对照。
- 浏览或单选工具下，左键拖动节点主图／图外标题可单独调整位置；超过屏幕拖动阈值才开始移动，不改变 B／A、选择、语义连线或创作基底，不触发双击大图。其他节点不跟随、不被推开，无吸附，可自由重叠；最后摆放的节点在上层。拖动用原生 rAF 更新节点与连线，靠近画布边缘自动平移，滚轮缩放仍保持抓取点；Esc、指针取消、窗口失焦或关闭视图取消本次摆放。图钉、分页和状态浮片只执行各自操作，多选／框选／批注不进入节点拖动。位置仅本页按演进与节点身份保存，关闭重开保留，刷新清空，不改变演进修订号或草稿基底。活动占位出现后保存当前排布，节点与空白框分别保持独立位置；翻样本保持锚点并适配实际画幅。
- 画布可直接拖动空白区域平移；H 手型工具、按住空格或鼠标中键可在节点上平移，框选模式仍以空白拖动框选。滚轮以指针为中心缩放。拖动期间不强制居中，松手只保留少量内容可达；「适应全部」或 Home／0 显式回到全景。切换样本、图钉或生成落图不抢回镜头。画布平移与缩放视野按演进身份保留在本页；关闭重开、进入大图后返回以及新图落入预留位置时保持当前视野，不自动适应全图，刷新后随本页演进状态清空。
- 活动创作基底后方显示一条虚线与空白加号画框，按固定样本的真实比例预示后续分支区域；回退旧版时避开已有子树与其他节点。画框仅是视图，不新增版本、不参与 A/B 或批注；图钉成功恢复后才跟随新的基底，浏览其他版本或样本不改变其绑定。加号只收起演进并切到所属 IMAGE／EDIT／CHAT 工作区继续编辑，保留当前配方与基底，不恢复、不生成；未改配方的续抽仍进入当前版本。成功新增后占位随新基底推进，失败不变，解除／定稿后消失。80 节点满额时加号禁用并提示交给 ASK 合并阶段，续抽仍遵循原规则。空白框是可独立摆放的预备节点，单选／浏览状态下拖动框体调整位置，中央加号仍只返回画板；H、空格或中键在框体上仍平移全图。支持单选、多选与框选，选中时亮紫色边框与紫色加号，加号不加填充底色；再次单选取消。占位选择仅用于画布反馈，不计入真实版本或批注，也不改变右侧配方对照。拖动任何真实节点时，空白框保持自己的世界坐标，只更新虚线端点；拖动空白框时真实节点完全不动，松手也不自动避让或吸附。位置与版本节点一样仅保留本页，关闭重开不丢失。切换图钉至其他基底后初始化对应新占位；实际新增版本直接继承空白框的主图左边缘、垂直中心与叠放顺序，保留其他节点排布及画布视野；图片画幅变化时仍围绕同一锚点适配。批量后续样本留在同一节点，不重复占位或重置位置；随后为新基底另建占位。虚线区域可透出点阵，远景收起加号与虚线细节。
- 配方对比采用可收起的独立悬浮面板：B 缩略图、版本号与阶段名组成统一身份，A／B 缩略图外框均按具体样本的真实比例完整展示，横图不套竖框；阶段名最多两行，停靠与关闭保持独立；下行保留「对比」、A 基准胶囊与交换按钮。样本编号保留在悬停信息、读屏及基准菜单中，选择与恢复仍绑定具体图片；A 小缩略图不重复叠加角标。演进选项与结束状态收在基准行右侧，保留解除／继续跟踪。内部按「基础、角色、操作与来源（EDIT／CHAT）、参数」连续分组，以极浅凹槽底区分，不加分组描边；沿用红绿成对差异块与组间留白。配方／改动／全文在滚动容器外，展开组头在内容内吸顶，恢复／定稿操作留在底部。改动模式下无变化的分组默认收起，可展开阅读原文。
- 桌面配方默认以浮窗展开；标题栏的停靠按钮切换为贴边全高侧栏，两种形态下画布构图与底部胶囊均避开配方，浮窗避让包含其外侧留白。演进图仍铺满整个面板并延伸到浮窗背后，构图范围与画布裁切分开，浮窗上方及圆角外侧不出现整列直切边。独立的「关闭配方」按钮仅隐藏配方并将焦点交回底部配方胶囊；「关闭演进」始终位于画布右上，侧栏时随画布边界移动。860px 及以下默认收起，展开后覆盖画布且内部独立滚动，不显示停靠切换，与 ASK 互斥显示。切换视图或停靠形态保留开合、样本与对比状态，选择节点不强制弹开。
- 演进图空白画布采用低对比标准圆点阵，点径约 1.5px，100% 缩放时基础间距 24px，明暗外观共用现有主题变量。点阵随画布平移，缩放时保持点径并平滑切换密度，极小缩放逐渐淡出；大图模式继续使用纯色衬底。两种视图均延伸至底部胶囊背后，不裁出整条工具栏留白，胶囊间隙可操作后方画布。背景仅供空间参照，不改变节点位置、吸附或选择规则。
- 词文只比较用户原始 `prompt / negative / characters / params`；EDIT／CHAT 另外比较已记录的操作、真实底图、参考图、历史文字与蒙版摘要，没有 `sent_prompt` 切换。保留大小写、空白、重复、顺序和权重；先过滤停用（`on=false`）或正负词均为空白的角色，再按有效角色顺序对应，分配 ID 不算改动。仅负向有内容的角色仍参与；旧 `cfg` 开关已不发送，不作为差异展示。全文显示完整原文，未改动字段可折叠，原文缺失明确标记。过滤只用于读取和对比投影，不删除源记录中的角色槽，恢复仍使用完整原始快照。
- 「恢复到画板」始终取 B 的具体样本：IMAGE 保留 Seed 与批次数；EDIT 将该图设为底图并恢复记录配置、保留当前画布蒙版；CHAT 选择该具体轮次／版本／图片作为分支起点，不发送。「ASK」在演进内打开应用原有浮窗，可继续对照、讨论与提交草稿；有未发送输入或正在执行的操作时只打开窗口，空闲且输入为空时才预填当前 A/B 样本与选中对象的批注。不自动发送，不创建第二个 ASK 服务或窗口。

初次整理前不维护演进游标，不建树、不触发后台 ASK。激活后仅跟踪这张画板的实际成功生成和显式回退，导入不推断父子；普通手改与普通草稿只改配方，生成成功才落节点。没有演进数据库或第二套撤销栈。

## 入口与进行状态

| 入口 | 出现条件与操作 |
| --- | --- |
| IMAGE 历史更多菜单 | 历史区展开且有至少两条记录时提供「请 ASK 发起演进」；只预填提问，不自动发送 |
| 画板名称旁「演进」胶囊 | 当前画板存在进行中的演进时显示亮色与小圆点；打开最近激活的一份 |
| EDIT 画板入口／CHAT 顶栏 | 有版本时提供发起菜单；所属画板／会话跟踪中时复用亮色演进胶囊 |
| ASK 输入框上方 | 同一当前演进的一行摘要；与 Todo 共存时依次为演进摘要、待办、输入面板，待办可独立展开 |
| ASK 消息版本图片条 | 成功回复保留当时的演进快照；标题打开面板，图片直接定位版本。先显示最多六版，其余收进更多入口；数量和状态集中在标题行 |
| 任务总览 | 列出本页演进，进行中优先并优先当前画板；已解除／已定稿折叠在「历史」，打开不自动激活 |

首次整理仅在 ASK 成功轮次结束后登记，绑定发起 IMAGE 画板、EDIT 画板或 CHAT 会话，IMAGE 默认以树内创建时间最新的相关样本为具体基底；EDIT／CHAT 的实际底图属于树内时优先对齐该具体样本，生成归属始终再取真实输入。激活不恢复配方。同一画板至多跟踪一棵树，后续 ASK 整理默认更新这棵稳定身份的树。组件挂载、打开历史和切回画板不会自动续跟踪。

「关闭面板」只收起视图。「解除跟踪」撤下画板与 ASK 当前入口，消息图片条和总览历史保留；可继续查看、Diff 和显式恢复，编辑批注需先继续演进。手动解除反馈可撤销，但只能在原画板续跟踪；继续时检查原画板与基底图片可用。ASK 状态工具只在用户明确要求时使用。

## 活动树与生成归属

本页服务保存稳定演进 ID、权威 `edges`、当前节点及具体样本绑定。父节点由 `edges` 推导，不维护另一套可独立改写的父子数据。`vN` 是稳定编号，ASK 合并后不复用历史编号。

| 操作 | 结果 |
| --- | --- |
| 点击／翻图／A/B／多选／框选 | 仅查看，不移动创作基底 |
| 同有效配方生成，仅 Seed／批次变化 | 新样本追加当前节点，具体基底推进到最新成功样本 |
| 修改有效配方后生成 | 以提交时基底为父创建子节点，默认使用简短阶段名，精确改动摘要放入独立描述，节点以 NEW 提示 |
| 恢复旧节点具体样本 | 原写入成功后回拨基底，下次生成才形成分叉 |
| 内置回退草稿确认 | 完整恢复指定样本并叠加修改，同时回拨；不生成 |
| 普通收藏 | 不结束跟踪，中间好图可以随时收藏 |
| 设为定稿 | 未收藏先保存收藏；成功后记录节点及具体样本，结束跟踪，高亮根至定稿路径 |
| 解除／切换或新建画板或 CHAT 会话／IMAGE 清空历史 | 停止原树自动跟踪；总览与历史保留，切回不自动恢复 |

普通 `rewrite`、输入框清空或关闭面板不判为换题。当前「清空」操作是清空全页图片历史：用户确认后结束当前画板跟踪，不将其描述成清空配方。换题可直接解除跟踪或切换／新建画板；不增加草稿新主题字段或词条相似度判定。

生成提交时捕获树、来源画板、跟踪代次、父节点和具体基底；落图取本次实际配方。批量第一张成功图决定归组或新增一个节点，其余同批样本进入同节点；失败／取消未出图不建节点，部分成功只记录已落图，`isComparison` 合成图排除，重复通知不重复记数。

等待期间用户显式回退后，迟到图仍可归提交时分支，但不抢回游标；解除、定稿或切板后不再挂树，重新跟踪也不接收旧代次请求。ASK 合并节点后按样本真实身份映射来源，不能确定时提示重新整理。演进同步失败不把成功生图改成失败，不自动重试上游。

每树最多 80 个节点。需新增而达上限时，保留全部分支与正常生成历史，提示请 ASK 合并归纳阶段；相同节点仍可追加样本。

## EDIT／CHAT 的操作证据与续接

- **实际输入**：EDIT 成功操作记录原始说明／负向／有效角色、实际生效参数、底图记录、操作类型与冻结蒙版；图生图、局部重绘、放大、Director、Photopea 修改、正式回贴与融合分开标记。CHAT 记录当轮原始描述、有效模型选项、实际底图／参考图、选入的历史文字与区域批注，不以消息父轮次代替图片来源。生成前的报价、预览和纯蒙版返回不建图像节点。
- **蒙版变化**：使用冻结像素及尺寸的 SHA-256 区分真实修改，同时提供覆盖率和边界几何。相同范围但像素不同仍算改动；未记录、已知无蒙版、已记录蒙版三者分开。外扩、羽化、色彩对齐和聚焦范围按实际操作记录，不把休眠选项当作请求参数。Diff 不展示哈希，也不自动识别画面内容。
- **生成归属**：EDIT 每次按实际提交的底图挂分支，通常只切换查看结果、不会自动把结果设为底图；同底图同输入再次生成追加原阶段，改输入另起子节点。Photopea 图像返回按原流程设为底图后推进。CHAT 从实际发送的底图挂分支，遵守原「跟随最新」设置；未记录来源的旧图只提供证据，由 ASK 归纳，不补造父子。NAI 自动直出与正式回贴属于同一次生成的样本；后续人工应用回贴／融合是独立操作。`isComparison` 仍只用于排除展示用拼图。
- **显式交接**：把活动树中的具体图片送入 EDIT，或确认交接到 CHAT 时，可按稳定来源记录接续同一棵树，保留节点与排布；目标已有活动树时仅在其成员内移动基底，选择外部来源结束原跟踪。普通切换画板／会话仍解除跟踪，重新打开不会自动接续。
- **恢复边界**：EDIT 恢复要求图片仍在目标板，配置仍被当前模型支持；同尺寸保留现在的蒙版，跨尺寸按原 EDIT 规则清空蒙版及聚焦框。内置回退草稿只接受同尺寸版本；尺寸不同先显式从该图开始并检查蒙版。旧版本未记录配置时明确拒绝完整恢复，可在 EDIT 手动设为底图。CHAT 恢复具体版本与底图来准备分支，保留现有输入框、模型选项和上下文选择；需要调整描述／排除文字时使用草稿，不能把历史 CHAT 词文当作 NAI 配方恢复。
- **稳定身份**：CHAT 短码随分支改变，演进按会话／轮次／版本／资产身份重新绑定，保留节点与当前所选样本；在途生成保留提交时来源，不按新短码串图。短码标签变化不算配方变化。旧快照没有完整输入或蒙版时标记未知，不用当前配置补齐。

EDIT 的输入证据与配置随本页版本保存；CHAT 输入证据随已有会话存储和备份保存。两者都不持久保存活动演进树，也不额外保存蒙版像素副本。刷新后仍需按需整理，原图保留沿用各工作区规则。

## 候选配方组

实现：[recipe.ts](../../src/ask/retrospect/recipe.ts)。纯函数只在本轮首次调用候选读取工具时运行，输入是该 ASK 轮次冻结的图片库，以及本会话确实引用过、当前仍存在的收藏记录。冻结库中未引用的收藏不会因为可读就自动参与演进。

读取 IMAGE 历史、EDIT 版本和当前 CHAT 会话的各分支，排除 `isComparison` 拼接对比图。正式蒙版回贴和 Photopea 精修是可引用的实际结果，保留其直出来源。CHAT 的其他分支只在候选工具被调用时加入该轮冻结库，不预载其他会话。相同记录的历史／收藏别名只计一次，不同记录即使图片字节相同仍分别计数。按画板及创建时间组织序列，折叠相同配方的连续段；无归属的收藏独立成组。`A、A、B、A` 保留三个候选组，不自动连线。

有效签名采用已记录的基础正负词、过滤停用与空白槽后的有效角色内容与顺序、模型、尺寸、步数、采样器、Guidance、预设、透明底、定位和参考资产／配置等。忽略 Seed、批次数／序号、临时角色与参考行 ID、路由、界面偏好与已不发送的旧 `cfg`。IMAGE 原始词文取 `basePrompt / baseNegative / localCharacters`，EDIT／CHAT 优先取成功操作冻结的输入；缺失时为未知，不使用实际发送词文或当前默认值补造，原文不完整的记录不会相互合并。

代表图优先采用组内最新已收藏样本，否则采用最新样本。张数是本次现存记录数。历史默认全画板共享 35 条；被淘汰的废稿无法追回，历史上限和收藏生命周期保持不变。

## ASK 工具与结构

实现：[tools.ts](../../src/ask/retrospect/tools.ts)、[model.ts](../../src/ask/retrospect/model.ts)。候选读取与呈现只读；状态工具只更新本页演进入口，不持有画板或生成写入端口。三者均不结束工具阶段。

| 工具 | 输入与返回 |
| --- | --- |
| `get_recipe_clusters` | 默认 `scope=current`，读取当前工作区画板／CHAT 会话、无归属历史及已引用收藏；`scope=all` 跨画板，`cluster_id` 可聚焦候选所在画板，`retrospect_id` 可读取已有树。一次返回范围内全部候选的完整配方、封面、张数、时间与所有样本编号，不分页、不截短词文。候选计算只执行一次，后续读取沿用同轮冻结视图。 |
| 相邻演进上下文 `evolution` | 同一次返回全部相关图片的时间序列。每图包含 `id / cluster_id / board_id / previous_id / seed / effective_params`；EDIT／CHAT 另含冻结 `input` 和可核验的 `parent_id`；各独立序列首图提供 `baseline`，后续图提供相对前图的参数与 Prompt／Negative／有效角色 Diff。参数忽略 Seed、批次和旧 `cfg` 等噪音，噪声调度优先读取记录中的实际 `noise_schedule`，缺失字段不补默认值。文本 `parts` 的 `same+del`／`same+ins` 可完整重建前后词文；不需要再逐对调用 `diff_meta` 或逐张 `get_meta`。时间相邻仅为证据，不自动认定父子。 |
| `show_retrospect` | 接收 `retrospect_title`、`nodes: [{ id, label, description?, image_ids, primary_id? }]` 与 `edges: [{ from, to, summary }]`。最多 80 节点；可引用已读取候选及目标树已验证的旧样本。更新携带 `retrospect_id / expected_revision`；已读当前活动树时默认更新该树。字段避开部分接口会剥离的 Schema 元数据名 `title`。 |
| `set_retrospect_status` | 使用当前状态中的 `retrospect_id` 与 `active / ended`，仅在用户明确要求结束或继续时调用。整轮成功后才提交；失败／取消不改状态，运行中发生手动状态变更时不覆盖。 |

`label` 为简短阶段名，通常 2–10 个汉字、最长 24 字符，不带重复阶段编号、图片编号或括号解释；补充调整与依据写可选 `description`，通常一句话、40 字以内（上限 160 字符）。例如标题「画板定型」，描述「高低景深错位对峙，以 #h5 为代表」。由 ASK 输出时区分两者，前端不按标点猜拆历史标题。图上只展示短标题；详情中版本号与标题同行，下方为最多两行小字描述，无描述不留空行。已有树读取与收藏回复快照保留两字段；旧节点无描述仍可查看。

`vN` 表示由 ASK 归纳的语义演进阶段，允许将同阶段伴有词句、权重、参数微调或空角色槽变化的多张图合并，不要求组内配方全等，也不设置相似度阈值强行拆版。候选组仍是确定性同配方连续段，与最终版本节点不是一一对应关系。

程序校验唯一 `vN` 编号、真实图片绑定、样本不重复、端点存在、单父与无环。封面、计数与逐图 `recipes` 快照从真实记录生成，节点的 `recipe` 对应代表图；`primary_id` 必须为成员，省略时收藏优先／最新。模型不能提交自拟参数。ASK 可以合并非连续候选或不同配方的同阶段尝试，也可以排除无关主题；程序不根据生成顺序重写其语义判断。旧卡没有逐图快照时沿用当时已校验相同的节点配方。

初始 `<workspace_state>` 的 `retrospects` 摘要仅包含当前会话或当前画板关联的最近 20 份本页演进，字段包括 `retrospect_id / title / status / board_id / versions / revision / cursor / final`；不预载全部配方、拓扑或批注。`get_state(scope=latest)` 在同一轮范围内刷新状态，并反映本轮待提交的状态选择，不扩大可操作范围或改写草稿基底。`rN` 属本页登记，`vN` 属单份演进，二者都不是图片身份。

读取已有树还会返回完整拓扑、每图配方、代表图、批注、游标、定稿与读取版本。ASK 更新在成功轮次后提交；生成、批注或状态变化使版本过期时拒绝覆盖并明确反馈。旧图被淘汰后可凭既有绑定与配方快照保留成员，新增样本仍必须来自已读取的真实记录。

重整保留未合并节点身份；当前基底、定稿按记录身份映射。已有编号不能改指完全不同的样本。节点批注可随合并追加不同原文；会丢失批注、连线不再对应或合并超过 2000 字时拒绝，要求先处理批注，不静默删除或挪用意见。重整不写画板，也不擅自激活／解除跟踪。

视觉诊断仍使用既有 `view_image / view_sheet` 和原视觉预算；仅元数据时不能声称看过图片。词文差异、修改意图与画面因果分别表述，真实诊断效果须另行核验。

## Diff、恢复与生命周期

实现：[diff.ts](../../src/ask/retrospect/diff.ts)、[text-diff.ts](../../src/ask/retrospect/text-diff.ts)、[restore.ts](../../src/ask/retrospect/restore.ts)、[演进卡](../../src/ask/retrospect/RetrospectCard.vue)及[面板](../../src/ask/retrospect/RetrospectPanel.vue)。样式归组件，沿用现有 modal、按钮和红绿 Diff token。

文本先剔除完全相同的前后文，再对中间部分做有界精确 LCS；超过计算上限时仅中间部分降级为删／增，相同前后文保持中性。中文支持无空格的局部字词对比，保留 Unicode、原始空白、大小写与词序；两侧均可无损拼回原文。ASK 相邻演进证据使用同一计算结果，不请求模型计算差异。「改动」以完整词条／短句提供上下文，保留权重与括号的完整边界，并在其中突出真正变化的字词；「全文」保留两侧全部原文。参数是否改动由原值判定，格式化后相同的不同类型（如数值 `5` 与字符串 `"5"`）以可区分的原值形式展示，尺寸也保留原始类型差异。

角色分组保持独立折叠，Prompt／Negative 沿用全宽红绿词条块。位置使用独立的 X／Y 坐标展示，只将发生变化的轴标为旧值 → 新值，不输出 JSON，不对原始精度做四舍五入；多点按顺序逐行显示。启用状态不在有效角色中重复，未改动字段收为单个展开项。角色明确新增／删除与原文未知分开：已知不存在的一侧为空，不误报「未记录」；实际缺失仍保留未知状态，原始配方与恢复内容不改变。

成功生成保存每张样本的实际来源绑定 `sampleBases`，不增加第二套拓扑或 ASK 写入字段；重整阶段时按真实记录身份映射来源与别名。来源不再属于相应父版或样本已移出树时，使用父版代表图，不把未知关系伪造为精确来源。ASK 重新整理后的消息快照携带已验证的来源绑定；此前未记录来源的历史快照不补造。

演进卡保存逐图配方快照与本轮稳定图片绑定，不保存图片或 Object URL。借用图片服务的缩略图；原记录失效后仍可切换样本阅读各自的配方 Diff，但不能以失效记录恢复或继续引用。恢复和 ASK 预填严格使用当前所选样本，失效时不会静默改用同节点另一张图；用户可主动切换到仍有效的样本。不按旧短码绑定新图。

| 数据 | 关闭面板／刷新后的行为 |
| --- | --- |
| 活动树增量、游标、定稿状态、节点／连线批注、手动排布与画布视野 | 本页内存；关闭重开保留，刷新清空，不进入普通备份 |
| 版本关系、原始配方快照与图片绑定 | 随所在 ASK 回复保留；收藏会话时走既有 `koma-ask` 存储，刷新恢复后作为已解除历史查看，不自动激活 |
| 原图与缩略图 | 沿用现有图片生命周期，收藏 ASK 不会保存普通历史原图；旧 `#h` 不指向新页同号图片，原记录仍在收藏中时可按身份解析 |

活动树与消息快照分开：删除来源会话或截去来源轮次，只移除来源关联，不删除本页活动树。历史回复图片条保持当时快照，打开关联面板查看同一棵树的最新内容。自动生长、批注与状态不持续回写旧回复或持久活动树；收藏 ASK 不承诺保存后续生成增量。

恢复是用户在面板中的显式操作：IMAGE 调用已有 `drawing.writeDraft`，EDIT 调用编辑服务的版本／配置写入，CHAT 调用分支选择与既有持久化。重新核对来源身份与配方、当前模型／采样器／参数、角色数量和参考资源；原字段不完整、参数需被静默归一化、资源缺失或画板在异步准备期间变动时，拒绝写入并显示原因。复用数据租约、冲突检查与失败回滚，不新建撤销机制；这次直接恢复不产生 ASK 草稿检查点，活动树仅在原板仍跟踪时同步回拨基底，不提前创建节点。

## 内置 ASK 回退草稿

`propose_draft` 在内置 ASK 的 IMAGE／EDIT 草稿开放可选 `base_image_id`，指定当前活动树中的具体样本。IMAGE 使用真实 `#h / #f`；EDIT 使用同板已记录配置的版本。CHAT 继续使用 `chat_distill_branch`，不复用 IMAGE 配方恢复。外部 Bridge／手动 JSON 保持原 Schema，`PROTOCOL.md` 不增加此字段；不能与新画板、CHAT／EDIT 交接组合。

EDIT 回退草稿冻结所选版本配置与当前现场，确认和撤销同时检查底图、配置、蒙版修订与演进基底；只改变明确指定的底图和配置，不恢复历史蒙版、不报价。CHAT 分支草稿支持本轮已读取的旧分支及非当前选中版本，确认／撤销同步具体版本选择与演进来源。

`base_hash` 保护当前画板；IMAGE 的 `base_image_id` 则指定恢复的完整原始基础、角色及参数，在其上顺序执行本次修改。保留 Seed、批次数与优化偏好。来源角色重新分配 `cN` 后映射同稿目标，避免修改错角色。局部 `restore_partial.source` 不自行改变演进基底。

草稿显示回退节点／图片及实际恢复字段，与增量修改整体审阅，不可取消部分步骤留下半次恢复。应用前检查原记录、模型／采样器／参数、参考资源、当前画板及演进绑定；失败或冲突不留游标变化。写入完成后才提交游标，提交失效时补偿配方；文件组合提交失败也补偿这次基底写入。

应用、回退和恢复复用全页 50 条草稿栈，按原顺序／冲突规则同步基底。自动生长不会删除已确认的回退记录；撤销草稿也不删除实际生成的样本／分支。跟踪已解除、定稿、重整失去映射或换板时，过期撤销不得复活跟踪。

## 图上批注

[批注规则](../../src/ask/retrospect/annotations.ts)与[本页状态](../../src/ask/retrospect/store.ts)由 ASK 应用服务持有，图片、配方、拓扑保持原样。

- 工具栏直接复用 EDIT 的胶囊和选择菜单：「平移」「选择（单选／多选／框选）」「批注」。再次点击当前工具退出；再次单选同一对象取消。框选按节点交集、连线中点命中，Shift 追加。
- 有选择时点击批注立即打开编辑条；无选择时启用批注后点击节点或连线。键盘 H／V／M／N 切换工具；输入时不触发图快捷键。输入条沿用区域批注的徽标、无边框文本框、垃圾桶与完成按钮。
- Enter／完成保存，Shift+Enter 换行，Esc 取消；打开或取消不会写入。单项可修改、清空或用垃圾桶删除。多项批注相同时可共同更新／删除；内容不同时新增文字逐项追加，禁止一键删除不同原文。每项最多 2000 字，追加越界整次不写入。
- 批注仅保留本页，关闭重开仍在；以演进及对象身份隔离。发送给 ASK 的仅为此次明确引用的节点／连线意见。引用使用原记录绑定解析当前编号，失效旧号不指向同号新图。

| `annotations.ts`、`RetrospectNote.vue`、`store.ts` | 批注原子编辑、活动树、生成归属、基底及定稿生命周期 |
| `RetrospectHost.vue`、`../service.ts` | 唯一 ASK 宿主、成功轮次登记／同树更新、状态提交、生成订阅、草稿基底与恢复／定稿端口 |

`RetrospectHost.vue` 通过 Vue Teleport 将唯一 ASK 移入演进 dialog，关闭时归位；仅当前宿主 dialog 允许 ASK 键盘／粘贴，其他 modal 继续阻止。HOME／词典打开演进时也使用浮窗；窄屏 ASK 仍按已有全屏模式。组件私有样式与共享控件的归属见[界面维护](../engineering/ui-maintenance.md#演进)，本地原型不作为第二套产品实现。
