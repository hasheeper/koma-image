# 版本演进

更新：2026-11-14。版本演进以 **IMAGE 为唯一实时主干**：手动尝试归入阶段相册，事后可提拔选中单图；EDIT／CHAT 是关联工坊，只把选定成果或方向否定记入树。日常创作无需提前建树，ASK 在用户请求复盘时归纳 IMAGE 历史与分支。本文是唯一现行维护入口；发布与真实待验状态见[当前状态](../status.md)。

## 使用与职责

在 IMAGE 历史区更多菜单、EDIT 画板入口或 CHAT 顶栏选择「请 ASK 发起演进」，或直接向 ASK 请求「复盘」「演进」「梳理／回顾修改脉络」「看看之前哪版更好」，均可开启或更新版本演进。入口只预填，发送后才推理。围绕同一画面连续多轮打磨仍陷入瓶颈时，ASK 可在回复末尾提醒用户使用演进；未获用户请求时不主动调用演进工具。日常生图不必提前开启或维护演进。

- 完整面板不设顶栏，演进图与大图铺满画布。底部复用 EDIT 胶囊，提供「大图／演进图」切换、当前视图工具、配方开关和独立 ASK；右上仅保留关闭按钮。图节点采用折叠相册，同一演进阶段的多图可就地翻页；外框按当前样本的真实图片比例完整展示，翻页从横图切至长竖图时同步变形，自动布局的行列间距、连线端点、框选和批注定位随尺寸更新；独立摆放后按主图左边缘与垂直中心锚点变形。原图失效时优先按所选样本配方中的尺寸展示占位。图支持平移、缩放；默认视野适度放大并围绕当前版本与对比基底，点击「适应全部」查看整棵树，双击节点进入大图。大图可查看 A、B 或并排，支持滚轮／双指缩放与拖动。节点默认采用代表图，切换 A 或 B 内的具体样本时，图片、右栏配方 Diff、恢复与 ASK 引用同步采用该图的真实配方；节点拓扑保持原样。
- 图外轻量标题行仅显示版本号与有足够空间的阶段名；NEW、A／B、定稿状态和样本翻页位于相册背图下方，右对齐主图边缘，采用按内容收缩的小浮片承托：短圆角、主题玻璃底色、细边和短投影，状态与翻页之间用轻分隔线区分。NEW 用主题强调色文字，翻页按钮只在悬停或键盘聚焦时提供反馈；远景减去模糊与分隔线。IMAGE 图片右上提供图钉「从这里开始」，工坊节点同位置提供「定位原版本」，默认隐藏，仅悬停节点或键盘焦点进入节点时展示，当前基底也遵循此规则；左下仅在有批注时提示。主图保留一圈边界，B 与多选同时存在时不叠第二个框；相册背图轻微向下叠放，图外文字按最大叠放位置留距，悬停不推动文字。图钉恢复该节点当前显示的具体样本，不改变 A／B 对照或触发批注、生图；只有活动基底的节点与样本均匹配时图钉点亮。配方收起时，恢复结果与错误仍在画布内反馈。原记录失效或当前不可写时禁用对应图钉，整树已结束时，恢复不会自动续跟踪；仅解除 IMAGE 收集时，显式恢复可重新选择该主干。
- 图片按画布真实缩放；标题、图钉和分页采用受限的反向缩放，屏幕尺寸缓慢变化并封顶于常规控件大小，放大后相对图片变小。阶段名按自身剩余宽度决定是否展示，空间仅够一两个字时直接隐藏，完整名称仍可悬停查看；图外状态浮片按空间收起样本数字与次要状态。远景只保留版本和必要标记，极小概览隐藏控件，以起点圆点标识当前基底。上下文字预留、连线图中点和框选／批注命中使用同一尺寸规则，缩放不重排拓扑。
- 新版本节点用亮色 `NEW` 文字提示，位于图片外侧右下方的状态与翻页行，空间不足时缩为亮色圆点。首次打开面板时保留，关闭后再次进入消失；面板打开期间新建的节点同样保留到本次离开。首次整理、自动新增及 ASK 新建阶段均按节点身份判断，已有阶段追加样本不重复标记。仅本页查看状态，不修改演进修订号、配方或草稿基底。
- 单选版本设为 B，默认对比父版本 A；自动生成的分支优先采用当时实际回退的父版样本，连续续抽沿同阶段来源找到该样本。ASK 推演或旧快照中没有生成来源的连线沿用父版代表图。手动翻选 A 样本优先于自动参照，图节点、大图、Diff、恢复与 ASK 引用始终一致。Shift 点击或对比基准菜单选择任意 A，支持交换与恢复跟随父版。手选 A 后切换 B 保留 A；若 A 与 B 相同则恢复自动父版。多选／框选不改变右栏对照。
- 浏览或单选工具下，左键拖动节点主图／图外标题可单独调整位置；超过屏幕拖动阈值才开始移动，不改变 B／A、选择、语义连线或创作基底，不触发双击大图。其他节点不跟随、不被推开，无吸附，可自由重叠；最后摆放的节点在上层。拖动用原生 rAF 更新节点与连线，靠近画布边缘自动平移，滚轮缩放仍保持抓取点；Esc、指针取消、窗口失焦或关闭视图取消本次摆放。图钉、分页和状态浮片只执行各自操作，多选／框选／批注不进入节点拖动。位置仅本页按演进与节点身份保存，关闭重开保留，刷新清空，不改变演进修订号或草稿基底。活动占位出现后保存当前排布，节点与空白框分别保持独立位置；翻样本保持锚点并适配实际画幅。
- 实际版本、预设分支与普通后继框共用默认平滑曲线、线宽及基础色，不为预设增加直角绕线或共享通道。已生成用实线，待生成用虚线；拖动时只随端点更新同一曲线。节点底部仅有状态标记时胶囊左右等距，圆点与 A/B 按字母可见高度居中对齐。
- 节点、空白框和连线由同一个场景坐标写入器同步绘制，Vue 更新完成后与拖动每帧均按当前场景重绘，不混用节点位移动画与旧连线路径。生成进度、参数表单和图片资源通知不取消正在进行的摆放；只有被拖对象的实际坐标／尺寸或身份变化才取消。其他节点生成落图时，继续保留正在拖动的对象与各自已保存位置；减少动态效果设置也不为坐标引入过渡。
- 画布可直接拖动空白区域平移；H 手型工具、按住空格或鼠标中键可在节点上平移，框选模式仍以空白拖动框选。滚轮以指针为中心缩放。拖动期间不强制居中，松手只保留少量内容可达；「适应全部」或 Home／0 显式回到全景。切换样本、图钉或生成落图不抢回镜头。画布平移与缩放视野按演进身份保留在本页；关闭重开、进入大图后返回以及新图落入预留位置时保持当前视野，不自动适应全图，刷新后随本页演进状态清空。
- 连续相机输入先更新原生状态，缩放和平移合并到同一显示帧；双指围绕前次中点缩放后随新中点平移。视口边界只在当前待提交帧内复用，不反复读取画布尺寸或回写未变的点阵／节点缩放样式。松手补齐显示，隐藏和卸载取消待执行帧并保存最终相机；已有节点拖动调度保持独立。浏览器回归覆盖双指累计缩放、尚未显示的滚轮输入在关闭后恢复，以及节点拖动与生成落图。
- 只有已确认 ASK IMAGE 修改才出现普通虚线加号框，表示下一张成功图的落点；手动改词和恢复旧配方不提前占位。框体可独立拖动，选中为紫框及无填充紫色加号；加号只返回 IMAGE，不改配方、不生成。首图继承框的主图左边缘、垂直中心与叠放顺序，兑现后不遗留新空框。失败保留目标；同一方案生成前连续修订复用落点；载入完整预设则由预设接收首图。
- 工坊挂件单独显示「EDIT／CHAT · 待交付」，没有版本号、加号、图像或配方载入按钮；可拖动、打开工坊或取消挂靠。同一关联只显示一份当前待交付状态：打开时定位本轮最新待交付结果，不能回落到已经记入的历史图；尚未出图时打开对应工作面板。交付结清当时已有尝试并收起挂件，旧尝试只留原生历史，已交付图只在阶段节点呈现。继续修改产出新结果后复用同一关联，重新显示一份待交付挂件。挂件与节点共用场景坐标和默认平滑连线；首次交付或选择下一阶段时，正式节点继承本次挂件锚点，续交追加不挪原节点；新一轮待交付不沿用已被历史节点占据的位置。目标关闭／删除时标明失效并禁用打开，仍可取消挂靠；整树结束时挂件标明已停止。
- 配方对比采用可收起的独立悬浮面板：B 缩略图、版本号与阶段名组成统一身份，A／B 缩略图外框均按具体样本的真实比例完整展示，横图不套竖框；阶段名最多两行，停靠与关闭保持独立；下行保留「对比」、A 基准胶囊与交换按钮。样本编号保留在悬停信息、读屏及基准菜单中，选择与恢复仍绑定具体图片；A 小缩略图不重复叠加角标。演进选项与结束状态收在基准行右侧，保留解除／继续跟踪。内部按「基础、角色、操作与来源（EDIT／CHAT）、参数」连续分组，以极浅凹槽底区分，不加分组描边；沿用红绿成对差异块与组间留白。配方／改动／全文在滚动容器外，展开组头在内容内吸顶，恢复／定稿操作留在底部。改动模式下无变化的分组默认收起，可展开阅读原文。
- 桌面配方默认以浮窗展开；标题栏的停靠按钮切换为贴边全高侧栏，两种形态下画布构图与底部胶囊均避开配方，浮窗避让包含其外侧留白。演进图仍铺满整个面板并延伸到浮窗背后，构图范围与画布裁切分开，浮窗上方及圆角外侧不出现整列直切边。独立的「关闭配方」按钮仅隐藏配方并将焦点交回底部配方胶囊；「关闭演进」始终位于画布右上，侧栏时随画布边界移动。860px 及以下默认收起，展开后覆盖画布且内部独立滚动，不显示停靠切换，与 ASK 互斥显示。切换视图或停靠形态保留开合、样本与对比状态，选择已生成节点不强制弹开；选择待生成预设时展开配方，便于生图前审阅。
- 演进图空白画布采用低对比标准圆点阵，点径约 1.5px，100% 缩放时基础间距 24px，明暗外观共用现有主题变量。点阵随画布平移，缩放时保持点径并平滑切换密度，极小缩放逐渐淡出；大图模式继续使用纯色衬底。两种视图均延伸至底部胶囊背后，不裁出整条工具栏留白，胶囊间隙可操作后方画布。背景仅供空间参照，不改变节点位置、吸附或选择规则。
- IMAGE 词文只比较用户原始 `prompt / negative / characters / params`；涉及 EDIT／CHAT 时分别展示各图原始输入、操作、真实底图、参考图、历史文字与蒙版摘要，不计算词文删改，没有 `sent_prompt` 切换。保留大小写、空白、重复、顺序和权重；先过滤停用（`on=false`）或正负词均为空白的角色，再按有效角色顺序对应，分配 ID 不算改动。仅负向有内容的角色仍参与；旧 `cfg` 开关已不发送，不作为差异展示。全文显示完整原文，未改动字段可折叠，原文缺失明确标记。过滤只用于读取和对比投影，不删除源记录中的角色槽，恢复仍使用完整原始快照。
- 「恢复到画板」始终取 B 的具体样本：IMAGE 保留 Seed 与批次数；EDIT 只定位原板及版本，不更换底图；CHAT 精确定位原会话／轮次／版本，不更换底图或发送。「ASK」在演进内打开应用原有浮窗，可继续对照、讨论与提交草稿；有未发送输入或正在执行的操作时只打开窗口，空闲且输入为空时才预填当前 A/B 样本与选中对象的批注。不自动发送，不创建第二个 ASK 服务或窗口。

初次整理前不维护演进状态。激活后只有关联 IMAGE 画板的成功生成自动收集；工坊分别保留派工与续交关联，不持有逐张生成游标。共享已有 50 步撤销栈，不新增演进数据库。
画布协创模式下，以上内容复用同一实例嵌入 IMAGE 左侧，不打开模态遮罩，也不把右侧 ASK 搬进演进宿主。配方与 ASK 共用右侧栏；选择预设切到配方 Diff，关闭时收起侧栏，选择 ASK 返回同一会话，不再打开独立配方浮窗。载入后的提示直接指向下方手动生成，检视与返回保留相机和选择。详情见 [IMAGE 协创](image.md#画布协创beta)。常规浮窗模式继续使用原演进 dialog。

## 入口与进行状态

| 入口 | 出现条件与操作 |
| --- | --- |
| IMAGE 历史更多菜单 | 历史区展开且有至少两条记录时提供「请 ASK 发起演进」；只预填提问，不自动发送 |
| 画板名称旁「演进」胶囊 | 当前画板存在进行中的演进时显示亮色与小圆点；打开最近激活的一份 |
| EDIT 画板入口／CHAT 顶栏 | 有版本时提供发起菜单；所属画板／会话跟踪中时复用亮色演进胶囊 |
| ASK 输入框上方 | 同一当前演进的一行摘要；与 Todo 共存时依次为演进摘要、待办、输入面板，待办可独立展开 |
| ASK 消息版本图片条 | 成功回复保留当时的演进快照；标题打开面板，图片直接定位版本。先显示最多六版，其余收进更多入口；数量和状态集中在标题行 |
| 任务总览 | 列出本页演进，进行中优先并优先当前画板；已解除／已定稿折叠在「历史」，打开不自动激活 |

首次整理在 ASK 成功轮次结束后登记 IMAGE 主干，以创建时间最新的相关 IMAGE 样本为当前阶段，不恢复配方。一个 IMAGE 画板至多有一棵实时跟踪树。EDIT／CHAT 有工坊关联时可读取和重整对应主干；无关联时提示从 IMAGE 建立主干，不从工坊全部试错生成另一实时树。组件挂载、浏览历史和切回画板不自动恢复跟踪。
「关闭面板」只收起视图。「解除跟踪」撤下画板与 ASK 当前入口，消息图片条和总览历史保留；可继续查看、Diff 和显式恢复，编辑批注需先继续演进。手动解除反馈可撤销，但只能在原画板续跟踪；继续时检查原画板与基底图片可用。ASK 状态工具只在用户明确要求时使用。

## 活动树与生成归属

`store.ts` 保存单个 IMAGE 游标、可选 ASK 待生成目标、工坊工单与交付锚点。树的 `edges` 是阶段关系；具体来源记录与实际操作底图分开保存，不用消息父轮次或图片哈希代替来源。

| 操作 | 结果 |
| --- | --- |
| IMAGE 手动改词、Seed、参数或续抽 | 成功图追加提交时的当前阶段，每图保留真实配方 |
| 「立为阶段」 | 仅将选中一图移到新子节点，原阶段保留其余图，IMAGE 游标切新阶段；单图阶段不可拆 |
| 内部 ASK 有效 IMAGE 修改确认 | 表单与待生成目标共同提交／撤销，首图原地兑现；已载入预设时不再加空框 |
| 恢复 IMAGE 具体样本 | 恢复原生配方并切 IMAGE 游标；保留 Seed／批次数，进入共享撤销栈，不自动生成 |
| 图片明确交接至 EDIT／CHAT | 目标成功接收后建立待交付工单；不改变 IMAGE 游标，不立即建立正式版本 |
| 工坊继续生成／改词／改蒙版 | 只更新原生历史，等待用户选图交付 |
| 普通收藏、关闭面板、切换工作区 | 不结束整树，不交付工单 |
| 切换 IMAGE 具体画板或清空历史 | 解除原 IMAGE 收集，已经派出的工单保留 |
| 显式结束／最终定稿 | 停止整树的新收集、派工与交付；原生历史仍可用 |

「立为阶段」保留原阶段位置；被移动图若被预设、工单或已交付子链引用，按记录身份重映射来源与批注。只改变阶段归属，不恢复表单、不移动其他样本，也不弹范围选择。新的 `vN` 使用单调编号，撤销、删除与重整不回收编号。

IMAGE 生成提交冻结树、画板、跟踪代次、来源样本及目标。同批成功图进入同阶段；取消／失败不造节点，展示拼图不入树。提交后切换目标，晚到图仍回原目标但不抢游标；解除收集或结束树后不再接收旧请求。在途来源参与重整保护，不能被 ASK 丢掉。同步失败不把成功生成改成失败，也不重发上游请求。

容量按 **已生成＋完整预设＋未兑现 IMAGE 目标（含在途）＋尚未交付过的工单 ≤ 80** 预留。兑现已有空位不重复计数；同一工坊的后续待交付可能只是更新原阶段，不预占另一阶段名额，选择「作为下一步」时再检查上限。满额仍可正常原生生成或追加阶段，禁止静默删除分支。取消挂靠释放未交付预留；工单不占 16 个 IMAGE 预设名额。

## EDIT／CHAT 工坊交付

明确派工绑定树内具体来源记录、目标 EDIT 板／CHAT 会话与接收身份；仅查看、导航、换底事件不派工。同一来源重复打开同一目标幂等，新目标可以并行挂单。普通 IMAGE→CHAT 传输、IMAGE／CHAT→EDIT、EDIT→新／原 CHAT、区域批注和 ASK 确认交接均接入成功接收通知。CHAT 多图只以明确底图派工，参考图不会各挂一单。

| 「记入演进」操作 | 行为 |
| --- | --- |
| 阶段成品／方向否定 | 首次在工单位置建立正式节点，选中图作为样本和封面；否定按具体样本保留 |
| 追加到本阶段 | 保留旧样本，新增图作为代表图，续交锚点更新为它，不移动节点 |
| 作为下一步 | 从最近交付阶段新增子节点，续交锚点顺延；可记录成品或方向否定 |
| 最终定稿 | 原图收藏成功后交付并结束整树，记录精确样本和根至定稿路径 |
| 取消挂靠 | 移除工单／续交关联，不改原生历史及已经交付节点 |

所有交付均不移动 IMAGE 游标，也不更换 EDIT 底图／CHAT 上下文。同一记录重复交付只定位已有节点，不追加、不把续交锚点拨回旧图；结果入口显示「已记入 vN」，菜单改为查看对应阶段，隐藏重复追加／新建／否定操作，仍可定稿或解除关联。只有新结果才显示记入选项。手动交付、提拔、取消挂靠及面板定稿复用共享撤销栈；撤销不删除工坊生成结果，后续交付／重整等依赖会阻止旧快照覆盖。收藏失败不结束树，收藏成功但树已变化则保留正常收藏并提示重新选择。撤销定稿恢复演进状态，不取消已完成的收藏。

明确将未入树工坊图送往另一个工坊时，在目标接收成功后，将选中图作为阶段成品结单（已有交付阶段默认追加），再建立下一工单；两项记账共同提交。目标接收失败不提前结单。循环接力使用新来源关系而不回连旧节点。存在多份可匹配来源时，交付菜单显示来源供选择；无法确定的自动接力要求先明确交付，不按最近打开的树猜测。

工坊输入证据继续记录原始提示词、参数、实际底图／参考图、历史上下文、区域批注及冻结蒙版。SHA-256 区分同范围不同蒙版，已知无蒙版与未记录分开。NAI、通用编辑、放大、Director、Photopea、原直出和正式回贴各保留原生记录；用户当前选中的具体结果才交付。

CHAT 使用会话／轮次／版本／资产的稳定身份。交接输入按会话绑定来源，不能以去重后的资产哈希认领另一工单；生成时冻结输入身份，重复相同像素仍保留不同操作记录。编辑／对话版本定位不回拨 IMAGE。EDIT 本地 `base_image_id` 回退仍可确认与撤销，不依赖工单或活动演进。

工单、锚点和位置限本页；已交付样本、来源和撤销所需记录通过现有资源引用保护，未交付中间试错遵循原生历史上限。没有交付的工坊结果不会因挂单而无限保留原件。刷新不恢复活动工单，也不以旧传输票据重新激活树。

## 候选配方组

实现：[recipe.ts](../../src/ask/retrospect/recipe.ts)。纯函数只在本轮首次调用候选读取工具时运行，输入是该 ASK 轮次冻结的图片库，以及本会话确实引用过、当前仍存在的收藏记录。冻结库中未引用的收藏不会因为可读就自动参与演进。

演进候选只读取 IMAGE 历史及相关收藏，排除 `isComparison` 拼接对比图。正式蒙版回贴和 Photopea 精修是可引用的实际结果，保留其直出来源。已交付工坊节点通过已有树提供原始输入，不将全部工坊试错塞入 IMAGE 候选。其他工作区原生记录仍可由视觉、元数据工具按需读取。相同记录的历史／收藏别名只计一次，不同记录即使图片字节相同仍分别计数。按画板及创建时间组织序列，折叠相同配方的连续段；无归属的收藏独立成组。`A、A、B、A` 保留三个候选组，不自动连线。

有效签名采用已记录的基础正负词、过滤停用与空白槽后的有效角色内容与顺序、模型、尺寸、步数、采样器、Guidance、预设、透明底、定位和参考资产／配置等。忽略 Seed、批次数／序号、临时角色与参考行 ID、路由、界面偏好与已不发送的旧 `cfg`。IMAGE 原始词文取 `basePrompt / baseNegative / localCharacters`，EDIT／CHAT 优先取成功操作冻结的输入；缺失时为未知，不使用实际发送词文或当前默认值补造，原文不完整的记录不会相互合并。

代表图优先采用组内最新已收藏样本，否则采用最新样本。张数是本次现存记录数。历史索引本页保留全部记录；全画板默认保留最近 35 张原图，演进／收藏引用保护额外原件。未受保护的较早图片只留缩略图与完整配方，事后首次整理也能读取、归组和精确 Diff，无法追回已释放的原图像素。收藏生命周期保持不变。

## ASK 工具与结构

实现：[tools.ts](../../src/ask/retrospect/tools.ts)、[model.ts](../../src/ask/retrospect/model.ts)。候选读取与呈现只读；状态工具只更新本页演进入口，不持有画板或生成写入端口。三者均不结束工具阶段。

| 工具 | 输入与返回 |
| --- | --- |
| `get_recipe_clusters` | 默认 `scope=current`，读取当前 IMAGE 或关联工坊的主干、无归属历史及已引用收藏；`scope=all` 跨画板，`cluster_id` 可聚焦候选所在画板，`retrospect_id` 可读取已有树。一次返回范围内全部候选的完整配方、封面、张数、时间、所有样本编号与逐图 image_availability，不分页、不截短词文。候选计算只执行一次，后续读取沿用同轮冻结视图。 |
| 相邻演进上下文 `evolution` | 同一次返回全部相关图片的时间序列。每图包含 `id / cluster_id / board_id / previous_id / seed / effective_params`；各独立序列首图提供 `baseline`，后续图提供相对前图的参数与 Prompt／Negative／有效角色 Diff。参数忽略 Seed、批次和旧 `cfg` 等噪音，噪声调度优先读取记录中的实际 `noise_schedule`，缺失字段不补默认值。文本 `parts` 的 `same+del`／`same+ins` 可完整重建前后词文；不需要再逐对调用 `diff_meta` 或逐张 `get_meta`。时间相邻仅为证据，不自动认定父子。 |
| `show_retrospect` | 接收 `retrospect_title`、`nodes: [{ id, label, description?, image_ids, primary_id? }]` 与 `edges: [{ from, to, summary }]`。最多 80 节点；可引用已读取候选及目标树已验证的旧样本。更新携带 `retrospect_id / expected_revision`；已读当前活动树时默认更新该树。字段避开部分接口会剥离的 Schema 元数据名 `title`。 |
| `set_retrospect_status` | 使用当前状态中的 `retrospect_id` 与 `active / ended`，仅在用户明确要求结束或继续时调用。整轮成功后才提交；失败／取消不改状态，运行中发生手动状态变更时不覆盖。 |

`label` 为简短阶段名，通常 2–10 个汉字、最长 24 字符，不带重复阶段编号、图片编号或括号解释；补充调整与依据写可选 `description`，通常一句话、40 字以内（上限 160 字符）。例如标题「画板定型」，描述「高低景深错位对峙，以 #h5 为代表」。由 ASK 输出时区分两者，前端不按标点猜拆历史标题。图上只展示短标题；详情中版本号与标题同行，下方为最多两行小字描述，无描述不留空行。已有树读取与收藏回复快照保留两字段；旧节点无描述仍可查看。

`vN` 表示由 ASK 归纳的语义演进阶段，允许将同阶段伴有词句、权重、参数微调或空角色槽变化的多张图合并，不要求组内配方全等，也不设置相似度阈值强行拆版。候选组仍是确定性同配方连续段，与最终版本节点不是一一对应关系。

程序校验唯一 `vN` 编号、真实图片绑定、样本不重复、端点存在、单父与无环。封面、计数与逐图 `recipes` 快照从真实记录生成，节点的 `recipe` 对应代表图；`primary_id` 必须为成员，省略时收藏优先／最新。模型不能提交自拟参数。ASK 可以合并非连续候选或不同配方的同阶段尝试，也可以排除无关主题；程序不根据生成顺序重写其语义判断。旧卡没有逐图快照时沿用当时已校验相同的节点配方。

初始 `<workspace_state>` 的 `retrospects` 摘要仅包含当前会话或当前画板关联的最近 20 份本页演进，字段包括 `retrospect_id / title / status / board_id / versions / expected_revision / cursor / pending / workshops / final`（workshops 列出待交付或已交付关联）；不预载全部配方、拓扑或批注。`get_state(scope=latest)` 在同一轮范围内刷新状态，并反映本轮待提交的状态选择，不扩大可操作范围或改写草稿基底。`rN` 属本页登记，`vN` 属单份演进，二者都不是图片身份。

读取已有树还会返回完整拓扑、每图配方、代表图、批注、游标、定稿与读取版本。ASK 更新在成功轮次后提交；生成、批注或状态变化使版本过期时拒绝覆盖并明确反馈。旧图被淘汰后可凭既有绑定与配方快照保留成员，新增样本仍必须来自已读取的真实记录。

重整保留未合并节点身份；各工作区基底、待生成目标及定稿按记录身份映射。已有编号不能改指完全不同的样本。节点批注可随合并追加不同原文；会丢失批注、连线不再对应或合并超过 2000 字时拒绝，要求先处理批注，不静默删除或挪用意见。重整不写画板，也不擅自激活／解除跟踪。

视觉诊断仍使用既有 `view_image / view_sheet` 和原视觉预算；仅元数据时不能声称看过图片。词文差异、修改意图与画面因果分别表述，真实诊断效果须另行核验。

## Diff、恢复与生命周期

实现：[diff.ts](../../src/ask/retrospect/diff.ts)、[text-diff.ts](../../src/ask/retrospect/text-diff.ts)、[restore.ts](../../src/ask/retrospect/restore.ts)、[演进卡](../../src/ask/retrospect/RetrospectCard.vue)及[面板](../../src/ask/retrospect/RetrospectPanel.vue)。样式归组件，沿用现有 modal、按钮和红绿 Diff token。

仅 IMAGE ↔ IMAGE 计算原始配方的词文、角色和参数 Diff。任一侧为 EDIT／CHAT（含同工坊两次操作）时展示「原始输入与操作」：分别展示 A／B 原始配方、指令、参数及来源，不渲染整段删增，也不把 NAI 标签当成 CHAT 修改指令。恢复始终按当前样本的配方工作区分派，不按整棵树最后活动的工作区分派。

文本先剔除完全相同的前后文，再对中间部分做有界精确 LCS；超过计算上限时仅中间部分降级为删／增，相同前后文保持中性。中文支持无空格的局部字词对比，保留 Unicode、原始空白、大小写与词序；两侧均可无损拼回原文。ASK 相邻演进证据使用同一计算结果，不请求模型计算差异。「改动」以完整词条／短句提供上下文，保留权重与括号的完整边界，并在其中突出真正变化的字词；「全文」保留两侧全部原文。参数是否改动由原值判定，格式化后相同的不同类型（如数值 `5` 与字符串 `"5"`）以可区分的原值形式展示，尺寸也保留原始类型差异。

角色分组保持独立折叠，Prompt／Negative 沿用全宽红绿词条块。位置使用独立的 X／Y 坐标展示，只将发生变化的轴标为旧值 → 新值，不输出 JSON，不对原始精度做四舍五入；多点按顺序逐行显示。启用状态不在有效角色中重复，未改动字段收为单个展开项。角色明确新增／删除与原文未知分开：已知不存在的一侧为空，不误报「未记录」；实际缺失仍保留未知状态，原始配方与恢复内容不改变。

成功生成保存每张样本的实际来源绑定 `sampleBases`，不增加第二套拓扑或 ASK 写入字段；重整阶段时按真实记录身份映射来源与别名。来源不再属于相应父版或样本已移出树时，使用父版代表图，不把未知关系伪造为精确来源。ASK 重新整理后的消息快照携带已验证的来源绑定；此前未记录来源的历史快照不补造。

演进卡保存逐图配方快照与本轮稳定图片绑定；IMAGE 历史索引与像素由 drawing 管理，ASK 仅登记演进实际节点的原图保护；EDIT 样本受版本淘汰保护，CHAT 仍使用持久会话原图。仅释放原图的 IMAGE 样本仍可读配方、做 Diff、恢复画板及通过 base_image_id 草稿回退分叉；不可交接到 CHAT／EDIT、精细裁切、收藏或设为定稿。图上及侧栏标明仅缩略图。关闭面板、结束跟踪或删除来源 ASK 回复不删除仍有演进引用的图片。主动删除原记录或刷新后普通历史失效时，仍可切换样本阅读各自的配方 Diff，但不能以失效记录恢复或继续引用；同字节的存活收藏只能补预览，不能替代被删除记录的配方。恢复和 ASK 预填严格使用当前所选样本，失效时不会静默改用同节点另一张图；用户可主动切换到仍有效的样本。不按旧短码绑定新图。

| 数据 | 关闭面板／刷新后的行为 |
| --- | --- |
| 活动树增量、游标、定稿状态、节点／连线批注、手动排布与画布视野 | 本页内存；关闭重开保留，刷新清空，不进入普通备份 |
| 版本关系、原始配方快照与图片绑定 | 随所在 ASK 回复保留；收藏会话时走既有 `koma-ask` 存储，刷新恢复后作为已解除历史查看，不自动激活 |
| 原图与缩略图 | IMAGE 最近额度内及演进／收藏引用的现存原图保留，其余历史只留缩略图与完整配方；EDIT 引用仍保护版本。主动删除／刷新仍按原边界处理；收藏 ASK 不会保存普通历史原图；旧 `#h` 不指向新页同号图片，原记录仍在收藏中时可按身份解析 |

活动树与消息快照分开：删除来源会话或截去来源轮次，只移除来源关联，不删除本页活动树。历史回复图片条保持当时快照，打开关联面板查看同一棵树的最新内容。自动生长、批注与状态不持续回写旧回复或持久活动树；收藏 ASK 不承诺保存后续生成增量。

恢复是面板中的显式操作：IMAGE 先用 `prepareRecipe` 校验字段、模型和参考资源，再通过共享 writer 原子提交表单与 IMAGE 游标；失败补偿，支持 50 步全局撤销。原 IMAGE 画板不存在时提示，不按当前 CHAT 工作区误恢复。EDIT 只调用原生 `locate`，CHAT 只定位指定会话／轮次／版本；更换底图另走工作区原生操作，不伪装成演进恢复。

## 内置 ASK 回退草稿

`propose_draft` 在内置 ASK 的 IMAGE／EDIT 草稿开放可选 `base_image_id`，IMAGE 指定活动树具体样本，EDIT 指定同板同尺寸原生版本。IMAGE 使用真实 `#h / #f`；EDIT 使用同板已记录配置的版本。CHAT 继续使用 `chat_distill_branch`，不复用 IMAGE 配方恢复。外部 Bridge／手动 JSON 保持原 Schema，`PROTOCOL.md` 不增加此字段；不能与新画板、CHAT／EDIT 交接组合。

EDIT 回退草稿冻结所选版本配置与当前现场，确认和撤销同时检查底图、配置与蒙版修订；只改变明确指定的底图和配置，不恢复历史蒙版、不报价。CHAT 分支草稿支持本轮已读取的旧分支及非当前选中版本，确认／撤销同步原生版本选择，不移动 IMAGE 游标。

`base_hash` 保护当前画板；IMAGE 的 `base_image_id` 则指定恢复的完整原始基础、角色及参数，在其上顺序执行本次修改。保留 Seed、批次数与优化偏好。来源角色重新分配 `cN` 后映射同稿目标，避免修改错角色。局部 `restore_partial.source` 不自行改变演进基底。

草稿显示回退节点／图片及实际恢复字段，与增量修改整体审阅，不可取消部分步骤留下半次恢复。应用前检查原记录、模型／采样器／参数、参考资源、当前画板及演进绑定；失败或冲突不留游标变化。写入完成后才提交游标，提交失效时补偿配方；文件组合提交失败也补偿这次基底写入。

应用、回退和恢复复用全页 50 条草稿栈，按原顺序／冲突规则同步基底。自动生长不会删除已确认的回退记录；撤销草稿也不删除实际生成的样本／分支。跟踪已解除、定稿、重整失去映射或换板时，过期撤销不得复活跟踪。

## IMAGE 并行预设分支

单图打磨需要比较多个方向时，ASK 可逐次调用 `stage_evolution_branch`，在同一棵活动树的具体 `base_image_id` 下挂出待生成预设，不新建画板、不改表单、不生成图片。本期仅 IMAGE；EDIT／CHAT 继续沿用实际版本演进，外部 Bridge 不扩展。

- 每次调用只有一个分支对象：`retrospect_id? / base_image_id / label / description? / edge_summary? / steps`；不支持 `branches[]`。通常逐次准备 2–3 个，每轮最多新增 **4 个成功预设**，每树最多同时保留 **16 个未生成预设**，与实际版本合计不超过 **80 个节点**。失败不占成功名额；转实或删除释放预设名额，删除不回收 `vN`。
- 以来源图片完整手写配方、原始角色 ID／空槽／停用槽为底本，独立执行 IMAGE `prompt_patch / params_patch / character_edit / restore_partial`，复用顺序锚点和 `checkNaiInput`。参数或锚点错误只拒绝当前调用；NAI Text 硬错拒绝，普通 Token 超量仍沿用警告口径。对比时过滤空槽，执行快照不删槽。
- `get_recipe_clusters` 返回原始角色槽映射与已有预设的目标配方／运行选项覆盖。单轮可先 `get_recipe_clusters → show_retrospect` 再连续挂分支：首个有效预设与准备树一起提交，后续成功立即保存。工具非终结，成功后可继续调用或回复；后续取消、网络失败不撤回已保存方案。相同基底、目标与标题说明的未生成预设重试返回已有节点，不重复扣名额。
- 预设是带完整目标快照的真实节点：虚线连线和边框、文档图标、轻实底、图外短标题与卡内改动说明；可独立摆放和批注。小缩放逐步收起描述与范围，不挤成不可读小字。普通空白后继框仍是透明点阵与紫色加号，仅用于预留位置。新预设在父节点右侧按两行逐个找空位，避让已有节点和已摆放的空白框；首次展示保存布局，后来新增预设不重排旧节点，转实保留主图左边缘、垂直中心与叠放顺序，图片比例变化只适配自身画幅。
- 点击预设即展示完整目标与父节点**指定样本**的红绿 Diff；父版翻图不改变自动基准，显式改选 A 时可与其他预设互比。预设没有图片编号，不显示图片失效，不进入图片计数或视觉工具；任一对照侧为预设时不进入大图。摘要分别显示已生成版本和待生成数。
- 「载入画板」明确确认后才写完整目标，并原子切换到预设游标，节点提示「已载入」，面板主操作切为「前往画板」，不把选中或载入误报为生成中。Seed／批次数默认沿用载入时画板，步骤显式指定时覆盖并在面板说明；优化偏好沿用当前值。原始角色仅在真实写入前分配合法新 ID，参考资源与模型再次检查。
- 「载入画板」为唯一紫色主操作，删除降为低权重图标；载入反馈留在面板，不同时重复 toast。真实任务在途才显示「生成中」并禁删，失败回到「已载入」。对照基底始终使用真实样本缩略图，预设转实后仍显示明确来源编号。
- 面板载入作为独立操作来源进入现有 **50 步全页撤销栈**，不伪造 ASK 回复、不替换待确认草稿。面板提供「撤销载入／重做载入」，以底部同一操作行左侧的图标按钮呈现，悬停与读屏保留完整名称，不为撤销单独增加一行；恢复、定稿或前往画板位于右侧。遵循共同栈顶和字段冲突规则；配方写入或游标提交失败共同回滚。A → B 可依序撤销。已生成后撤销不删节点，重做回到同一实节点的真实样本，不复活预设空壳。
- 首张成功图无论是否微调、仅换 Seed 或与父配方相同，都优先填入提交时冻结的预设；实际配方立即取代计划用于 Diff／恢复，后续同批图留在此节点。之后手动微调继续归该节点；新的 ASK IMAGE 改法才准备后继，手动尝试可事后单图提拔。A 在途后改载 B，A 的结果仍回到 A 且不抢 B 游标；切板、解除、定稿使旧跟踪代次失效。
- 可删除未生成预设；删除当前载入预设时游标回到具体父样本，表单不重写。正在生成的预设禁止删除，任务结束（含失败／取消）释放保护。ASK 重整自动保留预设并按真实来源重连，不能丢弃其基底或批注。定稿仅限真实图片，默认保留未采用预设。
- 活动树与位置仍限本页。收藏回复保存当次只读快照；刷新后历史预设不能载入或自动跟踪。

## 图上批注

[批注规则](../../src/ask/retrospect/annotations.ts)与[本页状态](../../src/ask/retrospect/store.ts)由 ASK 应用服务持有，图片、配方、拓扑保持原样。

- 工具栏直接复用 EDIT 的胶囊和选择菜单：「平移」「选择（单选／多选／框选）」「批注」。再次点击当前工具退出；再次单选同一对象取消。框选按节点交集、连线中点命中，Shift 追加。
- 有选择时点击批注立即打开编辑条；无选择时启用批注后点击节点或连线。键盘 H／V／M／N 切换工具；输入时不触发图快捷键。输入条沿用区域批注的徽标、无边框文本框、垃圾桶与完成按钮。
- Enter／完成保存，Shift+Enter 换行，Esc 取消；打开或取消不会写入。单项可修改、清空或用垃圾桶删除。多项批注相同时可共同更新／删除；内容不同时新增文字逐项追加，禁止一键删除不同原文。每项最多 2000 字，追加越界整次不写入。
- 批注仅保留本页，关闭重开仍在；以演进及对象身份隔离。发送给 ASK 的仅为此次明确引用的节点／连线意见。引用使用原记录绑定解析当前编号，失效旧号不指向同号新图。
