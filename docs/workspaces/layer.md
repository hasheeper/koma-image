# Koma Layer

Koma Layer 在 EDIT 内将平面立绘定稿拆分为可独立交付的 Live2D / Rig 分层素材。整体围绕 **「自动拆层入候选池 ➔ 图层栈精修与框选／套索切分 ➔ 局部补画 ➔ 切片包／PSD 导出」** 组织，母版定稿 `reference.png` 全程只读。

## 1. 图层栈与自动拆层

- **常驻图层栈**：主画布默认实时合成图层栈全部可见层，随时支持点击「对照原图」（快捷键 `\`）对比锁定母版，并在棋盘／黑／白底板上检查边缘。[图层栈引擎](../../src/layer/stack.ts) · [项目结构](../../src/layer/project.ts)
- **图层管理**：支持从本地导入 PNG / JPEG / WebP 图像直接作为新图层（同画布尺寸按原坐标 1:1 无损落位；不同分辨率或裁片自动与母版做多尺度特征匹配并缩放对齐，也可随时点击「自动对齐原图」或展开「调整位置与尺寸」手动微调）、拖拽与上下按钮实时调整层序（Z-Order）、显隐（👁）、独显（`S`）、锁定（🔒）、行内重命名、向下合并、复制、单层 PNG 导出与删除，全部接入 30 步撤销／重做（`⌘/Ctrl+Z`、`⇧⌘/Ctrl+Z`）并持久化在本机 `koma-layer` 存储（旧版 `v1` 检查点自动升级至 `koma-layer.v2`）。
- **Seedream 5.5 自动拆层与候选池**：全身、正式层和母版局部框均可拆层，支持显式选择 **输出分辨率（`2K` / `1.5K` / `1K` / `自动`，默认 `2K`）**；送图超过 8MB 时先尝试 1:1 高压缩 PNG，仍超限再渐进缩放并展示实际送图尺寸。待筛结果可刷新恢复，残余底图可人工收纳；落位放大超过 `1.15×` 的候选层与正式层会显示放大倍率提醒。单件细拆在原位建组并隐藏归档父件。具体操作、ASK 提示词与 Rig／PSD 像素验证见[递归拆层与 ASK 协同](layer-recursive-plan.md)。

保存时，母版、软蒙版和各图层的像素分别存入 IndexedDB。切换选中层或调整层序只更新项目清单。候选与已收纳层可以共用同一份像素。保存失败时，本页保留当前候选和图层，点「重试保存」可重写本地存档。已收纳的图层也可先导出为 PSD。旧存档仍可打开，会在下一次成功保存时换用分开存储的格式。

## 2. 局部拆分与局部补画

1. **框选（`M`）／套索（`L`）切分**：零 AI 调用，直接在画布上圈选合并在同一层的左右对称件（如双马尾、双袜），点击 **「拆分为新图层」** 分离为两个独立图层。
2. **递归细拆**：选中复合大件后点击 **「↳ 继续细拆此件」** 准备词栏，点击 **「开始细拆」** 发起生成。
3. **局部补画（原生透明 PNG）**：切换到「局部补画」页签，用蓝色「保留原件」（支持边缘吸附）与橙色「遮挡补全」在原画上粗略标出目标区域与遮挡段，按需展开折叠项「排除遮挡图层」勾选已拆出的遮挡物，调用支持原生透明底的模型（优先 Seedream 5.5 `background: "transparent"` + `output_format: "png"`）生成 `#1 / #2 / #3` 候选对比后加入图层栈。送图时 Image 1 保留无标记原画，Image 2 在完整原画上叠画半透明蓝／橙荧光提示（不做笔刷硬裁切），并明确提示模型仅作语义范围参考、按 Image 1 真实轮廓提取，避免粗涂溢出带出碎边。[局部补画](../../src/layer/targeted-reroll.ts)

在「补画参考」中，可以上传 PNG、JPEG、WebP，或从正式栈选一层。例如补右马尾时，可选左马尾参考发丝走向，再上传设定图参考发梢颜色。每张图都有独立用途和送图序号，参考层使用当前整层像素。文件、图层引用和用途随本机分件项目保存。「排除遮挡图层」用于标记应从结果中移除的前景，例如挡住马尾的袖子。多层遮挡合为一张输入，选中的每张正向参考各占一个位置，余量充足时附带未标记的局部母版。组合超过模型上限时会显示所需张数。

送图画幅默认使用 **「自动」**（大件自动按整张母版原比例送图，小件在画布内贴边裁切，严禁向画布外扩出透明空边），也可手动切换 **「整图原比例」** 或 **「局部裁框」**。输出尺寸按实际送图画幅的真实宽高比选档（Seedream 5.5 自动按原比例计算 `WxH`，不再强行压成 1:1 方图）；超过来源的输入像素或单图字节上限时按同比例缩放。回图落位绝不做非等比拉伸：宽高比一致时直接贴回画幅，若模型返回了不同宽高比则按原画做等比自动对齐或等比居中。候选默认展示 **「仅 AI 生成图」**，并支持即时切换 **「叠加蓝区原图」**（仅在 AI 有效透明轮廓内还原蓝区母版细节）、一键 **「自动对齐原图」** 及下载模型原始回图。[像素处理](../../src/layer/scalpel-resolution.ts)

点击「让 ASK 拟词」可带着当前部件与参考用途打开 ASK。需要看细节时，ASK 可按需查看参考原图或比较图层。可将调整参考组合、用途与补画说明放在同一张草稿卡，确认后生效，可撤回。点「生成透明部件」才会发起图像请求。

## 3. Photopea 一键精修与分组往返

- 点击图层栈顶部的 **「Photopea 精修」**，将当前全部正式图层、嵌套图层组（标准 `8BIMlsct` 组标记）及底部「锁定原图」打包为分层 PSD，通过站内全局保活的 Photopea iframe 一键打开。[Photopea 接入](../../src/overlays/PhotopeaPanel.vue) · [脚本](../../src/native/photopea-scripts.ts)
- 点击「应用并返回」后，Photopea 在内存临时副本中递归遍历图层与 `LayerSet` 分组（跳过底部锁定原图及顶层独立调整层，自动将剪贴蒙版与图层蒙版／样式烘焙到对应主体层），将全部新图层、新分组与精修像素同步回 Koma Layer 图层栈：
  - 图层栈支持按组折叠／展开、整组显隐（👁）与整组独显（`S`），并对本次新增／修改的层显示「新增」「已修」轻标记；
  - 整次同步记为 1 步可撤销操作，按撤销时弹出确认提示防止误触覆盖精修结果；
  - 导出 Rig 切片包（`manifest.json` 的 `groups` 字段）与分层 PSD（`8BIMlsct`）均完整保留嵌套分组结构。

## 4. 画布精修与交付导出

- **画布精修**：底部工具栏提供 **移动预览（`V`）**（拖拽检查底层遮挡、默认松手回弹，可选「保留偏移」）、**缩放对齐（`T`）**（在画布上直接拖动四角/四边控制点缩放、拖框位移、方向键 1px / `Shift+方向键` 10px 微调，默认「叠显原图」配半透明滑杆对照母版轮廓，按 `Enter` 或「应用变换」一次性高质量落盘并支持 `⌘Z` 撤销）、**软硬橡皮（`E`）**（笔径与 0%–100% 径向硬度）、**刷回原图（`R`）**（从锁定 `reference.png` 无损刷回并自动扩展包围盒）、**涂抹拽边笔（`S`）**（在当前正式层上按笔径与强度预乘 Alpha 外推拉伸切口边缘、零重抽制作防漏光关节出血位，推拉越过原裁切框时在母版画布范围内自动动态扩充图层像素缓冲与 `rect` 包围盒，完整接入撤销／重做栈并直接随 Rig 切片包与分层 PSD 导出）、**还原可见区原画／批量锐化**（自动避开上方可见前景层并带 2px 硬保护 + 5px 羽化与 7×7 局部色彩一致性保护，把未遮挡可见区无损恢复到母版 1:1 原始清晰度，同时完整保留被前景遮挡的 AI 补画区）及 **一键色彩对齐原画**（0%–100% 可逆强度滑杆）。
- **交付导出**：输出按当前可见层序排列的 **Rig 切片包（`koma-rig.slices.v2`，ZIP 或本机目录，可直接导入兄弟项目 [Koma Live / Koma Rig](https://github.com/hasheeper/koma-live) 绑骨与实时驱动）** 与 **分层 PSD（`8BPS`，保留图层名、显隐、锁定与精确偏移）**。[导出](../../src/layer/export.ts) · [PSD](../../src/layer/psd.ts)
- **仓库回归**：纯逻辑单元测试 `node --test tests/layer-*.test.mjs`，浏览器回归 `node --test --test-concurrency=1 tests/layer-provider.browser.mjs tests/layer.browser.mjs`。
