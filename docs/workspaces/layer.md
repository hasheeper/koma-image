# Koma Layer

Koma Layer 在 EDIT 内将平面立绘定稿拆分为可独立交付的 Live2D / Rig 分层素材。整体围绕 **「自动拆层入候选池 ➔ 图层栈精修与框选／套索切分 ➔ 局部补画 ➔ 切片包／PSD 导出」** 组织，母版定稿 `reference.png` 全程只读。

## 0. 双布局界面（传统三栏与画布协创 BETA）

- **传统布局（桌面三栏）**：顶栏保持与普通 EDIT 一致的克制骨架，仅承载 `Koma EDIT` 工作区切换、「编辑｜分件」模式分段、唯一 Photopea 分层精修入口及右侧图层栏折叠开关；当前项目标题、裸等宽尺寸、`⋯` 项目菜单（含「换图并清理」与「清空分件缓存」）与「原图｜结果」分段下沉到中栏画布左上透明无框题注；左栏专注「自动拆层」（含候选池）与「局部补画」及底部固定 AI 执行栏；中栏暗房画布底部闲置只显示单一玻璃工具胶囊（移动工具的「掀开检查／直接移动图层」收进图标附带菜单，仅在画笔／缩放对齐／选区待确认时按需上浮副胶囊）；右侧默认 248px 可拖拽调宽（228–420px，双击重置）且可一键收起，承载独立滚动图层栈与极简双行底栏（精修／变换与 ↑↓🗑、单一无缝分体导出按钮）。
- **画布协创 BETA 布局**：保持无顶栏满画布，画布左上玻璃浮岛承载单层项目胶囊（无冗余缩略图与内嵌尺寸盒）与原图／结果切换，右上承载画布选项、「编辑／分件」模式入口与「分件｜ASK」托盘切换；右侧单一玻璃托盘以「图层」「拆层」「局部补画」三段页签按上下文切换内容与底栏，图层页签共用独立滚动树与双行底栏，不重复主标题与退出按钮；移动端复用 `canvas-sheet` 底部抽屉与窥视条。

## 1. 图层栈与自动拆层

**打开 PSD**　从「打开图片或 PSD」或项目顶部「换图并清理」选择文件，可把 8 位 RGB PSD 作为分件项目打开。外部 PSD 使用保存的合成图作为锁定母版，缺少合成预览时按可见像素层重建。Koma 导出的 PSD 使用文件内的「锁定原图」作为母版。普通像素层直接进入图层栈，保留层序、偏移、透明度、显隐与嵌套组。手动重选同一文件会重新读取原始像素层。

**追加 PSD**　在图层栈点「导入图层」可以多选 PSD 和普通图片，一次撤销整批追加。PSD 与母版同尺寸时沿用文档坐标，尺寸不同时将整个 PSD 画布居中，保留各层间距与原始分辨率。只有合成图的 PSD 可作新母版，也可作为单层追加。

导入在本机后台线程解码，按 sRGB 像素处理。普通层不透明度、填充不透明度与基础位图蒙版会写入像素透明通道，非空分组保留，局部锁定和父组锁定按 Koma 的整层锁定处理。文字和智能对象使用已保存的栅格像素。剪贴蒙版、调整层、特殊混合模式、图层样式、组不透明度和复杂蒙版需先在 Photoshop 或 Photopea 中合并到普通像素层。遇到不支持的内容会提示相关层名，该次导入可以重新选择文件。[PSD 导入](../../src/layer/psd-import.ts)

- **原图对照**：拆层返回后，在画布顶部可切换「原图」与「拆分结果」。收纳到正式图层栈后，可切换「原图」与「图层合成」。原图取自锁定母版，切换保留缩放、候选显隐和图层状态。快捷键为 `\`。仍可用棋盘／黑／白底板检查边缘。[图层栈引擎](../../src/layer/stack.ts) · [项目结构](../../src/layer/project.ts)
- **图层管理**：支持从本地导入 PNG / JPEG / WebP 图像直接作为新图层（同画布尺寸按原坐标 1:1 无损落位；不同分辨率或裁片自动与母版做多尺度特征匹配并缩放对齐，也可随时点击「自动对齐原图」或展开「调整位置与尺寸」手动微调）、拖拽与上下按钮实时调整层序（Z-Order）、显隐（👁）、独显（`S`）、锁定（🔒）、行内重命名、向下合并、复制、单层 PNG 导出与删除，全部接入 30 步撤销／重做（`⌘/Ctrl+Z`、`⇧⌘/Ctrl+Z`）并持久化在本机 `koma-layer` 存储（旧版 `v1` 检查点自动升级至 `koma-layer.v2`）。
- **Seedream 自动拆层与候选池**　全身、正式层和母版局部框均可拆层。输出分辨率随来源显示，可用时默认选 2K。OpenRouter 兼容格式的 5.5 可指定 2–16 层上限。Kie 和 fal 兼容格式的 5.5 均可指定上限或交给上游，5.0 Pro／Flash 自动决定层数。送图超过 8MB 时先尝试 1:1 高压缩 PNG，仍超限再渐进缩放并展示实际送图尺寸。待筛结果可刷新恢复，残余底图可人工收纳；落位放大超过 `1.15×` 的候选层与正式层会显示放大倍率提醒。单件细拆在原位建组并隐藏归档父件。具体操作、ASK 提示词与 Rig／PSD 像素验证见[递归拆层与 ASK 协同](layer-recursive-plan.md)。

「换图并清理」成功读入文件后，一次替换本机的分件缓存。取消选图或导入失败时保留当前项目。点顶部「清空分件缓存」可以删除全部分件存档、候选和像素记录，当前母版留在画布上，可立即重新编辑。清空后首次编辑才重新保存。刷新或重新进入当前项目时可以继续上次的工作。需要长期保留的分层可先导出 PSD。

保存时，母版、软蒙版和各图层的像素分别存入 IndexedDB。切换选中层或调整层序只更新项目清单。候选与已收纳层可以共用同一份像素。保存失败时，本页保留当前候选和图层，点「重试保存」可重写本地存档。已收纳的图层也可先导出为 PSD。旧存档仍可打开，会在下一次成功保存时换用分开存储的格式。

## 2. 局部拆分与局部补画

Seedream 5.5 或通过 Kie、fal 接入的 5.0 Pro／Flash 拆层送图低于 262,144 像素时，可以先在本地等比放大、选择已配置的放大模型，或取消。放大只用于本次请求，返回的部件映射回原画布。模型放大和拆层分别按各自连接计费。

1. **框选（`M`）／套索（`L`）切分**：零 AI 调用，直接在画布上圈选合并在同一层的左右对称件（如双马尾、双袜），点击 **「拆分为新图层」** 分离为两个独立图层。
2. **递归细拆**：选中复合大件后点击 **「↳ 继续细拆此件」** 准备词栏，点击 **「开始细拆」** 发起生成。
3. **局部补画（原生透明 PNG）**：切换到「局部补画」页签，用蓝色「保留原件」（支持边缘吸附）与橙色「遮挡补全」在原画上粗略标出目标区域与遮挡段，按需展开折叠项「排除遮挡图层」勾选已拆出的遮挡物，调用支持原生透明底的模型（优先 Seedream 5.5 `background: "transparent"` + `output_format: "png"`）生成 `#1 / #2 / #3` 候选对比后加入图层栈。送图时 Image 1 保留无标记原画，Image 2 在完整原画上叠画半透明蓝／橙荧光提示（不做笔刷硬裁切），并明确提示模型仅作语义范围参考、按 Image 1 真实轮廓提取，避免粗涂溢出带出碎边。[局部补画](../../src/layer/targeted-reroll.ts)

「补画底图」默认使用母版。点「选择图层」可勾选一个或多个正式层，也可以在图层栈多选后点「补画所选」。所选层按画布坐标与原层序合成，隐藏层也可显式选用。没有蓝橙笔触时，直接以所选图层的非透明范围生成一个新候选；有笔触时沿用画布选区，边缘吸附、送图、回图对齐和蓝区还原均使用本次底图。项目保存所选层，全部取消后可重新勾选或切回母版。

在「补画参考」中，可以上传 PNG、JPEG、WebP，或逐一添加正式层。例如补右马尾时，可选左马尾参考发丝走向，再上传设定图参考发梢颜色。每张图都有独立用途和送图序号，参考层使用当前整层像素。文件、图层引用和用途随本机分件项目保存。「排除遮挡图层」用于标记应从结果中移除的前景，例如挡住马尾的袖子。多层遮挡合为一张输入，选中的每张正向参考各占一个位置，有笔触且余量充足时附带未标记的局部底图。组合超过模型上限时会显示所需张数。

送图画幅默认使用 **「自动」**（大件自动按整张母版原比例送图，小件在画布内贴边裁切，严禁向画布外扩出透明空边），也可手动切换 **「整图原比例」** 或 **「局部裁框」**。输出尺寸按实际送图画幅的真实宽高比选档（Seedream 5.5 自动按原比例计算 `WxH`，不再强行压成 1:1 方图）；超过来源的输入像素或单图字节上限时按同比例缩放。回图落位绝不做非等比拉伸：宽高比一致时直接贴回画幅，若模型返回了不同宽高比则按原画做等比自动对齐或等比居中。候选默认展示 **「仅 AI 生成图」**，并支持即时切换 **「叠加蓝区原图」**（仅在 AI 有效透明轮廓内还原蓝区母版细节）、一键 **「自动对齐原图」** 及下载模型原始回图。[像素处理](../../src/layer/scalpel-resolution.ts)

点击「让 ASK 选层」可让 ASK 按部件与说明提议补画底图，草稿显示组路径和图层名。点击「让 ASK 拟词」可带着当前部件与参考用途打开 ASK。需要看细节时，ASK 可按需查看参考原图或比较图层。可将底图选择、参考组合、用途与补画说明放在同一张草稿卡，确认后生效，可撤回。点「生成透明部件」才会发起图像请求。

### 用参考图层补缺失件

在「局部补画 → 补缺失件 · SD Layer」中选择底图，填写部件名称，点「生成缺失件」。「母版原图」发送整张母版，尚未拆层也可使用。「选择图层」按原坐标和层序合成所选层，裁至它们的联合范围。例如勾选面部与前发，填写「画面左侧的耳朵」，在描述中写「补全前发后面的耳根」。「让 ASK 选底图」可提议使用母版或指定图层。该模式单独记住底图选择，可使用已配置的 Seedream 5.5 原生、Kie、OpenRouter 或 fal 兼容拆层来源。

结果进入候选池。「单看部件」检查完整轮廓，「叠回图层」查看遮挡效果。位置不确定时可以点「校准」。选定一个候选并点「添加为独立图层」，新层沿用填写的部件名。使用母版时可切换「单看部件／叠回母版」，收纳后新层位于栈顶。使用图层时新层插在最靠前的参考层正下方。原图层及分组保留，可以撤销并重新选择。只收到残余底图或全透明回图时，界面会提示本次未获得部件。图层和落位由本机处理，完全不可见的结构由模型推断。

## 3. Photopea 一键精修与分组往返

- 点击图层栈顶部的 **「Photopea 精修」**，将当前全部正式图层、嵌套图层组（标准 `8BIMlsct` 组标记）及底部「锁定原图」打包为分层 PSD，通过站内全局保活的 Photopea iframe 一键打开。[Photopea 接入](../../src/overlays/PhotopeaPanel.vue) · [脚本](../../src/native/photopea-scripts.ts)
- 点击「应用并返回」后，Photopea 在内存临时副本中递归遍历图层与 `LayerSet` 分组（跳过底部锁定原图及顶层独立调整层，自动将剪贴蒙版与图层蒙版／样式烘焙到对应主体层），将全部新图层、新分组与精修像素同步回 Koma Layer 图层栈：
  - 以 Photopea 实际目录为准，移动或合并后的图层随目标目录回传，独立的同名目录保留各自的身份。图层与目录的显隐分别保留；
  - 图层栈支持按组折叠／展开、整组显隐（👁）与整组独显（`S`），并对本次新增／修改的层显示「新增」「已修」轻标记；
  - 整次同步记为 1 步可撤销操作，按撤销时弹出确认提示防止误触覆盖精修结果；
  - 导出 Rig 切片包（`manifest.json` 的 `groups` 字段）与分层 PSD（`8BIMlsct`）均完整保留嵌套分组结构。

## 4. 画布精修与交付导出

- **画布精修**：底部工具栏提供 **移动预览（`V`）**（拖拽检查底层遮挡、默认松手回弹，可选「保留偏移」）、**缩放对齐（`T`）**（在画布上直接拖动四角/四边控制点缩放、拖框位移、方向键 1px / `Shift+方向键` 10px 微调，默认「叠显原图」配半透明滑杆对照母版轮廓，按 `Enter` 或「应用变换」一次性高质量落盘并支持 `⌘Z` 撤销）、**软硬橡皮（`E`）**（笔径与 0%–100% 径向硬度）、**刷回原图（`R`）**（从锁定 `reference.png` 无损刷回并自动扩展包围盒）、**涂抹拽边笔（`S`）**（在当前正式层上按笔径与强度预乘 Alpha 外推拉伸切口边缘、零重抽制作防漏光关节出血位，推拉越过原裁切框时在母版画布范围内自动动态扩充图层像素缓冲与 `rect` 包围盒，完整接入撤销／重做栈并直接随 Rig 切片包与分层 PSD 导出）、**还原可见区原画／批量锐化**（自动避开上方可见前景层并带 2px 硬保护 + 5px 羽化与 7×7 局部色彩一致性保护，把未遮挡可见区无损恢复到母版 1:1 原始清晰度，同时完整保留被前景遮挡的 AI 补画区）及 **一键色彩对齐原画**（0%–100% 可逆强度滑杆）。
- **交付导出**：输出按当前可见层序排列的 **Rig 切片包（`koma-rig.slices.v2`，ZIP 或本机目录，可直接导入兄弟项目 [Koma Live / Koma Rig](https://github.com/hasheeper/koma-live) 绑骨与实时驱动）** 与 **分层 PSD（`8BPS`，保留图层名、显隐、锁定与精确偏移）**。[导出](../../src/layer/export.ts) · [PSD](../../src/layer/psd.ts)
- **仓库回归**：纯逻辑单元测试 `node --test tests/layer-*.test.mjs`，浏览器回归 `node --test --test-concurrency=1 tests/layer-provider.browser.mjs tests/layer.browser.mjs`。
