# CHAT 对话工作区

更新：2026-11-18。描述当前会话、上下文、版本与图片交接；编辑画板另见[EDIT 工作区](edit.md)。费用、能力和可用工具按 Profile 判断，不能用标准网关规则推断原生协议行为。

图片检视入口已接入[区域批注](annotations.md)，共享选区、ASK／CHAT 交接和人工回贴的规则由该专题维护。

## 会话与上下文

- 会话列表支持空白复用、手动重命名、菜单「AI 命名」、置顶、复制、删除确认及中断轮次恢复。设置 → ASK → AI 命名通过「自动命名」统一控制 ASK／CHAT：新会话首条需求提交后调用命名模型，无需等待生成完成；仅触发一次，保留手动名称。配置、并发与写回规则见[AI 命名](../ask/prompts.md#ai-命名)。列表、草稿、附件和分支状态由应用级服务保留，KeepAlive 切换不取消在途任务。
- 模型菜单按品牌分组，同模型合并为一行；模型名右侧的小标签显示当前参数来源的供应商，随来源和供应商改名同步。标签仅说明参数来源，生成仍按生图顺序选择兼容来源。
- 侧栏按置顶／今天／昨天／7 天内／更早分组，主会话显示缩略图与标题。展开的主会话和下方「分支／子区」用一条细导线连成一组，子项缩进，使用类型图标而不重复缩略图；只显示非空类别，父会话箭头统一展开或折叠。搜索保留命中项的上级。普通未发送对话由「新对话」行代表，不进列表；图片子对话创建即列在「子区」。空白页只显示品牌，输入框下方的起步建议只填入描述或打开文件选择，不发送请求。
- 保留底图／参考图、跟随最新、历史文字勾选、分支与多版本、实际发送文本和模型数量限制。手动改变底图、版本等选择会增加选择版本号，迟到的生成结果不能覆盖用户选择。
- 用户消息下一行是「编辑上下文」和「复制描述」。编辑只改后续请求引用的这轮历史文字，上下文面板展示同一文本；不改消息原文、已发送快照、输入框草稿或当前轮次，不走 ASK 回退。是否引用仍由该轮勾选控制，复制取原消息文本。重新生成既有轮次仍使用当时发送的快照。
- 上下文面板按当前分支每轮一张楼层卡片：勾选框管该轮文字，图片放在首次出现的楼层，角标为底图／参考序号／超出，未带入的图淡显带＋；本轮卡片放跟随开关和实际发送文本。顶部计数与输入框上下文按钮同图标、同顺序、同样标出超出张数。
- 上传／粘贴／拖入沿用单张 8MB、总量 32MB 和模型图片数限制。附件在取得任务槽、开始轮次时消费；失败或取消不退回附件栏，轮次引用与保留参考仍可找回。
- 预报价防抖 650ms；标准网关执行前按提交快照重新报价，携带当次 `max_cost`，涨价提示后继续；原生协议按其能力处理费用。一个轮次始终占同一全局任务槽，直到全部图片解码、校验和资源登记完成，无付费确认、自动重试或路线回退。
- 返回中的文本与全部图片按原顺序存储，多图回复也按原顺序展示；单图回复将模型文字作为图下注释。图下操作带含编辑、重新生成、基于此图新开对话、从此处分支、收藏及下载。下载保留原字节；桌面版本栏在右侧，手机端可横滑，空间不足时操作带另起一行。「设为底图」仍是图上图钉；「编辑」是进入 EDIT 的唯一入口，画板记住来源会话。加入参考由上下文栏 ＋ 完成，图上不重复。结果揭示与等待波浪由原生 Canvas 驱动。
- 会话与图片在同一 IndexedDB 事务保存，400ms 防抖，失败保留脏数据供下次保存。恢复时把未完成轮次标为中断；离开页面和进入备份读取前刷新待保存草稿。浏览器强制结束进程仍无法保证异步写入完成。
- 绘图图片先准备并保存 Koma 独立票据，再原地进入对话；票据只领取一次、30 分钟过期，已保活的对话也能领取。超限图片使用原压缩规则。没有读取旧应用票据或数据库。

「基于此图新开对话」打开独立的图片子对话：只保留并展示选中的来源图，可返回来源会话；不继承历史、不自动设为底图或加入请求。「从此处分支」继承直到选中轮次的历史，以该轮选中的版本和图片继续，不带后续楼层；只在新分支里设置起点。两者都不改原会话、不自动发送或生成，区别于图钉、重新生成与复制整场会话。来源按会话／轮次／版本／图片身份冻结，跟随普通 Koma ZIP 备份，冲突导入时映射到导入副本；删除来源会话不级联删除，保留图片来源，找不到父会话的分支与子区独立列出。

图下「重新生成」打开同轮设置，桌面跟随按钮，窄屏使用底部抽屉。默认带出所选版本的模型与参数，可换模型，也可用同模型只改参数或按原设置再生成。换模型沿用兼容值，其余使用目标模型的默认值；只显示所选模型支持的字段。点击「生成新版本」才走原报价、任务锁和取消路径，关闭设置丢弃本次修改。重跑沿用该轮实际发送的文本、输入图顺序与批注，不用当前结果图替换输入；模型无法承载原图片组合或原生标注时明确阻断。新结果追加到同一轮，不改变默认模型、输入草稿、当前版本选择、会话起点或底图。模型与实际参数归各版本、随会话保存；旧记录仍读楼层设置。

两个成功版本可从图下「对比版本」检视模型直出，桌面并排、手机 A/B 切换，多图结果各自选图。只在图片实际边缘加细描边，不给外壳或每列套框；图按比例显示，实际尺寸与参数列在图上方。检视不改会话或发请求。

CHAT 结果工具的「收藏」按具体会话／轮次／版本／图片保存原始字节，复用普通收藏的写入、取消和撤销行为；多个结果逐张收藏，不改当前底图、上下文或发送请求。收藏进入 IMAGE 收藏列表及 ASK `#f`，源会话删除后仍独立存在，也进入现有普通 ZIP。CHAT 提示词／选项不是绘图配方，不能直接拖入绘图参数或用 `restore_partial` 恢复；在其基础上产生的 NAI 编辑结果有自己的绘图参数。

传统模式仅保留桌面会话栏、对话流和非模态上下文栏，已移除手机侧栏菜单与底部上下文面板。窗口小于 1080px 时自动提示切换画布协创 BETA，手机内容适配只归协创布局。

## 画布协创（BETA）

共用模式与面板规则见[ASK UI](../ask/ui.md#12-画布协创beta)。CHAT 保留按轮组织的对话流与上下文，协创复用同一套消息操作和会话分支列表。

- 左侧仍是完整对话流与底部输入框，台面与 IMAGE／EDIT 相同；发送、报价、停止与失败反馈走原路径。顶部改为悬浮控件：工作区、当前会话（点击以抽屉打开原会话列表，选中或新建后收起）、进行中演进的胶囊、「⋯」选项（发起演进、账户与外观）以及「上下文 / ASK」切换；对话内容在顶区下方渐隐。手机顶区为同一行 40px 高的岛，只有会话标题让出宽度，面板切换进入底部抽屉。
- 右侧切换「上下文 / ASK」，再次点击当前项收起整列。上下文面板与原组件相同，仍按楼层勾选文字、调整底图／参考并查看实际发送文字；输入框的上下文按钮改为打开侧栏。手机通过输入栏把手或上下文入口展开共享的半屏／全屏抽屉，切换控件进入抽屉头；上下文保留原输入栏，ASK 接管同一底部输入位置，消息流按遮挡量留出滚动空间。需要整理上下文或改写本轮描述时直接询问 ASK，修改仍以草稿确认后写入，对应已有的分支提纯与 `chat.composer` 补丁。
- 结果图操作带增加「Ask」，引用该图的 `#cN.M`（多图带字母尾缀）并切到 ASK。手机上操作带与 ASK 图标同步收小，按钮间距收紧；顶部仅保留短而轻的渐隐，不形成整片深色遮罩。ASK 显示期间把草稿写入 CHAT 时，「上下文」切换显示提示点，打开上下文后消失；写入后仍需手动发送。
- 打开演进时 ASK 让出侧栏，关闭后返回；上下文与 ASK 的切换不改变会话选择或发送内容。

布局宿主归 `ChatWorkspace.vue`，私有样式在 `chat-canvas.css` 以 scoped 载入；`ContextPanel.vue` 的 embedded 模式保持非模态 dialog 并由页面面板选择控制开合，Esc 只由模态层拦截。会话、草稿、附件、在途任务与上下文状态仍归 `services/chat.ts`。

## 版本演进

顶栏复用演进入口；有工坊关联时打开对应 IMAGE 主干。明确图片交接成功后建立待交付工单，CHAT 生成与回贴保留原生历史，不自动挂成 vN；每张具体图片可「记入演进」，首次交付、追加本阶段或作为下一步均不移动 IMAGE 游标。多图交接只按指定底图派工，实际底图／参考图、历史文字及蒙版继续记录。演进节点定位原对话、轮次、版本与图片，不改底图；ASK 的起点提纯草稿继续经确认调整当前会话并支持撤销。完整规则见[版本演进](recipe-retrospect.md)。

## 服务与资源所有权

`src/services/chat.ts` 在 App 中创建一次，位于 KeepAlive 外；Vue 只订阅浅快照，模板拥有输入、消息和图片结构。原生 Canvas 驱动处理结果揭示、波浪与高频指针，Blob、图片 URL 和 AbortController 不进入深层 reactive。

切出工作区时暂停指针、键盘、Observer、计时和波浪；在途任务和会话图片继续保留。删除引用或销毁服务时释放对应 URL，不因单纯切页释放仍被使用的图片。

`ChatImage.vue` 为结果、版本、轮次参考、上下文、附件和会话封面共用展示入口。共享 IntersectionObserver 只为可见图片申请预览；结果长边最多 1280px，小图最多 256px，保留比例与透明通道，原始尺寸属性留作占位。离屏、切页和卸载撤去 `src` 并释放预览租用；结果揭示从预览加载完成开始，离屏取消，重入不重复播放。

`AssetStore.preview()` 按资产与预览尺寸共享生成任务和 URL，串行处理大图解码，尚未开始且已无人使用的任务跳过。已生成的压缩预览 Blob 仅在内存随原资产保留，最后一个展示使用者退出时释放 URL；删除资产、重载或销毁清除预览，迟到任务不能重建已移除资源。转换失败才回退原图。预览不写入 IndexedDB／备份，不替代原资产的身份、尺寸、请求编码、检视、收藏、下载或 EDIT 交接。[CHAT 回归](../../tests/workspaces.browser.mjs)验证按需加载、透明度、原件使用、共享租用及清理／重载隔离。

持久化经 `data.write`。备份前刷新已加载会话，未加载的缓存不以空值覆盖存储；维护完成先 reload 全部缓存，再恢复调度和模型／报价请求。HOME 的 `readStored()` 仅加载本地会话，打开首页不预热模型、报价或额度。

## ASK 与运行方式

ASK 的 `get_chat_context` 只读取发送时冻结的当前会话及其活动分支；`#cN.M` 读取该分支已有图片，多图版本逐张为 `#cN.M[a-z]`（兼容旧 `#cN.M.K`）。`text` 保留原文，`context_text` 是实际参与历史上下文的文字；图片子区的 `source_image` 可读取，但不属于生成输入，不带入来源会话历史。ASK 可提议新开一个图片子区、普通新会话交接或调整当前会话，不创建历史分支。草稿与生命周期见[ASK 运行契约](../ask/runtime.md#草稿与校验)；不改全局 CHAT 设置，不自动发送、生成或报价。ASK 打开、发送或写入前会预热 CHAT 的会话与模型目录，未进入 CHAT 时不请求报价或额度。

标准网关和两种 ASK 推理协议可使用本地环境变量代理；OpenAI Images／Gemini 原生／NovelAI 官方目前为浏览器直连。原生协议不提供预报价时保留未知费用状态，生成按钮暂不显示费用标签，工具仍受模型和协议能力约束。见[发布说明](../release-guide.md)及[图像协议](../integrations/image-protocols.md)。

ASK 对多图版本优先显示字母尾缀，如 `#c2.1a/#c2.1b`；旧数字尾缀仍可输入，无尾缀指第一张图。每轮冻结会话／轮次／版本／资产身份，切分支不重解旧回复；原图实体与收藏／EDIT 位置互通，参数仍归具体操作记录。见[图片身份](../engineering/image-identity.md)。

## ASK 的 EDIT 交接

chat_handoff 可将本轮 #e 原图经既有 CHAT 资产管道持久保存，确认后定位新会话但不发送。原字节共享实体；fitReference 转换字节后生成新实体，并保留冻结父记录／实体／作用域和 reference-fit 来源。刷新不影响已保存参考，也不会重解旧编辑短码。反向 edit_handoff 可从 CHAT 图创建或复用编辑画板，不自动跳转、缩放或请求生成；详见 [ASK × EDIT](../ask/edit.md)。
