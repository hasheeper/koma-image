# 图片区域批注与局部回贴

更新：2026-11-14。共享批注、ASK、EDIT 通用编辑与 CHAT 双图交接已随 [v0.5.0](../archive/README.md#发布记录) 发布；GPT Image 2.5／2.6 原生标注、边界色彩对齐与 Photopea 融合精修已随 [v0.6.0](../archive/releases/2026-11-10-v0.6.0-release.md) 发布。EDIT 参考图及区域关联随 v0.7.0 发布；真实供应商的多区域理解、位置保持和接缝质量仍待核验。

## 入口与选区

IMAGE 结果栏原「放大」位置改为单个「批注」入口，与 CHAT 大图检视、EDIT 批注工具共用圆角方形评论气泡的 SVG 图标（内部短横线，不带笔）。IMAGE／CHAT 点击后关闭大图检视，进入对应 EDIT 画板并自动启用点击批注；已有画板复用并定位到本次选择的图片，不另开批注窗口。几何与评论直接叠加在 EDIT 原画布，原图保持干净。批注模式用一条紧凑胶囊替换普通画布工具，提供选择、点、矩形、椭圆、多边形及撤销／重做／清空，末尾以「完成批注」返回编辑工具；右上角沿用 ASK／CHAT 交接。控件复用全局主题，图像覆盖层使用稳定的紫色描边与深浅衬线。

- 点批注在准确落点显示靶环，以短引线连接错开的编号，不遮住目标，也不生成范围；可拖动、不提供缩放手柄。矩形／椭圆需要拖拽绘制，原地单击不创建选区。多边形逐点绘制，有实时虚线与起点吸附；点击起点、双击、Enter 或「闭合」完成，绘制中可撤销末顶点或取消。
- 新建后在编号旁打开紧凑评论框，按内容增高；Enter 确认、Shift+Enter 换行。未选中的批注悬停显示摘要；点击选择后只显示编号、编辑与删除，双击或 Enter 再编辑。矩形／椭圆可拖动与四角调整；多边形可移动顶点、点击边中点插入、删除选中顶点，至少保留三点。删除整条后序号连续重排。
- 本次工具会话的绘制、几何调整、评论和清空可撤销／重做，最多保留 100 步；退出工具仍保留几何，重开不恢复操作栈。Ctrl／Cmd+滚轮缩放，H、空格拖动或中键平移，触屏双指缩放会取消未完成绘制。V／C／R／E／P／H 切换选择／点／矩形／椭圆／多边形／平移，输入文字时不触发。Esc 依次收起评论、取消绘制或选择、退出工具。
- 几何保存为相对原图的 0～1 坐标；稳定 key 与显示序号分开。点批注保存为独立的 `shape: point`，共用坐标记录中的宽高固定为 0，仅表示落点；不隐藏默认圆形范围。多边形按真实顶点处理，不以外接矩形代替蒙版。
- 每图最多 32 处、每多边形最多 128 个顶点、每处评论最多 2000 字，原图最多 3200 万像素；出站仍受各工作区的文字和图片大小限制。

批注绑定图片实体、记录和作用域；新版本不会仅因尺寸相同而继承旧选区。未交接草稿仅保存在本页内存，最多保留 64 张图片的几何，不长期保存原图副本。

## EDIT 参考图与批注关联

通用图像模型的画布批注框提供参考图入口，可上传、拖入或粘贴 PNG／JPEG／WebP；新图自动关联发起上传的批注。上传期间关闭批注或移除该区域时取消写入，不留下未关联图片。已有参考可在同一浮层多选复用。参考汇总紧贴修改说明框外下方，以随图片收紧的附件区展示缩略图和 R 编号，区头复用修改说明的标题样式，写「参考图」；单图不设文件名正文或常驻容量计数，多图时横向滚动；仅容量超限时显示数量警示，名称和用途可悬停或预览查看。汇总区不再提供上传入口；点击图片查看大图、编辑用途，拖动或 Alt＋方向键排序，叉号移除。添加图片只作为参考，不替换底图、不新建编辑版本。参考随编辑画板隔离；切回 NAI 后保留配置但不发送，NAI 仍使用其专用 Vibe／Precise。

每张参考分配稳定的 R 编号，删图或排序不改已有编号。批注评论框为紧凑编辑条，正文一行起步、随内容增高；尾部为已关联参考的小图按钮与确认勾号，不设独立底栏。点击参考按钮打开独立缩略图多选浮层，Esc 先收起选择，再收起评论。可勾选一张或多张 R，关联进入批注撤销／重做；未单独勾选的参考仍按全局用途发送。删去已关联图片后显示失效关联，须重新选择或移除关联再生成／交接。

每板最多保存 16 张，实际可添加数量取模型输入容量减去底图及双图定位图的占位；单图文件最多 8MB、4000 万像素，生成输入沿用单图 8MB／合计 32MB 限制。用户切换模型或新增批注使容量不足时明确提示，不截断参考图。

生成冻结参考原件、用途、顺序及每条批注的关联。双图请求顺序为「底图 → 定位图 → 参考图」，原生标注为「底图 → 参考图」并独立上传透明层，无批注／范围时为「底图 → 参考图」。程序在请求中写明 R 对应第几张图，排序或切换标注方式后自动换算；参考内容不进入本地蒙版像素。版本配置与演进操作记录保留参考身份及用途，回贴与 Photopea 精修继续关联该次生成输入。

参考原件由 EDIT 页内资源池持有，当前板、历史版本、在途任务或 ASK 草稿／撤销仍引用时保留；最后引用解除后回收。刷新不会恢复 EDIT 现场；交给 CHAT 或收藏 ASK 后由目标既有资产路径持有副本。

## ASK：原图、指示图与坐标

「问 ASK」原子准备干净原图、编号指示图及当前参考图；原图与指示图合并显示为批注卡，参考图保留缩略预览。展开可修改评论或回到 EDIT，并恢复参考原件与区域关联，即使原编辑板已关闭；移除组内附件会同时移除整组待发批注。ASK 仍为每轮最多 4 张图片，批注原图与指示图占两张，最多再携带 2 张参考；已有附件也计入容量，超限整组不写入。输入框只保留用户文字，发送时才追加 `<image_annotations>`；无文字时使用「请按这些批注逐条处理。」。历史显示卡片而不显示 XML，调试仍保留实际请求。图片权限、附件容量、收藏与手动失败重试沿用 ASK。

XML v2 的 `image`／`guide` 使用实际分配的 `#aN`，标明 `units="0-1"`。区域为 `n/shape/x/y/w/h`，点为 `n/x/y`，均保留三位小数并转义评论；模型状态采用同一投影，不发送多边形顶点。完整精度与真实几何保留本地。`reference` 记录 R 编号、实际 `#aN` 及用途，区域说明引用其关联参考。

`view_image({id,spec:"crop",annotation:编号})` 与 `region` 二选一，程序按冻结几何解析区域外接框；点取以短边 20% 为边长的检视窗口，再沿用既有 25% 外扩。编号不豁免「先看同一原图全图」：实际附图发送的原图已有资格；未附图的 EDIT 底图须先 `look/glance`，仅看过编号图、拼图或坐标不算。底图 ID 使用 `image_edit.annotations.image`，不能替换成可能不同的查看版本。聚焦草稿仍使用 0～1 坐标，经确认写入；ASK 不直接写蒙版或生成。

附件与输入随已收藏 ASK 会话保存，普通未收藏 ASK 仍仅保留本页，不进入普通 Koma ZIP。

## EDIT：选区与交接

EDIT 普通画布工具栏的「批注」沿用分体入口，开启后切换为单条批注工具栏，不再叠加第二排控制。批注直接覆盖当前图片，沿用 EDIT 的缩放、平移与视口；退出保留页内批注，换版本或离开 EDIT 停止当前交互，不改变底图、重绘模式或蒙版。NAI 聚焦框另用白色框线与八个手柄，和紫色批注明确区分。

画布右上角只放一枚「发送」胶囊，与 ASK 悬浮小球同高、同中线、相隔 8px；批注数仅显示在这枚胶囊。展开采用横向操作带：有 CHAT 来源且原会话仍在时，显示「ASK」「续改」和新建加号，下方会话名保持单行省略，悬停与无障碍名称提供全文；无原会话时只显示「ASK」「新对话」，宽度随内容收紧为胶囊。没有分组标题、来源标签或空白第二行。

操作带与「发送」共用玻璃底色、边缘和轻量开合／按压动效；亮色悬停为白色表面与轻投影，减少动态时停用动效。鼠标打开不预选操作，键盘打开聚焦第一项，支持左右／上下方向键、Home／End 与 Esc。ASK 小球继续负责打开助手。窄屏有去背景分段时，题注只留图片编号。有活动选区时携带原图、编号图与说明；没有活动选区时准备当前干净图片；有参考图时一并送出，CHAT 以当前图为底并准备完整参考组合、保留来源会话草稿文字，ASK 添加原图与参考附件。没有参考图时，送往来源会话仍按原路径添加为参考图。两种路径都由用户在目的工作区确认发送。

CHAT 来源由画板记住，而不是由批注入口传递：从 CHAT 大图「批注」、结果工具（如放大）进入 EDIT，或在 EDIT 中退出后重新批注，都会带上原会话及能识别的轮次／图片；「续改」按会话 id 切回原会话，即便 CHAT 已切到其他会话，其他会话的草稿不受影响。原会话已删除时，CHAT 目的地只剩「新对话」。批注界面不提供加入／替换蒙版、聚焦转换、选模参数或直接生成操作；NAI 重绘继续留在 EDIT 的现有工具中。

Image 2／Gemini 等通用模型已接入 EDIT 主模型菜单和生成按钮：以当前底图批注及手涂蒙版准备双图或原生标注，生成后在原画布切换原图、AI 生成与蒙版替换，人工应用后保存合成版本。参数、单图回退、版本和模型切换规则见 [EDIT 通用图像模型](edit.md#image-2gemini-等通用图像模型)。这条入口与 CHAT 会话独立。

EDIT 使用现行通用模型生成与比较路径；旧独立批注生成、审核转接和批注转 NAI 蒙版／聚焦服务已移除。CHAT 的批注审核继续保留，NAI 使用原有手绘蒙版与聚焦工具。

## 双图与原生标注

默认沿用「双图」：干净原图与带编号的指示图一起发送。GPT Image 2.5／2.6 参考在 EDIT 参数和 CHAT 待发批注卡中可改选「原生」：发送干净原图及独立透明标注层，指示图不占普通参考图名额。两代的 OpenAI Images 参考均默认提供 `markup`；来源是否启用可在「设置 → 模型 → 对应来源参数 → markup」调整，官方和兼容服务遵循同一配置规则。具体约束由[图像协议](../integrations/image-protocols.md#openai-images-26-与原生标注)维护。

两种方式共用点、矩形、椭圆、多边形及编号说明。EDIT 的手绘范围也可画入透明层；原图与标注层一起归一化和缩放，原分辨率底图与回贴蒙版仍留在本地。**选区继续支持**，但原生标注本身不构成强制局部编辑边界；范围外保持由人工审核后的本地回贴实现。点只定位、不凭空生成面积，现有混合点／区域的回贴限制不变。

无批注和手绘范围时 EDIT 只发送普通原图。用户可随时在未提交状态切回双图；不支持的型号或来源不会静默丢弃标注，也不会在上游失败后自动换方式重试。ASK 继续使用自己的原图／指示图视觉输入。

## CHAT：批注仅用于当轮

CHAT 改图交接只准备输入，不发送。送往来源会话时从来源轮次继续分支，并保留用户已有文字；点新建加号／「新对话」或来源为 IMAGE／上传时新建或复用空白会话。

输入区以同一批注卡片展示数量、可编辑评论及双图／原生标注／仅文字切换（原生标注仅对适用参考开放），不在输入框堆放机器说明。发送时与通用 EDIT 共用 `annotationPrompt` 模板，统一逐区域说明、用户补充及一次构图约束；只有额外手绘蒙版才追加范围描述。编号图使用紫色／白色／暗色衬线和错位编号，点的靶环与编号之间保留引线。

双图模式下，图 1 固定为干净原图的可发送副本，图 2 固定为编号指示图，批注关联的参考图按保存顺序在后，再加入普通会话参考；完整原图另存于既有资产池用于本地回贴。参考 ID 与会话资产映射随待发状态和轮次保存，刷新／备份恢复仍可解析；超出模型容量时阻止发送，不能丢弃后仍引用它。编号图占用实际输入名额，不能加入长期 `keepIds` 或成为底图。仅支持单图时阻止静默丢弃编号图；用户可明确选择「仅方位文字」。

原生模式额外保存同步归一化后的原图和透明标注层，首张输入改为该原图，透明层独立上传；提示词明确引用标注层，不再称其为「图 2」。编号指示图仍供卡片预览及切回双图使用，不进入原生请求。

每轮冻结标注方式、批注、边缘参数、原图和图序。提交消费准备状态，后续普通轮次不自动携带旧编号图或坐标协议；该轮重试仍用冻结输入。更换底图、删除配对图片或取消批注同步清理准备状态。模型直出不会自动取代本轮底图。

点批注同样支持双图交接、坐标说明和持久恢复，说明中明确点只定位、不限定修改范围。含点批注的轮次保留模型直出，不显示蒙版回贴操作；只有全部批注均有明确区域时才开放回贴，避免凭空给点补面积或静默遗漏点对应的修改。

已应用结果默认展示回贴图，可「查看模型直出」；切换查看不改变后续底图。正式应用后，仅在用户未改变选择且开启「跟随最新」时更新底图。原图、编号图、原生输入／透明层、直出、回贴和必要元数据沿用会话资产事务保存，刷新、分支及普通备份保留引用；重试复用冻结资产，不重新绘制。后续普通轮次不携带透明层。没有独立 API Mask 文件。

## 人工审核与合成边界

GPT／Gemini 直出先完整保存，审核默认显示直出；原图、直出、回贴预览可切换。点击「应用蒙版」或在 Photopea「应用并返回」才保存正式合成，预览和关闭窗口不写入结果，也不请求上游。官方 NAI 重绘继续生成后本地回贴，同时分别保留直出与合成版本，见 [EDIT](edit.md#nai-与专用工具)。

方向一致、宽高比相对误差 `abs((直出宽/直出高)/(原图宽/原图高)-1) ≤ 1.5%` 时允许预览和应用；接近正方形的像素取整差按同方向处理。无需相同像素尺寸，例如 2048×2048 底图可接收 1024×1024 直出。明显改变画幅时禁用应用。

合成画布始终为冻结底图原始宽高。直出按统一比例居中采样，只吸收容差内的取整边缘，不非等比拉伸。尺寸通过不能证明图内结构对齐；用户仍须检查主体位置、比例、构图和分格。

默认外扩为原图短边的 0.6%、羽化为 0.3%。EDIT 通用模型的「蒙版边缘」可调整为 0～2.5%，随生成冻结；批注交接到 CHAT 当前沿用批注快照的默认值，尚未提供独立的边缘参数控件。实际形状取并集后外扩，再作有限范围高斯羽化；非零羽化至少 1px，影响尾部限制到 3σ。**最终外扩／羽化影响范围外**的解码像素直接保留，输出 PNG；不是保证外扩带不变，也不承诺文件字节或元数据相同。羽化不能修复模型的全身位移或结构变化，用户可保留直出并不应用。

### 边界色彩对齐

「色彩对齐」默认开启，EDIT 对比区与 CHAT 审核区均可关闭。开关只影响本地准备的 AI 图层和合成预览，不修改直出、不请求上游；正式应用记录开关与算法版本，预览及已有合成按配置隔离。切换查看不同历史合成时恢复该版本设置。

程序在原图坐标识别连通选区，以各区边界内外环带的有效像素统计线性 RGB 均值与标准差，限制增益与偏移，并向内部逐渐减弱补偿。相邻环带只归属一个区域。透明、纯黑白、样本不足或整图无背景边界时保守跳过，低方差只做受限均值补偿；高度碎片化的蒙版也可跳过。最终 Alpha 为零处保留冻结原图，透明 AI 像素按图层叠加规则与原图合成。

### Photopea 融合精修

有冻结范围且画幅兼容时，EDIT 工具栏与 CHAT 审核区提供「融合精修」。EDIT 的比较与融合控制独立放在原工具上排，复用原胶囊和图标按钮；窄屏将比较模式、色彩对齐与融合精修收进同一个类型菜单，未保存预览的应用按钮外露。CHAT 沿用对话框分段、共享开关和动作按钮，比较名称与 EDIT 同为「原图／AI 生成／蒙版替换」，Photopea 图标与 EDIT 顶栏共用。

进入后底层为冻结原图，上层为对齐到原图尺寸的 AI 生成图，绑定外扩／羽化后的真实软灰度图层蒙版；采用进入时的色彩对齐设置，默认选中蒙版通道，可用黑白柔边画笔修边，也可选 AI 图层调色。

点击「应用并返回」后，EDIT 创建手动精修版本并关联原直出；CHAT 写回原轮次的正式合成，保留直出，不作为参考附件返回。CHAT 用户改变选择后仍可保存原轮次合成，但不自动跟随为底图；切会话、删除来源或已有合成被替换时拒绝旧回传。暂不应用保留本页分层现场，同结果同配置重开继续编辑。分层结构、通信保护和生命周期由 [Photopea 专题](../integrations/photopea.md#23-结果融合精修)维护。
