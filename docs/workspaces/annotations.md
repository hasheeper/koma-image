# 图片区域批注与局部回贴

更新：2026-11-06。共享批注、ASK、EDIT 转换与 CHAT 双图交接已随 [v0.5.0](../archive/releases/2026-11-06-v0.5.0-release.md) 推送并发布 Pages；真实供应商的多区域理解、位置保持和接缝质量仍待核验。原始调研及范围决策见[规划归档](../archive/workspaces/2026-11-04-region-annotations-research-plan.md)。

## 入口与选区

IMAGE 结果栏原「放大」位置改为单个「批注」入口，与 CHAT 大图检视、EDIT 批注工具共用评论气泡加笔的 SVG 图标。IMAGE／CHAT 点击后关闭大图检视，进入对应 EDIT 画板并自动启用点击批注；已有画板复用并定位到本次选择的图片，不另开批注窗口。几何与评论直接叠加在 EDIT 原画布，原图保持干净。批注模式用一条紧凑胶囊替换普通画布工具，提供选择、点、矩形、椭圆、多边形及撤销／重做／清空；右上角沿用 ASK／CHAT 交接。控件复用全局主题，图像覆盖层使用稳定的紫色描边与深浅衬线。

- 点批注在准确落点显示靶环，以短引线连接错开的编号，不遮住目标，也不生成范围；可拖动、不提供缩放手柄。矩形／椭圆需要拖拽绘制，原地单击不创建选区。多边形逐点绘制，有实时虚线与起点吸附；点击起点、双击、Enter 或「闭合」完成，绘制中可撤销末顶点或取消。
- 新建后在编号旁打开紧凑评论框，按内容增高；Enter 确认、Shift+Enter 换行。未选中的批注悬停显示摘要；点击选择后只显示编号、编辑与删除，双击或 Enter 再编辑。矩形／椭圆可拖动与四角调整；多边形可移动顶点、点击边中点插入、删除选中顶点，至少保留三点。删除整条后序号连续重排。
- 本次工具会话的绘制、几何调整、评论和清空可撤销／重做，最多保留 100 步；退出工具仍保留几何，重开不恢复操作栈。Ctrl／Cmd+滚轮缩放，H、空格拖动或中键平移，触屏双指缩放会取消未完成绘制。V／C／R／E／P／H 切换选择／点／矩形／椭圆／多边形／平移，输入文字时不触发。Esc 依次收起评论、取消绘制或选择、退出工具。
- 几何保存为相对原图的 0～1 坐标；稳定 key 与显示序号分开。点批注保存为独立的 `shape: point`，共用坐标记录中的宽高固定为 0，仅表示落点；不隐藏默认圆形范围。多边形按真实顶点处理，不以外接矩形代替蒙版。
- 每图最多 32 处、每多边形最多 128 个顶点、每处评论最多 2000 字，原图最多 3200 万像素；出站仍受各工作区的文字和图片大小限制。

批注绑定图片实体、记录和作用域；新版本不会仅因尺寸相同而继承旧选区。未交接草稿仅保存在本页内存，最多保留 64 张图片的几何，不长期保存原图副本。

## ASK：原图、指示图与坐标

「问 ASK」原子准备干净原图和编号指示图，托盘合并显示为一张批注卡片；展开可修改评论或回到 EDIT，移除时同时释放两张待发附件。输入框只保留用户文字，发送时才追加 `<image_annotations>`；无文字时使用「请按这些批注逐条处理。」。历史显示卡片而不显示 XML，调试仍保留实际请求。图片权限、附件容量、收藏与手动失败重试沿用 ASK。

XML v2 的 `image`／`guide` 使用实际分配的 `#aN`，标明 `units="0-1"`。区域为 `n/shape/x/y/w/h`，点为 `n/x/y`，均保留三位小数并转义评论；模型状态采用同一投影，不发送多边形顶点。完整精度与真实几何保留本地。

`view_image({id,spec:"crop",annotation:编号})` 与 `region` 二选一，程序按冻结几何解析区域外接框；点取以短边 20% 为边长的检视窗口，再沿用既有 25% 外扩。编号不豁免「先看同一原图全图」：实际附图发送的原图已有资格；未附图的 EDIT 底图须先 `look/glance`，仅看过编号图、拼图或坐标不算。底图 ID 使用 `image_edit.annotations.image`，不能替换成可能不同的查看版本。聚焦草稿仍使用 0～1 坐标，经确认写入；ASK 不直接写蒙版或生成。

附件与输入随已收藏 ASK 会话保存，普通未收藏 ASK 仍仅保留本页，不进入普通 Koma ZIP。

## EDIT：选区与交接

EDIT 普通画布工具栏的「批注」沿用分体入口，开启后切换为单条批注工具栏，不再叠加第二排控制。批注直接覆盖当前图片，沿用 EDIT 的缩放、平移与视口；退出保留页内批注，换版本或离开 EDIT 停止当前交互，不改变底图、重绘模式或蒙版。NAI 聚焦框另用白色框线与八个手柄，和紫色批注明确区分。

画布右上角只放一枚「发送」胶囊，与 ASK 悬浮小球同高、同中线、相隔 8px；批注数仅显示在这枚胶囊。展开采用横向操作带：有 CHAT 来源且原会话仍在时，显示「ASK」「续改」和新建加号，下方会话名保持单行省略，悬停与无障碍名称提供全文；无原会话时只显示「ASK」「新对话」，宽度随内容收紧为胶囊。没有分组标题、来源标签或空白第二行。

操作带与「发送」共用玻璃底色、边缘和轻量开合／按压动效；亮色悬停为白色表面与轻投影，减少动态时停用动效。鼠标打开不预选操作，键盘打开聚焦第一项，支持左右／上下方向键、Home／End 与 Esc。ASK 小球继续负责打开助手。窄屏有去背景分段时，题注只留图片编号。有活动选区时携带原图、编号图与说明；没有活动选区时准备当前干净图片，送往来源会话即加为该会话参考图（原工具栏「添加为参考图」已并入此项）。两种路径都由用户在目的工作区确认发送。

CHAT 来源由画板记住，而不是由批注入口传递：从 CHAT 大图「批注」、结果工具（如放大）进入 EDIT，或在 EDIT 中退出后重新批注，都会带上原会话及能识别的轮次／图片；「续改」按会话 id 切回原会话，即便 CHAT 已切到其他会话，其他会话的草稿不受影响。原会话已删除时，CHAT 目的地只剩「新对话」。批注界面不提供加入／替换蒙版、聚焦转换、选模参数或直接生成操作；NAI 重绘继续留在 EDIT 的现有工具中。

Image 2／Gemini 等通用模型已接入 EDIT 主模型菜单和生成按钮：以当前底图批注及手涂蒙版准备双图，生成后在原画布切换原图、AI 生成与蒙版替换，人工应用后保存合成版本。参数、单图回退、版本和模型切换规则见 [EDIT 通用图像模型](edit.md#image-2gemini-等通用图像模型)。这条入口与 CHAT 会话独立。

`editor.applyAnnotations` 蒙版并集／替换、撤销与 NAI 聚焦转换，以及先前的 `editor.runAnnotations` 仍保留为服务层能力，批注工具本身不增加这些按钮。NAI 不套用通用模型的三图流程。

## CHAT：双图仅用于当轮

CHAT 改图交接只准备输入，不发送。送往来源会话时从来源轮次继续分支，并保留用户已有文字；点新建加号／「新对话」或来源为 IMAGE／上传时新建或复用空白会话。

输入区以同一批注卡片展示数量、可编辑评论及双图／仅文字切换，不在输入框堆放机器说明。发送时与通用 EDIT 共用 `annotationPrompt` 模板，统一逐区域说明、用户补充及一次构图约束；只有额外手绘蒙版才追加范围描述。编号图使用紫色／白色／暗色衬线和错位编号，点的靶环与编号之间保留引线。

图 1 固定为干净原图的可发送副本，图 2 固定为编号指示图，其他参考图在后；完整原图另存于既有资产池用于本地回贴。编号图占用实际输入名额，不能加入长期 `keepIds` 或成为底图。仅支持单图时阻止静默丢弃编号图；用户可明确选择「仅方位文字」。

每轮冻结批注、边缘参数、原图和图序。提交消费准备状态，后续普通轮次不自动携带旧编号图或坐标协议；该轮重试仍用冻结输入。更换底图、删除配对图片或取消批注同步清理准备状态。模型直出不会自动取代本轮底图。

点批注同样支持双图交接、坐标说明和持久恢复，说明中明确点只定位、不限定修改范围。含点批注的轮次保留模型直出，不显示蒙版回贴操作；只有全部批注均有明确区域时才开放回贴，避免凭空给点补面积或静默遗漏点对应的修改。

已应用结果默认展示回贴图，可「查看模型直出」；切换查看不改变后续底图。正式应用后，仅在用户未改变选择且开启「跟随最新」时更新底图。原图、编号图、直出、回贴和必要元数据沿用会话资产事务保存，刷新、分支及普通备份保留引用；没有独立 Mask 文件或新上游协议。

## 人工审核与合成边界

直出先完整保存，审核默认显示直出；原图、直出、回贴预览可切换。**只有点击「应用蒙版」才保存正式合成**，预览和关闭窗口不写入结果，也不请求上游。

方向一致、宽高比相对误差 `abs((直出宽/直出高)/(原图宽/原图高)-1) ≤ 1.5%` 时允许预览和应用；接近正方形的像素取整差按同方向处理。无需相同像素尺寸，例如 2048×2048 底图可接收 1024×1024 直出。明显改变画幅时禁用应用。

合成画布始终为冻结底图原始宽高。直出按统一比例居中采样，只吸收容差内的取整边缘，不非等比拉伸。尺寸通过不能证明图内结构对齐；用户仍须检查主体位置、比例、构图和分格。

默认外扩为原图短边的 0.6%、羽化为 0.3%。EDIT 通用模型的「蒙版边缘」可调整为 0～2.5%，随生成冻结；批注交接到 CHAT 当前沿用批注快照的默认值，尚未提供独立的边缘参数控件。实际形状取并集后外扩，再作有限范围高斯羽化；非零羽化至少 1px，影响尾部限制到 3σ。**最终外扩／羽化影响范围外**的解码像素直接保留，输出 PNG；不是保证外扩带不变，也不承诺文件字节或元数据相同。羽化不能修复模型的全身位移或结构变化，用户可保留直出并不应用。

实际 Safari、移动真机、供应商生成效果和接缝仍待独立核验。未增加依赖，未新增 OpenAI Mask 上传或 `ModelLink` Mask 能力。
