# 设置、备份与词典

更新：2026-11-06。本文维护当前外观、连接、凭据、备份与 Tag 规则；阶段过程见[归档](../archive/2026-10-25/README.md)。

## 设置分组

设置首次打开时按需加载，成功后保留同一窗口。资源加载失败会提示先保存当前工作再刷新，并撤回未打开的设置路由；用户已切到其他工作区时不跳回、不弹过期提示。不会自动刷新，以保留本页 EDIT 与未收藏 ASK 现场。

「通用」底部的「关于」显示 Koma Image 版本号、更新日志和源码仓库。日志作为通用设置的子页在同一个窗口显示，顶部返回或 Esc 回到通用；最新的当前版本默认展开，其他版本按需展开。「未发布」内容独立标明，不作为已上线变化。内容随构建从根目录 `CHANGELOG.md` 读取，版本号来自 `package.json`，无需请求外部更新服务。打开当前版本后清除入口的小圆点，阅读状态以 `koma.release.seen.v1` 保存在本机并跨页同步，不进入普通备份。

连接、模型、通用、安全与备份、ASK 分组独立。外观、Tag 自动补全、绘图历史和编辑版本数量放在通用。IMAGE 历史与 EDIT 每画板的物理图片上限分开设置，默认均为 35 张，0 表示不限制；绘图历史设为 1 时只留最新一张，数量直接生效，不另设保留开关。数量失焦或按 Enter 后保存，不按输入中间值淘汰；只接受非负安全整数，空值或非法输入恢复原值。现有自定义值保留，缺失／无效配置使用默认值。数量随通用偏好持久化、跨标签同步并进入普通备份，图片本身仍按原生命周期保存；减小 EDIT 上限时保留原图、底图、查看组和最新结果，受保护图片可暂时超限。通用末尾单独一组「关于」，以 GitHub 标志链接在新标签页打开源码仓库 `hasheeper/koma-image`。设置即时保存、跨工作区可用，并同步其他标签页。

安全、备份、配置导入导出集中同页分组列表；`settings/backup` 为兼容入口。不重复大标题和说明，只保留基本信息与反馈。安全与备份无 Key 也可进入；Key 统一在供应商配置中管理。

## 外观

设置页顶栏右侧复用工作区的外观切换按钮，替换常驻的保存同步提示，与通用设置共用同一主题偏好。

设置内的供应商、模型目录、模型条目、来源参数及排序弹窗共用同一表面：暗色沿用工作区面板底色，输入只低一级，聚焦不额外压暗；亮色沿用白色浮起表面。背景与分隔沿用全局主题变量，不另造配色。

HOME／IMAGE／CHAT／EDIT／TAGS 均提供直接可见的外观按钮，手机端也不必展开工具菜单。月亮表示当前暗色，太阳表示当前亮色；单击直接切换另一档，不弹菜单。IMAGE／CHAT／EDIT 位于顶栏右侧，TAGS 位于右上角 ASK 启动图标左侧独立浮起，与左侧完整 Logo 分开；HOME 沿用自己的布局，入口位于设置旁。Key 仍由设置内的供应商配置管理。通用设置仅保留「暗色／亮色」两段选项，共用同一偏好服务。未设置或无效配置默认暗色，已保存的暗／亮选择保留，不跟随系统颜色变化。点击即时生效并保存到 `koma.theme.v1`。刷新先恢复主题再绘制界面，跨标签同步沿用应用偏好路径。此项为浏览器外观偏好，不进入普通备份或连接配置。

桌面为左侧「外观」、右侧三等分控件；容器宽度不足时标签上移，控件铺满下一行。采用浅灰底座与白色浮片，深色对应亮一级浮片，保留灰度悬停和原生 radio 键盘操作；键盘焦点用紫色环，不增加缩略预览、说明段或保存按钮。共享配色和 Canvas 展示重绘见[主题与材质变量](../engineering/ui-maintenance.md#主题与材质变量)。Photopea 新实例按当前外观使用 White（浅色）或 Dark Blue（深色）；保活实例沿用其内部主题，切换 Koma 外观不重建分层文档。

## 连接、目录与反馈

初始连接为空，填写连接名、URL 与 Key 后才访问上游。显式选择实际支持的 Profile，不按域名或名称推断。目录、额度和诊断使用只读请求，不提交生成。

连接采用已批准的摘要卡：头部显示名称、协议、地址、状态和测试；有账户额度时显示余额与额度池；模型数量打开模型列表。窄屏状态移到地址下方，测试只保留图标。完整地址和完整可用诊断通过提示查看，错误展示原因。

连接页按原添加顺序显示单列摘要卡，每个连接 ID 只显示一张卡；同名或同地址的独立连接也不自动合并。卡内先列「图像模型」、再列「文字模型」，只显示已开启的用途；整行可点击，手机仍上下排列。模型用途和品牌标识复用本地图标库，同一多模态 ID 可用于两类入口，不按名称限制。接口下拉分别提供「OpenAI 兼容」和「Gemini 原生」入口，不单列文字／图像协议变体。选中后均可独立开启文字（ASK）与图像（生图与参考图编辑），至少开启一项；编辑时恢复原开关，不自动增加能力，共用一份地址和 Key。用途开关留在供应商配置中；NAI 仅有图像入口，Anthropic 仅有文字入口。

连接图标统一用于连接卡片和供应商模型列表标题：NovelAI 官方 Profile 使用已有品牌 Logo；Google AI Studio／GCP Vertex AI、OpenAI 官方／Azure OpenAI 按明确的官方地址使用对应 Google/Gemini 或 OpenAI Logo。其余连接按 Profile 能力分为文本对话图标与生图图片图标，空列表使用中性连接图标。图标复用本地 SVG，不请求远程头像。

官方图标地址在 `domain/connection-icon.ts` 维护：Google AI Studio 为 `generativelanguage.googleapis.com`；Vertex 为 `aiplatform.googleapis.com`、区域 `*-aiplatform.googleapis.com` 与 `*.prediction.vertexai.goog`；OpenAI 为 `api.openai.com`；Azure OpenAI 为 `*.openai.azure.com`，以及 `*.services.ai.azure.com` 的 `/openai` 路径。只接受 HTTPS 官方主机边界，连接名、兼容协议名和转发路径不用于冒认品牌。此匹配仅选择图标，不改变协议、请求地址、鉴权、模型能力或默认连接。

NovelAI 官方的账户与图片请求统一发送到 `image.novelai.net`。有效账户响应即显示「Key 有效」，完整状态另行标明订阅是否激活；未订阅或零余额不会被当作 Key 无效。启动和模型来源目录读取失败保留对应来源的原因与重试入口。HTTP 401 显示「鉴权失败（401），请检查 API Key」，不回显可能包含密钥的响应正文；403、Cloudflare 拦截和网络错误分别反馈，一个来源失败不覆盖其他来源。真实生成权限及扣费由官方决定，不用账户识别结果承诺免费或可生成。

官方 NAI 连接卡将 Anlas 与 V5 额度分开：保留接口百分比与进度条，正值加购百分比单列；已激活 Opus 且用量可用时，百分比右侧同一行显示「约 X 张」，不增加卡片高度，提示注明官方 23 步、约 1MP 的换算基准。额度暂不可用和缺失数据分别展示，不显示恢复时间注释。未订阅或非 Opus 账号返回用量不等于拥有对应权益，也不展示可用张数。打开设置与测试成功后刷新，详见[官方额度规则](../integrations/novelai.md)。

「⋯」菜单只保留「配置供应商」和删除；新增入口也统一称为「配置供应商」。名称、接口协议、地址与 API Key 在同一个弹窗中一次保存，不再打开第二个 Key 弹窗。保留原 Koma Logo＋品牌名布局，弹窗内不再重复「配置供应商」标题；分组间距紧凑，不展示地址解释等长注释。API Key 默认隐藏，可用小眼睛切换显隐；编辑时按需查看已保存 Key，支持原生选中、复制、粘贴与修改，留空保留原值；修改地址或切换到其他协议须重新填写对应 Key，切换协议清空该供应商模型来源；在同一 OpenAI 或 Gemini 原生连接内切换文字／图像开关时保留 Key 和模型来源。不得把其他主机已保存的 Key 自动发送给 NovelAI 官方，需单独配置。删除前确认，再一并移除供应商、模型来源和无人引用的 Key。

新 Key 先使用独立凭据引用暂存，配置验证及保存成功后才启用；失败补偿暂存引用，避免新 Key 与旧地址短暂配对。单纯改名继续复用目录，不重新请求。取消或关闭弹窗清空 Key 输入，保存期间阻止重复提交与关闭。

OpenAI／Gemini 的「开启接口」复用公共复选框，只显示「文字」「图像」，从左紧凑成组排列；手机同样保持一行并增大点击热区，不重复添加用途图标、说明或选项外框。保存 Key 同样复用公共复选框。两种用途仍可同时开启，至少开启一项，随表单保存生效。

GPT 初始 6 个、Gemini 初始 7 个仅为参考预设：分组可新增，条目可编辑名称、参数参考与各来源 ID，参数能力和默认值按来源独立配置，也可删除；无连接时照常管理，未绑定显示待配置。NAI 五型号及专用适配固定，官方 NAI 连接只出现在 NAI 来源中。

模型设置采用 GPT／Gemini／NovelAI 单列分组：组头只放品牌 Logo、名称、数量及适用的新增按钮，不再显示「固定型号」。排版沿用设置页字号阶梯：组头 Logo 为 16px，组名为 13px 半粗，模型名称为 13px 常规，来源标签与 ID 为 12px，计数为 11px 等宽；组名与计数共用基线，Logo 和操作按钮垂直居中。模型行只保留名称、来源摘要和展开箭头；摘要显示首个启用来源及 `+N`，悬停查看完整名单，无可用来源时区分未配置、已停用和暂不可用。标题旁铅笔在展开、悬停或聚焦时显示，打开名称、参数参考和删除操作；新增表单同样只维护模型名称与参考。来源统一在模型展开列表中添加和编辑，弹窗不重复列出供应商或上游 ID。删除仍需确认。

模型列表与连接卡共用卡片底色、边线与文字色，展开区在同一配色上稍微压暗，标题保持原卡片底色，来源按已有生图顺序排列，以细分隔线区分供应商；展开区仅列出已有 ID 的来源，不为未配置供应商保留「填写 ID」空行。展开后隐藏重复的来源摘要，「＋」沿用原摘要位置，用于选择供应商并输入 ID；收起恢复摘要，不额外插入列或挤动标题、箭头。窄屏为「＋」保留同一操作槽，展开时去掉摘要所在的第二行。仅点击「＋」时显示紧凑输入行，保存后加入原有排序，取消或收起均不留下空行。每行显示供应商、完整上游 ID、参数入口和启停开关，NAI 不提供通用参数入口，当前工作区实际来源用小圆点及提示标记。不展示参考 ID、参考能力、顺位文案或重复编辑图标。GPT／Gemini 的上游 ID 点击后原位编辑，回车或失焦保存、Esc 取消，空值不覆盖原值；编辑时提供恢复自动匹配入口。模型条目弹窗不重复列出或覆盖已有来源 ID。供应商列加宽且名称保持单行，超长名称省略并可悬停查看，长 ID 完整换行；窄屏将 ID 放到供应商下方独立一行，开关仍靠右。目录错误在模型页按连接显示一次，并保留重试入口；目录失败不阻止手动 ID 编辑。NAI 条目继续固定，沿用已有目录映射与来源开关。

供应商模型目录恢复原有紧凑排版：桌面端每行依次显示小 Logo、模型名与同行淡色 ID、右侧能力图标和状态圆点；窄屏才将 ID 放到名称下方。能力以原有生图／改图／重绘／放大图标表示，悬停查看含义，不再将能力文案放入 ID 行。能力仍取目录声明，不表示真实供应商验证。长名称和 ID 省略时可悬停查看完整内容；模型关联与手动 ID 的数据路径保持。

目录中的未关联 ID 通过「关联模型」菜单选择，菜单展示完整模型名与参数参考 ID；名称与 ID 相同时不重复展示。选择仍沿用原映射保存路径，Esc 只关闭菜单并返回入口，滚动外部列表或关闭模型弹窗时收起菜单。

模型内部 ID 与上游 ID 分离，渠道别名不受官方命名或目录成员限制。每个来源均可直接输入完整 ID，目录只提供建议；手动 ID 缺项仍直接显示完整 ID，也纳入供应商模型列表。目录失败时仍能编辑；Images／Gemini 原生可按手动映射执行，标准网关仍需有效的报价保护目录，但允许手动补充目录未列出的 ID。同一供应商的同一个 ID 在图像用途内只关联一个模型条目，可同时选作 ASK 文字模型。

参数以「模型 × 来源」为单位管理，入口位于展开后的来源行。优先读取目录已有的 `image_capabilities.fields`；OpenAI／Gemini 标准模型列表通常没有完整参数声明，此时沿用用户选择的参数参考，并明确标注「参考预设」，附接口未声明参数的说明。不猜测额外能力地址，也不提交生图来探测能力。已声明的选项不会被参考型号的同名限制覆盖。来源参数使用平铺列表，默认值直接编辑，行尾开关控制启用；点击参数名按需展开一项字段定义，字段名在原行编辑，类型使用分段选择，可选值以标签增删，复用统一控件，不再嵌套参数卡片。可添加、编辑和关闭文本／数字／开关字段，设置可选值、数字范围、常用默认值；文本可允许其他值，手动字段可移除。空默认值和工作区的「跟随接口」均表示省略请求字段，不代填参考值。

手动补充与关闭项保存在该来源的 `Routing.links[connection][model].parameters`，与目录声明分开；刷新只替换接口声明，保留已保存和表单内尚未保存的手动修改。恢复接口／参考会清除该来源的手动覆盖。既有条目默认值继续兼容读取，来源覆盖优先；NAI 五型号沿用固定专用参数。选择另一模型时采用对应来源默认值，同一模型当前会话已保存的选项继续保留。

参数贯通工作区控件、保存与实际请求：Images 扩展字段写入请求体（改图使用 multipart），Gemini 扩展字段相对 `generationConfig`，支持 `imageConfig.imageSize` 等点分字段；既有 `aspect_ratio`／`image_size` 继续映射为原生图像参数。仅支持文本、有限数字和布尔值，不开放任意对象、数组或应用管理的模型、提示词、图片、数量等字段。标准网关仍发送 `image_options`，Gemini 标准改图仅在选定来源后将 `image_size` 转为 `output_size`。多来源筛选要求来源声明或手动配置支持所选字段和值，不能因未声明而放行后丢参。

增删改即时持久化并跨标签同步，删除的预设不自动补回，已有图片和历史保留；当前选中条目被删除时保留待重新选模状态。条目、来源参数、来源与接口开关随配置导入导出和普通备份保存，Key 继续隔离。

模型支持自动匹配、手动完整 ID、来源开关和恢复自动。图像／文字入口在名称旁用纯数字胶囊分别表示已启用／已选模型数，仅统计该连接的实际配置，不混入目录总数、不相加成模型总量；数量为零时入口仍可打开。图像行右侧用纯数字胶囊只读显示生图顺位，数量和顺位的完整含义保留在悬停提示与读屏名称中，行内不重复「已启用」「已选」「生图第 N 位」文案；当前工作区来源与 ASK 当前模型分别保留在对应入口的提示中。非本地模式且开启图像的连接多于一条时，页面顶部提供「生图顺序」，弹层仅列这些连接，用上下箭头调整；手机沿用底部弹层。排序即时保存，只改变生图顺位，主卡列表顺序和 ASK 手动选择保持；关闭返回入口，离开连接分区同时关闭弹层。模型页按同一顺序列出来源，并标记当前工作区实际来源，模型列表仍可筛选可用、优先来源与未启用。

排序、改名、来源开关和 ID 映射即时更新本地配置，保留目录列表、搜索、展开状态和当前操作节点，不先清空整页数据。原始目录按连接地址、协议与凭据版本复用，规范模型按新配置重新映射；地址、协议、Key 改变只使对应连接的目录和余额失效，清除 Key／删除也清除对应缓存。模型列表的「重新拉取」和连接测试只刷新该连接；设置分区之间切换不重复拉取已加载目录。文本连接的编辑不触发图像工作区目录重载。生成前的报价、额度和上下文有效性检查保持独立，不能使用目录缓存绕过。

顺序保存在非秘密的 `Routing.order`，经数据租约即时保存、跨标签同步并进入配置及普通备份；新连接追加到末尾，删除连接从顺序中移除。本地固定连接不提供排序编辑。绘图／CHAT／编辑按当前模型和操作筛选来源：停用、缺 Key、没有该模型或不支持原参数／工具的连接不参与；其余从上到下检查。标准网关按本次报价与积分余额判断；NAI 仅在明确无订阅且无余额，或 V5 暂不可用、加购为零且 Anlas 为零时判为不足。不将估算张数当报价，不用 V5 用量推导 V4.5 权益；日请求额度用尽的标准网关来源判为不足。余额接口缺失或读取失败视为未知，仍按排序使用；目录、鉴权或报价错误不冒充余额不足。提交后失败、取消及响应处理错误不换源重试。

报价预览与执行均从高优先级重新检查，额度恢复后重新优先使用前面的来源；执行使用新报价和对应 `max_cost`。来源变化使旧报价与额度失效；顶栏按当前模型显示品牌 Logo、实际来源的额度与余额，提示包含来源名称。官方 V5 同行显示百分比、张数估算和独立 Anlas；V4.5 只展示 Anlas，不增加下方注释。NAI 官方不支持的重绘／放大仍可由后面的可用来源执行，保留原参数，不压缩画布或删减附件以迁就来源。

OpenAI／Gemini 每次只读取一次目录，不按品牌前缀或额外能力字段筛掉 ID；未匹配 ID 供用户选择，不自动成为可执行模型。

启动时保留目标工作区；空配置或缺 Key 不自动打开设置或供应商弹窗，不请求缺少凭据的上游。有地址和可用 Key 自动读目录并显示进度及汇总结果，失败可手动测试。供应商配置由用户在设置中打开，显式设置／备份链接仍正常进入。连接／凭据改变重新反馈，迟到响应失效；改名和来源调整静默更新，排序不重新播报连接进度。没有可用模型时的生成提示可打开设置。

本地模式使用固定服务端配置，连接与安全展示只读，不显示连接菜单或添加按钮；GPT／Gemini 条目和模型来源仍可编辑。运行时地址、Key 和令牌不持久化，两种模式分别保存来源。详见[发布说明](../release-guide.md)。

## 凭据与安全

- 不再提供口令加密、解锁、修改口令或锁定功能，原独立 Key 弹窗已移除。
- 「在此浏览器保存 Key」默认开启，按供应商分别选择：开启将 Key 明文存入本站 localStorage 的 `koma.credentials.v1`；关闭仅写 sessionStorage，可刷新恢复。两种方式均不进入连接配置导出或普通备份，默认不向页面 DOM 回填已有值，用户点击小眼睛时才按需显示。
- Key 输入由原生 input 引用持有，不进入 Vue 深层 reactive；编辑留空或仅查看已有 Key 不替换凭据引用；关闭后清空输入并恢复隐藏，变更保存方式不影响其他供应商。
- 跨标签页用凭据专用锁合并保存和删除；同源 storage 事件刷新已保存 Key，Koma 同步频道共享会话 Key，启动最多等待 200ms 汇集其他页面的会话凭据。
- 「清除全部 Key」等待当前图像任务完成，跨页清除；清除世代阻止迟到消息或旧会话快照恢复已清除 Key。连接、模型来源和图片保留。
- 当前 Koma 会话 Key 表可继续读取；凭据服务只管理当前保存及会话记录，不检测、读取、转换或删除停用的口令密文与派生密钥记录。没有可用 Key 时由用户在供应商配置中重新填写。
- 本地代理模式仍为服务端只读凭据，不在网页填写或保存。弹窗沿用原生 dialog 的焦点、Esc 与取消语义。

## 普通备份


只接受 `app=koma-image`、`kind=backup`、`version=2` 的 ZIP。支持收藏原图及缩略图、对话与素材、逻辑偏好和不含 Key 的连接配置；NAI 参考原图与 Vibe 编码缓存一并保存，导入后恢复引用。

- 文件先通过 ZIP 结构、CRC、manifest 必要字段与引用、对话分支和素材 SHA-256 校验，才显示可导入预览；未校验对象不能导入。
- 使用原图字节，不重新编码。保留 ZIP32、条目数、目录、manifest 和单图片大小限制。
- 导入通过应用级独占数据租约，先排空写入并释放本页共享租约；其他标签页或进行中的任务会阻止导入。
- 对话与素材同事务写入；冲突创建副本，重映射轮次、版本和上下文引用。收藏按 ID 与原图哈希去重，冲突保留副本。同一备份重复导入不重复新增。
- 部分失败后恢复租约、刷新缓存；保留已校验文件供重试。偏好覆盖，Key 不覆盖；JSON 配置与 ZIP 中的连接仅在 ID、凭据引用、地址和协议族均与本机一致时沿用原 Key，否则断开关联并要求重新填写。导入／导出过程中禁用页面导航，并拦截浏览器历史切页与离开提醒。
- 不导出 Key、普通历史、EDIT 画板／版本／蒙版与 Photopea 分层、交接票据、HOME 展示副本与偏好、ASK 收藏、Slate 任务／成果及 Bridge 目录状态。没有旧数据检测、迁移、转换或对应 UI。

## 词典与描述控件

- 词典保持中文／英文搜索、默认分类、每页 24 条、分页、组合持久化、0.1–5 权重、复制和明确跳往公共词典的外链。候选数量以在线接口实际返回为准。
- 版式沿用 HOME：起始为居中品牌字、搜索胶囊、类型筛选行与欢迎卡；左上角保留原尺寸的完整「Koma TAGS」工作区标识，作为独立悬浮入口，不再铺满整条顶栏。点击仍可切换工作区或进入设置；窄屏搜索排在悬浮入口下方。搜索后胶囊收为工具栏高度，类型收进胶囊末端的菜单，与绘图 Tag 补全共用同一偏好。未命中与失败复用同一张卡，失败可重试。
- 关键词结果保持自适应列卡片，名称以空格形式显示；点文字区加入／移出组合。所有结果统一使用常显的「更多」按钮，菜单仅保留复制与原站外链，不再预留多个隐藏按钮的位置；菜单不会改变选中状态，Escape 返回入口。
- 组合有内容时右下角出现「组合」胶囊。宽屏打开后占右侧栏位，与展开的 ASK 共用同一栏位，后打开的占用，另一方收回；ASK 在 TAGS 宽屏展开时固定在该栏位，不可拖动或放大。窄屏组合为底部弹层。
- 绘图的基础／角色补全和页内查词面板随 Anime／Furry 模式切换。Furry 使用公开 NAI Furry 英文词库，不携带 Key，不混用动漫分类或回退；缓存按数据集隔离，切换立即取消旧请求并清除候选。完整词典与其他工作区保持原行为，详见[模式规则](../integrations/novelai.md#animefurry-模式)。
- 查询只在用户搜索或启用补全后输入时发送；保留公开 Tag 服务和英文查询的官方回退行为。生成业务不增加重试。
- 应用组合通过显式交接原地切换到绘图，确认后追加；30 分钟过期、只认领一次，保活激活不会重复插入。
- 页内选词面板直接插入／移除 Tag，保留未编辑文字；保留本次插入列表、方向键、IME、焦点返回和移动端布局。
- 高亮 `.hl-wrap`、镜像和 textarea 全部由 Vue 模板声明，纯算法生成经过转义的镜像内容；原生测量驱动只操作空测量宿主内部及明确委托的布局样式。
- 自动补全最多 20 条、280ms 防抖，支持 Enter／Tab／方向键；IME 使用实际 textarea 内容计算光标片段，关闭补全卸载监听，隐藏工作区中止查询和尺寸观察。
- 提示消息复用原图标、停留时间、重复合并和悬停暂停，通过 Teleport 进入当前弹窗，避免多个宿主重复计时。提示悬在顶栏下方 12px 的右上角，不遮挡顶栏控件；每条都有关闭按钮，点击提示任意处也会关闭，拖选文字时保留，操作按钮先执行自身动作。移动端侧栏仍使用已有 Teleport 宿主。

Tag 查询使用公开 `/api/tags/suggest`，只发送 `q`；每个来源上限 8 秒，候选缓存共享，词典按实际结果每页 24 条切分，不伪造分页。英文保留官方备用源，中文不回退到仅英文接口。错误区分未命中、网络／超时／取消、JSON 格式与备用源失败原因；不把响应体读取失败误报成格式错误，不改变既有回退顺序或增加生成重试。

搜索结果页的搜索区保持水平居中，顶部留白随屏幕高度适度变化，为完整悬浮 Logo 留出空间；初始欢迎页沿用原有居中布局。

## ASK 设置与隔离

ASK 独立管理推理模型、命名模型、图片开关、个人偏好、自由创作、压缩阈值及附件上限，见[ASK 现行契约](../ask/README.md)。配置可进入普通备份，独立自由创作开关不进入。

ASK 收藏会话、附件、记忆与归档保存在本机 `koma-ask`，刷新可续聊，不属于普通 ZIP；撤销执行栈和调用调试只留本页。普通绘图历史和 EDIT 编辑现场仅留本页，交接票据为有过期时间的一次性数据；Slate 的任务与成果独立持久保存。

普通 Koma v2 备份可带 `imageIdentity.version=1`：原图实体、收藏固定号、库身份与最小登记。导入验证字节；新空库可继承原库号码，异库仍合并并分配本地新号，不覆盖本机已有映射。用过再删空的库不视为新库。ASK、EDIT 现场及 Slate 继续不进入普通备份。细节见[图片身份](../engineering/image-identity.md#收藏与备份)。
