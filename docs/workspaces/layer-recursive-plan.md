# Koma Layer · 两级递归拆层与 ASK 协同

EDIT → Koma Layer。2026-11-22 本地实施与验收。

## 1. 全身初拆与单件递归

在「全身总拆」输入拆层说明，或点击「使用编号拆层模板」，设置层数上限后发起拆层。整图通常先拆 8～10 个可动大件。「候选图层」最上行显示在画布最前方。上下拖动候选行，或点行尾的上下箭头，可预览并调整遮挡顺序。眼睛控制预览，方框控制收纳。「全选」包含残余底图，无五官脸底可随眼部一起收纳。每批次单独保存层序与勾选，刷新或切换批次后可继续。层序可撤销、重做。

选中正式层，点击 **「↳ 继续细拆此件」**。此时可修改该部位的词与上限，点击「开始细拆」才发起请求。回图后可在画布切换候选预览与原栈。收纳时，选中子件按当前候选层序进入与原件同名的组。同批子件可分次收纳。父件留在组内隐藏归档。例如「躯干、头部、手套」从后到前排列，细拆后眼部仍在躯干前、手套后。只想提取一个高光时，可取消归档，采用「仅添加」。

一次撤销可还原来源层和本批待筛候选，再做会重新成组。检查点保存已收纳层、归档状态、待筛批次和勾选；30 步手工撤销记录限当前页面。刷新后可用归档行的恢复操作找回来源层。相邻同名组按独立 ID 区分。整组显隐保留每个子件原有的显隐。来源像素或选中层间次序发生变化时，收纳会提示重新细拆并保留候选。[递归与收纳](../../src/layer/recursive.ts) · [项目与检查点](../../src/layer/storage.ts)

### 微件如何归位

本地使用左闭右开的整数矩形。Seedream 原生回包有完整底图时，优先按 absolute 的左右、上下端点差定位。官方 normalized 坐标以 1000 为分母。兼容裁片回包时，逐轴比较 PNG 的原生宽高与端点差。例如左边界 12、末端 42、裁片宽 31，则右边界是 43；左边界 65、末端 124、裁片宽 59，则右边界就是 124。先映射左右／上下两端，再加来源原点并取端点之差。一比一归位时直接沿用原始 RGBA。

完整基底提供返回坐标系；仅含裁片时以实际发送的画幅为基准。能由绝对框无重叠铺满并验证宽高比的缩放回包可还原其画幅，明确的归一化框可定位其他缩放结果。尺寸与位置证据不足的小件进入「待定位」，保留原尺寸，确认原画布 X/Y 后才能收纳。[坐标约定与回归](../../tests/layer-placement.test.mjs) · [落盘像素与坐标](../../tests/layer-recursive.test.mjs)

候选行显示组件在原画布上的尺寸。展开「校准」可调整 X、Y、宽、高，再用「对照原图」检查。新版回包同时保留接口原始边界供核查。原生 PNG 的 1024×1024 可以对应画布上几十像素的眼部组件。[Seedream 拆层坐标定义](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)

完整虹膜和眼白直接叠加时，虹膜可能伸出眼口。在虹膜行打开「校准」，选择同侧眼白作为「裁片轮廓」，点「另存可见裁片」。裁片按两层的原画布坐标与连续 Alpha 计算，自动勾选；完整虹膜留在候选池，可用于后续可动绑定。该操作生成静态裁片，移动眼球时的动态遮罩需在绑定端设置。被口罩遮挡的嘴形由模型推测，校准前可先隐藏口罩、手套检查下颌位置。

## 2. 母版框选、多选与精修

| 入口 | 送给 Seedream 的实际像素 | 收纳位置 |
| --- | --- | --- |
| 继续细拆此件 | 单个正式层当前的裁片 | 原层位置，默认隐藏归档父件 |
| 框选母版细拆 | 直接从只读母版按原画布整数坐标截取的矩形。空栈也可使用 | 默认栈顶，结果组名和插入位置可在候选区调整 |
| 多选 → 细拆所选层 | 只把所选层按当前遮挡顺序合成，裁至其联合包围盒 | 以所选最顶层为锚点。未选层继续保留原顺序 |

正式层列表顶部为前景。行尾可对当行执行复制、向下合并、删除等操作。跨组拖放将移动的叶层纳入目标组；拖动时可看画布遮挡，放下提交。双马尾已经在一张层上时，也可用原有的「框选／套索 → 拆分为新图层」直接切开。跨袖子的单件仍可切到「局部补画」，用蓝区标出真实可见发束、橙区标出需要延展的遮挡段。软橡皮、刷回母版、对色和拖开回弹沿用分件画布。[画布与精修](layer.md)

## 3. ASK 的三处词栏与两级备忘

ASK 每轮可读取项目、母版尺寸、焦点层或框、阶段、词栏、正式栈名称与组路径、最近返回的候选摘要。按需通过 `view_image` 看 `#layer`。全部图像生成仍由画师在分件表单点击触发。

**查看淘汰图。** 候选行的垃圾桶淘汰单张，「清空」淘汰当前批次的剩余候选。「局部补画」里可点「淘汰当前候选」。取消勾选、隐藏、切换候选和暂未收纳都保留待筛状态。主动删除已收纳的生成层会单列为「收纳后删除」，前提是该候选的最后一份已移除。撤销候选池淘汰或正式层删除会同步撤回记录。

有记录时，点击「让 ASK 查看淘汰图」，或直接询问某轮、某个部件。每个项目只保留最近三次成功生成的记录。每批全身拆层、递归或框选细拆各算一轮，每次局部补画也算一轮。第四轮完成时移出最早一轮的记录和预览，即使新一轮尚无淘汰图。所有待筛批次与已收纳图层按原流程保留。ASK 先读取轮号、来源、模型与人工移除的部件名称，按需用 `view_image` 或 `view_sheet` 查看最长边 512 px 的实际图像预览。记录随分件项目在本机保存，从启用功能后的生成开始计数。

**层数规划。** ASK 按本轮预计独立输出的部件计数，左右分件分别计数。默认多留 3 层给残余底图、配饰或需要单列的碎件，最多 99 层。例如预计 9 件，可在草稿中建议上限 12；用户明确指定最多 9 层时就设为 9。确认草稿后，画师点击生成，Seedream 才会收到 `layer_decomposition_options.max_images`。实际返回层数按画面需要。

**提示词示稿**须按照画面实际遮挡顺序，由前向后编号，点名左右、配饰、具体遮挡和需要补全的形状；同时必须显式包含**防齐根截断的关节出血位（Bleed Area）铁律**——严禁贴着遮挡分界线齐边截断，所有插入前方图层底下的连接端都须向遮挡物后方额外延伸绘出一截饱满的重叠出血区。下列顺序可由画师修改。

| 目标栏 | 可交给拆层模型的正文 |
| --- | --- |
| 全身总拆 · 预计 9 件，上限 12 | 按画面由前向后编号拆出 1. 手持配饰，2. 前置右手与手指，3. 右袖和外套，4. 前侧马尾，5. 头部总成，6. 躯干内搭，7. 百褶裙，8. 后侧马尾，9. 腿与鞋。按实际角色调整左右、数量与层序。逐件自动脑补前方遮挡的横穿缺失结构，接通袖后的发束、手腕和裙褶，不得留镂空断口，不得漏手部或配饰。严禁贴着遮挡分界线齐边截断：所有插入前方图层底下的连接端（如下巴后的颈部上端、躯干或袖口后的手臂根部、裙摆底下的大腿上端、刘海后的额头与发根），必须向遮挡物后方额外延伸绘出一截饱满的重叠出血区（Bleed Area），确保关节旋转时不露断口边角，保持原位、线色与比例。 |
| 头部细拆 | 由前向后编号输出 1. 蝴蝶结头饰，2. 前发刘海，3. 左右侧发，4. 左右上眼睑睫毛，5. 瞳孔高光，6. 虹膜与瞳孔，7. 眼白，8. 无五官光洁脸壳，9. 后发。按实际层序调整，自动补圆眼睑遮住的瞳孔边缘、补齐眼白，把脸壳保留为完整基底。严禁贴着遮挡分界线齐边截断：藏在刘海后的额头与发根、插在下巴后的颈部上端、被前发或头饰压住的后发与耳根连接端，必须向遮挡物后方额外延伸绘出一截饱满的重叠出血区（Bleed Area），确保转动时不露断口边角。左右微件各自独立归位，保住睫毛尖和高光大小，不留镂空断口，不漏头饰。 |
| 单件补画 · 右马尾 | 画完整右马尾。由前向后处理 1. 蓝区可见的蝴蝶结与外侧发丝，2. 蓝区上下两段主发束，3. 橙区原被宽袖遮住的中段。依两端发丝方向自动补全并连接中段，保留蝴蝶结、原线色与比例，单独输出连贯部件。 |

三类输出统一进入标准 Diff 卡。画师可检查修改前后、取消不需要的行、应用与撤销。跨项目、原词已变、目标已删除或已锁定的改名会触发相应冲突检查。[草稿实现](../../src/ask/draft/layer.ts) · [系统引导](../../src/ask/prompts/workspaces.ts)

- **填词卡**可以分别投递全身、一个确定来源的细拆词、单件补画词。全身与细拆可连词投递上限，也可只调最多层数。应用数值会切换到限层模式，撤销可恢复原来的数值和“不限制”状态。
- **两级拆件待办**随分件项目保存。在 ASK 输入框上方展开「拆件待办」，或从分件表单的「在 ASK 查看拆件待办」进入。点圆圈记录进度，点一级标题填总拆词，点行尾数字展开微件。在大件的「⋯」绑定正式图层后，点子项即可回到对应层的细拆表单，带入预设词和最多层数。尚无绑定时会打开母版框选。覆盖手改词之前会显示原词和新词，生成由画师另行点击。
- **改名卡**须由用户提出。每行按图层 ID 和组路径展示旧名与新名，应用只更新勾选行的名称。

## 4. 分阶段验收记录

| 阶段 | 本地验证 |
| --- | --- |
| 1 · 单层递归 | 两种回包分别验证闭区间与半开区间。受控高光、睫毛在导出 PNG 中仍为 31 × 34 与 59 × 64，RGBA 逐字节一致。右半袖回归从错误的 `[84,24,32,24]` 校正为 `[68,24,16,24]`。验证原位归档、撤销／重做和刷新后继续筛选。 |
| 2 · 局部框与多选 | 浏览器从 96 × 96 母版实框截取 48 × 48，核对出站 PNG 的左上像素。再选不相邻两层，送出的 16 × 16 合成图在未选中间件的位置保持透明，结果组落在最高选中层处。[浏览器回归](../../tests/layer-provider.browser.mjs) |
| 3 · ASK 协同 | 本地模拟推理协议走标准草稿预览、确认与回退；检验三处词栏隔离、人工进度保留、改名逐行取消和字段／项目冲突。另测按需看图，首个请求只带元数据，显式调用后才发送母版图像。相关操作的图像生成请求数为 0。[ASK 浏览器回归](../../tests/layer.browser.mjs) |
| 4 · Rig／PSD | DKH 1600 × 1600 母版与真实眼白、虹膜、下眼睑、睫毛、眉毛做本地回放。用五件替换眼部父件，所得 48 个可见叶层由 Rig Studio 打开。`rig verify-slices` 容差 1，超差像素 0，最大通道差 1。独立 PSD 读取确认同名眼部组、隐藏父件、母版、五个眼部层的整数坐标与 RGBA。两套已知像素的微件夹具另行导出，容差 1，超差 0，最大差均为 0。 |

Rig 包保留母版 `reference.png`、底到顶的可见叶层、绝对矩形与分组 ID。归档原件及临时独显、拖开位移只影响其相应预览。PSD 保留完整层栈和隐藏原件。[Rig 包](../../src/layer/export.ts) · [PSD](../../src/layer/psd.ts)

上述验证覆盖本地像素、界面与协议。31 × 34 与 59 × 64 是依用户实测尺寸构造的回归样本。真实 DKH 眼部素材来自现有切片。供应商现场重抽的画质、完整脸壳和耗时仍需用实际回图验收。
