# 绘图工作区

更新：2026-11-16。统一维护 IMAGE 绘图、独立画板与多角色。图像协议的实际能力以[协议说明](../integrations/image-protocols.md)为准。

图片检视入口已接入[区域批注](annotations.md)，共享选区、ASK／CHAT 交接和人工回贴的规则由该专题维护。

历史更多菜单的「请 ASK 发起演进」只预填提问；已有进行中演进时，画板名称旁显示带亮色圆点的「演进」胶囊。结束后移入任务总览历史，关闭面板不改变进行状态。手动改词、改参数与续抽默认归当前阶段；「立为阶段」只提拔选中单图并推进游标，原阶段至少保留一张。ASK 有效修改确认后才准备下一张落点。完整入口、原始配方对比、批注与恢复边界由[单图演进](recipe-retrospect.md)维护。

## 当前行为

- 使用原画幅、方向、比例、参数抽屉和本地设置结构。小／中／大幅保留独立预设；自定义尺寸匹配、方形方向记忆、宽高互换、64px 提交对齐及模型面积限制保持原规则。
- Prompt／Negative 接入持久化草稿、模板高亮、词典和显式格式清洗。提交时保留原来的首尾 trim；空白使用固定提示词，透明底开关只在支持的模型上显示，切到不支持的模型时保留偏好但不附加 Tag；原描述单独保存，导入参数和 ASK 读取的都是原描述。
- 左栏依次为画板、模型、提示词、角色、画幅。模型框显示 NAI 官方全称，下方为 Anime｜Furry 与 High｜Medium 分段；V4.5／V5 Full 和 Curated 均可切换模式，仅 V5 Full 提供 High／Medium；提示词框内底栏提供 Complexity、质量和透明底，负向页提供对应 UC 预设。按型号显隐，Medium 固定步数／采样器且负向只读；High 设置保留。参数抽屉以 Guidance 和 0–1 Rescale 替代混淆的 Scale／CFG 展示，详见 [NAI 参数规则](../integrations/novelai.md#界面与参数边界)。
- V4.5 的 Prompt 底栏目前仅有质量入口（关闭／Standard），迁入参数抽屉尚未实施。底栏背景覆盖到右边缘，保留原生拖动高度手柄，滚动文字不从边缘透出。
- 报价 650ms 防抖；加载时旧价淡显、失败时清空。生成过程中不运行输入预报价。执行仍由 Gateway Profile 重报、携带当次 max_cost、原生免费／Studio 分流，无新增付费确认、无自动重试，整批涨价最多通知一次。
- 绘图和编辑生成按钮只在有有效费用信息时显示标签，未知费用暂时隐藏；内部仍保留未知状态，不记为零费用，不影响标准网关已有报价与护栏。NAI 仅显示正 Anlas 估算，不显示免费或 V5 近似百分比；本地估算独立于账户余额与约张数，Anlas／用量、Opus 资格和未知边界见[NAI 专题](../integrations/novelai.md#费用与额度的实现状态)。
- 预检完成后捕获提交参数。一个串行批次占用一个应用级任务槽，直到各张解码、缩略图、展示和本地对比图完成。参数仍可编辑；在途尺寸不跟随表单。批量张数不受日额度限制，失败或取消时停止剩余队列。
- 普通历史为本页内存数据，索引与原图容量分开。设置「通用 → 最近原图」默认 35 张，沿用已有自定义数量；0 原图不限，1 仅默认保留最新原图，较早记录不会被裁掉。完整规则见下方「历史分层」。收藏独立保存原图、缩略图、参数、费用和时间，提交成功后才更新星标；取消收藏提供 8 秒撤销。收藏不受历史限额和刷新影响，其他标签页通过中性频道刷新缓存。
- 图片栏提供历史／收藏切换、收藏角标、清空确认、折叠预览、键盘导航及参数拖入。空白页居中显示品牌和一行快捷键提示（手机不显示提示），下方最多两行收藏：保持原比例、统一高度（大规格为桌面最高 240px，矮窗口按两行放得下缩小；手机约每行三张竖图），每行居中、不拉伸；放不下时显示「全部 N 张」，没有收藏时不画占位。空白页的收藏预览直接使用收藏原图，已有小缩略图不会影响清晰度；新生成的缩略图最长边为 768px、WebP 质量 0.9，保留透明通道且不放大小图。非 JPEG 原图遇到已有 JPEG 缩略图时，展示回退读取原图，不重写存储。透明区域铺低对比灰色棋盘，缩略图的图片范围与留边分开，留边仍使用原有模糊衬底；原图字节保持不变。选中的旧图不会被逐张到达的结果抢走；点击在途缩略图或按 Esc 返回任务。生成衔接保持连续：图片一到达，新缩略图即接替图片栏顶部的在途占位格并成为当前项；批量的下一张及合成对比图时才重新显示占位格。
- 结果支持 Seed 复制、原字节下载与放大查看；复用参数和复制 Tag 已从结果栏移除。原生图片包验证 ZIP 目录、CRC 和解压上限；普通图片及嵌入 JSON 图片均解码校验，拒绝失败占位图及仅含远程链接的返回。
- PNG／JPEG 参数读取复用审查后的纯解析模块，支持 NAI／WebUI、压缩文本、NAI Alpha 隐藏元数据及采样器映射；外部 PNG 的 Vibe 编码可勾选导入，点击后才落库，只有编码时锁定提取量。导入页对照勾选，仅覆盖选中的字段；无法映射的模型／采样器禁用，Guidance Rescale 与已支持的噪声调度独立导入，不映射为旧中转 cfg；外部有效词文导入时关闭对应自动预设并重置自动模式，手写 dataset 前缀仍有效，避免重复标签；本机历史恢复原文与模式。
- 收起图片栏时，横线长度由像素面积、宽高比、基于图片 ID 的固定 ±10% 波动及距当前选图的层数共同计算；距离越远相对越短、越淡，切页与重绘不会重新抽取随机值。横线整体向可用宽度加长，减弱距离对长度的衰减；空刻度按同一算法的 80% 显示并淡出，近远只保留轻微长度层次。纵向间距与粗细保持原样；空刻度不参与点击或键盘导航，真实图片仍保留完整点击区域。

NAI 的 Prompt／Negative 小计显示型号 token 预算，含启用角色与有效预设；超长提示与 `Text:` 检查见[输入预算](../integrations/novelai.md#输入预算与图片参数导入)。

传统模式保留桌面表单、图片舞台和历史栏，不再提供手机单栏、菜单内历史和固定生成底栏。窗口小于 1080px 时提示切换下述画布协创 BETA；切换复用当前画板、图片与 ASK，原地保留创作现场。

## 画布协创（BETA）

模式入口、断点、栏宽记忆和共用面板交互见[ASK UI](../ask/ui.md#12-画布协创beta)。IMAGE 只切换现有画板、演进、表单与历史的宿主，业务状态和生成目标保持同一份。

- 画布铺满左侧。工作区、画板选择、视图切换、型号／尺寸／Token 摘要及侧栏切换均以悬浮控件呈现，不叠加应用顶栏。视图入口为带分支图标的「演进」与画框图标的「画板」；节点检视时同一外壳显示「返回演进」和带图片图标的只读「检视」状态，不误标为当前画板。型号摘要仅在当前画板视图显示，演进及节点检视时隐藏；摘要始终来自活动生成画板，以型号主信息、尺寸和 Token 弱摘要分段呈现，型号前的动漫／兽人图标沿用当前画板的有效 NAI 模式；空间紧时先隐藏 Token，优先保留短型号与尺寸。点击可用原型号与画幅控件快速调整，账户、外观与任务入口也在此处。
- 顶部带图标的侧栏切换在当前画板显示「表单 / ASK」，演进及节点检视显示「配方 / ASK」。同一 IMAGE 表单与 RecipeInspector 经 Teleport 放入右侧共用侧栏，替换 ASK 的可见内容，不再单独浮在画布上。基础词、负面词、多角色、参考和参数继续经原写入路径同步；显式引用、ASK 入口或 ⌘J／Ctrl+J 会切回 ASK。
- 活动画板存在进行中演进时，首次进入显示嵌入画布。双击节点原地检视大图，返回保留镜头、节点选择与配方对照状态。后续分支到达或生成落图不抢走当前检视视图；选择预设会打开右侧配方，正文内部滚动；关闭配方收起侧栏。侧栏选择为配方／表单时，切换演进与当前画板会跟随切换上下文内容。载入反馈位于顶部控件下方。
- 底部操作统一为一排悬浮组件，不设独立底板或分隔边框。换行只按画布实际可用宽度判断：画板不超过 600px、演进图不超过 520px 时工具另占上排，不跟随侧栏的 1080px 断点提前换行。演进图铺满左侧直到下边缘，隐藏历史／收藏入口，左侧为平移、选择、批注和缩放胶囊，右侧为生成；配方只保留顶部切换入口，底部不重复展示；组件之间的空白仍可操作画布。切回大图或节点检视后恢复左侧历史入口、中间图片操作。历史入口、图片操作与生成同为 44px 全圆角；历史入口与生成区等宽分配两端，使图片操作对准画布中心。主生成按钮按内容保持适中宽度，运行时停止按钮另外占位，不从主按钮中挤出空间。图片操作合为一枚玻璃胶囊，以细线分为 Ask 与参数、编辑类、收藏与下载三组；Ask 带文字与浅紫底排在最前，按钮 36px 正方形，容器不超过 400px 时才收起 Ask 文字。主图、演进检视的图片操作与演进工具通过 Teleport 复用同一操作宿主。尺寸摘要可打开完整参数并复制；紧凑宽度只显示信息图标，图片编号不在历史／收藏标签旁常驻。
- 历史区复用同一份历史／收藏列表；底部入口沿用 EDIT 玻璃工具胶囊，桌面宽画布直接切换「历史／收藏」，桌面窄画布显示当前分类与数量的下拉入口，历史为空或切到收藏也保留该入口；更多菜单提供展开／收起与已有历史操作。桌面展开后缩略图以等宽、按原图比例自然高度的单列瀑布流排列；细凹槽紧贴实际图片左边缘，高度占满画布可用空间，不随横图缩短；缩略图较少时整组垂直居中，随数量增加向上下展开，超出可用高度后仅在历史列表内滚动；外层预览网格始终受可用画布高度约束，历史数量不撑高舞台。主图与生成占位保持按比例垂直居中，凹槽与图片作为一组水平居中。主图和演进大图均预留槽宽，不覆盖图片；收起时释放侧栏宽度，底部操作行保持原位。支持上下键导航与悬停预览，保持完整图像并使用内描边，不叠加按钮。选图后通过图片操作中的 Ask 引用，只改变查看对象，不改活动画板表单或生成目标。传统与协创历史栏均不再提供选择两图／Ask Diff 控件；ASK 仍能按明确提问比较图片，演进 A/B 检视保留。
- 手机历史入口直接打开瀑布流浏览层，不预留桌面窄槽。当前大图原位放大、虚化并偏向右侧作为背景，同一历史／收藏列表通过 Teleport 展示为保留原图比例的瀑布流，列数按实际可用宽度自动计算，缩略图等宽分配浏览区域，不额外保留单侧空白；手机按至少两列的缩略图大小展示，单张也不放大铺满；顶部分类、更多和关闭控件等高对齐。空列表仍可切换分类，空状态按整层居中。点图后自动收起并回到清晰大图，只改变查看对象；可用关闭、空白边缘或 Esc 退出，触屏不弹悬停预览。浏览层开合仅保留本页，不覆盖桌面历史展开偏好；打开创作面板、切演进图、画板、工作区或恢复桌面时收起。
- 生成占位和动画按本次任务画幅同步适应，浏览旧图再回到生成中也使用当前任务尺寸。生成、报价、忙碌状态与停止复用原控件及 `drawing.run()`，不提供额外 1×／4× 快捷项。原批量参数仍在表单中。ASK 草稿「写入」或演进「载入画板」之后，用户仍须手动点击生成，不新增自动生成或任务队列。

组件、Teleport 与驱动的维护入口见[协创布局归属](../engineering/ui-maintenance.md#imageeditchat-协创布局)。

手机顶区的画板标题按内容收宽，与右侧型号摘要同行；长名称省略，演进视图切换按需放在下方。底部抽屉入口与历史、生成保持同一排，默认仅显示把手，底边贴齐；鼠标悬停或键盘聚焦时入口向上展开，显示表单／配方与 ASK 快捷图标，移开后收回，不推动相邻按钮和图片。触屏仍可点击或上拉把手展开，再在抽屉内切换内容。

## 所有权与生命周期

`services/drawing.ts` 在 App 中创建一次，在 KeepAlive 之外持有任务、普通历史、收藏缓存、Blob 和 Object URL。组件通过浅快照订阅；大对象不进入深层响应式。数据库写入经过 `data.write`，新版备份恢复后重新读取收藏和参数，重新建立目录／报价上下文。未接入任何旧库检测或迁移逻辑。

`domain/drawing.ts` 管理预设、参数、Seed、请求字段白名单和命名。`native/` 中的解析、转换、对比合成及方块波浪为已审查复用算法；这些实现使用 TS，函数体与调用方接受同一套严格类型检查，不保留手写配对声明。没有载入旧应用的 DOM 操作脚本。

Vue 创建全部控件和 `.hl-wrap` 宿主，移动端图片栏继续使用 Teleport。波浪只在独立空宿主创建自己的 Canvas；分栏指针只修改委托的尺寸／拖动样式，在结束时保存偏好。计时更新不进入 Vue。激活时安装视口、拖动、导入和键盘监听，停用时移除监听、Observer、计时与 Canvas；任务和仍被历史／收藏／当前图引用的资源继续保留。

## 历史分层

- **最近历史**：最近 X 张默认保留原图。**更早历史**：默认折叠，展开后分批显示；其中演进实际节点或收藏引用的图片保留原图，其他只留缩略图与完整原始配方，并标明状态。
- 缩略图复用长边最多 768px 的 WebP；生成失败时保留唯一原图，不创建空预览。记录 ID、`#hN`、原始尺寸、基础／角色词文、参数和时间不变；只调整原图容量，不影响 EDIT 的独立版本上限。
- 仅剩缩略图的历史仍可供 ASK 检索、概览、归组、相邻 Diff、恢复 IMAGE 配方和回退分叉。编辑、批注、CHAT／EDIT 原图交接、原图下载、收藏、演进定稿与 Slate 成果绑定不可用，不把缩略图伪装为原件。
- 当前显示的原图、在途 ASK 工具读取、待确认及可撤销图片交接临时保留原件；离开或释放最后一项保护后重新计算容量。普通 ASK 正文提及不会永久保留原图。结束演进跟踪或删除其来源回复不删除树内引用。
- 调低上限立即释放未受保护的原图；调高或改为 0 不会复原已释放原件。收藏撤销可从真实收藏原件恢复。缩略预览 URL 与原图 URL 独立回收，正在查看的图不会突然破图。
- 主动删除／清空仍移除完整历史记录；已收藏图片独立保留。所有未收藏历史及演进现场仍限本页，刷新清空，不新增持久库或普通备份内容。

## 画板与多角色

### 画板所有权

- 每个画板持有独立的完整生成表单，包括基础 Prompt／Negative、模型、画幅、参数和角色；历史图片仍共用。通用偏好和布局全应用共享。
- 顶部胶囊切换画板，加号新建空白。菜单底部并列「新建空白」「复制当前」，各行「⋯」改名或删除该画板。复制保留完整表单；画板使用稳定 ID，改名不改变身份。
- 画板管理保存沿用偏好与数据租约；普通 Koma 备份包含画板。旧 Koma 偏好缺少角色时按零角色读取，不扫描或迁移旧应用数据。
- 生成提交冻结来源画板和完整参数；在途报价、执行、结果元数据使用同一快照。切换画板或编辑另一表单不改变已提交内容。
- 保存失败不能留下半套新板或覆盖来源板；回退新板应用时按草稿检查点恢复对应结构。

### 角色结构与位置

角色使用稳定 `cN` ID，不按数组下标定位草稿。每角色包含启停、Prompt、Negative、位置和中心列表；排序不改变身份。

| 模式 | 已接入行为 |
| --- | --- |
| 自动定位 | 不使用手动中心，不把所有角色伪装为中心点 |
| V4.5 手动定位 | A1–E5 网格，发送时投影到格中心；最多 6 个角色 |
| V5 手动定位 | 0–1 自由坐标；最多 22 个角色 |

切换模型不静默删除超额角色，也不覆盖 V5 原坐标。支持范围、启用角色数量和发送参数由领域校验决定；不支持角色的模型保留本地内容但不发送角色字段。界面重新选点与 `set_position` 均替换为单中心；仅指定坐标不自动开启手动定位，需显式 `set_placement=manual`。

基础描述、角色 Prompt 和角色 Negative 保持分工：单幅基础词文承载画风、总人数、镜头、场景、动作与表情；角色描述以 girl/boy/other 等对象开头，承载外貌、服饰与可选施受前缀。整页漫画的特殊写法由模型专项手册说明，前端不做词义分类。

### 协议映射与元数据

| 路线 | 请求字段 |
| --- | --- |
| 标准网关报价／Studio／工具 | `characters: [{ prompt, uc, center }]` 与顶层 `use_coords` |
| 标准免费原生／NovelAI 官方 | 同一角色快照生成 `v4_prompt`／`v4_negative_prompt`，正负数组同序对应 |

V4.5 只投影发送坐标，V5 保留自由坐标；自动定位关闭 `use_coords`。原生字段与标准转换相互独立，不因另一条路线的转换修改原文。生成元数据、PNG 参数读写和参数恢复保留角色及定位结构；缺失字段不能从当前表单补造历史事实。

角色结构不决定操作能力。NAI 官方 Img2Img／普通 Inpaint／4× Upscale 和 V4.5／V5 参考已另行接入，适用型号与限制见[NAI 专题](../integrations/novelai.md)；CHAT 不使用这套角色生成协议。

### ASK 读取与草稿

活动画板的基础 Prompt／Negative、全部角色原文与状态始终完整随初始 `<workspace_state>` 发送。其他画板只给目录，`get_state({ board_id })` 读取本轮冻结原文；无锚点历史图片仍按需读取。

草稿锁定本轮来源板，以 `image.char.c2.prompt`／`image.char.c2.negative` 等稳定靶点修改角色；`character_edit` 支持新增、删除、排序、启停和定位，`restore_partial` 可恢复整组。目标被删除或外部修改时重新校验，不写到同位置的另一对象。

- 普通草稿默认写来源板，分体菜单可选新板；模型给出 `new_board_name` 时只提供「新建并应用」。
- 提议时不创建画板。确认后才沿原写入路径创建／应用；新板名由主 ASK 提议，不另触发命名调用。
- 角色修改按对象分组审阅，差异、实际勾选写入和回退覆盖完整结构。仅应用草稿不生图、不报价或发送 CHAT。
- 账本记录稳定来源／目标板 ID。改名只改变本地显示，不暗改已冻结的发送记忆。

### 界面与维护

`BoardSwitcher.vue` 接绘图画板服务，`shared/boards/BoardMenu.vue` 管共用胶囊和管理菜单，`shared/nai/CharactersEditor.vue` 管角色列表与词文，`shared/nai/CharacterPosition.vue` 管定位，`ImageLibrary.vue` 管归属标记，`DraftCard.vue` 管草稿分组与新板应用。

桌面列表行 36px、底部按钮 32px，窄屏／触屏保留 44px；长列表独立滚动、底部入口可达。嵌套菜单按视口翻转，Esc 先关闭子菜单并返回焦点。提示词高度恢复覆盖组件挂载、工作区激活和画板切换，重新建 Observer 前清理旧监听。命名、字体、样式与动效沿用共享入口。

验证使用合成数据与模拟上游，覆盖保存失败回滚、画板与备份往返、角色参数、草稿和四视口。真实角色生成与供应商质量仍见[待办](../status.md#仍待真实验证)。

Ask／Ask Why 入口只打开或预填 ASK，不自动发送；修改先审阅草稿，确认后走原写入路径。编辑结果留在 EDIT，通过原收藏路径持久保存，不自动进入 IMAGE 历史；编辑画板与蒙版规则见[EDIT](edit.md)。
## 底部参数与参考抽屉

`shared/nai/DrawingBottomPanel.vue` 在 `composer-foot` 内管理同一个抽屉；导航位于内容上方，生成始终在最下方。深色凹槽、上圆角及面板表面沿用已确认原型，内容与主按钮之间有固定 12px 间距。`DrawingParameters.vue` 承载原有参数控件，`NaiReferenceEditor.vue` 管上传、缩略图、逐图参与、类型／强度和导入导出。展开 260ms、收起 210ms，打断从当前高度续接；收起立即 inert，减少动态直接落位。KeepAlive 暂停 Observer／窗口监听／动画，Esc 返回对应入口焦点。移动端只给折叠底栏预留页面空间，展开高度不推长正文。

无适用参考来源的型号保留 36px 单行深色参数凹槽：左侧图标与「参数」，右侧显示当前采样器、步数和展开箭头；摘要随表单同步，Medium 使用实际生效的 Euler A／14 步，切回 High 恢复其保存值。长采样器名称省略，完整名称可悬停查看；不追加说明行，展开后沿用原参数控件。

V4.5 官方来源开放 Vibe／Precise，两组互斥并分别保存。V5 官方来源复用同一抽屉，提供参数／Precise 两项。上传后由用户启用参考组。配置随画板保存并进入结果快照，二进制留在应用级 `services/nai-references.ts` 与 IDB，不进入 Vue 深层状态或 localStorage。生成冻结来源板和参考计划，收费编码与解码／结果处理共用任务锁。收费、缓存、来源与备份契约见[NAI 参考](../integrations/novelai.md#vibe-与精确参考边界)。不支持已启用参考的型号或来源须先停用，不能静默省略。

传统布局中，绘图顶栏外观切换左侧的任务图标打开默认本地任务板；画布协创中入口收入摘要菜单。可管理 Todo、配方与持久成果，无需目录或 ASK 配置。任务板不是新的工作区／常驻侧栏，生成操作仍在原绘图面板。详见[任务板与外部协同](../integrations/bridge.md)。

图片编号使用应用页内递增 `#h` 和持久固定 `#f`；取消收藏不重排，EDIT 衍生结果不再自动写入本页历史。历史与收藏共享原记录时增加别名，实体共享不合并不同参数记录，详见[图片身份与引用](../engineering/image-identity.md)。
