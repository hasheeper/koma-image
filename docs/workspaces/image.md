# 绘图工作区

更新：2026-10-30。统一维护 IMAGE 绘图、独立画板与多角色；阶段过程与验收见[归档](../archive/2026-10-25/README.md)。图像协议的实际能力以[协议说明](../integrations/image-protocols.md)为准。

## 当前行为

- 使用原画幅、方向、比例、参数抽屉和本地设置结构。小／中／大幅保留独立预设；自定义尺寸匹配、方形方向记忆、宽高互换、64px 提交对齐及模型面积限制保持原规则。
- Prompt／Negative 接入持久化草稿、模板高亮、词典和显式格式清洗。提交时保留原来的首尾 trim；空白使用固定提示词，透明底开关只在支持的模型上显示，切到不支持的模型时保留偏好但不附加 Tag；原描述单独保存，导入参数和 ASK 读取的都是原描述。
- 左栏依次为画板、模型、提示词、角色、画幅。模型框显示 NAI 官方全称，下方为 Anime｜Furry 与 High｜Medium 分段；V4.5／V5 Full 和 Curated 均可切换模式，仅 V5 Full 提供 High／Medium；提示词框内底栏提供 Complexity、质量和透明底，负向页提供对应 UC 预设。按型号显隐，Medium 固定步数／采样器且负向只读；High 设置保留。参数抽屉以 Guidance 和 0–1 Rescale 替代混淆的 Scale／CFG 展示，详见 [NAI 参数规则](../integrations/novelai.md#界面与参数边界)。
- V4.5 的 Prompt 底栏目前仅有质量入口（关闭／Standard），迁入参数抽屉尚未实施。底栏背景覆盖到右边缘，保留原生拖动高度手柄，滚动文字不从边缘透出。
- 报价 650ms 防抖；加载时旧价淡显、失败时清空。生成过程中不运行输入预报价。执行仍由 Gateway Profile 重报、携带当次 max_cost、原生免费／Studio 分流，无新增付费确认、无自动重试，整批涨价最多通知一次。
- 绘图和编辑生成按钮只在有有效费用信息时显示标签，未知费用暂时隐藏；内部仍保留未知状态，不记为零费用，不影响标准网关已有报价与护栏。NAI 仅显示正 Anlas 估算，不显示免费或 V5 近似百分比；本地估算独立于账户余额与约张数，Anlas／用量、Opus 资格和未知边界见[NAI 专题](../integrations/novelai.md#费用与额度的实现状态)。
- 预检完成后捕获提交参数。一个串行批次占用一个应用级任务槽，直到各张解码、缩略图、展示和本地对比图完成。参数仍可编辑；在途尺寸不跟随表单。批量张数不受日额度限制，失败或取消时停止剩余队列。
- 普通历史为内存数据：默认 35 张，在「设置 → 通用 → 绘图历史」调整，0 不限、1 只留最新一张。已有自定义数量保留。收藏独立保存原图、缩略图、参数、费用和时间，提交成功后才更新星标；取消收藏提供 8 秒撤销。收藏不受历史限额和刷新影响，其他标签页通过中性频道刷新缓存。
- 图片栏提供历史／收藏切换、收藏角标、清空确认、折叠预览、键盘导航及参数拖入。空白页居中显示品牌和一行快捷键提示（手机不显示提示），下方最多两行收藏：保持原比例、统一高度（大规格为桌面最高 240px，矮窗口按两行放得下缩小；手机约每行三张竖图），每行居中、不拉伸；放不下时显示「全部 N 张」，没有收藏时不画占位。空白页的收藏预览直接使用收藏原图，已有小缩略图不会影响清晰度；新生成的缩略图最长边为 768px、WebP 质量 0.9，保留透明通道且不放大小图。非 JPEG 原图遇到已有 JPEG 缩略图时，展示回退读取原图，不重写存储。透明区域铺低对比灰色棋盘，缩略图的图片范围与留边分开，留边仍使用原有模糊衬底；原图字节保持不变。选中的旧图不会被逐张到达的结果抢走；点击在途缩略图或按 Esc 返回任务。生成衔接保持连续：图片一到达，新缩略图即接替图片栏顶部的在途占位格并成为当前项；批量的下一张及合成对比图时才重新显示占位格。
- 结果支持 Seed 复制、原字节下载与放大查看；复用参数和复制 Tag 已从结果栏移除。原生图片包验证 ZIP 目录、CRC 和解压上限；普通图片及嵌入 JSON 图片均解码校验，拒绝失败占位图及仅含远程链接的返回。
- PNG／JPEG 参数读取复用审查后的纯解析模块，支持 NAI／WebUI、压缩文本、NAI Alpha 隐藏元数据及采样器映射；外部 PNG 的 Vibe 编码可勾选导入，点击后才落库，只有编码时锁定提取量。导入页对照勾选，仅覆盖选中的字段；无法映射的模型／采样器禁用，Guidance Rescale 与已支持的噪声调度独立导入，不映射为旧中转 cfg；外部有效词文导入时关闭对应自动预设并重置自动模式，手写 dataset 前缀仍有效，避免重复标签；本机历史恢复原文与模式。
- 收起图片栏时，横线长度由像素面积、宽高比、基于图片 ID 的固定 ±10% 波动及距当前选图的层数共同计算；距离越远相对越短、越淡，切页与重绘不会重新抽取随机值。横线整体向可用宽度加长，减弱距离对长度的衰减；空刻度按同一算法的 80% 显示并淡出，近远只保留轻微长度层次。纵向间距与粗细保持原样；空刻度不参与点击或键盘导航，真实图片仍保留完整点击区域。

NAI 的 Prompt／Negative 小计显示型号 token 预算，含启用角色与有效预设；超长提示与 `Text:` 检查见[输入预算](../integrations/novelai.md#输入预算与图片参数导入)。

手机图片侧栏的历史／收藏页签显示图标、文字与数量；图片列表独立滚动，任务总览与外观切换归底部独立工具区。空列表使用居中的小图标和两行说明，不铺大块缩略图占位；至少两张图片时显示对比入口，已进入对比时保留退出操作，历史有图时保留清空。打开侧栏时暂时隐藏收起状态的 ASK 浮层，关闭后恢复，不改变对话、草稿或运行任务。

## 所有权与生命周期

`services/drawing.ts` 在 App 中创建一次，在 KeepAlive 之外持有任务、普通历史、收藏缓存、Blob 和 Object URL。组件通过浅快照订阅；大对象不进入深层响应式。数据库写入经过 `data.write`，新版备份恢复后重新读取收藏和参数，重新建立目录／报价上下文。未接入任何旧库检测或迁移逻辑。

`domain/drawing.ts` 管理预设、参数、Seed、请求字段白名单和命名。`native/` 中的解析、转换、对比合成及方块波浪为已审查复用算法；这些实现使用 TS，函数体与调用方接受同一套严格类型检查，不保留手写配对声明。没有载入旧应用的 DOM 操作脚本。

Vue 创建全部控件和 `.hl-wrap` 宿主，移动端图片栏继续使用 Teleport。波浪只在独立空宿主创建自己的 Canvas；分栏指针只修改委托的尺寸／拖动样式，在结束时保存偏好。计时更新不进入 Vue。激活时安装视口、拖动、导入和键盘监听，停用时移除监听、Observer、计时与 Canvas；任务和仍被历史／收藏／当前图引用的资源继续保留。

## 画板与多角色

### 画板所有权

- 每个画板持有独立的完整生成表单，包括基础 Prompt／Negative、模型、画幅、参数和角色；历史图片仍共用。通用偏好和布局全应用共享。
- 顶部胶囊切换画板，加号新建空白。菜单底部并列「新建空白」「复制当前」，各行「⋯」改名或删除该画板。复制保留完整表单；画板使用稳定 ID，改名不改变身份。
- 画板管理保存沿用偏好与数据租约；普通 Koma 备份包含画板。旧 Koma 偏好缺少角色时按零角色读取，不扫描或迁移旧应用数据。
- 生成提交冻结来源画板和完整参数；在途报价、执行、结果元数据使用同一快照。切换画板或编辑另一表单不改变已提交内容。
- 保存失败不能留下半套新板或覆盖来源板；回退新板应用时按草稿检查点恢复对应结构。

### 角色结构与位置

角色使用稳定 `cN` ID，不按数组下标定位草稿。每角色包含启停、Prompt、Negative、位置和中心列表；排序不改变身份。

| 模式 | 已接入行为 |
| --- | --- |
| 自动定位 | 不使用手动中心，不把所有角色伪装为中心点 |
| V4.5 手动定位 | A1–E5 网格，发送时投影到格中心；最多 6 个角色 |
| V5 手动定位 | 0–1 自由坐标；最多 22 个角色 |

切换模型不静默删除超额角色，也不覆盖 V5 原坐标。支持范围、启用角色数量和发送参数由领域校验决定；不支持角色的模型保留本地内容但不发送角色字段。界面重新选点与 `set_position` 均替换为单中心；仅指定坐标不自动开启手动定位，需显式 `set_placement=manual`。

基础描述、角色 Prompt 和角色 Negative 保持分工：单幅基础词文承载画风、总人数、镜头、场景、动作与表情；角色描述以 girl/boy/other 等对象开头，承载外貌、服饰与可选施受前缀。整页漫画的特殊写法由模型专项手册说明，前端不做词义分类。

### 协议映射与元数据

| 路线 | 请求字段 |
| --- | --- |
| 标准网关报价／Studio／工具 | `characters: [{ prompt, uc, center }]` 与顶层 `use_coords` |
| 标准免费原生／NovelAI 官方 | 同一角色快照生成 `v4_prompt`／`v4_negative_prompt`，正负数组同序对应 |

V4.5 只投影发送坐标，V5 保留自由坐标；自动定位关闭 `use_coords`。原生字段与标准转换相互独立，不因另一条路线的转换修改原文。生成元数据、PNG 参数读写和参数恢复保留角色及定位结构；缺失字段不能从当前表单补造历史事实。

角色结构不决定操作能力。NAI 官方 Img2Img／普通 Inpaint／4× Upscale 和 V4.5 参考已另行接入，适用型号与限制见[NAI 专题](../integrations/novelai.md)；CHAT 不使用这套角色生成协议。

### ASK 读取与草稿

活动画板的基础 Prompt／Negative、全部角色原文与状态始终完整随初始 `<workspace_state>` 发送。其他画板只给目录，`get_state({ board_id })` 读取本轮冻结原文；无锚点历史图片仍按需读取。

草稿锁定本轮来源板，以 `image.char.c2.prompt`／`image.char.c2.negative` 等稳定靶点修改角色；`character_edit` 支持新增、删除、排序、启停和定位，`restore_partial` 可恢复整组。目标被删除或外部修改时重新校验，不写到同位置的另一对象。

- 普通草稿默认写来源板，分体菜单可选新板；模型给出 `new_board_name` 时只提供「新建并应用」。
- 提议时不创建画板。确认后才沿原写入路径创建／应用；新板名由主 ASK 提议，不另触发命名调用。
- 角色修改按对象分组审阅，差异、实际勾选写入和回退覆盖完整结构。仅应用草稿不生图、不报价或发送 CHAT。
- 账本记录稳定来源／目标板 ID。改名只改变本地显示，不暗改已冻结的发送记忆。

### 界面与维护

`BoardSwitcher.vue` 管胶囊和管理菜单，`CharactersEditor.vue` 管角色列表与词文，`CharacterPosition.vue` 管定位，`ImageLibrary.vue` 管归属标记，`DraftCard.vue` 管草稿分组与新板应用。

桌面列表行 36px、底部按钮 32px，窄屏／触屏保留 44px；长列表独立滚动、底部入口可达。嵌套菜单按视口翻转，Esc 先关闭子菜单并返回焦点。提示词高度恢复覆盖组件挂载、工作区激活和画板切换，重新建 Observer 前清理旧监听。命名、字体、样式与动效沿用共享入口。

验证使用合成数据与模拟上游，覆盖保存失败回滚、画板与备份往返、角色参数、草稿和四视口。真实角色生成与供应商质量仍见[待办](../status.md#仍待真实验证)。

Ask／Ask Diff／Ask Why 入口只打开或预填 ASK，不自动发送；修改先审阅草稿，确认后走原写入路径。编辑结果留在 EDIT，通过原收藏路径持久保存，不自动进入 IMAGE 历史；编辑画板与蒙版规则见[EDIT](edit.md)。
## 底部参数与参考抽屉

`DrawingBottomPanel.vue` 在 `composer-foot` 内管理同一个抽屉；导航位于内容上方，生成始终在最下方。深色凹槽、上圆角及面板表面沿用已确认原型，内容与主按钮之间有固定 12px 间距。`DrawingParameters.vue` 承载原有参数控件，`NaiReferenceEditor.vue` 管上传、缩略图、逐图参与、类型／强度和导入导出。展开 260ms、收起 210ms，打断从当前高度续接；收起立即 inert，减少动态直接落位。KeepAlive 暂停 Observer／窗口监听／动画，Esc 返回对应入口焦点。移动端只给折叠底栏预留页面空间，展开高度不推长正文。

V5 等无参考入口的型号保留 36px 单行深色参数凹槽：左侧图标与「参数」，右侧显示当前采样器、步数和展开箭头；摘要随表单同步，Medium 使用实际生效的 Euler A／14 步，切回 High 恢复其保存值。长采样器名称省略，完整名称可悬停查看；不追加说明行，展开后沿用原参数控件。

V4.5 官方来源开放 Vibe／Precise，两组互斥但各自保存；查看入口不等于启用。配置随画板保存并进入结果快照，二进制留在应用级 `services/nai-references.ts` 与 IDB，不进入 Vue 深层状态或 localStorage。生成冻结来源板和参考计划，收费编码与解码／结果处理共用任务锁。收费、缓存、来源与备份契约见[NAI 参考](../integrations/novelai.md#vibe-与精确参考边界)。不支持已启用参考的型号或来源须先停用，不能静默省略。

绘图顶栏外观切换左侧的任务图标打开默认本地任务板，窄屏随外观切换收入菜单；可管理 Todo、配方与持久成果，无需目录或 ASK 配置。任务板不是新的工作区／常驻侧栏，生成操作仍在原绘图面板。详见[任务板与外部协同](../integrations/bridge.md)。

图片编号使用应用页内递增 `#h` 和持久固定 `#f`；取消收藏不重排，EDIT 衍生结果不再自动写入本页历史。历史与收藏共享原记录时增加别名，实体共享不合并不同参数记录，详见[图片身份与引用](../engineering/image-identity.md)。
