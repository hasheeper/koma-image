# M4 绘图工作区

状态：2026-10-19。绘图面板与执行、结果、普通历史、收藏和图片参数导入已接入。后续 M5／M6 已接通对话、编辑／放大及图片交接，原位置的结果入口现已启用，见 [对话与编辑实施记录](chat-editor-workspaces.md)。本阶段没有部署或真实收费生成。

## 实现范围

- 使用原画幅、方向、比例、参数抽屉和本地设置结构。小／中／大幅保留独立预设；自定义尺寸匹配、方形方向记忆、宽高互换、64px 提交对齐及模型面积限制保持原规则。
- Prompt／Negative 接入持久化草稿、模板高亮、词典和显式格式清洗。提交时保留原来的首尾 trim；空白使用固定提示词，透明底 Tag 仅在支持的模型上按原规则前置，原描述单独保存供复用与复制。
- 报价 650ms 防抖；加载时旧价淡显、失败时清空。生成过程中不运行输入预报价。执行仍由 Gateway Profile 重报、携带当次 max_cost、原生免费／Studio 分流，无新增付费确认、无自动重试，整批涨价最多通知一次。
- 预检完成后捕获提交参数。一个串行批次占用一个应用级任务槽，直到各张解码、缩略图、展示和本地对比图完成。参数仍可编辑；在途尺寸不跟随表单。额度未知及低于 300 的限制、原生免费例外由共享策略提供；保留用户原请求数量，解除限制后恢复。
- 普通历史为内存数据：默认 25、0 不限、关闭保留时最新一张。收藏独立保存原图、缩略图、参数、费用和时间，提交成功后才更新星标；取消收藏提供 8 秒撤销。收藏不受历史限额和刷新影响，其他标签页通过中性频道刷新缓存。
- 图片栏提供历史／收藏切换、收藏角标、清空确认、折叠预览、键盘导航及参数拖入。空白页居中显示品牌和一行快捷键提示（手机不显示提示），下方最多两行收藏：保持原比例、统一高度（大规格为桌面最高 240px，矮窗口按两行放得下缩小；手机约每行三张竖图），每行居中、不拉伸；放不下时显示「全部 N 张」，没有收藏时不画占位。首页预览直接使用收藏原图，已有小缩略图不会影响清晰度；新生成的缩略图最长边为 768px、JPEG 质量 0.9，不放大小图，原图字节保持不变。选中的旧图不会被逐张到达的结果抢走；点击在途缩略图或按 Esc 返回任务。
- 结果支持 Seed／Tag 复制、参数复用、原字节下载与放大查看。原生图片包验证 ZIP 目录、CRC 和解压上限；普通图片及嵌入 JSON 图片均解码校验，拒绝失败占位图及仅含远程链接的返回。
- PNG／JPEG 参数读取复用审查后的纯解析模块，支持 NAI／WebUI、压缩文本及采样器映射。导入页对照勾选，仅覆盖选中的字段；无法映射的模型／采样器禁用，额外信息仅查看，不把 CFG Rescale 写进 CFG。
- 收起图片栏时，横线长度由像素面积、宽高比、基于图片 ID 的固定 ±10% 波动及距当前选图的层数共同计算；距离越远相对越短、越淡，切页与重绘不会重新抽取随机值。空刻度独立缩短并淡出，不参与点击或键盘导航；真实图片仍保留完整点击区域。

## 所有权与生命周期

`services/drawing.ts` 在 App 中创建一次，在 KeepAlive 之外持有任务、普通历史、收藏缓存、Blob 和 Object URL。组件通过浅快照订阅；大对象不进入深层响应式。数据库写入经过 `data.write`，新版备份恢复后重新读取收藏和参数，重新建立目录／报价上下文。未接入任何旧库检测或迁移逻辑。

`domain/drawing.ts` 管理预设、参数、Seed、请求字段白名单和命名。`native/` 中的解析、转换、对比合成及方块波浪为已审查复用算法；这些实现已在 [T1–T4](typescript-migration-plan.md) 中迁为 TS，配对声明移除，函数体与调用方接受同一套严格类型检查。没有载入旧应用的 DOM 操作脚本。

Vue 创建全部控件和 `.hl-wrap` 宿主，移动端图片栏继续使用 Teleport。波浪只在独立空宿主创建自己的 Canvas；分栏指针只修改委托的尺寸／拖动样式，在结束时保存偏好。计时更新不进入 Vue。激活时安装视口、拖动、导入和键盘监听，停用时移除监听、Observer、计时与 Canvas；任务和仍被历史／收藏／当前图引用的资源继续保留。

## 验证

本机验收通过：32 项单元测试、5 项外壳浏览器测试、6 项服务测试、4 项公共界面测试与 7 项绘图测试，共 54 项；严格类型检查和生产构建通过。全部请求使用模拟网关和本机合成图，没有真实 Key 或收费请求。

- `npm run check`：严格类型、纯业务／网关／锁／备份／参数测试、生产构建。
- `npm run test:shell`、`test:services`、`test:shared`：原有 M1–M3 回归，更新了绘图草稿持久化和新增参数抽屉的预期。
- `npm run test:drawing`：原生 ZIP 与付费路线、Seed 0／回绕、整批锁、价格上涨、失败／取消、跨工作区保活、额度限制与恢复、浏览旧图、收藏提交失败／撤销／跨标签／刷新、备份缓存恢复和下载原字节。
- 仅检查 320／390／768／1440px。合成结果截图位于忽略提交的 `.local/m4/`；结果页、导入页和收藏页的检查不携带真实内容。
- 分栏高频 pointermove 和波浪绘制没有引起 Vue 更新；反复切页的监听集合、Canvas／锁数量及导入临时 URL 数量保持稳定。沿用既有基础验收，不做帧率跑分或多断点像素矩阵。
- 本阶段未改动 7 份正式 CSS；源码／资源／测试／构建产物检查不含私有渠道名称、地址、头像或旧存储前缀。
