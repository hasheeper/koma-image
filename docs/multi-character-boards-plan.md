# 多角色与画板

更新：2026-10-25。角色 A 与画板胶囊 A 的 C1–C5 代码、参数往返和本地模拟验收已完成。本文件保留现行契约；原勘探、UI 决策过程和阶段证据见[归档](archive/2026-10-25/README.md)。标准网关字段有真实只读解析／报价证据，生成采用情况与效果仍待实测。

## 画板所有权

- 每个画板持有独立的完整生成表单，包括基础 Prompt／Negative、模型、画幅、参数和角色；历史图片仍共用。通用偏好和布局全应用共享。
- 顶部胶囊切换画板，加号新建空白。菜单底部并列「新建空白」「复制当前」，各行「⋯」改名或删除该画板。复制保留完整表单；画板使用稳定 ID，改名不改变身份。
- 画板管理保存沿用偏好与数据租约；普通 Koma 备份包含画板。旧 Koma 偏好缺少角色时按零角色读取，不扫描或迁移旧应用数据。
- 生成提交冻结来源画板和完整参数；在途报价、执行、结果元数据使用同一快照。切换画板或编辑另一表单不改变已提交内容。
- 保存失败不能留下半套新板或覆盖来源板；回退新板应用时按草稿检查点恢复对应结构。

## 角色结构与位置

角色使用稳定 `cN` ID，不按数组下标定位草稿。每角色包含启停、Prompt、Negative、位置和中心列表；排序不改变身份。

| 模式 | 已接入行为 |
| --- | --- |
| 自动定位 | 不使用手动中心，不把所有角色伪装为中心点 |
| V4.5 手动定位 | A1–E5 网格，发送时投影到格中心；最多 6 个角色 |
| V5 手动定位 | 0–1 自由坐标；最多 22 个角色 |

切换模型不静默删除超额角色，也不覆盖 V5 原坐标。支持范围、启用角色数量和发送参数由领域校验决定；不支持角色的模型保留本地内容但不发送角色字段。界面重新选点与 `set_position` 均替换为单中心；仅指定坐标不自动开启手动定位，需显式 `set_placement=manual`。

基础描述、角色 Prompt 和角色 Negative 保持分工：单幅基础词文承载画风、总人数、镜头、场景、动作与表情；角色描述以 girl/boy/other 等对象开头，承载外貌、服饰与可选施受前缀。整页漫画的特殊写法由模型专项手册说明，前端不做词义分类。

## 协议映射与元数据

| 路线 | 请求字段 |
| --- | --- |
| 标准网关报价／Studio／工具 | `characters: [{ prompt, uc, center }]` 与顶层 `use_coords` |
| 标准免费原生／NovelAI 官方 | 同一角色快照生成 `v4_prompt`／`v4_negative_prompt`，正负数组同序对应 |

V4.5 只投影发送坐标，V5 保留自由坐标；自动定位关闭 `use_coords`。原生字段与标准转换相互独立，不因另一条路线的转换修改原文。生成元数据、PNG 参数读写和参数恢复保留角色及定位结构；缺失字段不能从当前表单补造历史事实。

这没有开放 NAI 官方重绘／放大，也不扩展 Vibe、CHAT 角色生成协议或其他新工具；能力边界见[图像协议](native-image-protocols.md)。

## ASK 读取与草稿

活动画板的基础 Prompt／Negative、全部角色原文与状态始终完整随初始 `<workspace_state>` 发送。其他画板只给目录，`get_state({ board_id })` 读取本轮冻结原文；无锚点历史图片仍按需读取。

草稿锁定本轮来源板，以 `image.char.c2.prompt`／`image.char.c2.negative` 等稳定靶点修改角色；`character_edit` 支持新增、删除、排序、启停和定位，`restore_partial` 可恢复整组。目标被删除或外部修改时重新校验，不写到同位置的另一对象。

- 普通草稿默认写来源板，分体菜单可选新板；模型给出 `new_board_name` 时只提供「新建并应用」。
- 提议时不创建画板。确认后才沿原写入路径创建／应用；新板名由主 ASK 提议，不另触发命名调用。
- 角色修改按对象分组审阅，差异、实际勾选写入和回退覆盖完整结构。仅应用草稿不生图、不报价或发送 CHAT。
- 账本记录稳定来源／目标板 ID。改名只改变本地显示，不暗改已冻结的发送记忆。

## 界面与维护

`BoardSwitcher.vue` 管胶囊和管理菜单，`CharactersEditor.vue` 管角色列表与词文，`CharacterPosition.vue` 管定位，`ImageLibrary.vue` 管归属标记，`DraftCard.vue` 管草稿分组与新板应用。

桌面列表行 36px、底部按钮 32px，窄屏／触屏保留 44px；长列表独立滚动、底部入口可达。嵌套菜单按视口翻转，Esc 先关闭子菜单并返回焦点。提示词高度恢复覆盖组件挂载、工作区激活和画板切换，重新建 Observer 前清理旧监听。命名、字体、样式与动效沿用共享入口。

验证使用合成数据与模拟上游，覆盖保存失败回滚、画板与备份往返、角色参数、草稿和四视口。真实角色生成与供应商质量仍见[待办](implementation-plan.md#仍待真实验证)。
