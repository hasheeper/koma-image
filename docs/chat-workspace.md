# CHAT 对话工作区

更新：2026-10-28。描述当前会话、上下文、版本与图片交接；编辑画板另见[EDIT 工作区](edit-workspace.md)，历史证据见[归档](archive/README.md)。费用、能力和可用工具按 Profile 判断，不能用标准网关规则推断原生协议行为。

## 会话与上下文

- 会话列表支持空白复用、重命名、置顶、复制、删除确认及中断轮次恢复。列表、草稿、附件和分支状态由应用级服务保留，KeepAlive 切换不取消在途任务。
- 侧栏按置顶／今天／昨天／7 天内／更早分组，每条单行显示当前分支最新一张图的缩略图与标题；搜索覆盖标题和每轮描述。未发送的对话由「新对话」行代表，不进列表。空白页只显示品牌，输入框下方的起步建议只填入描述或打开文件选择，不发送请求。
- 保留底图／参考图、跟随最新、历史文字勾选、分支与多版本、实际发送文本和模型数量限制。手动改变上下文或版本会增加选择版本号，迟到的生成结果不能覆盖用户选择。
- 上下文面板按当前分支每轮一张楼层卡片：勾选框管该轮文字，图片放在首次出现的楼层，角标为底图／参考序号／超出，未带入的图淡显带＋；本轮卡片放跟随开关和实际发送文本。顶部计数与输入框上下文按钮同图标、同顺序、同样标出超出张数。
- 上传／粘贴／拖入沿用单张 8MB、总量 32MB 和模型图片数限制。附件在取得任务槽、开始轮次时消费；失败或取消不退回附件栏，轮次引用与保留参考仍可找回。
- 预报价防抖 650ms；标准网关执行前按提交快照重新报价，携带当次 `max_cost`，涨价提示后继续；原生协议按其能力处理费用。一个轮次始终占同一全局任务槽，直到全部图片解码、校验和资源登记完成，无付费确认、自动重试或路线回退。
- 返回中的文本与全部图片按原顺序存储，多图回复也按原顺序展示；单图回复将模型文字作为图下注释。支持版本切换、下载原字节、继续编辑、加入参考、重试及放大。结果揭示与等待波浪由原生 Canvas 驱动。
- 会话与图片在同一 IndexedDB 事务保存，400ms 防抖，失败保留脏数据供下次保存。恢复时把未完成轮次标为中断；离开页面和进入备份读取前刷新待保存草稿。浏览器强制结束进程仍无法保证异步写入完成。
- 绘图图片先准备并保存 Koma 独立票据，再原地进入对话；票据只领取一次、30 分钟过期，已保活的对话也能领取。超限图片使用原压缩规则。没有读取旧应用票据或数据库。

CHAT 结果工具的「收藏」按具体会话／轮次／版本／图片保存原始字节，复用普通收藏的写入、取消和撤销行为；多个结果逐张收藏，不改当前底图、上下文或发送请求。收藏进入 IMAGE 收藏列表及 ASK `#f`，源会话删除后仍独立存在，也进入现有普通 ZIP。CHAT 提示词／选项不是绘图配方，不能直接拖入绘图参数或用 `restore_partial` 恢复；在其基础上产生的 NAI 编辑结果有自己的绘图参数。

## 服务与资源所有权

`src/services/chat.ts` 在 App 中创建一次，位于 KeepAlive 外；Vue 只订阅浅快照，模板拥有输入、消息和图片结构。原生 Canvas 驱动处理结果揭示、波浪与高频指针，Blob、图片 URL 和 AbortController 不进入深层 reactive。

切出工作区时暂停指针、键盘、Observer、计时和波浪；在途任务和会话图片继续保留。删除引用或销毁服务时释放对应 URL，不因单纯切页释放仍被使用的图片。

持久化经 `data.write`。备份前刷新已加载会话，未加载的缓存不以空值覆盖存储；维护完成先 reload 全部缓存，再恢复调度和模型／报价请求。HOME 的 `readStored()` 仅加载本地会话，打开首页不预热模型、报价或额度。

## ASK 与运行方式

ASK 的 `get_chat_context` 只读取发送时冻结的当前分支；`#cN.M` 读取该分支已有图片，多图版本逐张为 `#cN.M.K`，不自动包含其他分支。分支提纯或 composer 修改先成为草稿，用户确认后写入，ASK 不发送 CHAT 或占生图锁。从 IMAGE／TAGS 交给 CHAT 时一律用交接草稿新开会话（复用空白会话），写入参考图、尺寸类选项和输入框；不改全局 CHAT 设置，写入后直到用户再次操作 CHAT 才报价。ASK 打开、发送或写入前会预热 CHAT 的会话与模型目录，未进入 CHAT 时不请求报价或额度。见[ASK 运行契约](ask/ask-contracts-and-decisions.md)。

标准网关和两种 ASK 推理协议可使用本地环境变量代理；OpenAI Images／Gemini 原生／NovelAI 官方目前为浏览器直连。原生协议不提供预报价时保留未知费用状态，生成按钮暂不显示费用标签，工具仍受模型和协议能力约束。见[发布说明](release-guide.md)及[图像协议](native-image-protocols.md)。
